# 资产、声音台账与风格中心调整

以用户附件《资产提取SKILL.md》为依据，增量修改现有流程。

1. 子卡支持手工上传替换图片：资源上传成功后绑定新资产版本，保留身份、状态、声音和关联；上传失败保留原图；旧出图回调不得覆盖新图。手工确认图片可作为后续参考，不伪装成自动生成三视图。
2. 按附件制作优先级整理道具：普通穿戴物归人物，同一实体跨场复用；明确需独立制作的动作道具、信物、产品及可移动物保留。背景低优先级清单不等于默认全部排图；通过分级和默认选择控制制作量，保留依据与人工提升入口。
3. 台词、画外、旁白使用独立技能从完整剧本建立有出处的声音台账，分镜引用台账后核对。未落镜的原句也必须报告；不以现有镜头反推应有台词。冒号前后括号、OS/VO、单字回应、跨行台词与重复原句需要覆盖。
4. 恢复原公共风格中心的预览、分类、搜索及字段展示；公共视觉规格与新增导演字段组合输出，避免只剩主色卡。个人导演结果与公共预置分开。
5. director/analysis 来源的个人风格仅创建人可读写，公共 seed/manual 条目继续展示；列表、封面、建项及锁定选用在服务端统一鉴权。历史个人条目同样生效，管理员不会因此获得查看他人个人导演风格的业务入口。名称校验也需避免跨用户暴露。

当前实现尚在开发，专项测试、完整回归和浏览器验收未完成，不作为已发布记录。暂不调用真实视频模型。
