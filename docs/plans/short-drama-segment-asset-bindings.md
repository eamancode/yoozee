# 分段资产关联同步

## 目标

分段 `spec.refs`、工作区资产、界面已选状态和提交前媒体解析对应同一批固定资产版本。已存在的分段只补关联，不重新提取、出图或生成视频，不重试历史任务。

## 实现边界

- 通用镜头版本写入时，在同一数据库事务内投影分段引用为镜头资产关联。通过项目归属校验，区分固定版本 ID 和资产当前版本 ID。
- 关联以 `source=segment` 标识自动投影，以 `position` 保留引用顺序；只移除该段不再使用的投影，独立色卡、输出和连续衔接关联保留。
- 更换、取消在后端一次提交，同时修改分段和关联；取消后重排剩余图片引用编号。发生存储错误时回滚，不由前端分两次写入。
- 工作台使用固定版本的参考图预览，素材选择器包含人物子卡。
- 数据迁移补齐当前镜头版本已有的有效引用，不改历史版本、导演文档、图片、产物和任务。迁移可重复执行；无效或越权的原引用不建立关联，输出汇总告警供处理。

## 验收

1. 人物主卡、子卡、场景、道具可预览、更换、取消，刷新保持一致。
2. 参考图片编号、顺序及固定版本与提交前解析一致，解析缺失为零。
3. 验证保存失败全部回滚、越权拒绝、单段修改隔离、补齐幂等，以及历史失败任务不变。
4. 在真实页面完成绑定和预览验收，视频提交仅验证准备数据或模拟渠道，不调用真实视频模型。
