# 剧本容量、资产出图和镜头视频优化

| 同场景结束段     | 后端任务提交时按当前叙事相邻关系追加，不写入分镜原文            | A/A/A/B、末组、重排、版本变化、重复重试、原文保留      |

## 结束段正文

> 【本镜最后阶段】镜头平稳后拉并适度升高，最终停在能够完整交代场景空间布局的广角全景机位，将本场景所有人物的全身及主要场景结构纳入画面。保持人物在剧情结束时的位置、朝向、姿态及彼此距离，保持场景几何结构和道具位置不变。人物、服装、道具及环境统一转为无贴图的哑光白色三维模型，保留柔和阴影，使轮廓、前后层次和空间关系清晰可辨。上述运镜与白模转换须在视频最后1秒开始前完成；最后1秒锁定机位，将完成转换的白模全景画面定格至视频结束。

最后 1 秒包含在生成总时长内。相邻场景使用当前章节中 `spec.scene` 的非空稳定 ID；未知场景不猜测。镜头版本已变化时拒绝旧任务并提示刷新，防止旧提示词和新资产混用。

本轮不调用真实视频模型；生成视频的白模质量、全人物覆盖及精确末秒定格仍需单独实片验收，不能由请求参数测试代替。
