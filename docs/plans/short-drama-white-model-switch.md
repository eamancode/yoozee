# 同场景衔接：白模分镜开关与站位提示词优化需求说明

状态：已确认，进入开发与回归；发布结果以最终验收报告为准。

## 1. 目标与已明确的需求

1. 将后端提交时自动添加的站位参考提醒，替换为用户指定的精简文案。
2. 在项目创建页第 4 部分“怎么做”的红线位置增加“白模分镜”复选框；勾选开启，取消勾选关闭。
3. 开关控制整套自动白模衔接能力，不只是控制页面显示或一句提示词。

“白模”为统一用词。白模分镜指同场景前一镜头组的片末白模画面，用于后一组起始空间站位参考，不等同于普通分镜图或动作预演。

## 2. 建议一并确认的产品约定

以下推荐约定已随本文获准实施：

| 项目 | 推荐约定 |
| --- | --- |
| 新建项目默认 | 不勾选，由用户主动开启；不继承其他项目的勾选状态 |
| 历史项目 | 保留当前已启用的白模行为；升级时将该状态明确保存，不批量关闭已有项目 |
| 创建后调整 | 项目设置增加同名开关，支持当前项目后续修改 |
| 生效边界 | 新提交的生成请求或新建生成链采用当前开关；已接受的生成链使用提交时快照，避免执行中前后规则变化 |
| 旧失败任务 | 不自动重试。显式续跑沿用原链快照；要采用修改后的设置，重新预览并提交新链 |

项目设置应说明：“修改后对新提交的生成请求生效，已开始的生成链沿用提交时设置。”关闭开关不等同于取消运行中的链；取消仍通过现有“停止后续生成”操作完成。

## 3. 页面与交互

### 3.1 项目创建

位置：项目创建 → 第 4 部分“怎么做” → 生成模式流程条及“出视频要花钱……”说明下方，即截图红线所在位置。

控件及文案：

- 复选框：`白模分镜`。
- 辅助说明：`开启后，同场景连续镜头自动使用上一组片末白模作为站位参考；参考不可用时仍可继续生成视频。`
- 未勾选时，不阻止创建项目或正常生成视频。
- 切换画幅、视频模型、每段时长或生成模式时，不擅自改变勾选状态；三个生成模式均可独立选择白模分镜。
- 使用真实复选框，支持点击文字切换、键盘操作和焦点提示；无需额外确认弹窗。
- 创建请求带上明确的布尔值，创建成功后以服务端保存状态为准。保存失败必须显示错误，不呈现为已保存。

### 3.2 项目内回显

- 项目设置中回显并可修改“白模分镜”。权限沿用项目设置编辑权限。
- 单组生成与连续链预览显示“白模分镜：开启 / 关闭”，区分当前项目设置与历史任务快照。
- 关闭时说明：“本次不自动添加白模结束段或传递片末站位参考。”
- 开启但未使用到白模时，显示真实原因，不将“开启”误报成“已使用站位参考”。
- 连续链按钮仍可使用；关闭白模不关闭连续批量生成能力。

## 4. 站位参考提示词

### 4.1 新文案

后端提交时，使用以下完整模板：

> 【站位参考】请以「{站位参考图标识}」该图中的人物位置、朝向、彼此距离，以及场景结构和道具位置，作为本镜起始状态的空间参考；

当实际标识为 `@图片15` 时，提交内容必须为：

> 【站位参考】请以「@图片15」该图中的人物位置、朝向、彼此距离，以及场景结构和道具位置，作为本镜起始状态的空间参考；

规则：

1. 使用用户指定的新文案，不自动补回旧版“为上一镜头组的片末白模画面”及后续外观、材质、光照和机位说明。
2. `@图片15` 是示例，不是固定编号。标识必须对应本组实际上传的前一组截帧，并符合所选模型的图片引用语法。
3. 仅在白模功能开启且实际参考图成功加入本次请求时添加。
4. 位于当前镜头组原有提示词之前，以换行分隔；原正文保持完整。
5. 重复提交、显式重试和断点恢复不得叠加提醒。以原始正文重新构建本次最终提示词，不在历史最终提示词上继续追加。
6. 仅替换系统自动生成的前缀，不批量改写历史任务、原始剧本或用户自行填写的正文。

### 4.2 最终提示词顺序

1. 新版站位参考提醒：开启且本组实际使用白模时才添加。
2. 当前镜头组原有提示词。
3. 片末结束段：开启且当前组存在同场景相邻后续组时才添加。

## 5. 开关控制范围

| 行为 | 开启 | 关闭 |
| --- | --- | --- |
| 同场景组的连续生成 | 按原有顺序执行 | 仍可按原有顺序执行 |
| 非最后一组自动追加白模片末结束段 | 添加 | 不添加 |
| 自动截取/复用前组片末作为站位图 | 尝试执行 | 不执行 |
| 自动登记白模资产及后一组分镜图附件 | 成功取得参考时执行 | 不自动新建或补登记 |
| 自动上传/附加白模站位参考 | 模型支持且容量允许时执行 | 不执行 |
| 自动添加站位参考提醒 | 实际参考成功加入时添加 | 不添加 |
| 已有普通人物、场景、道具和风格参考 | 保留 | 保留 |
| 历史白模图片和附件 | 保留且可查看 | 保留且可查看，不自动带入新请求 |
| 视频任务失败后的暂停与显式续跑 | 保留 | 保留 |

关闭后必须从自动输入中排除系统标记为连续性白模的附加参考，不能只去掉提醒而仍上传图片，也不能删除用户的普通参考来达到关闭效果。用户明确手动选择某张历史白模作为普通参考的，按普通参考处理；不因此自动恢复白模结束段或传递逻辑。

## 6. 开启时的连续链规则

1. 按镜头组叙事顺序及场景归属建立连续链，不跨场景传递片末参考。
2. 链内第一组直接提交；除最后一组外，提交时自动加入片末结束段。
3. 第二组及后续组等待前组视频成功且可读取，尝试获取最接近视频结束的可读末帧。
4. 截帧沿用现有资产化：保存来源镜头、来源视频、消费镜头及修订信息；放入后一组所属场次、对应镜头组的“分镜图”附件；不覆盖用户原有分镜图，不重复保存物理图片。
5. 将白模参考追加到原参考图片之后，上传成功后使用实际引用标识生成新版开头提醒。
6. 单独存在的镜头组，不添加片末结束段；同场景链最后一组可使用前组参考，但不添加结束段。
7. 单独提交后一组但缺少可用前组视频或白模时，不强制补生成前组。
8. 缺图、截帧失败、可选登记/上传失败、模型不支持额外参考或容量不足时，有原因地跳过白模，按原正文及原参考图继续。
9. 原参考图本身无效或上传失败，仍按正常错误暂停；前组视频任务失败仍暂停依赖组，保留显式续跑入口。
10. 不增加白模识别、质量校验、人工确认或真实模型调用环节；不自动重试历史失败任务。

片末结束段沿用已确认文本，本轮不调整：

> 【本镜最后阶段】视频最后1秒，硬切至斜向下45度俯视的大全景机位，画面同时切换为无贴图的哑光白色三维白模。完整呈现场景空间布局、主要道具及本小节最后一个镜头结束时仍在场景内人物的全身。保持人物原有站位、朝向、姿态及彼此距离，保持场景结构和道具位置不变。锁定机位与构图，持续1秒直至视频结束；人物仅有轻微呼吸起伏和身体自然晃动，双脚保持原位。保留柔和阴影，使人物轮廓、遮挡关系和空间层次清晰可辨。

最后 1 秒包含在本次生成总时长内，不额外延长视频。

## 7. 连续三个同场景镜头组示例

| 开关 | 镜头组 | 前组白模 | 开头提醒 | 片末结束段 |
| --- | --- | --- | --- | --- |
| 开启 | A | 无 | 无 | 有 |
| 开启 | B | 尝试使用 A 末帧 | A 末帧实际加入时添加 | 有 |
| 开启 | C | 尝试使用 B 末帧 | B 末帧实际加入时添加 | 无 |
| 关闭 | A、B、C | 均不自动截取或传递 | 均无 | 均无 |

开启时若 A 截帧失败：B 显示跳过原因并正常生成；B 如成功且末帧可用，C 仍可使用 B 的末帧，不因 A 截帧失败永久关闭后续白模功能。

## 8. 数据、接口和一致性

- 持久化为项目级布尔配置，建议字段名 `whiteModelStoryboardEnabled`；前端不能仅靠本地状态控制。建项、设置、项目读取使用同一语义。
- 项目设置是唯一有效来源，不在 UI、技能提示词与生成链中维护相互冲突的独立开关；任务只保存提交时配置快照用于审计与恢复。
- 新项目显式保存 true/false；历史项目按第 2 节约定初始化，禁止在不同入口各自猜测缺失值。
- 后端对普通单组提交、连续链预览、正式提交、仅准备参考、Agent 等可进入的视频业务路径统一应用开关。
- 开关、镜头顺序、修订、场景归属及参考清单参与预览有效性判断；预览后配置变化必须重新预览报价，不能使用过期预览直接提交。
- 实际引用、能力校验、报价和提交输入保持一致。关闭时不将自动白模计入参考数量或引用相关价格；保留正常计费与预算校验。
- 原 15/30 秒档位适配、模型最近使用记忆、预演可选、声音回退、权限、取消及防重复提交保持现有行为。

## 9. 验收标准

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| W01 | 创建页第 4 部分 | 红线位置出现可操作的“白模分镜”复选框和辅助说明 |
| W02 | 新建项目未勾选/已勾选 | 分别保存 false/true，刷新及再次进入状态一致 |
| W03 | 换生成模式、模型或每段时长 | 勾选状态不被隐式改变 |
| W04 | 关闭后普通提交及连续链提交 | 无自动白模结束段、截帧、上传、附件登记及站位提醒；正常视频功能可用 |
| W05 | 开启，同场景 A/B/C | A/B 有结束段，C 无；B/C 有图才加新版提醒 |
| W06 | 实际白模编号为 15 或其他编号 | 分别引用真实编号，不硬编码 15；引用对应实际上传图片 |
| W07 | 新提醒文本 | 与指定精简模板一致，不自动携带旧版后半段 |
| W08 | 跨场景或独立一组 | 不跨场景继承；无同场景后续组则不追加结束段 |
| W09 | 缺图/截帧或可选上传失败/容量满 | 显示跳过原因并继续，原参考完整保留，不伪造开头提醒 |
| W10 | 原参考上传失败或前组视频失败 | 正常暂停，保留显式处理入口，不自动重试 |
| W11 | 关闭已有白模附件的项目 | 附件仍可查看，新请求不自动携带；普通分镜图及其选中状态保留 |
| W12 | 重复提交、断点恢复、显式续跑 | 无重复参考图、附件、前缀、结束段、视频任务或计费 |
| W13 | 项目开关在预览后发生变化 | 旧预览失效，重新生成对应输入及报价 |
| W14 | 已开始的链与历史失败链 | 沿用原配置快照；修改项目设置不自动取消、修改或续跑历史任务 |
| W15 | 修改设置、刷新、切换项目及账号 | 只影响有权限的当前项目，服务端状态准确，无项目或账号串用 |
| W16 | 回归验证 | 模拟上游覆盖报价→参考处理→视频提交；真实视频模型调用为 0 |
