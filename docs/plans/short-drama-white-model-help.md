# 白模分镜提示交互优化

## 范围

创建项目“4. 怎么做”和项目设置“短剧生成”中的白模说明，从常驻段落收纳到“白模分镜”标签右侧圆形问号。其他说明文字和生成业务逻辑不变。

## 内容

创建页：开启后，同场景连续镜头自动使用上一组片末白模作为站位参考；参考不可用时仍可继续生成视频。

项目设置在上述内容后补充：修改后对新提交的生成请求生效，已开始的生成链沿用提交时设置。

## 交互

- 问号与文字垂直居中，采用既有图标按钮及浮层组件、语义颜色和焦点样式。
- 悬停、键盘聚焦、点击均可查看；移入浮层可继续阅读；Esc 或点击外部关闭。
- 提示自动换行并避让视口边缘，触控可点击查看。
- 问号为独立按钮，位于复选框 label 外，点击或键盘操作不改变勾选值、不提交表单、不触发保存或模型任务。
- 点击复选框或文字仍切换选项；默认值、草稿、保存持久化和已接受生成链快照不变。

## 验收

验证两个真实入口的显示、交互、开关隔离、明暗主题、窄屏及保存刷新；运行相关建项/草稿/设置回归和前端构建。不得调用真实视频模型、自动重试历史失败任务或取消运行任务。
