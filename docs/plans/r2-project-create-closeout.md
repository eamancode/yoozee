# R2 建项目后续开发与验收

本次接续历史 #54 的后续清单，代码基线为恢复交付 `383038269`。范围为建项页面、账号草稿与异步响应边界、三档生成模式验收和相关旧文案；R3 的跨线路计费、M6 技能包自动启用门禁及其他产品口径不在本卡内。

## 实现

- 草稿存储显式捕获账号 scope，切号时重建作曲区并取消旧定时器；迟到的读取不覆盖用户刚输入的正文，迟到的保存不显示为当前草稿已保存。
- 建项过程检查发起账号仍有效，切号或离开页面时取消上传、建项、创意与流水线请求；取消后不重试同名项目或分片上传，不继续生成、不清除新账号草稿、不跳转旧项目。同步 ref 阻止快速重复 Ctrl/⌘+Enter，缓存清理失败独立提示。
- 摘要跳转优先聚焦已选 radio，项目名输入及时保存；章集编号不再直接成为项目名。主按钮放在摘要左侧，避免窄屏被助手形象遮住。
- TXT/Markdown 导入增加读取错误提示和请求序号，关闭弹窗后的旧结果不能覆盖新文件；正文类型和切分方式复用支持方向键的单选组。
- 流水线进度更新后刷新概览和章节统计，避免装段已完成而“当前任务”仍提示生成分镜。修正不存在的画风停用入口提示，评测数据改用 runMode。

## 本地验收

使用独立数据目录、两个测试账号、当前真实 Vite 页面与后端 Worker，通过本机确定性 OpenAI 兼容上游返回文本和图片。测试数据、脚本、截图和日志留存在本机恢复归档，不提交账号凭据或数据库。

| 范围 | 已验证结果 |
| --- | --- |
| 建项及基础交互 | 单一作曲区、类型不预选、缺类型时快捷键阻止提交、方向键及可见焦点、摘要聚焦已选类型 |
| 草稿隔离 | 两账号保存与恢复、切号后旧写入仍归原账号；正文未写入 localStorage 的配置存储 |
| 请求竞争 | 快速两次快捷键仅一个建项；响应挂起期间切号，恢复旧响应后不导航、不清理新草稿、不发起生成；新账号不能读取旧账号项目 |
| 文件导入 | 切分预览、确认导入、单选组键盘、非文本扩展名拒绝、读取失败提示、关闭后迟到结果不覆盖新文件 |
| 页面布局 | 明暗主题、820px 窄屏、无水平溢出、主按钮真实命中、减少动效 |
| 老项目 | 真实设置页补填一次画面类型，补填后服务端拒绝变更 |
| 风格复用 | 风格库建项跳过全局导演分析，仍生成场次色卡并遵守停点 |
| every_step | 初次开始后在下一阶段停；明确继续只推进一个阶段；刷新不会新增任务 |
| review_from_assets | 风格/色卡完成后停在资产阶段 |
| until_video | 从页面开始制作，文本、资产出图、两集分镜和装段自动完成，停在视频前；概览统计同步 |
| 切模式 | 已停阶段不自动追补 |
| 取消与恢复 | 在慢文本任务运行中取消，不链式推进；明确继续后恢复并到达视频前 |
| 视频门禁 | 流水线继续接口返回 409 / pipeline_video_manual；本机验收库无视频或剪辑任务 |

浏览器累计 42 项检查、服务端流程累计 13 条断言通过，包含挂起 409 同名响应后切号不重试。本轮没有新增收费模型调用；模型输出质量仍以独立内容评测为准。
