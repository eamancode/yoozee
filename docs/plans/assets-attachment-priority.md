# 资产提取：附件优先的增量优化

## 执行原则

以用户附件《资产提取 SKILL》v1.3.0 的人物、道具、场景分析方法为准。线上 JSON Lines 只承担传输职责，不再以旧字段限制删去出处、交叉索引和状态轨迹。技能包沿用 yz-assets-extract ID，版本升为 1.3.0；正文保留，修正与附件冲突的生产适配段。

## 实现

- 人物 appearance 仍为年龄、性别、肤色、发型发色、五官、服装的完整段落。design.identity_appearance 额外保留不含服装、特定年龄和临时状态的身份特征，供子卡继承，避免默认服装与新服装叠加；design.role 落到剧情定位。
- design.evidence 保存原文 / 推导 / 设计建议分类、出处和内容；characters / props / environments 按标准名称保存交叉引用；states 保存场次段落、触发条件与状态。跨场合并累积且去重，默认外观不被后续磨损覆盖。
- 道具 prop_design、场景 spatial_layout 保存完整设计与空间分析；资产卡可展开查看。场景主图采用正面全景微俯视 15～25°，可移动道具独立设计，场景只引用位置。
- 项目指定图片模型不可用时明确报错，单卡请求不再被全局 imageModel 覆盖。
- 图片鉴权、权限、余额或接口不存在的终止性错误不自动重试，暂停同批未提交项；手工恢复形成新批次，旧回调不使用旧渠道提交新批任务。暂时性失败仍沿用同任务一次自动重试。
- 恢复出图面板可选择模型、资产及查看错误；暂停计入流水线失败状态。生成中计时随新一轮重置，模型选中后关闭下拉。
