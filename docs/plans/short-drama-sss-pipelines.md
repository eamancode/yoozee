## 4. 功能需求

### FR1 技能导入与拆分
- 两个原技能逐字节导入 `backend/builtin/yz-sss-film-director/`、`backend/builtin/yz-sss-drama-director/`，附 `<id>.SHA256SUMS` 对照；平台另加 `package.json`、`runtime-context.json`（不改原文件）。
- 4 个单文件技能 `backend/builtin/yz-sss-{film,drama}-{script,style}/SKILL.md`（+ `package.json`），技能库可见、有版本号、可编辑。

### FR2 流水线编号与迁移
- 新映射：`pipeline-1` SSS 电影、`pipeline-2` SSS 短剧、`pipeline-3` 本体论、`pipeline-4` 资产一体化、`pipeline-5` 原流程。
- 迁移：`pipeline-3→5`、`pipeline-2→4`、`pipeline-1→3`（由高到低），空值→`pipeline-5`；历史任务 metadata 里的流水线 ID 同步改写；幂等。
- 流水线三、四、五行为、技能、契约、出图版式不变（回归测试锁定）。

### FR3 拆剧本（流水线一、二）
- 用对应 `yz-sss-*-script`；运行多出第一轮「立意与全集结构」，输出 `## 立意页`、`## 全集结构表`；之后一轮一集照旧按 `script.adapt@1` 写剧本。
- 立意页与全集结构表存为项目文档（kind `concept`），之后的集按它写。

### FR4 导演定画风（流水线一、二）
- 用对应 `yz-sss-*-style`；契约仍是 `style.lock@2`（风格锚、色板、画风档案）；另输出 `## 世界基准段`、`## 视觉总谱`、`## 声音总谱`，存为项目文档（kind `world`）。

### FR5 SSS 分镜运行时（流水线一、二）
- 轮次（每轮只装本轮文件，不截断技能原文；轮与轮之间不带对话历史）：
  - 立项（项目还没有圣经时）：读立意页、全集结构表、世界与总谱、素材清单 → `## 全剧圣经`、`## 待确认`。
  - 每集：规划（`手册/00/04/05` → 第一、二部分）→ 讲戏（`06` → 第三部分）→ 切分（`07/08` → 整场镜头表、第四部分单元总表、每单元的启发库条目）→ 每个单元两轮：单元卡（`09` + `模板/04` + 选用的启发库条目）、编译（`10` + `模板/05` → 粘贴提示词与风险备选）→ 复看（`11` + `质检/02` + `模板/03` → 第六、七、八部分）。
  - 返修：诊断重写（`12` + `质检/03` + `模板/04`）→ 编译。
- 单元卡校验：标题行（`### E集-U单元｜…｜叙事 T 秒＋定格 1 秒＝总时长 秒｜N 镜＋定格｜…`）、单元时长 ≤ min(30 秒, 模型单段上限)、镜头表时间首尾相接、粘贴提示词在代码块里、即梦十五段齐全且顺序正确、≤15000 字符、含「本段不使用背景音乐」、命名标签全部对上素材清单、参考图数量 ≤ 模型上限。
- 收尾：单元卡 → 段（粘贴提示词原文存 `spec.verbatim`，标签换成 `@图k`，参考按出现顺序），八部分、圣经、交接卡、素材清单写文档表；续跑、整集替换确认、单集串行锁沿用本体论做法。

### FR6 前端
- 建项流水线单选五项，默认二；选一、二时预填画幅。
- 旧版：项目头部「导演文档」抽屉对 SSS 项目显示圣经、立意与结构、世界与总谱、各集八部分、交接卡、待确认；单元返修入口。
- 新版 `/drama-flow`：同样的文档查看与单元返修入口。
- 流水线名称处处显示新编号。

### FR7 文档
- 同步 `features.mdx`、`http-api.mdx`、`backend-database.mdx`（迁移、文档 kind）、`code-map.mdx`、`pending-test.mdx`（CRLF）。

## 5. 非功能要求
- 每轮提示词超过上限直接失败、不截断；不自动生成视频；不自动重试历史失败任务；不清理他人数据。
- 生产升级前停写并备份数据库、资源卷、配置；迁移先在生产库副本演练；部署前查磁盘（上次 99% 满）。
