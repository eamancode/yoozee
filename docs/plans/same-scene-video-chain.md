# 同场景连续视频生成链

## 需求合同

按章节镜头组的当前叙事顺序和非空场景 ID 形成连续链。A/B/C 同场景时，A 直接生成且附结束段；B 等待 A 的视频、截帧和参考图准备完成，使用 A 尾帧并附结束段；C 使用 B 尾帧，不附结束段。场景改变即断链，单组不附结束段。

最终提示词顺序为站位参考提醒、原镜头组正文、片末结束段。提醒必须对应实际发送的参考图编号。保留人物、场景、风格等全部原有参考图，将尾帧新增为站位参考，不当作锁定首帧，不自动丢弃超限图片。

### 结束段

> 【本镜最后阶段】视频最后1秒，硬切至斜向下45度俯视的大全景机位，画面同时切换为无贴图的哑光白色三维白模。完整呈现场景空间布局、主要道具及本场景所有人物的全身。保持人物原有站位、朝向、姿态及彼此距离，保持场景结构和道具位置不变。锁定机位与构图，持续1秒直至视频结束；人物仅有轻微呼吸起伏和身体自然晃动，双脚保持原位。保留柔和阴影，使人物轮廓、遮挡关系和空间层次清晰可辨。

### 站位参考提醒

> 【站位参考】参考图片「{站位参考图标识}」为上一镜头组的片末白模画面。请以该图中的人物位置、朝向、彼此距离，以及场景结构和道具位置，作为本镜起始状态的空间参考；后续动作与运镜按照本镜正文执行。人物外观、服装、场景材质、色彩和光照遵循本镜正文及其他对应参考图，白模材质和参考图机位不作为本镜的画面风格或起始机位要求。

末秒只锁机位和构图，人物保留微动，且包含在实际生成总时长内。不增加白模识别、质量判定或人工确认。

## 开发边界

- 后端持久化调度进度，逐组建立依赖；关闭或刷新页面不会令已发起的链丢失后续步骤。
- 视频成功且文件可读后提取实际末帧；精确末帧不可读时使用最接近片末的可读帧。保存图片及来源镜头组、视频资源关联，复用成功且仍有效的结果。
- 失败显示具体阶段（视频、截帧、上传或提交）和重试入口，依赖组继续等待。超出参考图能力时停下提示，不忽略站位图。重复提交、恢复和重试不得重复创建图片或叠加提示词。
- 取消链只停止尚未开始的后续提交，保留已经完成或已发往供应商的任务和产物。
- 当前镜头顺序、版本、场景、资源或模型发生改变时重新判断，失效的依赖不能继续复用。
- 前端提供一次发起整条链的入口、逐组进度、失败原因、重试及停止后续生成，不要求逐组手工提交。
- 本轮禁止真实视频模型调用；用假上游、既有样片和真实路由交互验证时序、截帧、上传、取消和幂等性。

## 实现进展

已完成后端控制链、前端面板及检查点恢复。`project_video_chain*.go` 持久化逐组状态，视频子任务沿用标准准入、计费、媒体保存与项目产物登记；不复用旧剧情段的强制锁首帧行为。控制任务释放等待中的 worker，视频任务领取优先于轮询控制链，单 worker 不会饿死子任务。停止时封锁后续准入并取消仍排队的任务，已提交视频的最终结果继续在面板显示。

上传使用同一协议适配器，逐张持久化成功结果，并按模型、渠道、服务地址及凭据范围校验复用。上游上传返回值加密存储。末帧图片和来源视频纳入资源引用保护；提取使用精确最后可读帧，片末无法寻址时降级顺序解码，不增加白模识别或质量门禁。

## 本地验证

- 前端 3144 项测试通过，类型检查、构建与 UI 退场规则通过。首次并行运行的两项进程型测试未启动成功，隔离复测 4 项及随后全量 3144 项均通过，未改动无关实现或测试。
- 后端专项覆盖顺序依赖、末帧与编号、部分上传复用、失败续跑、显式视频重试、取消与重启、父链租约、重复提交、越权及单 worker 调度。相邻场景不同、单组、模型参考超限均不越界执行。
- 真实 Chrome + 真实业务 API + 本地模拟上游完成 A→B→C：只发起 3 个模拟视频请求，参考图依次为 1/2/2 张，5 张上传在提交阶段未重复；20 秒镜头统一发送 30 秒档，原时长不变。关闭面板及刷新不打断链，末帧图片可预览，820px 无横向溢出。
- B/C 实际末帧图片与既有样片最后一帧的 PNG SHA256 完全一致，两组来源镜头及来源视频关联正确。运行证据保存在忽略的本地验收目录，不包含真实视频模型调用。
- 真实页面共 17 项检查通过，补充覆盖上传失败时不提交视频、失败入口续跑、双击仅创建一条链、停止后 A 已提交任务完成而 B/C 不再提交、明暗主题与滚动。以上共使用 4 个本地模拟视频请求，没有访问真实视频上游。
- 本轮真实视频模型调用为 0；白模、人物全身覆盖、站位微动与实际生成画面效果仍需后续真实成片验收。
