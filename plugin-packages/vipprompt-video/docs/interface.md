## 协议身份

- 插件 ID：`vipprompt-video`
- Provider ID：`vipprompt`
- 能力：`video`
- 创建：`POST /v1/videos`（application/json）
- 查询：`GET /v1/videos/{{taskId}}`
- 取文件：`GET /v1/videos/{{taskId}}/content`

## 配置字段

| 字段 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `apiKey` | secret | 是 | 渠道 API Key，以 Bearer 方式发送。 |

## 请求体

| 统一字段 | 上游字段 | 说明 |
| --- | --- | --- |
| `model` | `model` | 视频模型 ID |
| `prompt` | `prompt` | 顶层提示词（不能放进 `input`） |
| `duration` | `seconds` | 字符串秒数 |
| `aspectRatio` | `size` | 画幅比例或尺寸 |
| `images` | `input_reference` | 参考图 URL 数组 |

## 响应与轮询

创建响应里的 `id` 即任务 ID；轮询 `GET /v1/videos/{{taskId}}`，`status` 进入 `completed` 或 `failed` 即结束。完成时取查询响应中的完整 `url`（已签名，取文件不再需要 API Key），或直接 `GET /v1/videos/{{taskId}}/content` 下载视频。

## 排错

- `only supports JSON requests` → 请求被当成 multipart 发送
- `input is not supported` → prompt 被包进 `input` 对象
- 401 `Invalid token` → 渠道 API Key 无效
