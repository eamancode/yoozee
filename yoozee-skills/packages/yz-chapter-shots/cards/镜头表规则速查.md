# 镜头表规则速查（验证器会查的硬规则）

> 来源：yoozee 2.2 `rules/shots.json`。error 会让装段拒绝，warn 记进报告。

| 规则 | 级别 | 要求 |
| --- | --- | --- |
| R-SHOT-001 | error | 剧情文本里每一句台词在镜头表里恰好出现一次（逐字），一句台词只落一个镜头 |
| R-SHOT-002 | warn | `cam.z` 与 `size` 一致（Z1 大特写 … Z9 大远景） |
| R-SHOT-003 | error | `move` 最多两轴；`fixed` 不与别的同列 |
| R-SHOT-004 | error | Z1～Z3 不用 orbit / spiral / roll |
| R-SHOT-005 | error | push 与 pull 不同列 |
| R-SHOT-006 | warn | 档案配额：人物特写占比、连续同运镜 ≤2、连续同景别 ≤2、重技法（dolly_zoom 1、orbit 3、snorricam 1、roll 1） |
| R-SHOT-007 | warn | 同一主体相邻两镜：景别跨两级，或 X / Y 改变；否则是跳切 |
| R-SHOT-008 / 009 | warn | 连续同运镜 ≤2 镜、连续同景别 ≤2 镜（对话场尤其别一路 fixed + 近景） |
| R-SHOT-010 | error | 含台词且超过 4 秒的镜头，`action` 里必须有动作动词（走 / 转 / 抬 / 放 / 推 / 握 / 低头 / 抬头 / 伸手 / 上前 / 后退 / 挪 / 攥 / 捏 …） |
| R-SHOT-011 | error | 室内镜头必须有 `light.source_anchor`；真人剧 `policy` 不得 stylized |
| R-SHOT-012 | warn | `blocking.at` 只用场景锚点名（场景里的实物），不用方位词 |
| R-SHOT-013 | warn | 中景及更宽的人物镜头写全在场人物的站位 |
| R-SHOT-014 | warn | 相邻镜 `start_state` 等于上一镜 `end_state` 原文，变了在动作里写出 |
| R-SHOT-017 | error | 声音、动作里不得出现配乐、BGM、背景音乐、弦乐、钢琴声、鼓点 |
| R-SHOT-019 | error | 动作场每镜有 `fight`，`contact` 只一种 |
| R-SHOT-021 | warn | 对话场第一个人物镜景别在中景 / 中全景 / 全景 / 中近景里 |
| R-SHOT-022 | warn | 真人剧档案摄影机跟情绪：有 `performance` 的人物镜头要写 `camera_emotion`（focal + type） |
| R-SHOT-024 | warn | 真人剧含表演的镜头 `performance.beats` 至少一条；泛情绪词不单独出现 |
| R-SHOT-025 | error | `emotion_arc.id` 必须在情绪弧索引里；段号合法；continues 指向同场同人物更早的镜 |
| R-SHOT-026 | warn | 真人剧 / 短剧视感：含台词或表演的人物镜头要有 `emotion_arc` 或手写节拍 |
| R-SHOT-027 | warn | 衔接写「硬切」但同主体景别只差一级且机位未变 → 跳切；写「动作匹配切」但上一镜没有动作 |
| R-SHOT-029 | warn | 台词三元（pace / tone / emotion）写了就写齐 |
| R-SCHEMA | warn | 契约校验：`fight` / `emotion_arc` / `camera_emotion` 用不上就整个不写（不写 null、不写空 id）；`transition.cut_point` 只能是 视线 / 动作 / 声音 / 光线 / 道具 / 场景锚点；`emotion_arc.phase_from/to` 从 1 起 |
| R-SHOT-030 | error | 实景光档案下 `light.fill / rim / key` 不得写补光、反光板、柔光箱、LED 板 |

估时：台词 4.5 字/秒（喊 6，哽咽 3，旁白 3.5）+ 动作每个动词 0.6 秒 + 1 秒 + 表演 0.5 秒；镜头 `est` 写这个数。一场戏合计超过 30 秒会被拆成两段，切点优先在无台词的动作镜之后，一问一答之间不拆。
