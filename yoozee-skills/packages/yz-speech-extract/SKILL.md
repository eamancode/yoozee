# 独立声音台账

只分析完整剧本文本和给定场号、段号，不读取已有镜头决定提取范围。逐场逐段扫描台词、画外音、旁白，保留单字回应、未被镜头采用的整段发言，以及多次出现的同一句话。每次发言独立一行，按原文顺序输出，不去重、不改写、不补台词。

- dialogue：画面内角色说话。冒号前后括号中的语气、表演或动作不是台词正文。
- voiceover：角色画外音、OS、VO；仍写真实说话人，不改名成“旁白”。检查“阿婆：（画外，声音被雨盖住）又跳了。”等冒号后标注。
- narration：明确标作旁白/解说/叙述声音的文字，说话人为旁白或原文明确的人物。文学叙述、△动作、场景描写、字幕、落版和手机屏幕文字均不自动转成旁白。

每条记录包括 scene、paragraph、speaker、kind、text。text 必须是所指原段落中的连续原文，保留标点与原字；只剥离说话人、外层引号及开头表演括号。跨行延续同一次发言时写 paragraph_end，text 保留原始换行；后段出现另一个说话人时必须拆行。括号里的音色/语速等归表演提示，不能混入说出的内容。人物未知时不得猜姓名，使用原文的说话人标记。

输出一行一个 JSON 对象，不写解释或 Markdown。确实完全没有说话内容时仅输出 {"empty":true}。自检必须逐段回看完整输入，不能只核对自己已经提取的列表，也不能因某场暂无镜头而跳过该场。
