# 更新记录

## 未发布

- 柚子「生成分段」的输出契约升到 `chapter.shots@3`：一镜一行（JSON Lines），柚子在一个任务里按场续写、边流边解析，任务收尾由服务端解析、绑资产、写镜头表。字段与 `@2` 相同，只是不再包一层 `{"title", "rows"}`。`packages/yz-chapter-shots/package.json` 与 `tests/packages/cases.json` 同步改成 `@3`，技能正文不变。柚子线上已有的包版本清单仍写 `@2`，运行不受影响（契约文字按线上步骤表生成），下次上传前清单要写 `@3`，否则静态校验报 `contract`。画布拆镜仍是整段 JSON 的 `@2`。

## 1.0.0（2026-10-15）

- 首个版本：12 个技能、5 个知识包、4 份数据契约、能力端口清单。
- 本机运行时沿用分镜师 4.0 的尺子脚本（门禁、质检、候选指标、听写与台词量数、三视图裁切、房间声床）。
- 柚子运行时映射到柚子后端的短剧工具。
- 生成模型：Seedance 2.0（一段 ≤15 秒）、MiniMax-H3（≤15 秒）、Seedance 2.5（≤30 秒）。Seedance 两家的档案来自官方文档，尚未在本账户实测；MiniMax-H3 档案为实测。
