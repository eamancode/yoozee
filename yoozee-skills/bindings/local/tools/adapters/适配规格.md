# 适配层：一家模型一个文件

规则和分段表都不认厂商。分段表里每段是中性描述（镜头、时间点、台词、参考角色、声音、模式），适配文件负责翻译成这家的方言并跑任务。换模型 = 现写一个适配 + 跑校准技能。下面是接口规格；写全的样例在模型库（MiniMax-H3/适配_视频.py 等），用的时候拷到这个目录。

## 视频适配必须有
```python
CAPABILITIES = {
    "modes": {"lock_identity": "...参数说明", "lock_first_frame": "..."},  # 两种能力词各对应它的什么参数；互斥写明
    "duration": {"min": 4, "max": 15, "step": 1},
    "resolutions": ["768P", "2K"],
    "ref_audio_total_sec": 15, "ref_images_max": 9,
    "price_per_sec": {"768P": 0.08, "2K": 0.13},
    "audio_in_video": True,
}
def build_job(segment, resolution, n=1) -> dict      # 中性分段 → 任务（含方言提示词、参考/首帧、时长、输出路径 生成/<id>[_vK].mp4）
def job_inputs(job) -> list[str]                      # 任务用到的本地文件，用来查缺
def run_jobs(jobs, poll=20) -> list[dict]             # 并发提交、轮询、下载；已存在的跳过；每个任务旁边写 .json 登记
```
中性分段的字段：id、scene、dur、mode（lock_identity / lock_first_frame）、refs[{file, role: identity|location|plate|prop|frame, note}]、voices[{character, file}]、shots[{at, text, lines[{speaker, text, vo?, delivery?}]}]（vo=true 表示画外音：内心独白或旁白，嘴不动；delivery 是这一句的表演状态：怎么说、多大声、什么情绪，紧贴台词翻译进方言，样本只管嗓音）、sound、rules、first_frame。

## 图片适配
`generate(prompt, out, refs=[], roles="", aspect="21:9", realism=True)` 和 `--jobs`；realism=True 时把 tools/realism.txt 拼在提示词最前面。

## 配音适配
`design(描述, 试听文本) -> voice_id`、`speak(voice_id, 文本, out)`；参考音频按视频模型档案的上限裁，另出一条短版。

## 音乐与音效适配
`music(prompt, ms, out)`、`sfx(text, seconds, out, loop=False)`、`score(plan, out)`（分段作曲：plan 里每段 name、ms、text、positive、negative；出完按各段时长切成 out_<name>.mp3）。

## 写适配的规矩
- 先用探路员读官方文档，不凭记忆写参数；所有外部调用能重试、能续跑；下载链接有时效就成功后立刻下。
- 密钥用 common.need() 从 .env 读；日志走 common.log()。
- 写完用校准技能里那一段真跑一次，坑写进工具档案。
