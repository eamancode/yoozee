二十、常见错误修正表与最终粘贴模板
============================================================

本节用于约束任意语言模型在最后一步自我纠偏。输出前如果发现以下问题，必须立刻修正，不要把错误版本交给用户。

常见错误修正表：

1. 错误：输出变成小说改写。
   修正：改回分镜提示词格式，保留小节、镜头、时间码和镜头字段。

2. 错误：只写“镜号1：某某做了某事”，字段过少。
   修正：补齐画面、构图、镜头、运镜、动作、表情、台词、画外音、声音、灯光与光影、衔接、起始画面、结束画面。

3. 错误：台词被改写、合并、删减。
   修正：恢复原文台词，长台词按语意拆镜，不改句子本身。

4. 错误：每个镜头都堆满复杂运镜和强光效。
   修正：每镜只保留一种主要运镜；文戏稳定，动作戏跟随，爆点才用强运镜。

5. 错误：人物表情只写“愤怒、悲伤、震惊”。
   修正：把抽象情绪拆成眉毛、眼神、嘴唇、下颌、呼吸、手部和肩膀动作。

6. 错误：场景、光源、道具在镜头间跳变。
   修正：回看人物站位、场景锚点、光源方向、道具位置，保持同一小节内连续。

6.1 错误：上一镜角色站在某个明确场景锚点前，下一镜背景却无端变成另一个位置。例如上一镜许默从电梯走出并站在电梯门口，下一镜中近景背景却写成地下车库走廊，而不是关闭或开启状态明确的电梯门。
    修正：建立“场景锚点连续锁定”。如果角色没有移动，下一镜背景必须承接上一镜所在地，例如电梯门、门框、电梯间灯光、门前地面反光；如果要改成车库走廊背景，必须先写清角色转身离开电梯门并移动到走廊，或明确镜头反打到相反方向。

7. 错误：打斗一镜写完整复杂动作。
   修正：拆成发起、路径、接触、结果、反应。

8. 错误：长台词配大幅运镜。
   修正：长台词镜头保持稳定，用说话人特写、听话人反应、道具特写拆分承载。

9. 错误：镜头没有目的。
   修正：补写镜头目的，并让景别、机位、运镜、灯光都服务这个目的。

10. 错误：输出太长，无法直接使用。
    修正：删掉重复风格词、重复场景描写、重复持续光源；保留剧情、动作、台词、灯光变化和衔接。

11. 错误：分镜拖沓，把普通走路、推门、转身、坐下、抬头等过渡动作拆成多个镜头。
    修正：合并成一个镜头，除非该动作承载危险、悬念、身份揭示、情绪爆点或关系变化。普通走路用一个跟拍或中景概括完成，不要为走路单独连续设计多镜头。

12. 错误：短台词镜头时长严重浪费，例如角色只说“别动！”“动手！”两个字，却给3-4秒固定近景，导致节奏拖沓。
    修正：先估算台词时长。短命令通常0.4-0.8秒说完，镜头总时长控制在0.8-1.8秒；如果需要更长，必须让画面同时承担压迫动作、武器逼近、听话人反应或群像态度变化。否则缩短镜头，或把短台词并入动作镜头。

13. 错误：群像小节只有3个大镜头，且大量台词都压在中全景/全景里，代表人物表情看不清。
    修正：4-30秒群像冲突小节通常拆成4-10个镜头（20-30秒建议6-10个）。全景只负责建立/重建空间；短切给代表讲话人近景/面部特写、听话人反应、武器/手部动作、群像路人表情，不平均拍每个人。

13.1 错误：一个3秒群像镜头同时承担“十几名猎人跑入围拢、包围圈成形、三名猎人依次说三句台词、展示多人表情、林川扫视、队长蓄力”等任务，导致台词说不完、动作看不清、镜头信息过载。
     修正：先估算口播时间和动作时间。3秒不能承载三句以上台词和完整群像调度。应拆成多个镜头，例如：0-2秒群像跑入围拢只保留杂乱喊声；2-4.5秒猎人A近景说完整关键台词；4.5-6秒猎人B举斧短切喊“杀了他！”；6-7.5秒猎人C/群像附和并举矛；7.5-9秒林川反应或队长蓄力，为“动手”承接。若必须保留同一小节，总时长应扩到8-12秒并拆成4-6镜。

14. 错误：连续多个镜头都是中景/全景，或者对同一角色从中景硬切到中近景/中景，导致画面重复、闪烁和审美疲劳。
    修正：按“景别等级表”重写镜头段落。建立空间后切说话人近景、听话人反应、手部/道具特写、主观视角或空间压迫镜头；硬切必须让景别跳跃大于两个等级，或让机位角度偏转超过30度；有运镜时必须写清“起始景别 -> 结束景别”。

15. 错误：机械理解为“谁说话就必须拍谁”，导致对话平铺直叙，缺少潜台词和画面层次。
    修正：判断台词真正改变了什么。如果改变的是听话人的心理，画面给听话人反应；如果台词指向危险、秘密、证据或环境压力，画面给空镜、道具特写、手部动作、主观视角或空间压迫镜头；说话人的声音可作为离画台词或画外音存在，并在台词、画外音、声音和衔接字段写清。

16. 错误：镜头虽然专业词很多，但没有高级视听策略，仍然只是顺着剧情拍流水账。
    修正：为每个小节选择一个主导策略，例如悬疑段落用信息遮蔽/延迟揭示/负空间，反转段落用误导性构图/反应先行/遮挡揭示，情绪段落用沉默反应/手部插入/声画反差，动作段落用动作匹配切/情绪插针/原因先行，群像段落用选择性注意力/权力站位变化。

17. 错误：为了显得高级，在同一镜头里堆叠反射、拉焦、遮挡、长镜头、荷兰角、蒙太奇、强运镜，导致AI生成混乱。
    修正：每个镜头只保留一个主要高级策略，其余景别、机位、灯光、声音都服务该策略；如果需要多个策略，拆成多个镜头或多个小节。

18. 错误：长剧本被压缩成少量小节，导致后半段台词、动作或反转被概括掉。
    修正：按剧情段落分批输出，每批保留全部原文台词，并在批次结尾写清下一批承接点。

19. 错误：追逐或打斗没有空间地图，只写“狂奔、躲避、混战”，观众不知道方向和距离。
    修正：先建立主角、追兵、出口、障碍、危险来源的位置；每2-3镜交代距离变化；投掷物必须写清飞行路径和落点。

20. 错误：追逐镜头把被追者和追兵写到同一前进方向的前方，例如“林川向画面右侧奔跑，猎人队长和追兵在画面右侧边缘或背景中追赶”，导致林川像是在往猎人方向跑。
    修正：建立“运动方向锁定”。如果林川向画面右侧/世界东侧逃跑，猎人必须位于林川左后方、正后方、侧后方或画面外身后追来；如果想让观众看到林川表情和身后猎人，改用正面倒退跟拍；如果想看路线，背后跟拍只看林川前方障碍和道路，追兵用身后喊声、脚步声或反打表现。

21. 错误：内心OS只用声音解释，画面没有给判断依据。
    修正：OS必须配合观察镜头，例如敌人后退、武器垂下、环境异常、道具细节、主角眼神变化，让观众看见角色为什么这样想。

22. 错误：未知生物或怪物第一次出现就完整露脸，破坏悬念且增加生成难度。
    修正：先拍环境异常，再拍局部短暂露出，例如背鳍、影子、鳞片、爪痕、水花，最后给人物反应或后果。

23. 错误：群体敌意平均拍每个人，导致分镜冗长混乱。
    修正：按领导者、代表性喊话者、听话人/被围困者、背景群体四类注意力调度；代表性喊话者承载关键台词，可用近景/面部特写看表情；听话人/主角承载心理反应，可用近景/特写；背景群体负责包围、压迫和群声，用全景/中全景建立或重建空间。

24. 错误：小节结尾没有钩子，只是动作停下或人物继续跑。
    修正：结尾必须留下危险逼近、声音先入、视线目标、动作未完成、环境异常、角色决定或未知生物短暂露出等承接点。

25. 错误：连续镜头内人物动作或武器状态无端改变，例如上一镜猎人手持长矛抵住咽喉，下一镜突然空手站立或把长矛收起。
    修正：建立动作连续锁定；下一镜起始画面必须承接上一镜结束姿态。只有明确写出“收回长矛、放下武器、转身、起身、停步”等过渡动作后，人物状态才允许变化。

26. 错误：同一场景内持续音效中断，例如荒原风声、雨声、人群声上一镜存在，下一镜无故消失。
    修正：在每个小节底部写“小节声音连续性总结”，说明持续环境声如何从头到尾保持，哪些声音增强、减弱、先入、延后或被动作音效短暂压过。

27. 错误：生成BGM、配乐、背景音乐、弦乐、钢琴、鼓点或音乐卡点。
    修正：删除所有BGM/配乐内容，只保留环境声、动作音效、台词、画外音和非音乐化环境低频氛围音。

28. 错误：群像人物全部长得一样，追兵、猎人、村民或背景人群像复制粘贴出来的同一张脸。
    修正：在“群像差异化锁定”和群像镜头画面中写明差异化锚点：年龄层、脸型、发型、胡须、疤痕、纹身/颜料、饰品、身高体型、肤色深浅、站姿和表情差异；统一服装文化可以保留，但脸、体型和表情不能统一。

29. 错误：只在小节开头写人物、场景和人物站位，镜头列表结束后没有再次标注该分镜组人物都有谁、场景在哪里、人物处于场景什么位置。
    修正：每个小节底部必须补写“小节人物场景站位标注”，分三行写清“人物、场景、人物在场景中的位置”。人物位置必须包含关键背景锚点、彼此距离、朝向和前后景关系。

30. 错误：只在小节开头写统一的人物站位、场景锚点连续锁定、运动方向锁定和动作连续锁定，但每个具体镜头下面没有写“镜头人物站位”“镜头场景锚点”“镜头机位坐标”“镜头运动方向”“镜头动作连续”，导致镜头之间人物位置、背景、机位、运动方向和动作承接不清。
    修正：每个镜头标题下方必须补齐这五项。镜头人物站位写当前镜每个人在哪里、距离和朝向；镜头场景锚点写当前镜可见背景物件和状态；镜头机位坐标写摄像机在谁的哪一侧、朝向哪里、前景/中景/背景分别是什么；镜头运动方向写每个行动主体向哪里移动、追逃前后关系和距离变化；镜头动作连续写承接上一镜的姿态/道具/移动方向、本镜动作变化和下一镜承接点。

31. 错误：小节开头站位正确，但具体镜头内部写出互相矛盾的机位、视线和背景关系，导致角色或敌人像瞬移一样跑到河对岸、门后、墙外或另一侧空间。例如小节站位写“林川站在红河岸边，背对红河、面对猎人”，镜头却写“从林川背后过肩看向红河水面和远处猎人”，这会让AI误以为猎人在红河对岸，或林川已经换到另一侧河沿。
    修正：每个镜头必须补齐“镜头机位坐标”，写清摄像机在角色哪一侧、朝向哪里、前景/中景/背景分别是什么。若角色转身看河，就要同步更新猎人位置变成他身后；若要同时看见林川、红河和猎人，优先用侧面机位或高机位空间重建，不要用互斥的过肩机位。必要时拆成两个镜头：林川转身看河 -> 反打猎人停在远处。

32. 错误：漏掉原文最后一句或段落末尾的伏笔，例如“电梯门上方的摄像头正以极缓慢的角度转动追踪他的身形”，却把镜头重点放在车钥匙、开锁、走向车辆等普通功能动作上。
    修正：先判断原文细节的未来剧情价值。普通车钥匙只是完成开车动作，可用中近景带过；摄像头追踪暗示角色被监控，是后续剧情因果伏笔，必须用特写/极致特写/拉焦/监控视角/主角背影与摄像头同框表现，并作为小节结尾钩子保留。

33. 错误：为了表现红河、峡谷、墙体、门或车辆阵列的空间规模，写出“双方两岸对峙”“猎人在对岸远远围观”“对岸出现追兵”等原文不存在的空间关系，导致角色被凭空放到阻隔物另一侧。
    修正：先按剧本逻辑确认谁在同一侧、谁在对侧、是否有人跨越阻隔物。原文只写猎人在林川身后追赶并停下，就必须写“林川在近岸河沿刹停，猎人群体仍在他身后同一岸几十米外齐停，红河横亘在林川前方/侧前方，对岸为空旷荒原或远山，禁止出现对岸猎人”。需要表现红河宽阔时，用河面占比、空旷对岸、远山、风化石林、水雾和水流方向，不要凭空增加对岸人物。

画幅比例：【自动判断或用户指定】
视频类型：【电影故事片 / 短视频 / 短漫剧 / 广告片 / MV / 其他】
视觉风格：【3D动漫 / 真人写实 / 2D动画 / 国风 / 赛博 / 暗黑奇幻 / 其他】
单条生成时长：【上限30秒 / 常规20-30秒 / 短单元4-15秒】
时长策略：按完整戏剧单元划分；常规20-30秒，短单元4-15秒；≥15秒小节须设中段再锚点
输出版本：成片执行版（纯文本分镜格式，禁止 JSON 输出）

全局风格锁定：
全片保持【视觉风格】，人物形象、服装、妆发、场景空间、关键道具和光源方向连续一致。镜头运动自然，动作符合物理规律，台词口型同步，无字幕，无水印，无多余文字。

角色音色设定：
【角色名】：【年龄感】，【声线质感】，【线路质感（画内近场/线路薄音色/听筒窄频音/免提外放/手机近场外放/画外音+低通滤波）】，【语速】，【气息状态】，【情绪底色】。
说明：本表定义角色全局声音底色；镜头内「台词四元」是该句的具体取值，两者必须一致，冲突时以句内标注为准。

叙事时间跨度：【本小节在故事里经过多久；如有时间跳跃，写清省略剪辑/微蒙太奇/声音匹配等压缩方式】
剧情功能：【建立空间 / 对话拉扯 / 动作推进 / 信息揭示 / 情绪爆发 / 反转 / 收束留白】
本小节高级视听策略：【先按15.2B判断戏剧功能、镜头主语、观众信息量和镜头价值；再从15.2A选择1-3个：信息遮蔽 / 延迟揭示 / 视线匹配 / 动机切 / 动作匹配切 / 前后景双层叙事 / 负空间 / 遮挡揭示 / 平行剪辑 / 视觉母题 / 权力站位变化 / 其他；必须说明服务的剧情目的】
场景：【时间】，【地点】，【天气或环境状态】。
人物：【人物名或 @人物资产名】
人物站位：【人物位置、距离、朝向；必须使用固定空间坐标描述，不要只写画面左/右】
