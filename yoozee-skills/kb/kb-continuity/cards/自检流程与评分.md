16.10 最终自检流程
============================================================

在输出最终分镜前，语言模型必须在内部完成以下检查，默认只输出简短自检摘要，不输出长表：

1. 台词检查
   - 原文台词是否全部保留。
   - 台词是否被改写。
   - 长台词是否合理拆分。

2. 时间检查
   - 每个小节是否落在 4-30 秒内（常规 20-30 秒，短单元 4-15 秒），是否为完整戏剧单元。
   - 每个镜头是否有时间码。
   - 关键动作是否避开开头和结尾 0.5 秒安全区。
   - 每个镜头时长是否与台词字数、语速、情绪和动作复杂度匹配；短台词是否被无理由拉长。
   - 两三个字的短命令、短反应是否控制在0.8-1.8秒或并入动作镜头；如果超过2秒，是否有明确动作爆点、听话人反应或空间变化支撑。
   - 多句台词是否被硬塞进1-3秒短镜头；如果同一镜头有三句以上台词或三名以上说话人，是否已拆镜或延长时长。
   - 群像围拢、奔跑、举武器、表情展示、主角反应、队长蓄力等动作是否和台词争抢时间；如果动作复杂，是否减少台词或拆出代表讲话人短切。

3. 空间检查
   - 场景描述是否一致。
   - 每个镜头是否都包含“镜头人物站位”“镜头场景锚点”“镜头机位坐标”“镜头运动方向”“镜头动作连续”。
   - 每个镜头的人物站位、背景锚点和动作连续是否承接上一镜，而不是只依赖小节开头的统一描述。
   - 人物站位是否连续。
   - 背景锚点是否连续：门窗开合、电梯门状态、车辆/桌椅/墙面/地面痕迹/道具位置是否承接上一镜。
   - 当前镜背景是否符合人物上一镜结束时所站的位置；是否存在人物没移动但背景换地方的问题。
   - 镜头机位是否符合空间坐标：摄像机是否无解释跨到河对岸、墙外、门后、车辆另一侧或人物未到达的位置。
   - 过肩、背面、主观转身镜头是否写清摄像机在谁的哪一侧，镜头朝向哪里，前景/中景/背景是否符合人物朝向。
   - 追逐和逃亡镜头是否写清被追者远离追兵，而不是朝追兵方向移动；如果角色向画面右侧逃，追兵是否被错误写在画面右侧前方。
   - 屏幕方向和视线是否匹配。
   - 上一镜结束姿态是否被下一镜起始画面承接。
   - 人物手部动作、身体朝向、武器/道具状态是否无端变化。
   - 群像人物是否避免同脸；是否写明年龄、脸型、发型、疤痕、饰品、体型、站姿或表情差异等差异化锚点。
   - 原文是否存在未来伏笔、隐藏观察者、监控设备、异常物件或危险信号；这些内容是否被保留并给了明确镜头。
   - 是否错误地把普通功能道具拍成重点，却漏掉真正影响后续剧情的伏笔。
   - 同一场景的持续环境声是否保持连续。
   - 每个小节底部是否输出“小节人物场景站位标注”，并明确写出本小节人物都有谁、场景在哪里、每个人物处于场景什么位置。
   - 每个小节是否包含“小节动作连续性总结”“小节场景连续性总结”和“小节声音连续性总结”。

4. 视听检查
   - 每个镜头是否有明确目的。
   - 运镜是否有理由。
   - 灯光与光影是否具体。
   - 声音是否服务画面。
   - 是否完全禁止BGM/配乐，只保留环境声、动作音效、台词、画外音和非音乐化环境低频声。
   - 对话是否机械地只拍说话人；是否根据戏剧目的使用了听话人反应、空镜、道具插入、主观视角、离画台词、画外音、J-cut 或 L-cut。
   - 画外音/离画台词是否写清声音来源、当前画面对象和声画关系。
   - 是否根据剧情功能选择了至少一种高级视听策略，例如信息遮蔽、延迟揭示、视线匹配、动机切、前后景双层叙事、负空间、遮挡揭示、平行剪辑、视觉母题或权力站位变化。
   - 每个镜头是否只使用一个主要高级策略，避免把多种复杂策略塞进同一镜头。

5. 景别节奏检查
   - 是否连续3个镜头使用同一景别或相邻景别拍同一主体。
   - 是否出现镜头2、3、4、5连续都是中景/全景的安全镜头。
   - 是否对同一角色从中景硬切到中近景或中景。
   - 若存在硬切，景别跳跃是否大于两个等级，或机位角度是否偏转超过30度。
   - 对话戏是否根据说话人、听话人反应和权力关系分配镜头，而不是所有台词都放在中景/全景。
   - 每个运镜是否写清“起始景别 -> 结束景别”。

6. 生成稳定性检查
   - 是否有一镜塞太多动作。
   - 是否有复杂手部动作。
   - 是否有多人同框过度细节。
   - 是否避免群像同脸、复制脸、统一表情和统一姿势。
   - 是否有光源乱跳或场景瞬移。

简短自检摘要写法：
自检摘要：已保留原文台词；每个小节控制在 4-30 秒（常规 20-30 秒）；每镜包含时间码、镜头人物站位、镜头场景锚点、镜头机位坐标、镜头运动方向、镜头动作连续、灯光与光影、衔接、起始画面、结束画面；每个小节底部已输出“小节人物场景站位标注”，明确人物、场景和人物在场景中的位置；人物站位、空间坐标、运动方向、机位朝向、背景锚点、门窗/电梯门状态、场景物件位置和光源方向已保持连续；已检查追逐/逃亡镜头中被追者远离追兵、追兵位于正确后方或侧后方；已检查未来伏笔、隐藏观察者、监控设备、异常物件和危险信号没有遗漏，并优先于普通功能道具处理；群像人物已避免同脸并写明差异化锚点；已检查对话声画关系，合理使用画内台词、离画台词、画外音、听话人反应、空镜或道具插入；已按导演思维判断戏剧功能、镜头主语、观众信息量、镜头价值和节奏曲线，并选择高级视听策略，控制每镜一个主要策略；已检查景别节奏，避免连续中景/全景、同景别/相邻景别硬切，并已标注运镜的起始景别和结束景别；已避免一镜过载、复杂手部、无目的运镜和机位跨越空间阻隔。

16.11 跨模型长文本处理与输出版本控制
============================================================

不同语言模型的输出习惯不同：有的模型喜欢解释，有的模型喜欢压缩，有的模型在长文本后半段容易丢格式。因此必须用以下规则约束最终输出。

1. 长剧本分批规则
   - 如果原文很长，允许分批输出，但每一批都必须从完整小节开始，不要从半个镜头中断。
   - 每一批都必须保持相同字段：小节信息、镜头字段、小节约束。
   - 每批结尾写：本批结束，下一批从【剧情位置/下一小节】继续。
   - 不要因为分批而重新改写前文台词或改变已建立的场景站位。

2. 输出版本规则
   - 默认输出“成片执行版”：字段完整，适合直接复制给即梦 SD2.0。
   - 输出一律为纯文本分镜格式（参数确认 → 全局风格锁定 → 角色音色设定 → 小节 → 镜头 → 小节约束 → 即梦粘贴提示词 → 台词核对摘要 → 自检摘要），禁止输出 JSON、YAML 或任何结构化键值封装。
   - 如果用户要求简洁，输出“压缩执行版”：保留画面、镜头、运镜、动作、台词、声音、灯光与光影、衔接、小节约束，删除解释性内容。
   - 如果用户要求审核，输出“导演审核版”：可额外写问题、风险和修改建议。
   - 用户没有特别要求时，不输出分析版，只输出成片执行版。

3. 模型跑偏修正规则
   - 如果输出开始变成小说续写，立即回到分镜字段。
   - 如果输出开始变成理论教学，立即删除理论，只保留镜头提示词。
   - 如果输出开始省略灯光、声音、衔接，必须补齐字段。
   - 如果输出开始加入原文没有的新剧情，必须删除新剧情，只保留合理视觉补充。

4. 冲突处理规则
   - 用户指定风格与本文档默认风格冲突时，优先用户指定。
   - 用户指定时长与平台 4-30 秒上限冲突时，按平台限制拆分成多个小节；不超过 30 秒不拆。
   - 原文台词过长与单镜台词限制冲突时，拆镜，不删台词。
   - 画面炫技与剧情清晰冲突时，优先剧情清晰。
   - 原文方位词自相矛盾时，不要机械照抄矛盾方位。必须以动作因果和物理空间为准，建立一个可拍的空间坐标，并在“空间坐标锁定”中写清。例如角色跑到河岸、猎人从陆地方向追来，则“红河在角色河岸侧，猎人在陆地方向几十米外”；即使原文同时出现“背对大河”和“猎人在身后”，也要统一为“角色侧身或转身观察，让红河和猎人处于可成立的前后/侧后关系”。
   - 统一空间坐标不等于改剧情。不能改变人物关系、台词和事件结果，只能把模糊或矛盾的前后左右修正成镜头可执行的位置关系。
   - 原文时间跨度与生成时长冲突时，必须区分“生成时长”和“叙事时间跨度”。例如故事里过了十几分钟，视频可以用12秒微蒙太奇压缩，但必须写清时间压缩方式。
   - 运镜复杂与生成稳定冲突时，优先稳定镜头。

5. 统一术语规则
   - 同一人物名字必须前后一致，不要换称呼。
   - 同一地点名字必须前后一致，不要同义替换。
   - 同一道具名字必须前后一致，不要一会儿叫“匕首”，一会儿叫“短刀”，除非原文如此。
   - 同一情绪阶段不要频繁换抽象词，要用具体表情和动作承接。

16.12 专业质量评分标准
============================================================

语言模型输出后必须在内部按以下标准检查，最终只输出简短自检摘要，不输出完整评分表，除非用户要求。

1. 剧情忠实度
   - 5分：台词完整保留，剧情因果和人物关系完全准确。
   - 3分：剧情大体准确但有轻微台词压缩或信息遗漏。
   - 1分：改写台词、删情节、改变人物动机。

2. 镜头可生成度
   - 5分：每镜目的单一、动作具体、画面清楚、无过载。
   - 3分：画面可理解但元素偏多或运镜偏复杂。
   - 1分：一镜塞太多动作、多人、台词和光效，难以生成稳定视频。

3. 连续性
   - 5分：站位、轴线、视线、道具、光源、场景锚点全部连续。
   - 3分：局部连续但部分镜头承接不够清楚。
   - 1分：人物瞬移、方向乱、场景或光源跳变。

4. 导演视听语言
   - 5分：景别、机位、焦距、运镜、灯光、声音都服务剧情功能。
   - 3分：镜头语言专业但部分炫技。
   - 1分：堆砌术语，没有叙事目的。

5. 3D动漫表演
   - 5分：表情、重心、预备动作、跟随动作和剪影都清楚。
   - 3分：动作可理解但表演细节不足。
   - 1分：只写抽象情绪，动作跳跃。

6. 即梦 SD2.0 适配度
   - 5分：每小节 4-30 秒（常规20-30秒＝完整戏剧单元），字段完整，素材引用明确，适合直接粘贴。
   - 3分：大体可用但提示词偏长或字段不稳定。
   - 1分：不是视频生成提示词，无法直接使用。

7. 群像差异化与生成稳定性
   - 5分：群像人物有统一阵营风格，同时具备年龄、脸型、发型、疤痕、饰品、体型、站姿或表情差异，不同角色不会同脸。
   - 3分：群像有部分差异，但背景人物仍可能显得重复。
   - 1分：追兵、猎人、村民或背景人群像复制粘贴出来的同一张脸。

如果任一项低于 4 分，必须在最终输出前自行修正，不要把低质量版本交给用户。
