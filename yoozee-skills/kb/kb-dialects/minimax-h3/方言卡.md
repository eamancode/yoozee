# MiniMax-H3 方言卡

## 结构（三段，两段声音都要写，不写会出随机噪音）

```
integrated_multimodal_description:
Reference roles: <Picture 1> is the exact identity reference of {note}...; <Audio 1> gives only the sound of the voice (timbre) of {人物} (S1). How each line is delivered ... comes only from the acting described in the scene, never from the audio references; do not reuse any words from them.
[Shot 1] {风格块}{表演块}{本段约束}{镜头 1 文字} (S1), {怎么说}:
<d>[Chinese] 台词</d>
[Shot 2] At 00:05.500, {镜头 2 文字}
...

overall_soundscape: {环境声}

non_diegetic_music: N/A
```

## 规则

1. 镜头文字用英文写（实测稳定）；台词保持原文语言，用 `<d>[Chinese] …</d>` 包住。
2. 说话人按 voices 的顺序编号 (S1)(S2)；画外音加 `[off-screen voiceover]`，嘴不动。
3. 参考按 refs 顺序编 `<Picture k>`，每张写清角色：identity（照脸、发型、小特征和衣服，忽略灰底）、location（布局材质光线，里面没人）、plate（某机位背景）、prop（道具）、frame（只取构图，脸以人物参考为准）。
4. 锁首帧模式：只给 first_frame（可加 last_frame），不能同时挂任何参考；首帧模式只锁第一帧的脸，人一动脸就变，所以有脸要连戏的段用锁人物模式。
5. 提示词 ≤7,000 字符；参考图 ≤9（第 6 张起加收费用）、参考音频 ≤3 条合计 ≤15 秒、混合输入合计 ≤12 个文件；参考图宽高比 0.4～2.5。
6. 一段 4～15 秒整数；实际片长会比请求略长（10 秒 → 10.125 秒），剪辑按实测时长排。
