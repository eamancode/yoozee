# Seedance 方言卡

`prompt.compile` 按下面的结构把一段中性分段编译成一条连续的中文提示词。你写分段表时照这个思路写镜头文字，编译出来才通顺。

## 结构

```
以@图片1为{人物}的人物参考、@图片2为场景参考……@音频1为{人物}的音色参考（只取音色，不复用其中的话），生成{时长}秒视频。整体风格为{风格块}。{表演块}{本段约束}
0-4秒：{镜头 1：景别、机位、运镜、人物动作和表情、光影}。{人物}（{怎么说}）：“{台词}”
4-9秒：{镜头 2 ……}
……
声音：{环境声、动作音效}；不要背景音乐和配乐。
约束：人物与参考一致、场景连续、光源方向不变、口型与台词同步、无字幕、无水印、除参考里已有的字外不出现可读文字。
```

## 规则

1. **镜头文字用中文写**，自然叙述，不堆关键词。每个时间段写清景别、机位、运镜、动作、表情和光。
2. **时间段按镜头切**：第 k 个镜头从它的开始秒到下一个镜头的开始秒；最后一个到段末。不固定套四段。
3. **素材引用必须说明用途**：@图片 按分段里 refs 的顺序编号（人物 / 场景 / 某机位背景 / 道具 / 构图），@视频 只用于运镜参考，@音频 只用于角色音色；**禁止把 @音频 用作背景音乐**。
4. **锁首帧模式**：首帧图记为 @图片1、尾帧图（若有）记为 @图片2；这时不能再挂参考图和参考视频。
5. **台词原文一字不改**，写成 `人物（表演状态）：“台词”`；画外音写 `人物（画外音，嘴不动）：“台词”`。
6. **不写配乐**：声音只写环境声、动作音效、台词、画外音。
7. 身份描述只写参考里真有的特征：提示词里点名的东西会被画出来。
8. 太长时先压缩风格词和重复的场景词，不删台词和关键动作；字数上限见 models.json 的 `prompt_max_chars`。
9. 一段时长不超过 models.json 里该模型的 `duration.max`（Seedance 2.0 为 15 秒）。
