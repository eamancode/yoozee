一、打斗底层逻辑（为什么这么打）
战斗不是动作的随机拼接，而是 态势 → 决策 → 动作 → 反馈 的闭环。每一招都得有“前

因后果”，否则再满屏也只是视觉噪音。

1. 态势感知与强弱判定（先定打法） - 出稿第一句先写清“敌我对比”：数量、战力、站

位。三者

决定整体打法—— - 以寡敌众（1vN）：不硬刚，

靠走位把千军万马切成“局部一对一”逐个清（见 ⑩        ㊴ 御剑风暴的“移动风球”逻
辑）； - 势均力敌（1v1）：攻防互换、见招拆招，谁露破绽谁

挨

打； - 碾压局（觉醒/满屏）：压上连招、满屏清场，不给对方喘息。 - 隐性“血条/能

量”设定：每场给主角设初始能量阈值。小技能耗能量、击

杀/

蓄力回能量，能量见底=危险信号（该撤/该觉醒），能量满=放大招窗口。

2. 攻防博弈与破绽窗口（见招拆招） - 攻击 → 对手格挡/闪避 → 我方变招；防守 → 读对

手破绽

→ 反击窗口。永远“攻中有守、守中有攻”。 - 破绽

窗口（vulnerability window）：敌方每次大招/重击后有“后摇”，这是我方最佳进攻点。

提示词里写“趁敌巨兽落地后摇，主角突进补

刀“比”主

角一直打“更有逻辑。 - 1v1 见招拆招链（第 9 章九）：格挡(火花)→借力打力→闪避反

击→上挑→绝杀，本质就是”接招→转化→反打“的博弈

逻

辑。

3. 以寡敌众的战术逻辑（割草核心） - 走位制造单点接触：主角始终背靠空地/墙体，把

魔

潮“引”成从正面来的局部战，挨个清，避免被包饺子。 -

控场优先于硬刚：先手控制（定身/冰冻/拉拽）再收割，效率最高。对应         ㉕ 寒冰领域、

后

是空地——呼应第 3 章“魔物来回穿梭”铁律的攻防对称性。

4. 战局五态流转（宏观逻辑） 试探 → 交手 → 被压制 → 爆发（觉醒/底牌）→ 终结。每

个

10/15/30s 模板都应按这五态组织，否则“全程满屏”会

审美疲劳。

能量
