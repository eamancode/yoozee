15.1 镜头语言第一判断：镜头到底要完成什么
============================================================

每个镜头只能优先完成一个主要目的：

1. 建立空间
   - 目的：让观众知道人物在哪里、危险从哪里来、人物之间的距离和方向。
   - 推荐景别：远景、全景、中全景。
   - 推荐机位：平视建立、略高俯拍、鸟瞰、门口视角、走廊纵深视角。
   - 推荐焦距：24mm-35mm，深景深。
   - 推荐运镜：固定、缓慢推入、缓慢拉远、上升镜头、横移揭示。
   - 禁忌：一上来就面部特写，观众不知道空间关系。

2. 捕捉反应
   - 目的：让观众看懂人物听到信息后的心理变化。
   - 推荐景别：中近景、近景、面部特写。
   - 推荐机位：正面平视、轻微侧面、过肩反打。
   - 推荐焦距：50mm-85mm，浅景深。
   - 推荐运镜：固定、微推镜、极轻横移。
   - 重点：眼神、呼吸、嘴唇停顿、下颌、喉咙、肩膀变化。

3. 揭示信息
   - 目的：让观众看见关键道具、文字、身份、伤口、证据、机关。
   - 推荐景别：道具特写、极致特写、过肩看物。
   - 推荐机位：角色视线方向机位、桌面高度机位、主观机位。
   - 推荐焦距：50mm-100mm，浅景深或微距。
   - 推荐运镜：推向道具、下摇揭示、拉焦、焦点从人物切到道具。
   - 重点：信息必须可读可见，不能被景深、运动模糊、遮挡破坏。

4. 推进行动
   - 目的：让观众看清人物从哪里开始、做了什么、动作结果是什么。
   - 推荐景别：全景交代动作方向，中景看动作过程，特写看接触点。
   - 推荐机位：侧面机位、斜侧面机位、低机位跟拍、过肩跟随。
   - 推荐焦距：24mm-50mm，保持动作清楚。
   - 推荐运镜：跟拍、横移、快速推近、手持、稳定器跟随。
   - 重点：动作因果必须清楚，禁止只写“激战”“冲上去”“大战”。

5. 强化情绪
   - 目的：把人物内心变化转成观众能感到的视觉压力。
   - 推荐景别：中近景、近景、面部特写、极致特写。
   - 推荐机位：平视、低机位压迫、高机位孤立、荷兰角不安。
   - 推荐焦距：50mm-85mm，浅景深。
   - 推荐运镜：缓慢推镜、固定长镜头、环绕、轻微手持。
   - 重点：情绪靠停顿、呼吸、眼神和光影，不靠空泛形容词。

6. 制造反转
   - 目的：让观众先相信一个方向，再通过镜头揭示真实情况。
   - 推荐结构：铺垫镜头 -> 信息误导 -> 关键揭示 -> 反应镜头。
   - 推荐景别：先中景或过肩隐藏信息，再特写揭示。
   - 推荐运镜：遮挡转场、拉焦、下摇、从人物反应切道具、快速推近。
   - 重点：反转必须有观众能看懂的视觉证据。

7. 收束留白
   - 目的：让动作结束、情绪落地、给下一段留下余味。
   - 推荐景别：远景、中近景、背影镜头、静态空镜。
   - 推荐机位：固定、背后机位、高机位俯拍、门外视角。
   - 推荐运镜：缓慢拉远、固定长镜头、轻微下摇。
   - 重点：结尾 0.5 秒保持稳定姿态，方便下一小节衔接。

15.2 对话戏怎么拍
============================================================

对话戏的核心不是“每句话都切”，而是看权力关系、信息变化和情绪变化。

对话镜头分配硬规则：
- 谁在说话，就要根据台词重要性适当给谁镜头。普通信息可用中近景，关键台词用近景或面部特写，压迫性台词可用低机位近景，隐瞒性台词可用侧脸或前景遮挡。
- 听话人必须有反应镜头，但反应镜头不一定每句都有；只有当听话人的心理变化、权力变化或信息接收很重要时，才给近景或特写。
- 群体嘲笑、远处喊话、多人围观可以用全景或中景建立关系，但不能连续多镜头都用全景/中景。建立关系后必须切入代表讲话人中近景/近景/面部特写、听话人反应近景/特写、主角反应、关键道具或手部动作。
- 对话段落建议景别节奏：建立关系全景/中景 -> 说话人中近景/近景 -> 听话人反应近景 -> 过肩关系镜头 -> 关键台词特写或道具特写。
- 如果一段对话连续出现多句台词，不要让所有台词都落在同一个中景。必须根据台词重点切换到说话人近景、听话人反应、手部动作、道具特写或空间压迫镜头。
- 高级对话不是机械执行“谁说话就给谁镜头”。当台词真正改变的是听话人的心理，画面优先给听话人的反应；当台词的含义指向环境、道具、记忆、危险或潜台词，画面可以给空镜、道具特写、空间压迫、手部动作或主观视角，同时让说话人的声音以画外音/离画台词存在。
- 对话镜头时长必须和台词预计时长匹配。两三个字的短命令不能给3-4秒，除非画面同时承担明确动作爆点、压迫推进或听话人反应；否则用短切或并入动作镜头。
- 情绪语速必须影响时长：愤怒、追喊、命令通常快；撒娇、哽咽、犹豫、告白通常慢；冷酷威胁字少但可留短暂停顿，不等于自动给长镜头。

高级对话、画外音与声画分离视听语言：

1. 画内台词 on-screen dialogue
   - 定义：说话人出现在画面中，观众能看到口型、姿态和面部表情。
   - 适用：第一次建立角色、重要身份亮相、关键命令、威胁、告白、谎言被观察、口型同步非常重要的台词。
   - 镜头：中近景、近景、低机位近景、过肩反打、侧脸半遮挡。
   - 目的：让观众确认“谁在说”和“他怎么说”。

2. 离画台词 off-screen dialogue
   - 定义：说话人位于画面外，但声音来自当前场景空间内。
   - 适用：画面重点不在说话人，而在听话人的反应、危险接近、门外声音、背后威胁、群体议论、空间压迫。
   - 镜头：听话人近景、背影镜头、门口/窗外空镜、主观视角、道具特写。
   - 目的：让声音扩大空间，让观众感觉画外仍有压力或未知人物存在。
   - 示例逻辑：A在画外说“你早就知道了。”画面给B的近景，B的眼皮微垂，喉结滚动，手指压紧杯沿。

3. 画外音 voice-over
   - 定义：声音不一定来自当前可见空间，可是旁白、回忆、内心独白、信件朗读、录音、未来/过去的声音。
   - 适用：回忆、心理独白、命运感、旁白交代、书信/录音内容、时间跨越、人物无法说出口的真实想法。
   - 镜头：空镜、人物无声特写、背影、旧物特写、环境变化、慢推或缓慢拉远。
   - 目的：让“声音讲信息，画面讲情绪或主题”，避免把解释性台词拍得呆板。
   - 禁忌：不要把所有台词都变成画外音；角色正在当场交流、需要口型同步或冲突对峙时，仍要保留画内台词。

4. 听话人反应镜头 reaction shot
   - 定义：台词声音继续存在，但画面切到听话人。
   - 适用：台词击中痛点、听话人发现真相、权力关系改变、听话人隐藏情绪、说话人的话不重要而听者的反应更重要。
   - 镜头：近景、面部特写、眼睛特写、手部特写、肩背僵住、呼吸暂停。
   - 目的：让观众读到“这句话造成了什么后果”，而不是只看“谁说了什么”。
   - 规则：关键台词之后至少保留 0.5 秒反应空间；反应必须写成眼神、嘴角、下颌、呼吸、手指、肩膀等可见变化。

5. 空镜承接 cutaway / empty shot
   - 定义：台词继续，画面切到没有主要人物的环境、天空、走廊、门、窗、灯、雨、战场、废墟等。
   - 适用：孤独、命运感、时间流逝、关系断裂、危险逼近、台词含义超过人物本身、人物说不出口的情绪需要环境代说。
   - 镜头：远景、静态空镜、缓慢推向门缝、风吹窗帘、灯光闪烁、空椅子、无人走廊。
   - 目的：用环境表达潜台词，让画面有呼吸，不让对话一直停留在人脸之间。
   - 禁忌：空镜必须有叙事功能，不能为了“高级感”随便插入；空镜出现后要能承接情绪、信息或下一镜动作。

6. 道具/手部插入镜 insert shot
   - 定义：台词声音存在时，画面切到手、武器、杯子、信件、戒指、按钮、伤口、屏幕等关键物。
   - 适用：谎言露馅、人物紧张、信息揭示、危险触发、关系象征、台词背后有关键证据。
   - 镜头：特写、极致特写、浅景深、拉焦到道具。
   - 目的：让观众看到台词背后的“证据”或“真实心理”。
   - 示例逻辑：A画外说“我没碰过那把刀。”画面给A袖口的血迹特写，焦点从袖口拉到他微微攥紧的手指。

7. J-cut 声音先入
   - 定义：下一镜的声音先于画面进入。
   - 适用：提前制造悬念、让观众先听到威胁/哭声/枪声/门铃/人群声，再切到声源；也适合从安静场景过渡到冲突场景。
   - 写法：衔接字段必须写“下一镜声音先入”，声音字段写清哪一种声音提前进入。
   - 目的：用声音带观众进入下一场或下一情绪，剪辑更流畅。

8. L-cut 声音延后
   - 定义：上一镜的声音延续到下一镜画面。
   - 适用：台词余味、创伤回响、回忆覆盖现实、人物离开后声音仍压在画面上、告别或反转后的情绪滞留。
   - 写法：衔接字段必须写“上一镜声音延后”，画外音字段写清哪句声音延续。
   - 目的：让一句话在画面之外继续影响观众和角色。

9. 声画对位 / 声画反差
   - 定义：声音表达一种表面意思，画面展示相反信息或更深潜台词。
   - 适用：讽刺、谎言、双面人物、反转、黑色幽默、表面平静但危险逼近。
   - 镜头：平静台词配危险道具特写；温柔旁白配破败环境；胜利宣言配失败后果。
   - 目的：让观众比角色更早意识到真相，制造戏剧张力。

10. 主观听觉与主观视角
   - 定义：镜头和声音贴近某个角色的感知，声音可变闷、变远、耳鸣、心跳放大。
   - 适用：恐惧、眩晕、震惊、创伤、濒死、社交压迫、角色无法处理信息。
   - 镜头：主观视角、浅景深、轻微手持、焦点漂移、人物脸部近景。
   - 目的：把观众放进角色身体里，而不是旁观台词。

11. 沉默反应与延迟回答
   - 定义：台词结束后不立刻切走，保留人物无声反应。
   - 适用：真相揭露、告白失败、威胁生效、人物压抑怒火、关系破裂。
   - 镜头：固定近景、面部特写、手指微动、视线避开、喉结滚动。
   - 目的：让观众感受“没说出口的话”，比继续台词更有力量。

12. 不可靠叙述
   - 定义：画外音/角色叙述与画面事实存在偏差。
   - 适用：悬疑、反转、记忆被篡改、角色自欺、谎言包装成真相。
   - 镜头：叙述说“我很平静”，画面给颤抖的手；叙述说“那里什么都没有”，画面给角落里的影子或被藏起的物件。
   - 目的：让观众主动读画面，提升高级感和悬念。

13. 内心OS画面化
   - 定义：角色内心独白必须配合可见观察、微表情或环境证据，不能只让声音解释。
   - 适用：推理、判断敌人弱点、发现规则、压抑惊讶、危机中找到机会。
   - 镜头：角色眼神扫视 -> 观察对象特写 -> 敌人反应/环境异常 -> 角色微表情变化。
   - 写法：内心OS字段保留原文内容；画面字段必须展示他为什么这样想。
   - 示例逻辑：林川OS“他们怕这条河？”画面必须同时给猎人后退、武器垂下、老猎人发抖、红河翻涌等证据。
   - 禁忌：不要让OS替代画面推理；观众必须能看见角色判断的依据。

声画分离使用决策：
- 如果台词的重点是“说话人的态度、身份、威胁、命令”，优先拍说话人。
- 如果台词的重点是“听话人被击中、理解、隐瞒、崩溃、动摇”，优先拍听话人反应。
- 如果台词的重点是“空间压力、危险来源、孤独、命运、环境变化”，优先拍空镜或空间镜头。
- 如果台词的重点是“证据、谎言、秘密、危险触发”，优先拍道具/手部/屏幕/伤口等插入镜头。
- 如果台词连接两个时空或两个场景，优先使用 J-cut 或 L-cut。
- 如果台词只是解释信息，画面必须承担额外叙事：展示动作、关系、证据、环境变化或听话人反应，避免画面只做台词插图。
- 如果观众必须看清口型、身份亮相或现场冲突，不能整句都用画外音。

1. 普通平等对话
   - 景别：中景、中近景、过肩镜头。
   - 机位：双方平视，轴线稳定。
   - 焦距：35mm-50mm。
   - 运镜：固定或轻微推近。
   - 剪辑：说话人和听话人反应交替，避免每句机械反打。
   - 适用：解释、试探、日常交流、关系尚未失衡。

2. 权力压迫对话
   - 强势方：低机位仰拍、中近景或近景，背景压迫感强。
   - 弱势方：高机位俯拍、留白构图、人物被压在画面边缘。
   - 焦距：强势方可用35mm略贴近，弱势方可用50mm-85mm压缩孤立。
   - 运镜：强势方可缓慢推近，弱势方多固定或缓慢后退。
   - 灯光：强势方轮廓清晰，弱势方半张脸入暗或顶光压迫。

3. 情绪拉扯对话
   - 景别：从中景逐步进入中近景、近景。
   - 运镜：随着情绪升级缓慢推近；情绪退缩时缓慢拉远。
   - 焦点：眼睛优先；关键句后给听话人反应特写。
   - 剪辑：关键台词后保留 0.5-1 秒沉默反应。
   - 适用：告白、争吵、背叛、坦白、告别。

4. 隐瞒与试探
   - 景别：过肩、侧脸、前景遮挡、中近景。
   - 机位：门缝、窗框、镜面、背影、侧面半遮挡。
   - 运镜：轻微横移、缓慢推近、拉焦到关键道具。
   - 灯光：侧光、半明半暗、百叶窗光影、低光。
   - 目的：让观众感到“话里有话”。

5. 审讯与逼问
   - 景别：面部特写、手部特写、中景对峙。
   - 机位：顶光下的正面固定，低机位压迫，过肩逼近。
   - 焦距：50mm-85mm，浅景深。
   - 运镜：固定长镜头制造压迫，关键逼问时缓慢推镜。
   - 灯光：顶光、硬光、高反差、眼窝阴影。

6. 群像对话
   - 先用全景建立人物站位，再切中景/近景；全景只负责交代“谁和谁在场、距离多远、权力关系如何”，不能让整段群像台词都停在全景。
   - 说话人位置必须与全景站位一致。
   - 群像里真正说关键台词的人，可以给中近景、近景或面部特写，让观众看清恐惧、愤怒、迟疑、怂恿或撒谎。
   - 听话人、被威胁者、被误解者或真正被这句台词改变的人，可以给近景或特写反应；必要时让说话人的声音以画外音存在。
   - 反应镜头只给剧情相关人物，不平均分配。
   - 轴线要稳定，避免人物左右关系混乱。
   - 群像小节不宜只用3个大镜头吞掉所有动作和台词。4-30秒的群像冲突小节通常可拆成4-10个更精准的镜头（20-30秒建议6-10个）：空间建立、领导者短命令、代表喊话者近景、主角反应、武器/手部动作、群像包围重建或动作爆点。
   - 群像台词短而多时，不要把所有人放在同一个中全景里说完。可用0.8-1.5秒短切给代表路人近景/面部特写，展示不同脸、不同表情和不同态度。
   - 群像近景不是平均拍每个人，而是挑选“最能代表群体情绪的人”：恐惧的老者、兴奋的年轻人、犹豫的旁观者、残忍的队长、幸灾乐祸的嘲笑者。

7. 群体敌意三层调度
   - 群体敌意不能平均拍每个人，必须分三层：领导者、代表性喊话者、背景群体。
   - 领导者：负责权力和最终命令，适合低机位、中近景、沉默压迫、手势制止或下令。
   - 代表性喊话者：负责表达群体理由或恐惧，可选1-3人给中近景、近景或面部特写，每人只承载一句关键台词，并写清表情细节。
   - 听话人/被围困者：当群体台词真正制造压力、误解、羞辱或威胁时，优先给听话人近景/特写反应，而不是机械回到全景。
   - 背景群体：负责包围、起哄、后退、举武器、脚步声和空间压力，用全景/中全景概括和重建空间，不逐个特写，也不能让全景承载全部群体台词。
   - 群体态度变化必须可见：举矛逼近 -> 齐声喊叫 -> 发现禁地后后退 -> 武器垂下 -> 形成远距离包围。
   - 群体台词可以用画外群声或背景齐喊，但关键代表台词必须保留原文并标注说话者。
   - 群像差异化：群体可以共享同一文化服装和阵营风格，但必须至少写出2-4类可见差异锚点，例如年长者白胡须、年轻人瘦削脸、脸颊疤痕、不同颜料纹样、骨饰数量差异、高矮胖瘦差异、站姿差异、恐惧/愤怒/迟疑等表情差异。
   - 背景群体不需要每个人单独设定，但必须避免同脸、复制脸、统一表情和统一姿势；群像镜头中可写“十几名猎人脸型、年龄、疤痕和颜料纹样各不相同”。
   - 禁忌：不要连续给十几个猎人单独镜头；不要让群体在画面中无序乱动；不要让群体人物长成同一张脸。

对话戏常用结构：
建立空间全景 -> 说话人中近景 -> 听话人反应近景 -> 过肩关系镜头 -> 关键台词特写 -> 沉默反应或道具特写。
