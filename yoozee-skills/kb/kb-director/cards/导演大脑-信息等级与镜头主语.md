十五、好莱坞导演视听语言知识库
============================================================

本章是分镜判断核心。生成每个镜头前，必须先判断该镜头的“戏剧功能”，再选择景别、机位、焦距、运镜、剪辑和光影。镜头语言不是装饰，必须服务叙事：观众该看见什么、感受到什么、什么时候紧张、什么时候释放、什么时候理解信息。

15.0 顶级好莱坞3D动画分镜导演大脑：先做导演判断，再写镜头
============================================================

本节是十五章的核心。语言模型不能把剧本逐句翻译成镜头，也不能先套景别、机位、运镜词库。必须先像专业分镜导演一样判断：这段戏真正要让观众知道什么、感受什么、期待什么、误会什么、害怕什么，以及下一段要靠什么钩子继续。

导演大脑总流程：
1. 读剧情功能：本段是建立空间、人物出场、对话拉扯、喜剧反应、情绪崩溃、动作推进、追逐逃亡、信息揭示、身份反转、伏笔埋设、悬疑恐惧、群像压力，还是收束留白。
2. 读信息等级：把原文信息分成四级。
   - S级：影响后续剧情因果的伏笔、真相、危险信号、隐藏观察者、关键反转、身份信息、不可删除的动作结果。必须给明确镜头。
   - A级：当前小节推进所需的关键动作、关键道具、人物决定、重要反应。必须出现，但不一定特写。
   - B级：帮助画面稳定的环境、氛围、普通动作、空间锚点。可以合并到镜头里。
   - C级：重复性走路、普通拿物、普通转身、无剧情价值的过渡。应省略或压缩。
3. 定镜头主语：每个镜头只服务一个主语，可以是人物、道具、危险、空间、声音、伏笔或观众视角。镜头主语不是谁说话就一定是谁，而是谁在这一秒发生信息变化。
4. 定观众信息量：观众知道得比角色少、一样多，还是更多。悬疑常让观众少知道；戏剧性反讽常让观众多知道；沉浸发现常让观众和角色同步知道。
5. 定镜头价值：每个镜头必须至少提供一种新价值：新空间、新信息、新情绪、新动作结果、新关系变化、新危险、新伏笔、新主题暗示。没有新价值的镜头必须合并或删除。
6. 定注意力中心：每镜只能有一个主要注意力中心。可以是脸、手、钥匙、摄像头、门、血迹、屏幕、车辆、远处人影、声音来源。其他元素只能辅助。
7. 定场面调度：人物站在哪里、看向哪里、与门/车/桌/墙/镜头/危险的距离如何变化。人物和背景锚点必须连续。
8. 定视听策略：从15.2A选择一个主要策略，例如延迟揭示、反应先行、视线匹配、拉焦揭示、前后景双层叙事、负空间、框中框、声画反差、监控视角。
9. 定生成稳定性：一镜不要塞太多动作、多人、光效和复杂运镜。复杂戏拆成多个清楚镜头；简单动作合并。
10. 定结尾钩子：每个小节结尾必须留下可承接点：危险、伏笔、异常物、角色决定、未完成动作、声音先入、视线落点或反应余波。

原文信息优先级硬判断：
- 原文最后一句通常不是废话，尤其是“某物正在看、跟踪、转动、闪烁、响起、出现、消失、靠近、停住”。这些常是段落钩子，必须优先检查。
- 原文中没有台词但影响后续剧情的动作，和台词同等重要。例如摄像头追踪、屏幕亮起、门锁自动反锁、远处人影停住、红点闪烁、血迹滴落、某人背后出现影子。
- 当前功能动作不等于剧情重点。拿钥匙、按按钮、开门、走路、上车通常是功能动作；只有当它们触发危险、揭示身份或改变关系时才给特写。
- 如果普通功能动作和伏笔同时存在，先拍清楚功能动作的结果，再把镜头价值交给伏笔。例如“按下车钥匙，黑色大众灯闪两下”可以用中景带过；“摄像头缓慢转动追踪他”必须作为监控伏笔镜头。

镜头主语选择矩阵：
1. 说话人是镜头主语：
   - 适用：身份亮相、威胁命令、谎言表演、情绪爆发、口型同步重要。
   - 常用：中近景、近景、低机位、侧脸遮挡、50mm-85mm。
2. 听话人是镜头主语：
   - 适用：台词真正改变听话人的心理、权力、秘密或决定。
   - 常用：近景、面部特写、手部特写、固定镜头、0.5秒沉默反应。
3. 道具/证据是镜头主语：
   - 适用：信息揭示、谎言证据、危险触发、身份线索。
   - 常用：特写、极致特写、桌面机位、拉焦、微推镜。
4. 空间是镜头主语：
   - 适用：陌生环境、孤独、压迫、迷路、追逐路线、敌人包围。
   - 常用：远景、全景、广角、深景深、纵深构图、高机位。
5. 伏笔/隐藏危险是镜头主语：
   - 适用：监控、窥视、倒计时、门缝人影、红点、摄像头、未知声音、异常机械动作。
   - 常用：特写、极致特写、前景遮挡、监控视角、拉焦揭示、主角背影+伏笔同框、轻微机械声。
6. 观众视角是镜头主语：
   - 适用：观众需要比角色先知道危险，制造戏剧性反讽。
   - 常用：原因先行、负空间、背景危险、远处人影、桌下录音笔红灯。

不同剧情的导演决策矩阵：
1. 人物出场
   - 目标：建立身份气质和观众第一印象。
   - 景别：先环境中全景/全景，再中近景或特写。
   - 机位：普通人物平视；强势人物低机位；弱势人物高机位；神秘人物背影/剪影/局部。
   - 焦段：24mm-35mm建立空间，50mm-85mm建立面部识别。
   - 光影：轮廓光、门框光、屏幕光、顶光或背光决定人物气质。
   - 禁忌：没有空间就直接特写脸，观众不知道他从哪里来。

2. 普通对话
   - 目标：让观众看清人物关系和信息变化。
   - 结构：关系全景 -> 说话人中近景 -> 听话人反应 -> 过肩关系 -> 关键台词特写。
   - 机位：轴线稳定，双方屏幕方向不能乱。
   - 运镜：少动，固定或轻微推近。
   - 声音：台词清晰，环境声持续。
   - 禁忌：每句台词都用同角度中景；谁说话就机械拍谁。

3. 吵架冲突
   - 目标：表现权力拉扯、攻击和防御。
   - 景别：中景建立距离，近景看攻击性台词，听话人特写看受伤反应，手部/道具特写看失控。
   - 机位：强势方低机位或占画面中心；弱势方高机位、边缘化或被前景压住。
   - 焦段：35mm贴近冲突，70mm-85mm压缩空间增加窒息感。
   - 运镜：攻击升级时缓慢推近；退缩时拉远或固定不动。
   - 光影：硬侧光、顶光、眼窝阴影、高反差。
   - 禁忌：连续全景喊台词；没有反应镜头。

4. 甜蜜感情戏
   - 目标：表现靠近、迟疑、心动和微妙边界。
   - 景别：中全景建立两人距离，手部特写表现试探，近景表现眼神，双人中近景收住。
   - 机位：平视、轻微侧面、过肩柔和反打。
   - 焦段：50mm-85mm，浅景深，背景柔化。
   - 运镜：慢推、轻微横移、固定停顿。
   - 光影：柔光、暖边光、眼神光，低反差。
   - 声音：呼吸、衣料摩擦、环境声，不用BGM。
   - 禁忌：大幅环绕、强烈快切、过度解释情绪。

5. 孤独/迷茫/穿越后困惑
   - 目标：让空间吞没人，让观众感到人物不知道自己在哪里。
   - 景别：远景/全景建立陌生空间，中近景看空茫表情，主观视角扫视环境，关键物或异常物特写。
   - 机位：平视或略高机位，人物可被放在画面边缘。
   - 焦段：24mm-35mm表现空间，50mm表现人物迷茫。
   - 运镜：固定、缓慢横摇、主观扫描。
   - 光影：冷光、顶光、低饱和、空间回声。
   - 禁忌：只拍脸不拍环境证据。

6. 监控/被观察/直播伏笔
   - 目标：让观众意识到角色不知道自己正在被看见。
   - 信息关系：观众知道得比角色多。
   - 景别：人物中景完成普通动作，随后摄像头/红点/屏幕特写，或主角背影与摄像头同框。
   - 机位：监控视角、高处俯拍、长焦窥视、门框/柱子前景遮挡。
   - 焦段：70mm-135mm制造窥视感；特写可用85mm-100mm。
   - 运镜：极慢推镜、拉焦到摄像头、摄像头机械转动、固定监控画面。
   - 光影：冷白灯、红点闪烁、屏幕微光、低照度。
   - 声音：通风管道低鸣、轻微机械转轴声、电流声，禁止BGM。
   - 剪辑位置：如果出现在段尾，优先作为最后一个镜头和下一小节钩子。
   - 禁忌：把监控物件当背景删掉；把车钥匙、开锁、走路等普通动作拍成段落重点。

7. 悬疑/恐惧
   - 目标：控制观众不知道什么，延迟揭示危险。
   - 结构：异常空镜 -> 角色察觉 -> 主观寻找 -> 局部线索 -> 反应 -> 延迟揭示。
   - 景别：空镜、负空间中景、局部特写、主观视角。
   - 机位：门缝、低机位、背后机位、角落窥视。
   - 焦段：35mm空间不安，85mm孤立角色，长焦窥视。
   - 运镜：慢推、极慢横移、拉焦、固定等待。
   - 光影：低光、侧逆光、闪烁灯、轮廓光、深阴影。
   - 声音：声音先入、环境声突然变清晰、反常安静。
   - 禁忌：第一次就把危险完整展示；用台词解释恐惧。

8. 信息揭示/身份反转
   - 目标：让观众清楚看见证据，并看到人物如何理解。
   - 结构：人物察觉 -> 证据特写 -> 反应特写 -> 空间关系重建。
   - 景别：道具特写、屏幕特写、文字特写、面部特写。
   - 机位：主观视角、过肩看物、桌面高度。
   - 焦段：50mm-100mm，确保可读。
   - 运镜：微推、下摇、拉焦、视线匹配切。
   - 禁忌：证据不清楚；只让角色说“原来如此”但画面不给依据。

9. 动作/打斗
   - 目标：让动作因果清楚，冲击有重量。
   - 结构：空间建立 -> 发起 -> 路径 -> 接触 -> 结果 -> 反应。
   - 景别：全景看方向，中景看过程，特写看接触点，反应镜头看代价。
   - 机位：侧面、斜侧面、低机位、跟拍，不要乱越轴。
   - 焦段：24mm-50mm保证动作清楚；70mm压缩冲击只用于瞬间。
   - 运镜：跟拍、横移、快速推近、甩镜只在爆点用。
   - 禁忌：一镜写完整复杂打斗；每个动作都极致特写导致空间丢失。

10. 追逐
   - 目标：让观众知道方向、距离、障碍和危险来源。
   - 结构：路线全景 -> 跟拍主角 -> 障碍/追兵特写 -> 距离变化 -> 新危险钩子。
   - 景别：高机位路线、背后跟拍、侧面全景、危险特写。
   - 机位：背后跟随、侧面平移、高机位重建空间。
   - 焦段：24mm-35mm表现速度；70mm压缩追兵距离。
   - 运镜：稳定器跟拍、横移、快速摇到障碍。
   - 禁忌：只写“狂奔”“追赶”，不交代距离变化。

11. 群像/围攻/会议
   - 目标：建立群体压力，同时保持主次清楚。
   - 结构：全景建立群体关系 -> 领导者近景 -> 代表讲话人近景/面部特写 -> 听话人或主角反应近景/特写 -> 全景重建包围或权力结构。
   - 群像层级：领导者、代表性个体、背景群体。
   - 景别：全景/中全景只负责建立人数、空间和包围关系，不能承载整段群像对话；代表讲话人可用中近景、近景或面部特写看清表情；听话人、被威胁者或主角可用近景/特写表现被台词击中的反应；背景群体用全景/中全景维持压力。
   - 机位：高机位看包围，低机位看压迫，过肩看关系。
   - 禁忌：连续多个群像全景硬撑台词；平均给每个人特写；群像同脸；人物站位和武器状态跳变。

12. 喜剧/尴尬
   - 目标：让反应和停顿制造笑点。
   - 结构：误会建立 -> 关键台词/动作 -> 角色僵住 -> 反应停顿 -> 小动作或环境声收尾。
   - 景别：固定中景、近景反应、道具插入。
   - 机位：平视固定，少动。
   - 声音：环境声、衣料声、尴尬停顿，禁止BGM。
   - 禁忌：用大运镜和快切破坏笑点。

13. 收束留白
   - 目标：让情绪落地，同时给下一段方向。
   - 景别：远景、背影、中近景、空镜、关键物特写。
   - 机位：背后、高机位、门外、窗外、静态观察。
   - 运镜：缓慢拉远、固定长镜头、轻微下摇。
   - 声音：环境声回归，动作音效收尾，声音先入可引下一小节。
   - 禁忌：结尾只是“继续走”，没有信息变化或情绪余波。

导演镜头选择快捷表：
- 想让观众理解空间：远景/全景 + 24mm-35mm + 深景深 + 固定或轻微移动。
- 想让观众理解心理：近景/面部特写 + 50mm-85mm + 浅景深 + 固定或微推。
- 想让观众理解证据：道具特写/极致特写 + 50mm-100mm + 清晰焦点 + 视线匹配或拉焦。
- 想让观众感到被监视：高处机位/长焦窥视/监控视角 + 冷光 + 机械声 + 主角不知情。
- 想让观众感到压迫：低机位强势方、高机位弱势方、长焦压缩、框中框、顶光或硬侧光。
- 想让观众感到孤独：远景、人物边缘化、负空间、缓慢拉远、环境声扩大。
- 想让观众感到惊讶：反应先行、延迟揭示、快速推近、声音骤停。
- 想让观众感到悬疑：信息遮蔽、负空间、门缝视角、声音先入、局部特写。
- 想让观众感到反转：误导性构图、拉焦揭示、对照蒙太奇、反应特写。
- 想防止拖沓：普通动作合并，关键结果保留，伏笔单独给镜头。

AI执行时必须问自己的导演问题：
1. 这段原文最重要的不是“发生了什么”，而是“什么信息改变了观众对剧情的理解”？
2. 哪个细节如果删掉，会导致后续剧情因果断裂？这个细节必须给镜头。
3. 当前镜头应该让观众看人物、看道具、看空间、看危险，还是看伏笔？
4. 这个镜头是否提供新信息、新情绪、新动作结果、新关系变化或新伏笔？
5. 有没有把普通动作拍得太重，却漏掉真正重要的非台词叙事句？
6. 如果原文段尾有异常物或隐藏观察，它是否成为结尾钩子？
7. 这个镜头能否被即梦稳定生成？如果不能，是否需要拆成更简单的镜头？
