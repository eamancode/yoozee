三、拆分逻辑：小节、镜头、台词与节奏
============================================================

1. 小节拆分
   - 按时间变化、场景变化、关键动作完成、情绪转折、信息揭示、长台词承载来拆分小节。
   - 每个小节＝一个完整戏剧单元：常规 20-30 秒；短反应、普通过渡、单句命令等短单元可用 4-15 秒。
   - 小节内部仍可切镜（用时间段描述），内部切镜不产生条间拼接成本，因此鼓励把完整单元写满。
   - ≥15 秒的小节必须设置「中段再锚点」；20-30 秒小节中途必须有一次转折或信息增量。
   - 每个小节是一条独立 Seedance 2.0 生成任务，必须能单独复制生成。
   - 每个小节只表现一个连续叙事段落，不要把无关场景塞进同一条提示词。

1.1 长剧本分批策略
   - 如果原文较长，必须先在内部按剧情段落分批，不要一次性强行压缩成少量镜头。
   - 分批标准：场景变化、追逐开始/结束、权力关系变化、敌我目标变化、重大信息揭示、爽点反转、段落钩子。
   - 每一批必须保留该批出现的全部原文台词，不得因为分批而删台词、合并台词或改写台词。
   - 每一批结尾必须有明确承接点：声音先入、动作未完成、视线方向、危险逼近、角色决定、环境异常或悬念钩子。
   - 如果剧本很长，输出时可以分为“第1批/第2批/第3批”，每批仍按完整格式输出；不要为了省篇幅把后半段概括掉。
   - 长剧本推荐先内部分段，例如：醒来遇险 / 群体围攻 / 追逐逃亡 / 抵达禁地 / 禁地反转 / 爽点收束。
   - 分批不是改剧情，只是为了防止提示词过长、镜头过载、台词遗漏和模型注意力衰减。
   - 分批前必须先检查原文是否存在方位词冲突、时间跨度冲突或动作过程过长。例如“角色背对大河”却又写“猎人在他身后”，必须按动作因果建立一个物理可成立的空间坐标；例如“十几分钟后”不能按真实时间生成，必须用时间压缩或省略剪辑处理。

2. 镜头密度
   - 镜头数服从剧情功能，不机械固定。
   - 文戏反应：1-3 个镜头，保证表演连续。
   - 对话拉扯：2-4 个镜头，使用说话人、听话人反应、过肩、道具特写。
   - 动作推进：3-5 个镜头，按“发起 -> 接触 -> 结果 -> 反应”拆分。
   - 信息揭示：1-3 个镜头，保证关键道具、文字、身份或证据可读可见。
   - 情绪留白：1-2 个镜头，保留沉默、呼吸、眼神和光影变化。
   - 4-15秒小节通常建议 3-5 个镜头；20-30秒小节通常建议 6-10 个镜头，除非是长镜头、长台词或强情绪留白。不要把一个小节长期压成3个大镜头，导致每个镜头时长虚胖。
   - 单个短命令、短反应、两三个字的台词，通常不应独占3-4秒；应控制在0.8-1.8秒，或与动作准备、反应、群像细节合并。
   - 一个小节内如果出现多人说话，不要用一个中全景吞掉所有台词。应拆成代表说话人近景/面部特写、听话人反应、背景群像压力或动作接触点。
   - 景别必须有节奏变化，禁止连续多个镜头都使用中景/全景这种安全景别。每个小节内应根据剧情功能穿插远景、全景、中景、中近景、近景、特写、极致特写或道具特写。
   - 对话镜头要根据“谁在说话、谁在听、谁被影响”分配景别。说话人适合中近景、近景或面部特写；听话人适合反应近景、过肩镜头或沉默特写；关系交代才使用全景/中景。
   - 同一小节中连续 3 个以上镜头不得全部是中景或全景。若连续使用同类景别，必须改变机位角度超过 30 度、改变构图关系，或加入明显焦点/运镜变化。

3. 反拖沓分镜规则
   - 禁止为了凑镜头数把普通过渡动作拆碎。一个人普通走路、推门、坐下、转身、抬头、拿起普通物件，通常用一个镜头完成。
   - 只有当动作承载剧情功能时才拆镜：走路途中发现危险、推门前后有悬念、坐下代表权力变化、转身揭示身份、抬头触发情绪爆点、拿起物件是关键证据。
   - 普通过渡动作写法：用一个中景或跟拍镜头概括完成，例如“他从走廊尽头走到门前，脚步停住，手搭上门把手”。
   - 关键动作拆镜写法：先写预备动作，再写接触点，再写结果和反应。
   - 如果一个镜头没有推进剧情、揭示信息、改变关系、制造情绪或建立空间，就删除或合并。
   - 留白不是拖沓。留白必须服务悬念、情绪余味、危险临近或下一场衔接。
   - 制作工具、搜集材料、打磨、搓线、布置陷阱、备战等重复劳动不能逐步实拍。只保留“材料来源 -> 关键变形 -> 结果验证 -> 反应/误解”四类节点；中间重复动作使用省略剪辑或微蒙太奇压缩。

4. 镜头合并原则
   - 同一人物连续完成的简单动作应合并。
   - 同一空间内没有新信息的空镜应合并或删除。
   - 同一情绪没有变化的连续表情特写应合并。
   - 同一句台词不要拆成过多镜头，除非台词内部有明显语意转折。
   - 分镜数量由剧情功能决定，不为了“看起来专业”而增加镜头。

5. 台词拆分
   - 一个镜头原则上只安排一个人说话。
   - 单镜台词建议不超过 25 个汉字；超过则按语意拆分到下一个镜头。
   - 台词必须用中文引号“”标注。
   - 台词后是否给反应时间，要看台词价值。关键威胁、情绪刺痛、信息反转后给 0.5-1 秒反应；普通短命令或动作口令可只给0.2-0.5秒动作承接，不要无意义拖长。
   - 镜头时长必须和台词长度、语速、情绪、动作复杂度匹配。短台词不能强行给长时长，长台词不能塞进极短镜头。
   - 同一镜头内有多名角色连续说话时，必须把每句台词的预计口播时间相加，再加上至少0.2-0.5秒的换气、反应或动作衔接。不能把三句以上台词、群体围拢动作、表情展示和下一个动作蓄力全部塞进3秒。

5.1 台词时长估算与语速规则
   - 生成镜头时间码前，必须先估算本镜台词实际说话时长，再加必要动作/反应时间。
   - 常规中文口语语速：每秒约4-5个汉字。
   - 生气、命令、追喊、惊恐喊叫：语速偏快，每秒约5-7个汉字，停顿少，镜头时长可短。
   - 威胁低吼、冷酷命令、压低声音：语速偏慢但字数少，通常0.8-1.8秒即可，除非同时承载关键动作或压迫反应。
   - 撒娇、哽咽、犹豫、告白、悲伤、试探：语速偏慢，每秒约2-4个汉字，需要更多停顿和表情反应。
   - 解释信息、旁白、内心OS：每秒约3-4个汉字，若超过25字必须拆镜或配合画面证据分段。
   - 两三个字的短台词，例如“别动！”“动手！”“来了。”，通常台词本身只需0.4-0.8秒；镜头总时长根据动作和反应控制在0.8-1.8秒，不应无理由给3-4秒。
   - 10-15字的普通台词通常需要2-4秒；如果语气急促可更短，如果撒娇、哽咽或压迫停顿可更长。
   - 台词很短但镜头需要长时间时，必须说明长出来的时间在拍什么：动作准备、环境反应、听话人微表情、危险逼近、群像变化或道具细节。否则必须缩短镜头。
   - 时间码自检：如果台词少于5个字却给超过2秒，必须问“多出来的时长是否有明确动作或反应价值？”没有就压缩。
   - 问号、省略号、破折号、感叹号要转译成可见或可听的表演节奏。

6. 头尾安全区
   - 每条生成任务开头 0.5 秒不要放关键动作或关键台词，先建立主体或环境。
   - 每条生成任务结尾 0.5 秒让动作自然收住，给下一镜或下一小节留衔接姿态。

7. 段落钩子与小节结尾
   - 每个小节结尾必须回答“这一段改变了什么”，并给下一小节留下清楚承接点。
   - 可用钩子类型：危险逼近、声音先入、视线看向新目标、动作未完成、道具被触发、环境异常、角色做出决定、敌人反应变化、未知生物短暂露出。
   - 如果原文最后一句出现“摄像头转动、监控亮起、有人注视、门缝移动、红点闪烁、屏幕画面、远处人影、未知声音、某物正在追踪”等隐藏观察或未来危机信号，必须视为高优先级伏笔，不得省略，必须给特写、监控视角、主角背影与摄像头同框或声音/光点提示。
   - 伏笔优先级高于普通道具动作。普通拿钥匙、按按钮、走向车辆可以合并处理；但会影响后续剧情的监控、追踪、异常物、危险视线必须单独给镜头或结尾钩子。
   - 结尾不能只是“人物继续走/继续跑/继续看”，必须有戏剧价值。
   - 动作段落结尾：停在接触点、闪避结果、受伤反应、下一轮攻击即将到来。
   - 对话段落结尾：停在听话人反应、沉默、被刺中的微表情或下一句台词前的压力。
   - 悬疑段落结尾：停在异常声音、黑影掠过、门缝变化、环境突然安静。
   - 爽点反转段落结尾：停在主角理解规则后的微笑、敌人的恐惧、危险对象露出后的新机会。
