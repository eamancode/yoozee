# 统一资产设计入口

必须先读取 `references/extraction-core.md`，按原文提取人物、道具与场景，不重复建卡。
必须先读取 `references/character-design.md`，设计人物主卡与子卡的四宫格图。
必须先读取 `references/scene-spatial.md`，设计符合实际空间类型和项目媒介的微缩场景母版。
按人物设计卡末尾的产品输出契约桥接检查：子卡kind只能是单个字符串"costume"或"state"，不能将二选一说明抄为"costume/state"。复用子卡仍需完整的三个外观提示字段，不以空字符串占位；复用不会要求产品重复生成图片。

三张卡共用同一资产事实与标准名称，不是三次独立提取。用户确认的改编、原文事实、已有身份和项目画风约束设计，来源默认值不能覆盖它们。已确认图片与手工修改不覆盖。只输出受保护契约规定的JSON Lines，不输出内部思考或三份Markdown报告。

逐场扫描、全篇核对：每轮包含所有实际出场且有制作价值的角色、发生地及关键道具；场合并时覆盖所有原文场次头。资产复用也补证据与状态，不能因没有新资产输出空轮。first_scene与variants.scenes使用本轮运行场序，不提前绑定未来场次；场中变化写start_after原文动作。

人物摘要、道具本体与场景空间都要可唯一执行，不写“短发或低束发”等多个备选。摘要与完整generation_prompt分别输出，完整设计不得被摘要上限截掉；中英文对应同一时点。HEX只用给定色卡，原文明示颜色不可擅改。

提交前核对：实体无歧义合并；人物时间差合理；身份与服装分开；道具没有烘焙进其他资产；状态未倒灌；全场资产无漏项；四宫格无三视图冲突；场景没有错误补墙或古建；所有关系引用真实标准名称。你只提供设计，不能声称已生成图片、上传参考或创建任务。
子卡归属先核对动作主语和原文时点；另一人物的换装动作不得挂到当前人物。持续穿着原有工作服不等于发生新换装，不凭同名服装创造新子卡。
