# 人物设计与四宫格提示词

来源：character-asset-prompts及intake/design/layout-platform/output参考。采用其设计方法，执行权限仍由产品授权控制。

从剧本、角色设定、已确认主卡和项目风格读取已知条件，不固定向每个人追问2～4项。缺失关键事实注明；可设计的空缺选一个合理方案并标为设计建议，不臆造关系、年龄事实或历史。外观不代表善恶，不把成人皱纹、伤疤、肮脏或高级时装作为全员默认。

选3～5个可见辨识锚点，形成精炼锁定描述；信息足够才扩展8～12条，不凑数。身份、服装、阶段与临时状态分别控制。服装先设计功能、轮廓、层次与材质可见行为，再谈纹理；不能堆砌镜头不可见的纺织术语。设计强度与媒介独立，尊重写实、三维、二维、定格或用户指定画风。

默认一张竖版2:3四宫格，两列等宽，上排38%、下排62%，浅色细十字分隔：左上正面头像；右上严格90度侧脸，默认鼻尖朝画面左、展示人物左侧面，有明确另一侧标记时以角色本地左右为准；左下从颈/衣领以下至鞋底的正面身体，头在该格外不是无头人偶；右下含完整头部发型至鞋底的背面全身，不回头。人物比例一致但允许各格按裁切目标缩放，身体用自然A姿态、双脚可见。非人角色按实际解剖适配。

同一张图的四格是同一人物、同一时间阶段、同一服装材质，不添加另一套造型。不要渲染文字标号水印，不手持独立道具。背景中性、柔和均匀光照便于识别，不改变项目媒介。禁止全局“无头”“不要重复人物”这类与四格目标冲突的负面词。

提示词顺序：版式→身份锚点→本阶段外观→服装材质→鞋饰→姿态与左右→项目画风→光线背景→跨格一致性。中文说明优先，prompt_en保留英文摘要，完整generation_prompt可用清楚的中文或语义对等英文，不混成相互冲突的两份说明。

子卡引用真实主卡图保身份，只改其明示服装、年龄阶段或状态；年龄变化不强迫发型体型永远不变，不把CEO的领带默认叠到学生身上。局部修改保留已确认部分，不擅自重做全脸或全套服装。

不编造MJ版本、采样器或CFG等渠道未支持的参数，不把源技能4000 Unicode字符阈值当所有模型上限。删冗词保身份与版式，不能静默截断关键约束。最终图仍需人工/产品验收，不能保证100%一致。多次独立生图再合成是额外计费范围，不自动展开。
首次建主卡前通读全篇，以主叙事时段最常见的干燥中性外观为基准，不能把回忆中的年轻淋湿外观设成主卡；临时雨湿和不同年龄阶段归子卡。从某场开头即适用的子卡，scenes包含该场且start_after为空；只有场中明确动作之后才改变形象时才填start_after，不把场次开头当作必须手选的中途动作。

## 主卡字段与当前场次分开

先在全篇范围选定一个默认年龄阶段和一套基准服装，再填写三个主卡字段：appearance是该默认形象的中文说明；prompt_en是同一默认形象的英文摘要；generation_prompt是同一默认形象的完整四宫格设计。三个字段的年龄、发型、衣服、干湿必须相互一致。不能中文先写西装，再用“本场为……”追加雨湿学生；也不能中文是西装、英文或完整提示词却是湿T恤。

例如，故事先出现五年前的雨夜学生，后面的主叙事长期为干燥商务形象：主卡三个字段均写主叙事的干燥商务形象；本轮雨夜学生的年龄、普通学生服、贴额湿发只写入state子卡的三个字段。first_scene仍写实际首次出场轮次；本轮scenes引用该学生子卡。不要因“本轮只写第一场”而改变主卡基准，也不要把成年基准西装再写成一个多余子卡。

design.identity_appearance仅保存跨状态身份锚点；design.clothing对应基准服装，本场差异属于variants及design.states。若当前场次不出现默认造型，照样保留默认主卡，通过子卡承载本轮实际外观。四宫格的每一格必须使用该卡自己的同一造型。

## 产品输出契约桥接

本节只澄清资产输出，不改变阶段顺序、任务权限、模型选择或图片调度。原文事实、现有身份和项目画风仍按三份来源技能处理。不要把规范用语当成新资产内容。

### 子卡种类必须二选一

JSON中kind仅允许两个完整字符串之一：服装变化写"costume"；雨湿、受伤或年龄阶段写"state"。不得写斜杠组合、数组、中文种类、占位符或其他新枚举。契约里的二选一说明不是可照抄的字段值。
label只写服装或状态的名称，不加母卡姓名或“姓名·”前缀；产品负责拼成“姓名·变体”。后续场次照抄既有label，不为同一年龄、服装和状态换一个近义名。

合法语法示意（仅演示字段形状，替换占位描述，不创建示例实体）：

```json
{"label":"本轮实际出现的标准子卡名","kind":"state","scenes":[2],"appearance":"该人物本阶段可确认的具体中文外观","prompt_en":"Complete English summary of this character and this exact state, with the four-panel layout.","generation_prompt":"该人物本阶段的完整竖版2:3四宫格设计：左上正面头像、右上严格侧脸、左下颈下正面身体、右下含头背面全身；填写该人物的身份锚点、具体年龄状态、衣服鞋饰、姿态与项目媒介，各格同一人物同一造型。","start_after":""}
```

换装时使用同样字段，将kind改为"costume"，并写出具体衣物差异。不要把"state"和"costume"拼成一个值。

### 复用母卡与复用子卡分开

复用母卡时，母卡的appearance、prompt_en、generation_prompt可以按既有复用规则留空，design仍补本场依据和状态。

variants中每一项都必须自足：无论本轮新增还是复用，label、kind、scenes、appearance、prompt_en、generation_prompt都要有效。复用子卡须沿用既有标准名、身份和已确认差异，并重述本阶段的完整四宫格设计；这三个文本字段不得留空，不只输出label和scenes，不用“同上”替代。完整重述是文本契约要求，产品仍复用已有子卡，不代表重复建卡或自动重出图片。

仅列本轮实际出现的非默认造型，不把全部已知子卡一并绑定。scenes使用给定运行场序且为正整数；整场已经适用的子卡start_after为空，仅场中明确变化才逐字引用动作。

### 先核对归属再写子卡

逐项核对“动作主体→原文动作→实际场序→变体差异”。明确主语优先，代词须回指到唯一人物；不能因为人物在同一摊位或都穿围裙，就混用动作和服装。

例如，原文是林深取围裙、系围裙，变化属于林深，不属于阿婆。阿婆后续继续穿原有工作围裙，不构成一次新的换装动作。不能把前一场动作移到数日后的场，也不能仅因需要填start_after就借用另一人物的动作。

### 输出前逐项检查

检查每个variants元素的种类是否单值、三个设计文本是否齐全、完整提示词是否明确四宫格、场序是否正确、动作主体是否属于该母卡。收到缺字段反馈时保留本轮全部资产，精确补齐该字段；不要将二选一说明改成组合枚举。保留原文证据，禁止用猜造的人物关系或换装动作填补缺口。
