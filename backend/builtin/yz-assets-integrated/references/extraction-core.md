# 原文驱动的人、物、场设计

来源：小墨character-analyzer v1.3.0，增量保留现有yz-assets-extract的证据、时序和别名修复。

先通读完整剧本，区分跨时段稳定结构、各时点状态和尚未确定的补全。第一优先原文，标记证据位置；第二为时代身份与世界观支持的推导；第三为设计建议。三者写design.evidence的kind、location、text，不把想象当事实。

人物六要素连贯成段：年龄、性别、肤色、发型发色、1～3个显著五官、服装。description不是性格评语。design.role记录身份；identity_appearance只记录跨状态辨识特征，不混入特定年龄、服装、手持物或淋湿。年龄阶段是同一人物state子卡，结合原文年数核对；主卡取常见稳定形象，其余造型按场与动作边界建子卡。日常佩戴与衣服归角色，独立使用的物件单列道具。

道具卡完整保留：类别、持有者和首次出现、轮廓、尺寸、结构、材质、配色、关键细节、用途与交互、原文依据、制作优先级、关联人物与场景、初始/中间/最终状态。body_description与图只展示当前空置本体和固定部件。橙子、桶、杯、榨汁机不要画成推车固定的一部分。后文揭示的稳定接口和按键可补初始结构；后发生的换轮、撕贴纸、胶印、长期磨亮不可提前出现。

分析完整不等于全部建卡排图：核心信物、产品、反复互动或特写为high；确需独立制作的工具容器为medium；背景或一闪而过为low，默认不排图。普通陈设可在spatial_layout保留，消耗品合理归组，不为每只橙子建卡。明确参与动作的毛巾、勺子等不能因普通就漏记。眼镜、围裙、手套、帽子一般归服装，独立交换或作为信物时再单列。

同一物体换持有者或位置不另建。旧保温杯与便携榨汁杯不是同一资产；清洗水桶与果汁保温桶不能仅因“桶”合并。aliases只收唯一定位别名，禁止杯子、机器、小伙子等泛称跨实体合并。固定零件与贴纸线索保留在所属本体，不自动另造资产。

场景以观察站位→近景地面→左右中景→纵深→实际光线顺序白描，补空间类型、边界、结构、通道、色彩和地标。移动道具只引用标准名称与位置，详情留本道具。characters/props/environments双向引用真实标准名，不能虚构生产ID。场景日夜天气通常同一空间，差异写states；实际地点改变才另建。

群众可归组，未出现且无画面制作价值的被提及人物不乱建。信息稀疏时少而准确，设计选择明确标记，不能补满固定数量。每轮保留当前场新证据与状态，即使资产已存在。

主卡选择必须在第一轮前通读全篇：主叙事时段中出现最多的、干燥中性稳定形象作为主卡，不能因为回忆段先出现就以回忆中的年轻或临时淋湿作为默认。回忆年龄、淋湿、换装分别建state/costume子卡，scenes只绑定实际出现轮次；主卡只保存稳定身份与基准服装，不抱书包、不持手机等独立道具。

道具建卡前按本体与制作用途合并：同类普通手机不按持有者分别建卡，除非原文明确其差异需跨镜识别；“抹布”“清洁抹布”等同一本体合并。人物换穿的普通围裙归服装子卡，橡皮筋、旧报纸、普通包装袋和货箱若仅承担背景/收纳用途，保留在关联与空间描述，不单独排图。普通物件出现一个动作不自动升级medium；仅需独立细节图支撑反复互动、关键动作、特写或身份线索时升medium/high。毛巾、刮勺、旧信物等有关键情节价值时仍应保留。所有道具明确production_priority。

结构化design必须遵守受保护契约：role、identity_appearance、clothing、prop_design、body_description、spatial_layout只能为字符串，不能写对象或数组；关联与证据使用契约数组。先填身份与优先级，再写完整generation_prompt，禁止因完整文案较长省略design。
