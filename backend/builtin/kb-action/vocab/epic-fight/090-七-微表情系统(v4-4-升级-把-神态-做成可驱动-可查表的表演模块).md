七、微表情系统（v4.4 升级·把“神态”做成可驱动、可查表的表演模块）
微表情是“动态博弈”的灵魂：没有微表情的高速连打只是木头人互抡。本系统把原散

落在运镜/双剑客铁律里的“眼神交锋/冷笑/

咬牙“系统化，让每一个镜头都有可被镜头捕捉、且能驱动下一步动作的真实神态。

1. 微表情四级梯度（禁止面瘫为底线）

等级 状态 表现 适用

L0 面瘫（禁） 无神、空洞、与情绪脱节 全程同一表情、眼神放空 一律禁止

L1 基础神态 有情绪但不张扬 嘴角微抿、目光专注 远景/中景铺场

L2 动态博弈神态 随攻防实时变化 锁死、冷笑、咬牙、怒意交替 攻防互换段（主力）

L3 极致微表情 情绪压到临界点 瞳孔骤缩、青筋、战意催泪、下颌紧绷至颤 绝杀/觉醒/尾

帧

2. 面部微表情要素库（按部位拆解，写提示词时直接点名）

· 眉：微蹙（蓄力专注）/ 挑眉（轻蔑挑衅）/ 拧眉压目（被压制憋狠）/ 眉峰一扬（反手

得手）

· 眼：锁死（近身兵器相交双目钉死）/ 冷冽（出手前的平静杀意）/ 睥睨（碾压态俯视）

/ 惊愕（被突袭瞬间瞳孔放大）/ 狂热（觉醒满屏

时）/ 狠厉（绝杀前）/ 眼神转厉（尾帧悬念，下一波将至）

· 嘴：抿唇（隐忍）/ 冷笑（看穿对手破绽）/ 咬牙（承压、硬稳住）/ 低吼（发力）/ 嘶吼

（全力爆发）

· 下颌：紧绷（全力戒备）/ 微抬（傲然宣告）

· 微动作：额角细汗（战损）、战意催泪（非悲伤，是极致专注的生理反应）、鼻息轻哼

（不屑）、颈侧青筋（聚力）

3. 微表情状态机（按战斗阶段自动流转，出稿时逐段标注）

战斗阶段 微表情 镜头配合

起手蓄力（0.3s 快蓄力） 专注凝神、眉微蹙、目光锁敌 CU 急推捕捉眉眼

高频交手 眼神锁死 + 嘴角紧绷，随攻防在冷冽/狠厉间切换 MCU 近景，微表情清晰

被压制顶点 怒意上涌、咬牙、额汗、下颌紧绷 CU 咬牙特写 + 急推

反击/绝杀 狠厉 + 冷笑（看穿破绽）+ 瞳孔骤缩 CU 瞳孔 + 亮度骤增

尾帧悬念 眼神转厉（不是松懈），战意催泪未干 CU 定格 0.3-0.5s（悬念，非战斗命中定

格）

4. 镜头拍法（让微表情被看见）

· CU 特写占比 10-15%，专拍眉/眼/嘴/下颌；MCU 近景占比约 30%，微表情可见且带身法。

· 微表情与动作节奏同步：攻击瞬间眉挑、命中瞬间咬牙、格挡瞬间眼神骤变——神态随

打击节拍走，不另起炉灶。

· 禁在慢动作里摆表情（与去顿帧冲突）；禁口型与台词脱节；禁同一微表情贯穿全片。

5. 微表情→动作触发逻辑（神态是动作的前置信号）

· 眼神骤变 = 格挡/闪避启动（预判对手来招）

· 嘴角冷笑 = 反手反击已构思完成（看穿破绽）

· 瞳孔骤缩 = 大招起手（能量蓄满临界）

· 眉峰一扬 = 得手确认（连击续上）
