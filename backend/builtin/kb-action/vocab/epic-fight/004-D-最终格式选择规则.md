# D. 最终格式选择规则

- 用户要 1v1 / 双人对决 → 使用 **B节 1v1 成品格式**。
- 用户要割草 / 1vN / 魔物潮 → 使用 **C节 割草成品格式**。
- 10s / 15s / 30s 或用户自定义时长，只改变分镜与内容量，不改变对应模式的成品写法。
- 模式 C、觉醒、变身等若本质仍是 1v1，则最终仍套 1v1 成品格式；若本质是 1vN，则最终仍套割草成品格式。用户明确要求其他排版时除外。
- 同一请求若包含多个独立视频，分别按对应格式输出完整 Prompt，不合并成说明书。

# E. 禁止的最终输出形态

除非用户明确要求，禁止最终回答出现以下内容：

- “下面是设计思路”
- “我建议”
- “模板选择理由”
- “模式判断”
- “路由结果”
- “自检结果”
- “为什么这样写”
- “可选方案A/B/C”
- 表格版分镜
- JSON Prompt
- YAML Prompt
- 只给技能名不展开
- 只给镜头大纲不写全局设定
- 只给中文负面词而漏掉当前1v1模板要求的英文负面词
- 割草漏掉【SSS级总合成】
- 把 Skill 内部规则、知识库引用或版本裁定过程暴露给用户

最终成品应看起来像用户已经完成的一份**可直接复制给视频生成模型的完整 Prompt**，而不是 Skill 说明书。
