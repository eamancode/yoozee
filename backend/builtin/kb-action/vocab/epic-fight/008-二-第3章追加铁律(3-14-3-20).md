3.14 瞬移系统铁律（v4.19 · 全模板可用）

总纲：瞬移 = 高频位移 + 进攻起手，0 帧瞬发、无读条、无蓄力，与“瞬步/流光位移”

并列为主角基础机动；

模式 A/B/C 全部模板可用。

五条规定：

1. 瞬移必有轨迹：起点留下配色残影/光粒（停留 0.2-0.3s 消散，属运动残留非定格，不

破去顿帧），终

点光聚凝实。禁“凭空消失再出现”（呼应负面词“人物瞬移无轨迹”）。

2. 瞬移必接动作：瞬到敌后必接背刺/肘击/剑气，瞬移闪避必接反打。禁连续瞬移不攻

击、禁把瞬移当

纯位移装饰。

3. 频率上限：常规段每秒≤2 次；爆发幕可「瞬移连打」——3-5 连瞬，每次落点不同方

位（上/下/左/

右/背后），多点残影织网围攻。

4. 视觉规格：瞬移轨迹 = 配色流体光线 / 雷弧折线 / 金色剑光；轨迹在三维空间折线分

布，不贴同一平

面。

5. 与旧资产关系：继承第 9 章③空间瞬移、3.13 流光位移、⑨紫金灵剑“超光速化流

光”；瞬移是“更

快“不是”减速“，不违反 3.7 快节奏。

3.15 单发慢镜头特许铁律（v4.19 · 全片仅 1 个）

总纲：3.7 禁慢镜头总铁律依然生效，v4.19 起每部片特许 1 个慢镜头（slow-motion），只

用于全片最高

光瞬间；除此之外任何位置仍禁一切慢放/定格/子弹时间。

五条规定：

1. 数量锁死：10s/15s/30s 任何模板，全片慢镜头 ≤1 个。写出第 2 个即质检不通过。

2. 时长：0.5-1.0s（60fps 下 30-60 帧），结束立即恢复全速，禁连续慢放、禁慢镜头套慢

镜头。

3. 位置三选一：① 尾帧绝杀命中瞬间（能量爆核扩散）；② 觉醒蜕变满屏光爆瞬间；③

超光速对撞最

大碰撞点爆发瞬间。禁用于铺垫幕/试探幕/普通连击。

4. 写法规格：慢镜头内——粒子火花悬停般缓速飞散、冲击波环缓慢扩张、发丝衣袂缓

飘、主体动作仍

清晰可见（是慢放不是定格）；慢镜头内允许全片唯一的缓推镜头。

5. 前后衔接：慢镜头前一镜必须是全速高密度动作（快慢对比拉张力）；慢镜头结束写

“猛然恢复全速

+ 冲击波二次爆发 + 受击方猛飞“。

负面词配套：第 11 章模块二“慢动作/慢镜头”保留，附注“（全片特许 1 个除外，见

3.15）”。

3.16 超光速对撞·流光来回穿梭铁律（v4.19）

总纲：双方化作两道配色流光，在战场上空超光速来回穿梭，每一次交错 = 一次碰撞爆

点；光轨在三维空

间织网，碰撞点连环爆发冲击波——“看人不看形，看光轨看爆点”。

五条规定：

1. 流光化：对撞双方化作流光（继承⑨紫金灵剑“超光速移动化作紫金流光”），本体

隐没，只见两道配

色光轨 + 残粒拖尾。

2. 来回穿梭（核心）：光轨必须折返来回而非单向——Z 字折返 / 螺旋绞缠 / 交叉八字穿

梭；一段超光速

对撞含 5-9 次交错碰撞，碰撞点高低错落三维分布。

3. 碰撞反馈：每次碰撞 = 打击感五件套满配（见 3.18）：亮度骤增 + 镜头急推/震屏 + 环状

冲击波 + 双

方流光被弹开折向 + 星火粒子迸发。

4. 运镜：FS 全景看光轨织网全貌 ↔ TRACK 跟随单条流光急推，交替使用；禁全程特写丢

空间关系

（呼应 v4.12 景别锁定）。

5. 收尾：最后一次碰撞 = 最大爆点（可动用 3.15 特许慢镜头），双方流光炸散、本体从

光中弹出、各

自滑行落地立刻续招，禁喘息站桩。

适用范围：模式 A 1vN（主角流光 vs 精英魔将流光）、模式 C 觉醒段、1vN 各割草模板高

潮段。模式 B

1v1 默认禁用（1v1 v4.19 禁对撞，见「三」）；仅当用户明示“1v1 超光速对撞版”时破

例启用，并替换绝

杀段。

3.18 全模板打击感增强铁律（v4.19 · 全部模板强制）

总纲：凡“命中”（武器交击/技能命中/拳脚命中/碰撞爆点）必须写打击感五件套。模

式 A/B/C、清屏流、流

光割草、割草六型——全部模板强制，质检逐项核对。

打击感五件套（普通命中至少写 3 项；关键命中——绝杀/对撞爆点/破防——必须 5 项

全写）：

1. 亮度骤增：命中帧画面亮度瞬间拉爆，配色闪光。

2. 镜头急推/震屏：PUSH 急推 + 高频短促 screen shake 镜头震颤。

3. 冲击波环：环形气浪/球状涟漪从命中点扩散，掀飞周围碎石尘土。

4. 受击方物理反馈：猛飞/滑行倒退/身形弓起/甲片崩裂，带惯性抛物线（呼应 3.19）。

5. 粒子火花迸发：配色星火、碎片、电弧从命中点喷溅。

辅助增强项（按需叠加）：空气扭曲热浪、低频轰鸣音画词（deep bass impact hit）、地面

龟裂从命中

点放射扩散、高速命中带马赫环。

密度要求：连击段可打包简写（“拳拳到肉，每拳命中带亮度骤增+火花迸溅”）；关键

命中单独展开五件

套。

与去顿帧关系：打击感全靠动态元素实现，仍禁顿帧/定格（3.15 特许的 1 个慢镜头除

3.19 物理引擎·真实物理光影铁律（v4.19 · UE5.4 Chaos + Lumen 落地）

总纲：全部模板画质词追加物理引擎与真实光影规格，让打斗“有重量、光有色温”。

物理五规：

1. 刚体与碎裂：碎石/瓦砾/断木被冲击波掀飞时带真实重力抛物线 + 落地二次弹跳 + 滚动

（Chaos

destruction）；禁碎片匀速飘散、反重力悬浮。

2. 惯性与重量：受击方猛飞带惯性滑行、落地铲出土痕；重武器挥动有起手重量感（仍

0.3s 内完成，不

破快节奏）。

3. 布料与毛发：衣袂/披风/发丝随动作与冲击气浪真实飘动（cloth simulation）；禁“铁块

披风”。

4. 流体与尘埃：爆炸扬尘体积化翻滚（volumetric dust/smoke）、水面/熔岩溅射带重力回

落。

5. 交互一致：踏地有尘、踩水有溅、撞墙留坑、掠草草伏——一切接触有物理反馈（呼

应 v4.14 环境因

果链）。

光影五规：

1. 全局光照：Lumen GI——技能光芒真实照亮环境与人物（金光扫亮岩壁、雷光照透云

层）。

2. 体积光：体积雾 + 丁达尔光柱（volumetric lighting / god rays），大招光芒穿尘成柱。

3. 接触阴影：人物/武器/碎片均有接触阴影（contact shadows），禁“贴图感无影人”。

4. 反射折射：冰面/水面/金属甲面实时反射技能光，冰晶折射寒光。

5. 光色一致：技能配色 = 环境染色配色（紫金雷光把战场染成紫金）；禁“技能发光但

环境不变色”。

画质词追加（英文，直接并入模板画质串）： Unreal Engine 5.4, Chaos physics destruction,

realistic rigid-body debris with gravity arcs, cloth simulation, Lumen global illumination,

volumetric lighting, god rays, contact shadows, physically-based rendering, ray-traced

reflections

负面词追加（并入第 11 章，见「七」）：反重力碎片、碎片匀速飘散、无惯性、无接触

阴影、光影不一

致、技能发光环境不变色、布料僵直、穿模。
