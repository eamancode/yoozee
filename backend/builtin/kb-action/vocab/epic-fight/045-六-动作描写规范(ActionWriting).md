六、动作描写规范（ActionWriting）
铁律 1：每句以视觉动词开头 -    ✅ 正确：横扫斩开前排 / 反身撩斩 / 蹬墙借力 / 空中三连
踢-✅ 错误：有一道刀气 / 在空中 / 地上有坑
铁律 2：特效必须挂在物体上 - ✅ 正确：剑身上红金流体纹路流动 / 拳面砸在甲壳上炸开

黑红粒子 / 脚下地面龟裂 - ✅ 错误：有火焰特效 / 画面很

炫/

到处是粒子

铁律 3：动作密度三级写法（v3.5 升级） - 常规交锋段：动作 1/动作 2/动作 3/动作 4（编

号写法，3-4 动作/秒） - 高速连击段：连击串写法，动

词密

集排布，一个镜头 6-10 个短动词串 - 灵力仙法段：连击串+灵力涌动+法阵展开+仙灵扑杀

同时进行（12-15 动作/秒）

铁律 4：动作要有物理反馈 - 挥剑 → 剑气撕开空气产生刺耳嗡鸣 - 落地 → 脚下地面炸出

环形坑洞，泥土飞溅 - 被撞 → 身体像断了线的风筝飞出

十

多米，背部护甲刮擦出火星 - 踢中 → 巨兽身体瞬间僵住，被能量冲击波震得向后仰倒

铁律 5：去顿帧的打击节拍（v3.5 关键变更，替代 v2.1 hit-stop） - 旧版（v2.1）：命中瞬间

画面定格 0.05-0.1 秒顿帧 - 新版（v3.5）：命中瞬

间

画面亮度骤增（白光暴闪 0.1-0.2s）+ 镜头急推 + 冲击波瞬间放大 + 受击方猛飞 - 节奏公

式：冲（极速靠近）→ 砸（命中爆裂+亮度骤增）→ 爆

（受击方猛飞）→ 续（下一串连击） - 禁止使用“定格”“暂停”“顿帧”“bullet

time”“slow motion”等任何停顿描述
