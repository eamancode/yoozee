# B. 1v1 / 双人对决最终输出格式（强制）

1v1、单挑、宿敌对决、高手过招、双人战斗等最终 Prompt，必须严格按以下顺序输出，**不得增删主章节、不得换序**：

【全局·画质设定】  
完整写入渲染规格、引擎、PBR、Lumen/Nanite/Path Tracing（如当前模板适用）、ACES、HDR、8K、60fps、高速动作清晰度、物理引擎、刚体碎片、布料、体积光、接触阴影、反射、CG风格、场景、环境材质、光影、画面畸变/色散、画幅比例。必须写成连续完整成品描述，不得改成参数表。

【全局·角色与特效】  
先写 A，再写 B。每名角色必须完整写外貌/服装/武器/武器材质/能量配色/身体特效/位移轨迹/瞬移残影/可用小技能。随后写特效厚度、双方能量区分、物理光影、环境受光。不得只写角色名字或简写资产编号。

【全局·核心规则与铁律】  
把当前真正生效的 1v1 战斗规则直接写进成品 Prompt，不得只写“遵循模式B/v4.19”。包括但不限于：是否零魔物、是否禁对撞、攻防有去有回、三维机动、空中连段、垂直互换、环境借力、瞬移轨迹、打击感、物理光影、运镜/画面/动作密度联动、1秒1镜、去顿帧、慢镜头规则、CU限制、尾帧规则、对话规则、核心禁止项。交锋链要直接写成：击中→格挡→卸力→闪避→反打（或用户当前指定的等价链）。

【分镜表（XX秒·1秒1镜·……）】  
分镜必须逐秒书写。每镜统一采用：  
`序号 tX-Ys｜景别·运镜｜动作+攻防+技能+物理反馈+环境反馈。`

示例格式仅用于约束排版：  
`1 t0-1s｜MS·TRACK贴地｜A滑步突进……；B横刀格挡……。`

不得改成表格；不得写“镜头一：”；不得用项目符号替代逐秒行；不得把多秒合成一镜，除非用户明确要求不按1秒1镜。

【完整负面提示词】  
最后必须保留完整负面词。1v1默认分为：  
`中文：……`  
`英文：……`

不得只写几个关键词，不得省略英文版，除非用户明确要求只要中文。

**1v1最终输出必须从【全局·画质设定】直接开始，到【完整负面提示词】结束。正文之外不追加解释、总结、建议。**
