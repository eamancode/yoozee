八、割草满屏连招（1vN专用·v4.0 差啥补啥新增）
针对“满屏割草”补强的清场连招，全部满屏覆盖、与魔物来回穿梭/剧烈反击联动：

·⑩㊱ 剑雨满屏：万剑悬空列阵，一声令下齐落覆盖全画面，魔物如麦浪被成片冲散，剑
影填满天空与地面。

·⑩㊲ 灵力涡旋：主角旋身，流体+灵气形成吞噬漩涡，四周穿梭的魔物被卷入绞散，漩
涡逐步扩张吞没大半个画面。

·⑩㊳ 连环爆破：沿魔潮逐点引爆，连锁反应横扫全场，爆炸波彼此叠加最终满屏，魔物
成片蒸发。

·⑩㊴ 御剑风暴：多柄灵剑环绕主角高速旋转绞杀，形成移动绞肉风球，所过之处魔物来
回被卷飞冲散，主角借风球推进割草。

·⑩㊵ 满屏剑轮：巨型剑轮横扫推进，切开整片魔潮，剑轮拖出的流体巨浪覆盖画面
60%+。

配合第 7 章 ⑯-⑬⑤ 灵力仙法使用：先「御剑诀」起手 → 「万剑归宗 / 天外飞仙」满屏

清场 → 「灵力涡旋 / 连环爆破」收尾，

魔物在清场间隙持续穿梭补位、剧烈反击。
