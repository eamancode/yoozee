# C. 1vN / 割草最终输出格式（强制）

割草、1vN、魔物潮、清怪、清场、群战等最终 Prompt，必须严格按以下顺序输出，**不得增删主章节、不得换序**：

【全局·画质设定】  
完整写入画质、渲染、CG风格、帧率、场景、天空/地面、雾效、体积光、整体色调、镜头畸变/色散、毛发/布料、高速动作与流光表现。必须写成连续成品描述，不得改成参数清单。

【全局·角色与魔物】  
先写：`主角｜角色名称`，完整描述发型、面部特征、饰品、服装、武器、武器材质、能量表现、位移形态、攻击表现。  
再写：`魔物｜魔物名称`，完整描述数量、密度、外观、能量核心、穿梭、扑杀、补位、被击中后的能量化表现、残骸规则。不得只写“成千上万魔物”。

【全局·核心规则与铁律】  
直接写出当前真正生效的割草规则：帧率、顿帧/慢镜/定格规则、打击感、伪一镜到底、运镜九字诀、暴力表现边界、魔物崩解方式、残骸保留、景别、超远景禁令、纯静止武器特写禁令、场景破坏、技能尺寸、人物视觉占比、动作密度、纯动作流、钟摆式穿梭、突入→斩击→脱出→另一侧突入、魔物持续补位与持续反击等。

【分镜表｜XX秒｜X技能各X秒】  
随后逐技能展开。每个技能必须使用下面的固定成品格式：

【技能①｜0-3秒】  
技能名称  
留痕：XXXX  
完整动作与技能正文……  
运镜：  
XXXX。

后续技能严格沿用：  
【技能②｜3-6秒】  
技能名称  
留痕：XXXX  
……  
运镜：  
XXXX。

每个技能正文必须把当前模板需要的内容完整写出来，包括：如何进入上一招留下的环境痕迹、如何发动、技能视觉如何展开、如何覆盖战场、魔物如何被灭敌/清屏、主角如何高速换位、平A/普通连击如何穿插（若当前模板允许）、魔物如何反击、主角如何规避、敌方攻击如何反向影响战场、本招留下什么永久痕迹、运镜如何服务发出→灭敌→清屏。

如当前割草模板启用环境因果链，则必须明确写成：  
`上一招留痕 → 本招发动平台 → 本招新留痕 → 下一招发动平台`。  
禁止多个技能互相独立、像MV拼接。

【SSS级总合成】  
割草 Prompt 必须保留这一正式章节。将整支视频重新压缩为一段连续可执行总描述，至少覆盖：时长、整体风格、伪一镜到底、运镜九字诀、人物视觉占比、核心动作类型、技能顺序、发出→灭敌→清屏、技能尺寸、环境因果链、钟摆式穿梭、魔物补位、魔物反击、主角闪避、敌方攻击反向清屏、残骸、场景破坏、尾帧、高速、去顿帧、慢镜头规则、无等待/无站桩。

【完整负面提示词】  
必须保持完整自然语言负面词写法，从“禁止：”开始逐项写清，不得压缩成几个关键词。若当前模板已有专属负面词，则完整继承并按本次资产做必要同构替换。

**割草最终输出必须从【全局·画质设定】直接开始，到【完整负面提示词】结束。正文之外不追加解释、总结、建议。**
