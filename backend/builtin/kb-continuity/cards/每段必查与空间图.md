> 来源：分镜师 4.0 · 连戏表模板、审片员（inspector）八项
> 何时读：写连戏表、画空间图、审一段候选时读

## 每段必查八项

| 项 | 查什么 |
| --- | --- |
| 人物 | 脸、发、眼镜、小特征、服装和连戏表一致；同一段里没变成另一个人；和定妆照、同场其他段并排看 |
| 台词 | 一字不差；听得懂；落在哪一秒；尾巴没被切掉 |
| 崩坏 | 手指、五官、虚影、闪烁、穿模，只在连续帧里看得出（大动作窗口每秒至少 8 帧密查） |
| 空间 | 位置、身后、视线方向对空间图；面对面两人身后不能有同一样东西 |
| 道具 | 数量、位置、状态对年份；同一画面同一件道具只能有一个 |
| 文字 | 招牌、屏幕、纸上的字逐字对；没有真实品牌；没有乱码 |
| 声音 | 不该有的音乐或人声；电平跳变；无声洞；爆音 |
| 肤质 | 鼻头额头油光；纹理过锐 |

入片前三项必须有证据文件：**同一个人**（人脸表）、**台词一字不差**（听写和字错率）、**无崩坏**（抽帧拼图）。

## 空间图（每场一张）

`
            北：{{窗 / 墙 / 门}}
 西：{{}}      {{人物 A}}（{{座位}}）   {{人物 B}}
               ========== {{桌}} ==========          东：{{}}
                      {{人物 C}}
            南：{{}}
`

- 视线：拍 A 时他朝画面左 / 右；拍 C 时朝哪边。
- 正反打各机位身后用哪张图（A 侧、C 侧各一张无人空景）。
- 道具位置。
- 跨时段的同一地方以一张布局为底，其他时段只改光线、新旧和剧情要求的新增物。

## 生成时写死的约束（编译进提示词）

- 正反打谁朝画面哪边看、每个机位身后是哪张图。
- 只拍手的写谁的手、什么袖口；有隔板、门框的近景写「边框只在两侧，不穿过人脸」。
- 背景里已有的道具不再点名；数量词不可靠，反应镜头拍紧把道具留在画外。
- 除参考里已有的字外，不出现可读文字。
- 场景参考图可能被当成每个机位的背景贴：正反打时用该机位身后那张图，不用整个场景的总图。
