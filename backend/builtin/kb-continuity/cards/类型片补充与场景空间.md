16.6 类型片专项补充
============================================================

1. 喜剧
   - 喜剧重点是反应和停顿，不是镜头乱动。
   - 使用中景建立尴尬关系，近景捕捉反应，空镜或道具特写制造反差。
   - 包袱后停半秒，让观众看到人物尴尬或得意。

2. 恐怖
   - 恐怖重点是未知、负空间、声音先行。
   - 画面一侧保留空白或黑暗区域，让观众担心那里出现东西。
   - 使用低光、门缝、走廊纵深、镜中反射、背后空间。
   - 惊吓前先安静，惊吓点用硬切或突然声音。

3. 史诗/玄幻
   - 重点是尺度、层级和仪式感。
   - 使用远景、仰拍、上升镜头、航拍、群像站位。
   - 光影可用侧逆光、轮廓光、金色神圣光、体积光。
   - 动作要先建立能量来源，再展示释放结果。

4. 短剧爽点
   - 重点是身份揭示、打脸反应、强台词、情绪反转。
   - 关键台词用中近景或近景固定，反应镜头必须给足。
   - 爽点结构：挑衅 -> 证据/身份揭示 -> 对方震惊 -> 主角冷静收束。

5. 广告/产品
   - 重点是产品识别、使用动作、结果反馈。
   - 产品首次出现必须独立镜头。
   - 使用微距、干净光线、手部动作、结果对比。
   - 情绪不能盖过产品。

16.7 场景空间连续性知识库
============================================================

1. 固定空间锚点
   - 每个场景必须有 2-4 个稳定锚点：门、窗、桌子、楼梯、祭坛、屏幕、出口、街灯。
   - 同一小节内这些锚点位置不能随意变化。
   - 镜头切换时用锚点帮助观众确认空间。

2. 光源方向连续
   - 主光来自左侧，后续镜头不要无理由变成右侧。
   - 霓虹、火光、月光、屏幕光等特殊光源必须位置稳定。
   - 若光源变化，必须写出原因：灯熄灭、门打开、车灯扫过、手机亮起。

3. 道具位置连续
   - 关键道具放在哪里、被谁拿起、什么时候掉落，必须连续。
   - 道具特写前后要能对应人物动作。
   - 武器、信件、手机、钥匙、证据不能在镜头间瞬移。

4. 人物移动路线
   - 人物从 A 点到 B 点必须有动作过程。
   - 例如：从桌边起身 -> 绕过椅子 -> 走到门口。
   - 如果镜头切掉中间过程，下一镜要写“他已经来到门口”，并用动作或衔接解释。
