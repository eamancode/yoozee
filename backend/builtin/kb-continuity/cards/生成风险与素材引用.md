16.8 AI视频生成风险控制知识库
============================================================

1. 多人同框风险
   - 多人同框容易变脸、换衣、站位乱。
   - 群像镜头不要给每个人复杂表情。
   - 重要人物用名字或 @资产明确，群演用整体描述。

2. 手部风险
   - 手指特写容易变形。
   - 手部动作要少而明确，不要写复杂连续手势。
   - 手拿道具时写清“握住刀柄”“按住信封”“扶住桌沿”。

3. 快速动作风险
   - 一镜不要写完整复杂打斗。
   - 高速动作要拆成发起、接触、结果。
   - 快速横摇和手持晃动不能同时过多，否则画面容易糊。

4. 长台词风险
   - 长台词不适合搭配大幅运镜和复杂动作。
   - 长台词要拆镜，使用说话人特写、听话人反应、道具特写填充。
   - 台词镜头要保证口型和表情清楚。

5. 光影风险
   - 不要一镜内频繁切换多种颜色光。
   - 强闪烁、闪电、警报灯要短暂使用，避免画面不稳定。
   - 光源方向和颜色必须服务剧情，不要每镜乱换。

6. 场景风险
   - 同一场景描述必须保持字面一致。
   - 不要在一个小节里塞入多个不相关地点。
   - 复杂场景先用建立镜头，不要直接特写。
   - 有河流、悬崖、门、墙、车辆、桌子等明确阻隔物时，必须说明角色和机位是否在阻隔物同一侧。角色没有跨过阻隔物，下一镜就不能出现在阻隔物另一侧。
   - 剧本未写对岸、墙外、门后、车阵另一侧有人时，画面中禁止凭空出现对侧人物或群体。需要表现空间尺度时，用空旷对岸、远山、风化石林、雾气、水流或阴影，不要生成新人物。
   - 不要把“画面背景好看”优先于空间逻辑。背景必须由角色位置和机位朝向决定，不能为了构图把远处人物挪到河对岸、门后、墙外或另一个场景。

风险控制口诀：
多人少细节，手部少复杂，动作拆因果，长词稳镜头，光源别乱跳，场景先建立。

16.9 @素材引用、首尾帧与参考资产规则
============================================================

如果用户提供 @图片、@视频、@音频，必须明确每个引用的用途，不能只写“参考@图片1”。

1. 人物参考
   - 写法：以 @图片1 的人物形象作为【角色名】。
   - 后续镜头不重复展开外貌，只写动作和表情变化。

2. 场景参考
   - 写法：场景参考 @图片3 的【地点名】。
   - 同一场景内保持空间结构、光源方向和主要锚点一致。

3. 首帧/尾帧
   - 首帧用于锁定开头构图、人物姿态和场景状态。
   - 尾帧用于锁定结尾姿态和衔接方向。
   - 写法：@图片1 作为首帧，镜头从该姿态开始；@图片2 作为尾帧，镜头结束时贴近该构图。

4. 视频参考
   - @视频可作为运镜、动作、转场、节奏参考。
   - 必须写清：参考 @视频1 的运镜节奏 / 动作编排 / 甩镜转场 / 打斗节奏。

5. 音频参考
   - @音频只能作为旁白音色、角色音色、环境音或动作音效参考，禁止作为BGM、配乐或背景音乐参考。
   - 必须写清：环境声参考 @音频1；旁白音色参考 @音频2；角色音色参考 @音频3。

6. 素材数量控制
   - 单条提示词里不要引用过多素材。
   - 优先引用对画面稳定最重要的人物、场景、关键道具。
   - 没有必要时，不要每个镜头都重复引用同一素材。
