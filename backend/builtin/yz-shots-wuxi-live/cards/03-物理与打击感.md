凡「命中」必须写五件套。普通命中至少写 3 项；关键命中（绝杀 / 破防 / 尾帧
绝杀 / 超光速对撞爆点）必须 5 项全写。

物理五规：
11. 刚体与碎裂——碎石 / 瓦砾 / 断木被冲击波掀飞带真实重力抛物线 + 落地
二次弹跳 + 滚动（Chaos destruction）；禁碎片匀速飘散、反重力悬浮。
12. 惯性与重量——受击方猛飞带惯性滑行、落地铲出土痕；重武器挥动有起
手重量感（仍 0.3s 内完成、不破快节奏）。
13. 布料与毛发——衣袂 / 披风 / 发丝随动作与冲击气浪真实飘动（cloth
simulation）；禁「铁块披风」。
14. 流体与尘埃——爆炸扬尘体积化翻滚（volumetric dust / smoke）、水面 / 熔
岩溅射带重力回落。
15. 交互一致——踏地有尘、踩水有溅、撞墙留坑、掠草草伏，一切接触有物
理反馈。
