## 一、3.22 2D 闪帧补丁

### 1. 总则

仅在「重击造成伤害·喷血」瞬间插入 **1-3 帧高对比 2D 闪帧（flash frame）**——肉眼难以逐帧捕捉、潜意识清晰可感，是动画打击重量感的经典手法。闪帧**无文字、无拟声词、无漫画描边、不占时长、不减速**，纯画面闪动，不破电影连续感。

### 2. 闪帧五型

| 型号 | 名称 | 画面构成 | 帧数（60fps） | 适用力度 |
|---|---|---|---|---|
| **F1** | 白闪 | 全画面白光爆闪 | 1-2 帧 | P3/P4 爆点 |
| **F2** | 黑闪 | 全画面瞬间切黑 | 1-2 帧 | P2/P3 重击力量感 |
| **F3** | 负片闪 | 画面反色（负片效果） | 1-2 帧 | P3 能量命中/技能暴击 |
| **F4** | 剪影闪 | 高对比黑白剪影（角色黑色剪影+背景白爆，或反相） | 2-3 帧 | P4 绝杀/终结技 |
| **F5** | 单色闪 | 全画面瞬间染主角配色 | 1-2 帧 | P2/P3 配色强化/觉醒 |

### 3. 帧数规格（硬性）

- 单闪 **1-3 帧**（60fps 下 16-50ms；30fps 项目按 1-2 帧处理）
- **禁超过 3 帧**——超过即被肉眼识别为「画面错误/剪辑事故」
- 闪帧嵌入所属镜头内部，**不减速、不暂停、不占独立镜位、不改变镜头时长**

### 4. 触发条件（继承 v6.1 力度体系）

必须 **同时** 满足：
- ① 命中（打击感五件套≥3 项）
- ② 力度 ≥ P2（v6.1 力度分级）
- ③ 受伤等级 ≥ L1（3.21 能量化伤痕谱）
- ④ 见血启用（{见血则加}）
- ⑤ 本片「2D 闪帧」开关 = 启用（**v6.2 默认启用**）

力度与选型联动：
- **P2 中击**：可选触发，限 F1/F2/F5 轻量型
- **P3 重击**：必触发，限 F2/F3 中量型
- **P4 暴击**：必触发，用 F4 剪影闪 或 **双连闪**（F2+F1 / F3+F1，两型各 1-2 帧连发）

### 5. 配额

- 闪帧极短不占时长，按命中次数配额：**每次 P2+ 命中 ≤1 闪**；P4 可双连闪
- 同一镜头内 ≤2 闪
- **全片无个数上限**（取代 v6.0 漫画冲击帧 1-3 个限制）——但每次闪光必须对应一次 P2+ 命中，禁无命中空闪

### 6. 衔接方式

- 无需滤镜化/转场——**闪帧本身即衔接**
- 嵌入链：命中帧（五件套）→ 闪帧 1-3 帧 → 受击反馈帧（3.24 R 级），一气呵成不中断

### 7. 与 3.15 慢镜头

- 慢镜头内允许 **1 次 F4 剪影闪**（绝杀点），与慢镜头不冲突
- 慢镜头外闪帧按常规触发

### 8. 配色锁定（F5 单色闪专用）

| 主角配色 | F5 闪色 |
|---|---|
| 红金橘 | 金闪 |
| 青蓝金 | 青闪 |
| 紫金雷 | 紫闪 |
| 银白风 | 白闪（带银调，与 F1 区分） |
| 玄金仙灵 | 玄金闪 |
| 黑红 | 红闪 |

### 9. 天气×闪帧联动（7 种）

| 天气 | 闪帧特殊处理 |
|---|---|
| 暴雨 | 闪帧带雨幕高亮反光 |
| 暴雪 | 闪帧带雪粒爆亮点 |
| 雷暴 | 闪帧与雷光爆闪同步 |
| 沙暴 | F4 剪影带沙粒轮廓 |
| 日落金光 | F4 剪影染金边 |
| 极光夜 | F3 负片带极光色带 |
| 雾锁云海 | 闪帧穿雾成瞬时光柱 |

### 10. 与参数表整合（替换 v6.0 三字段）

| 参数 | 说明 | 本片示例 | 可替换值 |
|---|---|---|---|
| **2D 闪帧** | 是否启用 | 启用（v6.2 默认启用） | 启用 / 禁用 |
| **闪帧选型** | 按力度自动 | P2→F1/F2/F5 · P3→F2/F3 · P4→F4 或双连闪 | 自动 / 手动指定 |

> v6.0 的「冲击帧位置」「冲击帧配额」两字段**废止**——闪帧嵌入命中帧内部，不占独立位置、不按片配额。

### 11. 与分镜骨架整合（嵌入写法）

v6.0 的「[2D 冲击帧] 0.4s 独立段」写法**废止**，改为嵌入写法：

```
镜 N｜{时间}｜{景别+运镜}｜{站位}｜{命中五件套满配·P 级} → [嵌入 2D 闪帧 {型号} {帧数}] → {R 级受击反馈}｜…
```

镜头时长按「1 秒 1 镜」正常计算，**闪帧不另占时长**。

### 12. 画质词（替换 v6.0 冲击帧画质词）

```
flash frame, white flash, black flash, inverted negative frame, high-contrast silhouette flash, single-color impact flash, subliminal impact frame
```

### 13. 负面词（替换模块十五·v6.2）

## 二、四·0 剧本层补丁（来自文件二·短剧编剧·仅模式 D 启用）

> 仅在「模式 D·短剧分镜」启用时使用。本节与原【四、分镜骨架】叠加使用，不替换原结构。**模式 D 启用时，v5.0「成片零台词、零战吼、零拟声」铁律（对话系统整体失效）豁免——短剧可有台词与对话；模式 A/B/C 该铁律照常生效，其余铁律全部不变。**

### 1. 主控思想

格式：一句话（价值 + 原因）
- 例：「温暖击穿冷漠，因为他看穿了惩罚背后的求救。」
- 例：「正义获胜，因为主人公比恶势力更狡猾、更顽强。」

### 2. 价值负荷

| 字段 | 取值 |
|---|---|
| 开端价值 | 正面 / 相反 / 矛盾 / 负面之负面 |
| 终局价值 | 与开端相反 / 相同（决定正负结局） |
| 价值翻转次数 | ≥3 次 |

### 3. 短剧五部分 → 打斗分幕映射

| 短剧结构 | 时间区间 | 打斗分幕 | 价值翻转 |
|---|---|---|---|
| 激励事件 | 0-3s | 起手段 | 平衡打破（正→负或负→正） |
| 进展纠葛 | 3-15s | 技能释放 + 技能追击 | 负价值递进（→矛盾） |
| 危机 | 15-24s | 合围/压制 | 负面之负面逼近 |
| 高潮 | 24-27s | 最终命中 + 慢镜头 | 绝对而不可逆转 |
| 结局/钩子 | 27-30s | 尾帧悬念 | 不可避免又出乎意料 |

> 对应关系：短剧五部分与 v5.0 节奏行六段一一对应——激励事件 = 起手(0-3)、进展纠葛 = 技能释放+技能追击(3-15)、危机 = 合围/压制(15-24)、高潮 = 最终命中·慢镜头(24-27)、结局/钩子 = 尾帧悬念(27-30)。两套命名同指一条时间轴，出稿时任选其一引用，不重复计算。

### 4. 蒸馏卡字段（七选一）

| 卡 | 名称 | 用途 |
|---|---|---|
| A | 礼貌对话/权力反转 | 角色表面对话实则争夺控制权 |
| B | 延迟危险揭示 | 危险存在但角色未确认 |
| C | 熟悉空间隐藏层 | 平凡位置藏有第二现实 |
| D | 压抑情感/欲望阻断 | 想说但说不了 |
| E | 训练痴迷升级代价 | 重复追求完美渐次消耗 |
| F | 追逐动作压缩节奏 | 目标清晰障碍不断 |
| G | 误导解读反转重写过去 | 观众重新评估早期画面 |
| H | 多人工作流/受控混乱 | 多角色同时行动 |

### 5. 短剧自检 10 项（模式 D 必查）

1. 前 3 秒是否有钩子？删掉开场后观众是否会错过任何必要信息？
2. 激励事件是否打破平衡并提出戏剧大问题？
3. 每个场景开篇价值与结尾价值是否异号？（相同→删除或重写）
4. 每个节拍是否强似上一个？有无重复循环？
5. 转折是否靠动作或揭示，而非解说？
6. 危机是否为真正的两难（两善或两恶），而非善恶/是非之间的假选择？
7. 高潮是否绝对而不可逆转？是否「不可避免而又出乎意料」？
8. 对抗力量是否强到让主人公开场即战败狗？负价值是否推进到位？
9. 有无中点之后的新巧合？结局是否靠巧合？
10. 结尾钩子（系列剧）：本集最后一个画面是否让「接下来会发生什么」灼烧观众？

## 一、3.23 景别+站位全模板强制铁律

### 1. 总则
所有模板（1v1 / 1vN / 觉醒 / 巨兽 / 双剑客 / 仙法清场）的分镜骨架，每镜除【景别+运镜】外，必须显式写出【站位】。站位缺失 = 该镜不合格，重写。

### 2. 站位四要素（每镜必写）

| 要素 | 取值 | 说明 |
|---|---|---|
| ① 画面位置 | 画左 / 画中 / 画右 + 前景 / 中景 / 背景 | 角色在构图中的二维位置 |
| ② 朝向 | 面向镜头 / 背向 / 侧向 / 相对 / 相背 | 身体朝向与双方相对关系 |
| ③ 距离 | A-B 直线距离（米，精确到 0.5m） | 必须与景别匹配 |
| ④ 高度关系 | 同高 / A 高 B 低 / A 空 B 地 / A 站 B 倒 | 俯仰角与权力位对应 |

### 3. 站位语法模板

```
{A 画左中景·面向右·距 B 2m·同高}
{B 画右前景·背向镜头·距 A 0.5m·A 站 B 倒}
{A 空中·俯冲姿态·距 B 5m 迅速逼近·A 高 B 低}
{B 画中央·仰面半跪·距 A 1m·A 高 B 低}
```

### 4. 景别×站位匹配规则
- CU/MCU：距离 ≤2m 或无第二人入画（写「单人·无第二人」）
