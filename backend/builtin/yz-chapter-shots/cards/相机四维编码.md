# 相机四维编码（Camera Codec，速查）

> 来源：seedance2-prompt-skill camera-codec，yoozee 2.x 镜头表契约 `cam`。

## Z 距离 = 景别（必须一致）

| Z | 景别 | 典型焦段 |
| --- | --- | --- |
| Z1 | 大特写（眼睛、手、物件局部） | 85～100mm |
| Z2 | 特写（脸、一只手连道具） | 85mm |
| Z3 | 近景（头颈肩） | 85mm |
| Z4 | 中近景（胸口以上） | 50mm |
| Z5 | 中景（腰以上） | 50mm |
| Z6 | 中全景（膝以上） | 35mm |
| Z7 | 全景（全身带环境） | 35mm |
| Z8 | 远景（人小环境大） | 24～35mm |
| Z9 | 大远景（人是一个点） | 24mm |

## Y 高度

Y1 虫视仰拍 ｜ Y2 仰拍 ｜ Y3 微仰 ｜ Y4 平视（默认）｜ Y5 微俯 ｜ Y6 俯拍 ｜ Y7 顶视 / 鸟瞰

## X 方位

X1 正面 ｜ X2 侧 45 度（对话默认）｜ X3 侧面 90 度 ｜ X4 背面

## F 镜头属性

`lens_mm`（24 / 35 / 50 / 85）、`dof`（shallow 浅 / deep 深 / rack 拉焦）、`identity`（pov 主观 / ots 过肩 / voyeur 偷窥 / mirror 镜面）、`geometry`（dutch 荷兰角 / symmetry 对称 / leading 引导线 / frame 框中框 / negspace 留白）。

## move 运镜枚举（最多两项；fixed 不与别的同列；push 与 pull 不同列）

fixed 固定 ｜ push 推近 ｜ pull 拉远 ｜ crane_up 升 ｜ crane_down 降 ｜ truck 横移 ｜ pan 摇 ｜ tilt 俯仰摇 ｜ roll 滚转 ｜ zoom 变焦 ｜ rack_focus 拉焦 ｜ track 跟拍 ｜ orbit 环绕 ｜ spiral 螺旋 ｜ handheld_micro 手持微晃 ｜ handheld 手持 ｜ handheld_violent 手持剧烈 ｜ dolly_zoom 滑动变焦 ｜ snorricam 主体稳定背景晃 ｜ jib 摇臂 ｜ fpv 穿越 ｜ one_take 一镜到底

禁令：Z1～Z3 不用 orbit / spiral / roll；S1、S2 小空间不用大远景、远景、Y7、升降；X 型窄道不用横移、拉、环绕、变焦、摇臂。

## 摄影机跟情绪（camera_emotion）

焦点人物愤怒 → handheld_jittery；冷静 → handheld_smooth；悲伤 → handheld_low_slow；震惊 → static_then_push；解脱 → static_then_pull。写 `{"focal": "人物", "type": "…"}`。

## 对话场的默认排法

第一个人物镜用中景 / 中全景 / 全景交代谁在场与站位；之后正反打 A（机位在甲身后看乙）与 B（机位在乙身后看甲）交替，X2 为主；同一主体相邻两镜景别至少跨两级，或 X / Y 改变；连续同景别、同运镜不超过两镜；插入镜（手、道具）用 non_person，Z2，Y5 或 Y6。
