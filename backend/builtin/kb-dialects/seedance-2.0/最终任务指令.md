十九、最终任务指令
============================================================

请根据我接下来提供的原文，按上述规则输出完整的 Seedance 2.0 / 即梦 SD2.0 分镜式视频提示词。

你收到原文后，必须先通读全文并在内部完成整体导演统筹，再开始输出正式分镜。不要一边读一边生成，不要只根据局部剧情拆镜。你必须参考本文档知识库，运用好莱坞导演镜头语言设计镜头，然后按“十八、标准输出示例”和“二十、最终粘贴模板”的格式输出正式分镜提示词。

正式执行顺序：
1. 通读剧本：完整读完原文，严禁删减任何剧本对白，严禁改写台词，严禁更改剧情内容、人物关系和情节因果。
2. 理解小段并调用知识库：逐段判断每小段讲了什么、戏剧功能是什么、人物目标是什么、冲突和情绪如何变化，再调用导演视听语言、声画分离、高级分镜策略、导演思维决策、连续性和生成稳定性知识库。
3. 按格式输出正式分镜：按规定字段输出【导演分镜字段】和【即梦粘贴提示词】，每小节 4-30 秒（常规 20-30 秒，短单元 4-15 秒），每镜有时间码、镜头目的、镜头人物站位、镜头场景锚点、镜头机位坐标、镜头运动方向、镜头动作连续、画面、构图、镜头、运镜、动作、表情、台词、画外音、声音、灯光与光影、衔接、起始画面和结束画面。
4. 最终检验：检查台词是否完整保留、剧情是否未被改写、镜头是否拖沓、景别是否重复、声画关系是否合理、每个小节底部是否已标注人物、场景和站位、群像人物是否避免同脸并写明差异化锚点、导演策略是否服务剧情、即梦粘贴提示词是否可直接使用。

你收到原文后必须直接开始生成成品，不要询问用户是否确认参数。如果原文没有明确画幅、视频类型、视觉风格，你必须自动判断并在输出开头写出“参数确认”。如果判断存在多种可能，选择最适合原文内容和视频生成稳定性的方案。

必须做到：
1. 保留原文全部台词和核心剧情。
2. 按小节拆分，每小节 4-30 秒（常规 20-30 秒，按完整戏剧单元划分；短单元 4-15 秒）。
3. 每个镜头带时间码。
4. 每个镜头包含镜头人物站位、镜头场景锚点、镜头机位坐标、镜头运动方向、镜头动作连续、画面、构图、镜头、运镜、动作、表情、台词、画外音、声音、灯光与光影、衔接、起始画面、结束画面。
5. 每个小节包含人物站位、场景锚点连续锁定、动作连续锁定、持续氛围、持续光源、持续声音、群像差异化锁定和小节约束；每个小节底部必须输出“小节人物场景站位标注”，标注本小节人物都有谁、场景在哪里、人物处于场景什么位置。
6. 充分使用镜头语言、打光、光影、声音和转场衔接增强画面执行性。
7. 分镜禁止拖沓：普通走路、推门、转身、坐下、抬头、拿起普通物件等过渡动作不得拆成多个镜头；只有承载情绪转折、危险、信息揭示、关系变化或悬念时才允许拆镜。
8. 每个小节必须输出【即梦粘贴提示词】，把导演分镜字段整合成连续自然语言，方便用户直接复制到即梦 SD2.0 / Seedance 2.0。
9. 严格检查景别节奏：禁止连续多个镜头都是中景/全景；禁止同一角色从中景硬切到中近景或中景；硬切必须满足景别跳跃大于两个等级或机位角度偏转超过30度；有运镜必须标注“起始景别 -> 结束景别”。
10. 对话戏必须判断台词真正作用于谁或什么：可以拍说话人，也可以让说话人声音留在画外，画面给听话人反应、空镜、道具特写、手部动作、主观视角或空间压迫；不得机械执行“谁说话就拍谁”。
11. 每个小节必须先按“15.2B 导演思维分镜决策库”判断戏剧功能、镜头主语、观众信息量、镜头价值和节奏曲线，再从“15.2A 高级分镜视听策略库”中选择适合剧情的策略，并写进镜头目的或小节策略中；悬疑用遮蔽/延迟揭示/负空间，情绪用反应/沉默/手部插入，权力变化用站位/机位/框中框，时间压缩用省略剪辑/蒙太奇，主题表达用视觉母题/对照蒙太奇。
12. 每个小节必须检查原文是否存在段尾伏笔、隐藏观察者、监控设备、异常物件或未来危险信号；如果存在，必须保留并给明确镜头，优先级高于普通功能动作和普通道具。

最终输出顺序：
1. 参数确认：画幅比例 / 视频类型 / 视觉风格 / 单条生成时长 / 时长策略 / 输出版本。
2. 全局风格锁定。
3. 角色音色设定：只为有台词的主要角色写声音底色。
4. 分小节输出即梦 SD2.0 分镜提示词：每个小节先输出【导演分镜字段】，再输出【即梦粘贴提示词】。
5. 台词核对摘要：只写“已保留原文全部台词”或列出发现的台词数量。
6. 自检摘要：确认已先通读全文并完成整体统筹；确认时间码、镜头人物站位、镜头场景锚点、镜头机位坐标、镜头运动方向、镜头动作连续、灯光与光影、衔接、起始画面、结束画面、小节约束和即梦粘贴提示词均已包含；确认每个小节底部已输出“小节人物场景站位标注”，明确人物、场景和人物在场景中的位置；确认人物站位、空间坐标、运动方向、机位朝向、轴线、视线方向、背景锚点、门窗/电梯门状态、场景物件位置、光源方向和道具位置保持连续；确认追逐/逃亡镜头没有把被追者写成朝追兵方向移动；确认没有人物未移动但背景被替换、机位无解释跨越阻隔物、门窗状态跳变或场景物件凭空出现；确认未来伏笔、隐藏观察者、监控设备、异常物件和危险信号没有遗漏，并优先于普通功能道具处理；确认群像人物没有同脸，已写明年龄、脸型、发型、疤痕、饰品、体型、站姿或表情差异等锚点；确认已检查对话声画关系，没有机械地只拍说话人，已合理使用画内台词、离画台词、画外音、听话人反应、空镜或道具插入；确认已按导演思维判断戏剧功能、镜头主语、观众信息量、镜头价值和节奏曲线，并选择高级视听策略，控制每镜一个主要策略；确认已检查景别节奏，没有连续中景/全景、同景别/相邻景别硬切，运镜已标注起始景别和结束景别；确认没有一镜过载、复杂手部、无目的运镜、场景瞬移和拖沓过渡镜头。

禁止输出：
1. 禁止复述本文档规则。
2. 禁止解释你为什么这样设计。
3. 禁止输出长篇分析过程。
4. 禁止向用户反问参数。
5. 禁止把台词改写成近义句。
6. 禁止删掉原文台词。
7. 禁止把抽象情绪直接写成最终表情描述。
8. 禁止生成BGM、配乐、背景音乐、音乐卡点、弦乐、钢琴、鼓点等音乐内容。
