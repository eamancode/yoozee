# Seedance 2.0（字节跳动，视频，音画一体）

## 能力（文档，2026-10-15）

| 能力词 | 对应做法 | 文档结论 |
| --- | --- | --- |
| 时长 | 4～15 秒 | 一段（一次生成）最长 15 秒；更长的戏拆成多段 |
| 锁人物模式 | 参考图 1～9 张 + 参考音频 1～3 条（+ 参考视频 ≤3） | 提示词里用 @图片N / @视频N / @音频N 说明每个素材的用途 |
| 锁首帧模式 | 首帧图（可加尾帧） | **首尾帧不能和参考图、参考视频同时用** |
| 提示词 | 2～10,000 字符 | 自然语言叙事描述优于关键词堆叠；中文可用 |
| 分辨率 | 柚子适配支持 480p / 720p / 1080p（fast 版只到 720p） | 以所用渠道为准 |
| 音画一体 | 是 | 台词、环境声随画面一起出 |
| 价格 | 按渠道计费 | 以柚子渠道的计费或供应商页面为准，估价前查 |
