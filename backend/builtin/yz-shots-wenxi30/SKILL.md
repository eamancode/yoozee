0.1、即梦 / Seedance 官方格式校准
============================================================

根据即梦官网与 BytePlus ModelArk 的 Dreamina Seedance 2.0 prompt guide 页面，可确认以下方向：

1. 即梦支持中文提示词创作，语言模型输出必须优先使用清晰中文，不要堆英文关键词。
2. 即梦支持文生视频、图生视频，并强调流畅运镜、自然动态、速度变化和首尾帧可控。
3. Seedance 2.0 / 即梦视频提示词更适合自然语言叙事描述，而不是只有表格字段或关键词堆叠。
4. 即梦 SD2.0 / Seedance 2.0 单条连续生成上限为 30 秒。10 秒以上的视频段落适合使用分时段描述，分段按总时长等比切分，不要固定套用四段：15 秒以内可按 0-3秒、3-6秒、6-10秒、10-15秒；20-30秒建议切成5-7段，并在中段保留一个转折节点。
5. 每条生成任务应围绕一个连续叙事段落，不要在一条提示词里塞入无关场景。
6. 素材引用必须说明用途，例如 @图片1 作为人物参考、@图片2 作为场景参考、@视频1 作为运镜参考、@音频1 作为环境声/旁白音色/角色音色/动作音效参考；禁止把 @音频 用作BGM或配乐。

用于直接复制到即梦 SD2.0 / Seedance 2.0。它必须是连续自然语言，按时间段描述画面，不要像表格一样零碎。它要包含：
素材引用声明 + 场景环境 + 人物动作 + 运镜方式 + 景别机位 + 光影氛围 + 台词/画外音/声音 + 转场衔接 + 生成约束。

- 多镜头式：一节内拆6-10个镜头，用时间段描述切；适合信息密集、多人对话、动作链复杂的小节，稳定性最好。
- 长镜头式：单镜20-30秒连续运镜调度，零内部切换；适合单一主体、情绪连续、空间完整的小节（一次完整的沉默对峙、一段连续奔跑）。使用长镜头时必须额外锁定：运动路径连续、被摄主体始终在焦平面内、光源方向不跳变、背景锚点不替换。
- 选择依据：本小节主语是否单一、动作是否连续、是否有必须让观众同步发现的信息。主语单一且动作连续 → 长镜头；主语多、信息密 → 多镜头。

情绪词规则（台词情感标注白名单，禁止越界）：
- 可用：不耐 / 防备 / 敷衍 / 托 / 转嫁 / 权衡 / 撑住 / 撤温 / 试探 / 克制。
- 禁用：咆哮 / 怒吼 / 激动 / 愤怒 / 崩溃 / 歇斯底里。
- 情绪升级优先表现为「撤温」（变冷、变快、变低、变随意），不要升高音量。

全局风格锁定写法：
全片保持【视觉风格】，画面具有【电影级构图 / 动漫电影质感 / 稳定3D角色一致性 / 流畅镜头运动 / 统一色彩基调】。人物形象、服装、妆发、场景空间、关键道具和光源方向保持连续一致。动作符合物理规律，台词口型同步，避免人物变脸、肢体变形、服装跳变、场景结构变化、光源方向混乱、镜头突然漂移、字幕、水印和无关文字。
