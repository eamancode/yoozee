# 示例 02｜2D 动漫轨：短片《纸飞机》u1

本示例为原创演示，没有参考图，外观全部由文字承担。整场叙事 12 秒，一个单元装完。片种为诗意短片，按 S3 第 4.2 节的片种预设偏离默认的短剧档，使用文艺档（P16），示范"怎样偏离默认节奏"。

## 单元头

```
### 单元卡 s01-u1｜总时长 13 秒（叙事 12 秒 + 交接 1 秒）｜3 镜｜节奏文艺档
事件链：犹豫 → 折纸飞机 → 放飞（价值：犹豫 → 放手）
节奏偏离：片种为诗意短片，圣经卡"镜头性格"预设为文艺档；每镜 4 秒
情绪变化链：犹豫 → 下定决心 → 释然
第一注意力：镜头1 信纸；镜头2 她的手；镜头3 飞走的纸飞机
空间地图：傍晚的学校天台；地标——齐腰高的绿色铁栏杆、远处的海；摄影机在阿遥右前方；夕阳在画面右上方
结束状态：阿遥站在栏杆前画面左侧，手放在栏杆上，望向画面右上方；纸飞机是天空中的一个小白点
```

## 粘贴提示词

```
13秒，横屏16:9，二维手绘动画质感，4个镜头，只在指定切点硬切，摄影机不自行加切。

全局设定：二维手绘动画，线条干净有轻微粗细变化，赛璐璐平涂配两层阴影，背景为水彩质感的手绘，色彩明亮通透，人物表情可适度夸张，动作有清晰的预备与收势。傍晚的学校教学楼天台，齐腰高的绿色铁栏杆，栏杆外是一片低矮的住宅屋顶和远处的海，天空从橙粉过渡到青紫。
阿遥：16岁女生，黑色短发齐耳，刘海被风吹乱，大眼睛，个子娇小；穿白色水手服配深蓝领巾，领巾被风吹向画面左侧。
空间：摄影机在阿遥的右前方；阿遥站在天台栏杆前，画面中央偏左，身体朝向画面右侧的海；夕阳在画面右上方。

首帧：中景，阿遥双手捏着一张写满字的信纸，低头看着，风把信纸的一角吹得翻起。

镜头1（0–4秒｜中景 47° 眼平 固定机位｜犹豫）
阿遥咬住下唇，双手把信纸捏出几道皱褶，随即又抚平。她深吸一口气，肩膀先往上提，再慢慢放下。风吹动她的刘海和领巾，向画面左侧飘。

镜头2（4–8秒｜特写 29° 略俯视 固定机位｜下定决心）
阿遥的双手利落地把信纸对折、压出折痕、再折出两只机翼，指尖在折痕上用力一划，随即把折好的纸飞机举到眼前。她的眼睛里映出夕阳的一点高光，嘴角轻轻抿紧后松开。

镜头3（8–12秒｜全景 84° 低角度仰拍 摄影机随纸飞机向画面右上方缓摇约2 km/h｜释然）
阿遥向前跨出半步，手臂向后一收作预备，随即把纸飞机向画面右上方掷出。纸飞机划出一道上扬的弧线，越过栏杆飞向海的方向，在橙色天空里变成一个小白点。阿遥的手臂停在半空，然后慢慢放下，搭在栏杆上，脸上露出一个小小的笑，头发和领巾随风扬起。镜头摇到纸飞机后定住。
各镜头内焦段不漂移。

结束状态：阿遥站在栏杆前画面左侧，双手搭在栏杆上，望向画面右上方；纸飞机是天空中的一个小白点。

镜头4（12–13秒｜全景 84° 高位45度斜俯 固定机位｜站位交接）
在第12秒从上一镜硬切到高位45度斜向下俯视的全景。摄影机位于阿遥正面一侧、栏杆外的高处，阿遥从头顶到鞋底完整入画，脸部正面四分之三清晰可辨；绿色铁栏杆和天台地面同时入画。阿遥保持上一刻的位置、朝向与姿态，只有头发、领巾随风的自然微动，嘴唇闭合；画面稳定保持完整1秒。

布光：夕阳从画面右上方照来，暖橙色，人物面向夕阳的一侧被染成暖色，背光一侧是青紫色的阴影，边缘有一条明亮的轮廓光；整体高调明亮。
声音：持续的天台风声一层；信纸被捏皱时清脆的纸声；折纸时指尖划过折痕的沙沙声；掷出时短促的破风声；远处隐约的海浪声。本段不使用背景音乐。

正向锁定：天台上只有阿遥一个人；全程只有一张信纸，折成纸飞机后飞走；阿遥始终在栏杆内侧。画面干净，无字幕、水印与边框。
```
