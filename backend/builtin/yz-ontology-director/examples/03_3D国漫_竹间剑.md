# 示例 03｜3D 国漫轨：短剧《竹间剑》第 3 集 s05

本示例为原创演示。整场 s05 叙事约 24 秒，含打斗，属于高复杂度单元，叙事封顶 25 秒（P13）。N = ⌈24 ÷ 25⌉ = 1，整场合并为一个单元。打斗段用紧档，发现家徽处用停留档，其余为短剧档。

## 单元头

```
### 单元卡 s05-u1｜总时长 25 秒（叙事 24 秒 + 交接 1 秒）｜10 镜｜节奏短剧档
事件链：听声 → 连挡三箭 → 发现家徽 → 认出仇人 → 竹梢黑影一闪 → 转身迎敌（价值：被追杀 → 知道仇人是谁，并且仇人就在附近）
节奏分段：0–8 秒 紧档（打斗）；8–14 秒 停留档（发现与认出）；14–21 秒 短剧档（新威胁）；21–24 秒 落地
具名主体：沈砚、长剑、箭（竹梢黑影不具名）
空间地图：雨中竹林小道；地标——粗竹、青石板小道、雾中远竹；摄影机在小道右侧；冷箭从画面右后方射来；黑影出现在画面右上方远处的竹梢
景别分布：特写/近景 6 镜，中景 3 镜，远景 1 镜
结束状态：沈砚站在小道中央，身体转向画面右侧的竹林，右手持剑、剑锋斜指地面；那支带家徽的箭插在腰带上；一支断箭落在左侧竹竿下，一支箭钉在身后的石板里
```

## 粘贴提示词

```
25秒，横屏16:9，三维国风动画质感，11个镜头，只在指定切点硬切，摄影机不自行加切。

素材映射：@图1 为沈砚。

全局设定：三维国风动画，角色皮肤与布料有真实材质和次表面散射，体积光穿过雾气形成光柱，水墨晕染的远景，动作有重量感，武打带拖影与气流，色调以青绿、墨黑和赤金为主。雨中的竹林小道，竹竿粗如手臂、密集挺立，地面是湿滑的青石板与落叶，雾浓度30%，20米外的竹子只剩淡墨色轮廓。
沈砚：25岁男性，剑眉，高束马尾，左颊一道浅疤，身形修长；本段穿墨黑交领长衫，腰束赤金色腰带，长衫下摆被雨打湿，背负一把乌鞘长剑。与@图1一致。
空间：摄影机在小道的右侧；沈砚站在小道中央，面朝画面左侧的小道深处；冷箭从画面右后方的竹林里射来。

首帧：近景，雨水从沈砚的眉骨滑下，他的右耳微微偏向画面右侧。

镜头1（0–2秒｜近景 29° 眼平 固定机位｜听声）
沈砚的眼睛向画面右侧一转，右手已经握住背后剑柄，指节收紧。远处竹叶被什么东西划破，发出一声短促的嘶响。

镜头2（2–4秒｜中景 63° 低角度 固定机位｜第一箭）
沈砚骤然转身拔剑，剑身出鞘带出一道银色弧光，剑锋迎上第一支箭，把箭杆从中劈断，断箭撞上左侧竹竿弹开，落在石板上。

镜头3（4–6秒｜中景 63° 低角度 固定机位｜第二箭）
他脚步不停，顺势回腕，剑背磕飞第二支箭，箭钉进身后的青石板，石屑溅起，金属撞击声压过雨声一瞬。

镜头4（6–8秒｜近景 29° 眼平 固定机位｜第三箭）
几乎同一瞬，他侧身让过第三支箭的箭头，左手一把攥住箭杆，箭尾在掌心里震颤。长衫下摆甩出一圈水珠，晚于身体半拍落下。

镜头5（8–11秒｜大特写 12° 平视 固定机位｜发现）
沈砚左手里的箭杆上刻着一个赤金色的鹤形家徽，雨水顺着刻痕流过。背景的竹林压成模糊的青绿色块，前景一片竹叶虚化，雨丝在长焦的压缩下排成密集的竖线，画面停留3秒。

镜头6（11–14秒｜近景 29° 略仰视 缓推约0.5 km/h｜认出）
沈砚盯着家徽，下颌咬紧，握剑的右手慢慢垂到身侧，剑尖点在青石板上。沈砚（低沉的青年男声，语速慢，咬字短促）说："鹤家。"口型与台词同步。雨水从他左颊的浅疤上滑过。

镜头7（14–16秒｜远景 8° 远距窥视 固定机位｜新威胁）
画面右上方远处的一根竹梢上，一个黑衣身影一闪即逝，竹梢随即弹回原位。前景几根失焦的竹枝遮住画面下部四分之一，雨雾横在镜头与竹梢之间，远处的竹林被压缩成一层层淡墨色的竖线。

镜头8（16–18秒｜近景 29° 眼平 固定机位｜警觉）
沈砚抬眼看向画面右上方，瞳孔一缩，呼吸停住，嘴唇闭合。

镜头9（18–21秒｜中景 47° 平视 固定机位｜迎敌）
沈砚把那支带家徽的箭插进腰带，随即转身面向画面右侧的竹林，剑锋斜指地面，双脚在湿石板上踩稳后定住。

镜头10（21–24秒｜特写 18° 平视 缓推约0.3 km/h｜落地）
沈砚的眼睛占据画面上三分之一，雨水从睫毛上滴落，视线锁定画面右上方的竹林深处，画面停稳1.5秒。
各镜头内焦段不漂移。

结束状态：沈砚站在小道中央，身体转向画面右侧的竹林，右手持剑、剑锋斜指地面；那支带家徽的箭插在腰带上；一支断箭落在左侧竹竿下，一支箭钉在身后的石板里。

镜头11（24–25秒｜全景 84° 高位45度斜俯 固定机位｜站位交接）
在第24秒从上一镜硬切到高位45度斜向下俯视的全景。摄影机位于沈砚正面一侧的高处，沈砚从头顶到鞋底完整入画，脸部正面四分之三清晰可辨；青石板小道、左侧的断箭、身后钉在石板里的箭和两侧竹林同时入画。沈砚保持上一刻的位置、朝向、姿态与持物，只有衣摆滴水和雨丝的自然微动，嘴唇闭合；画面稳定保持完整1秒。

布光：阴天的冷光从头顶透过竹叶洒下，约7000K，形成几道斜向的体积光柱穿过雾气；剑身和湿发上有冷白色的高光；赤金色的腰带和家徽是画面里唯一的暖色；整体低调，为沈砚的脸和剑曝光。
声音：持续的密集雨声打在竹叶上一层；箭矢破空的嘶响从画面右后方逼近；剑锋劈断箭杆的清脆断裂声；剑背磕箭的金属撞击声，箭钉进石板的闷响；左手攥住箭杆时布料和皮肤的摩擦声；远处竹梢弹回时竹叶的一阵沙响；最后只剩雨声和沈砚一次压低的呼吸。本段不使用背景音乐。

正向锁定：小道上只有沈砚一个人，黑衣身影只在镜头7的远处竹梢出现一次；三支箭依次射来，第一支被劈断，第二支钉入石板，第三支被他攥住后插在腰带上；沈砚始终站在小道上，脚下踏实。画面干净，无字幕、水印与边框。
```
