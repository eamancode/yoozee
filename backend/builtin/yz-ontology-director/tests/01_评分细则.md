# 评分细则

用来比较不同版本、不同运行环境（agent 版与对话版）的输出。每个测试用例在每种环境里至少跑 3 次，记录每次的分数，看平均分和波动。

## 一、三层评分

### 第一层：契约合规（自动可查，每项通过记 1 分，共 14 分）

| 编号 | 检查项 | 怎么查 |
|---|---|---|
| C1 | 七部分标题一字不差、顺序正确 | 文本比对 SKILL.md 第 5.2 节 |
| C2 | 每张单元卡标题行格式正确 | 正则：`### 单元卡 sXX-uN｜总时长 N 秒（叙事 T 秒 + 交接 1 秒）｜N 镜｜节奏X档` |
| C3 | 单元编号连续、不跳号 | |
| C4 | 粘贴提示词九段齐全且顺序正确 | 检查首句、素材映射、全局设定、首帧、镜头N、结束状态、站位交接镜头、布光/声音、正向锁定 |
| C5 | 每个叙事镜头标题有时间码、景别、视场角、机位、运镜、戏剧职责 | |
| C6 | 视场角只用 P50 的八档 | |
| C7 | 总时长 = 叙事时长 + 1，且 ≤P01 | |
| C8 | 交接镜头在最后 1 秒，写了硬切、45 度斜俯、全景 | |
| C9 | 每条提示词有"本段不使用背景音乐" | |
| C10 | 提示词里没有场次编号、"同上""接上一镜" | |
| C11 | 否定句只有技术项，且在 P61 限额内 | |
| C12 | 提示词长度 ≤P02 | |
| C13 | 叙事镜头数 ≤P15，叙事时长 ≤P13 | |
| C14 | 同一场的单元数是最少的，多切处写了理由；没有跨场合并 | 用 S3 第 4.3 节的算法复算 |

### 第二层：决策一致（半自动，每项通过记 1 分，共 13 分）

同一剧本多次运行时，以下决策应保持一致（允许的差异写在括号里）：

| 编号 | 检查项 |
|---|---|
| K1 | 单元划分一致（单元数相差不超过 1） |
| K2 | 每个单元的节奏档一致 |
| K3 | 同一单元的叙事时长相差不超过 3 秒 |
| K4 | 没有理由的镜头使用了 D062、D063、D064 缺省值 |
| K5 | 身份短串、声线锁、通用基准段与圣经卡逐字一致 |
| K6 | 台词改动的手术选择与 S2 第 4.3 节的首选手术一致 |
| K7 | 一个镜头一个说话人；单镜单人台词不超过 P31 |
| K8 | 正反打不越轴，或越轴写明了合法路径 |
| K9 | 结束状态与下一单元首帧一致 |
| K10 | 待确认清单包含所有用了默认值且影响大的项 |
| K11 | 节奏诊断的五个节点位置一致（相差不超过一个单元） |
| K12 | 全集景别分布符合 P58，非人物镜头符合 P53 |
| K13 | 每个镜头只装一个动作节拍（S6 的 D084） |

### 第三层：导演质量（人工盲评，每项 1–5 分，共 25 分）

评审时不告诉评审者来自哪个版本或哪种环境。

| 编号 | 维度 | 5 分的样子 |
|---|---|---|
| Q1 | 节奏 | 有短剧的推进速度：开场 3 秒有冲突，爽点和集尾卡点到位，情绪停留只在关键处 |
| Q2 | 讲戏与表演 | 目标、战术、变拍清楚；情绪在近景里一眼可读、不扮鬼脸；有眼活 |
| Q3 | 镜头语言 | 每个镜头答得出"删掉它会少什么"，景别、机位有情绪理由 |
| Q4 | 氛围 | 光有来源、色有归属、声有动作，随情绪变化 |
| Q5 | 可生成性 | 读起来像能直接拍出来；没有空泛形容词 |

## 二、判定标准

| 结果 | 条件 |
|---|---|
| 合格 | 第一层 ≥13/14，第二层 ≥11/13，第三层平均 ≥3.5 |
| 稳定 | 同一环境 3 次运行，第一层全部合格，第二层分数差不超过 2 |
| 两种环境一致 | agent 版与对话版的第一、二层平均分相差不超过 1 |
