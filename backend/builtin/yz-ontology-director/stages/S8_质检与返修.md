# S8 质检与返修

> 每集回合的最后一步，也是返修回合的诊断入口。上游：S7 的粘贴提示词与全部单元卡。下游：每集回合 → S1 写集交接卡；返修回合 → 回到责任环节重写。

## 1. 输入

- 每集回合：本集全部单元卡
- 返修回合：翻车的单元卡 + 症状描述

## 4. 写法

### 4.1 硬失败（H1–H11）

| 编号 | 硬失败 | 怎么查 | 责任环节 |
|---|---|---|---|
| H1 | 剧情事实、关系、因果被改；【保留】台词被改 | 对照剧本逐句核 | S2 |
| H2 | 提示词依赖上下文 | 搜"同上""接上""上一镜"、场次编号、不出场的 @ 标签 | S7 |
| H3 | 不变量漂移 | 身份短串、声线锁、通用基准段、场域锚句与圣经卡逐字比对 | S7 |
| H4 | 空间矛盾 | 越轴无合法路径、人物瞬移、左右互换、首帧空场 | S6 |
| H5 | 物理或道具矛盾 | 同一道具出现在两处、数量变化 | S6 |
| H6 | 超出平台限制 | 总时长 > P01；字符 > P02；素材数超限 | S3/S7 |
| H7 | 情绪只有标签 | 搜"很生气""很难过""紧张的气氛" | S4 |
| H8 | 站位交接缺失或错位（交接开启时） | 没有交接段；不在最后 1 秒；不是硬切；不是 45° 斜俯全景；人物不完整或只露背面 | S7 |
| H9 | 站位交接改变了状态 | 交接镜头里人物位置、持物、伤势、道具状态与结束状态不一致，或出现新动作、新台词 | S7 |
| H10 | 交接关闭却出现交接 | 交接关闭时提示词里仍有交接段或预留的交接秒 | S7 |
| H11 | 跨场合并或超出容量 | 一个单元包含两场戏；叙事时长超过 P13；叙事镜头数超过 P15 | S3 |

### 4.2 写作检查清单

逐单元打勾，不进自检结果表，有问题直接改：

- 九段顺序正确
- 每个镜头只装一个动作节拍；超过 P26 的短剧档、紧档镜头已自查（S6 的 D084）
- 同一场的单元数已经最少，多切的地方写了理由
- 本集定位里有节奏诊断；单元内各段的节奏档与诊断一致
- 全集景别分布符合 P58，非人物镜头符合 P53
- @ 标签使用正确
- 正文全部正向，否定只剩技术项
- 单位：km/h、%、米、K、视场角度数
- 方位全部用画面语言并绑地标
- 每个镜头有运镜（方向 + 速度）或写明固定机位；一个镜头一个主运动；运动有终点
- 一个镜头一个说话人；单镜单人台词不超过 P31；说话人静止不超过 P34
- 近景以上写了视线
- 光有实体光源、方向、曝光立场；颜色绑在材质和光上
- 音效绑在可见动作上；写了"本段不使用背景音乐"
- 首帧不空；结束状态写清
- 承重文字标了后期叠加
- 没有人名、作品名、设备型号

### 4.3 表演评分（主角镜头）

| 分 | 标准 |
|---|---|
| 5 | 有目标、有战术、有变拍，眼活清楚，两个以上通道外化，克制而有力 |
| 4 | 有目标和可见外化，眼活清楚 |
| 3 | 有可见动作，但看不出目标 |
| 2 | 主要靠表情描述，动作模糊 |
| 1 | 只有情绪标签 |

阈值见 P63。自评容易偏高；用审稿规程复审时，复审者重新打分，以复审分为准。

### 4.4 翻车症状与改法

先做"第一刀"，不行再升级。

| 症状 | 怎么认 | 第一刀 | 升级 | 责任环节 |
|---|---|---|---|---|
| 身份漂移、换脸 | 越动越不像 | 简化这一段的运动；逐字核对身份短串；补"与@图N一致"并用文字重述标志特征 | 请用户补一张干净的正面特写参考图 | S1/S7 |
| 单镜动作过载 | 一个镜头里的几件事都只做了一半，或后一件事没出现 | 按 J084 把镜头拆成每镜一个节拍；镜头数不够时删掉次要节拍 | 多切一刀 | S6 |
| 动作糊、退化成静止 | 写了动作，画面几乎不动 | 删掉并列的无关动作，只留因果顺承主链；动词领头 | 拆单元 | S4/S3 |
| 默认慢镜 | 整段像慢动作 | 加"骤然、猛地、快速"，写 km/h | — | S7 |
| 动作做一半卡住 | 动作悬在半空 | 补终点："随即定住""落回原位" | — | S7 |
| 运镜被无视 | 写了推，画面没动 | 一个镜头只留一个运镜；弱化抢能量的快速次要动作 | 换角度 | S6 |
| 每段重新开局 | 每个时间段人物回到起始位置 | 补"整段是一场连续发生的……，站位不在镜头之间重置" | 缩短单元 | S7/S3 |
| 节奏抢跑 | 比时间码快，眼泪提前 | 把情绪节点绑在时间上 | 拆单元给足时长 | S7/S3 |
| 表情夸张、开关式 | 表情跳变，没有过程 | 改成小动作 + 微表情两个通道；写"表情在两种情绪之间慢慢变化" | — | S4 |
| 多出来的人 | 背景冒出没写的人 | 首帧写全所有人；正向写"画面里只有 A 和 B" | — | S7 |
| 道具一变二 | 一件道具变成两件 | 正向锁"全程只有一个……" | — | S7 |
| 人群塌缩 | 一群人变成三五个人形 | 不写人数，写局部形态 | — | S4 |
| 字幕、乱码文字 | 出现字幕、贴纸、乱码招牌 | 加"仅发声，无字幕"；招牌写清唯一允许的文字 | 承重文字改后期叠加 | S7 |
| 冒出背景音乐 | 没写配乐却有音乐 | 确认写了"本段不使用背景音乐" | — | S7 |
| 音效假或缺 | 声音没有来源 | 按"动作 + 材质 + 距离 + 强度"补写 | — | S5 |
| 口型不对 | 嘴型对不上，抢拍 | 拆短句、正脸、退到中景 | 砍台词或换景别 | S2/S6 |
| 倾听者跟着动嘴 | 不说话的人在动嘴 | 写"嘴唇闭合，安静地听" | 拆成单人镜头 | S7 |
| 跨单元掉色 | 相邻单元色调不一致 | 核对通用基准段、场域锚句逐字一致；强调色收敛 | — | S7/S1 |
| 时代漂移 | 古装戏出现现代物件 | 时代锚句写进恒定层；正向列出该时代的物证 | — | S1/S7 |
| 空间混乱、左右互换 | 越轴、瞬移 | 空间地图逐字写进全局设定；方位绑地标 | 重画站位图，重排机位 | S6 |
| 场景每条都不一样 | 同一场景结构漂移 | 确认写了场景图只控环境与氛围的那句；强化地标 | 请用户补该角度的场景图 | S7/S1 |
| 物理穿模、软体 | 刚体扭曲，打击无反馈 | 补物理句：硬、有重量、有反作用力，衣摆头发晚于身体停下 | 简化动作或拆单元 | S4 |
| 后半段整体失控 | 前半可用，后半崩 | 判为单元超载：先把镜头数减到 8 以内（合并相邻的同景别镜头） | 按戏剧断点多切一刀，在节奏总表写多切理由 | S3 |
| 硬切没执行或乱切 | 镜头数比写的少，或切点漂移 | 每个镜头的时间码与标题行写全；相邻镜头景别拉开差距 | 减少镜头数；仍不行就多切一刀 | S7/S3 |
| 交接镜头构图不对 | 不是俯拍全景，或人物不完整 | 核对第 7 段写法；补地标名称 | 交接秒可剪除，下一单元改用末帧截图 | S7 |
| 交接镜头里人物在动 | 人物走位、转身、说话 | 补"保持上一刻的位置与姿态，嘴唇闭合" | 同上 | S7 |
