## 4. 写法

### 4.1 圣经的作用

世界圣经是整部剧唯一的事实库。多集短剧最怕第 3 集的人脸、声音和第 1 集对不上，圣经就是为此存在的。圣经卡里凡是要进提示词的内容，都写成可以直接粘贴的短句，不写散文。

### 4.2 事实三级

每条信息都分清来源：

- **剧本事实**：原文写了的；
- **强推断**：多处原文共同支持的；
- **导演提案**：原文没写，为了能拍而定下的。

导演提案一律进待确认清单，不能冒充原文。

### 4.3 五卷内容

**卷一 世界法则**：一句话故事（主角、目标、阻碍、变化）；主题；类型与写实程度；国家、城市、年代、季节、剧情时间轴；科技与生活边界；语言与口音；特殊规则（能力边界与代价）；时代锚句（见 P42）。

**卷二 存在者名册**

人物本体卡：

```
【人物】林夏｜核心
身份短串：28岁女性，齐肩黑发，左眉尾一颗小痣，偏瘦高，眼神安静
声线锁：中低音，语速偏慢，句尾下沉，带一点粤语口音的普通话，紧张时会先清一下嗓子
表演气质：情绪越重越安静；紧张时右手拇指摩挲食指侧面；笑的时候只动左边嘴角
状态表：A＝白衬衫灰西裤，干净整齐（第1集起）；B＝白衬衫湿透贴身，袖口有一道血迹（第3集起）
小传：外在目标——找到父亲失踪的真相；内在需要——原谅自己当年没回家；最大恐惧——证实父亲是自愿离开的
参考图：@图1
```

声线锁写音高、语速、质感、口音条件和一个标志性习惯。口音写成条件而不是标签，例如"川渝口音，平翘舌不分，句尾上扬"，而不是只写"四川口音"。

空间本体卡：

```
【空间】当铺｜内景｜核心
拓扑：临街正门进；进门即柜台；柜台后有一扇小门通库房
地标：齐胸高的深色木柜台、柜台上方一排铁栅、墙上手写价目木牌、柜台角一盏绿罩台灯、正门边的窗
光源物：绿罩台灯（暖）、窗外路灯（冷）
场域锚句：1998年广州老城区一间当铺，深色木柜台齐胸高，柜台上方竖着一排铁栅，墙上挂着手写价目木牌，柜台角一盏绿罩台灯，窗外是湿漉漉的骑楼街。
参考图：@图3
```

场域锚句只进发生在本空间的单元，别的空间一个字都不带：在院子戏里写一遍"柜台"，模型就会在院子里造出一个柜台。

物件本体卡：外观短串、状态序列（完好 → 被撬开 → 照片被取走）、承重文字（D019）。

群体卡：反复出现的群体才写；写人数感、年龄构成、统一服装、统一动作。

**卷三 关系与信息**：关系表（每对重要人物的权力高低、各自想要什么、隐瞒了什么）；信息差表（每个秘密谁先知道、观众何时知道、另一方何时知道）。

**卷四 美学宪法**：媒介轨；通用基准段（D020）；色彩母题（颜色 → 绑定的物件与光 → 叙事意义）；光的逻辑（全片的光从哪来、偏冷还是偏暖、高调还是低调）；镜头性格（默认按 S3 第 4.2 节的片种预设，写明默认节奏档）；声音基调；表演基线（默认"比电影外放一档"，见 S4 的 D054；可改为克制或喜剧夸张）。

三条媒介轨的通用基准段示范：

- 写实："真人实拍质感，皮肤有毛孔与细微油光，暖色灯光与冷色夜景并存，高光柔和滚降，暗部保留细节，细胶片颗粒，镜头克制，多用固定机位与缓慢推进。"
- 2D 动漫："二维手绘动画，线条干净有轻微粗细变化，赛璐璐平涂配两层阴影，背景为水彩质感的手绘，色彩明亮通透，人物表情可适度夸张，动作有清晰的预备与收势。"
- 3D 国漫："三维国风动画，角色皮肤与布料有真实材质和次表面散射，体积光穿过雾气形成光柱，水墨晕染的远景，动作有重量感，武打带拖影与气流，色调以青绿、墨黑和赤金为主。"

**卷五 时间之弧**：季弧；每集一句话与集末钩子；全剧情绪曲线（D021）；母题埋设与回收表。

输出格式见 `templates/02_世界圣经卡.md`。

### 4.4 补图建议

缺核心人物或核心场景的参考图时，在待确认清单之后给出生图提示词：

- 人物：一段连续文字，写年龄、身份、身份短串、本状态服装、9:16 正面半身、纯色背景、柔和均匀的光、媒介质感。
- 场景：写空间结构、地标、光源、时段，画面中没有人物。

### 4.5 集交接卡

每集回合的最后输出，是下一集的"上集结束状态"，也是圣经卡的补丁。长度见 P46。

```
【集交接卡】第2集 → 第3集
人物状态：
- 林夏：状态B（白衬衫湿透贴身，袖口有一道血迹）；位置：当铺门外骑楼下；手里：怀表；情绪余温：压着怒气，刚得知父亲还活着
- 老秦：状态A；位置：当铺柜台内；手里：空；情绪余温：后悔说漏了嘴
道具状态：
- 怀表：表盖被撬开，照片还在
空间与光：当铺台灯被碰倒，熄灭；外面雨停了
关系变化：林夏与老秦从"陌生的买卖"变成"共同保守秘密的人"
信息差变化：观众已知父亲还活着；林夏已知；老秦知道林夏已知
未解线头：照片背面的地址还没被看到
本集新增实体（请补进圣经卡）：【人物】出租车司机阿昌｜边角｜身份短串：……
圣经变更建议：无
集末钩子回顾：林夏翻过照片，背面写着一个地址（承重文字，后期叠加）
本集最后一个站位交接截图对应的单元：s05-u3
```
