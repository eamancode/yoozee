# S7 编译

> 把导演分镜卡翻译成可以直接粘贴的提示词。编译只做翻译和拼装，不做新的创作决定：分镜卡里没有的，提示词里不出现；分镜卡里有的，一件不漏。上游：S6 分镜卡、圣经卡的不变量。下游：S8 自检。

## 1. 输入

- S6 导演分镜卡（含镜头表、结束状态）
- 世界圣经卡：通用基准段、场域锚句、时代锚句、身份短串、声线锁
- 素材清单（@ 编号）

## 4. 写法

### 4.1 两层装配

- **恒定层**：通用基准段 + 本场场域锚句 + 时代锚句 + 出场人物身份短串 + 声线锁 + 空间地图。同一场的所有单元逐字复用。
- **可变层**：本单元独有的首帧、动作、运镜、光的变化、台词和声音。

装好恒定层后回读一遍：恒定层点名的每件陈设，本单元画面里都应该看得见；看不见，就是灌错了场域。

### 4.2 九段固定顺序

| 段 | 内容 | 要点 |
|---|---|---|
| 1 首句 | 总时长、画幅、媒介、镜头数、镜头组织方式 | "19秒，竖屏9:16，真人写实短剧质感，5个镜头，只在指定切点硬切，摄影机不自行加切。"总时长和镜头数都包含站位交接镜头；一镜到底写"叙事部分一镜到底，最后硬切到站位交接镜头" |
| 2 素材映射 | @图N 是谁、哪里、什么道具；音频属于谁 | 只说身份，不复述外貌；有场景图时加固定句："场景图只提供环境、材质与氛围，镜头的空间结构、机位、景别与构图以本提示词为准。"没有素材时整段删除 |
| 3 全局设定 | 恒定层 | 通用基准段、场域锚句、时代锚句逐字复制；每个出场人物一行：名字 + 身份短串 + 本单元状态 + "与@图N一致"；参考图上的关键细节用文字再说一遍；空间地图写清摄影机在哪侧、每人在哪个地标旁、画面哪侧、朝哪、隔着什么、光源在哪 |
| 4 首帧 | 第一帧的景别、谁在哪、在做什么、看向哪 | 首帧不空：首帧景别里应当出现的人物和物件都已在位并且在动；特写开场时只写特写里的内容，其余人物的位置由第 3 段的空间地图交代 |
| 5 逐镜 | 叙事镜头 | 见 4.3 |
| 6 结束状态 | 叙事最后一刻的画面 | 结束状态五字段写成一两句；落地写"画面停稳 N 秒"，接续写"动作仍在进行" |
| 7 站位交接镜头 | 最后 1 秒 | 见 4.4；交接关闭时整段删除 |
| 8 布光与声音 | 光与声 | 主光源实体、方向、光质、色温、影调、为谁曝光；环境声三层、绑定动作的音效、人声表演；最后写"本段不使用背景音乐" |
| 9 正向锁定 | 2–4 句锁 + 一句技术排除 | 见 4.5 |

### 4.3 逐镜的写法

标题行：

```
镜头2（4–9秒｜特写 18° 高位俯视 缓推约0.5 km/h｜揭示）
```

标题行后是一段连续文字，把构图、动作、表情、台词、音效、本镜的光揉在一起，不写成字段清单。合并后的单元镜头多，每镜段落控制在 P64 以内，同一件事只说一次：


- 动词领头，速度显式，动作有终点（"随即定住"）。
- 一个镜头的段落只写一个动作节拍（S6 的 D084）；发现一段里出现第二个做动作的人、第二个目的或一条新信息，说明分镜卡该多切一镜，回 S6 改，不在编译时硬塞。
- 摄影机运动和人物运动分开写。
- 台词：人物（声线锁逐字复制）说："台词。"口型与台词同步。
- 不说话的人写"嘴唇闭合"。
- 有音频参考时，台词后写"音色参考@音频N"。
- 情绪节点绑在时间上，防止模型抢跑："第12秒眼泪才滑落"。
- 多镜头单元，逐镜部分最后写一句"各镜头内焦段不漂移"。

### 4.4 站位交接镜头的写法（第 7 段）

有人物时：

```
镜头5（18–19秒｜全景 84° 高位45度斜俯 固定机位｜站位交接）
在第18秒从上一镜硬切到高位45度斜向下俯视的全景。摄影机位于所有人物正面一侧的高处，【人物A】和【人物B】从头顶到鞋底完整入画，脸部或正面四分之三清晰可辨；【地标1】【地标2】同时入画。所有人保持上一刻的位置、朝向、姿态、持物与场景状态，只有呼吸、衣料和环境的自然微动，嘴唇闭合；画面稳定保持完整1秒。
```

人物已全部离开画面时：

```
镜头N（T–T+1秒｜全景 84° 高位45度斜俯 固定机位｜站位交接）
在第T秒从上一镜硬切到当前场景高位45度斜向下俯视的全景，完整显示【地标】、【关键道具】的位置、出入口和环境状态，画面中只有场景本身，稳定保持完整1秒。
```

要点：

- 时间段必须是总时长的最后 1 秒。
- 有人被固定陈设挡住时，把"从头顶到鞋底完整入画"改写成具体可见范围，例如"老秦坐在柜台内，头部、上身与座椅靠背可见"。
- 用硬切进入，不写转场或运镜过渡。
- 不承载新的剧情、台词或动作。
- 其他段落不描述"是否追加交接""可剪除"之类的说明；交接只由这一段的存在来表达。

### 4.5 正向锁定（第 9 段）

只锁这一条最可能翻车的 2–4 件事，用正向句：

- 空间："两人在全片段中始终隔着柜台，林夏在画面左，老秦在画面右。"
- 数量："全程只有一块怀表。"
- 身份："林夏的脸与@图1一致，左眉尾的小痣清晰可见。"
- 时代：写成"街上行人腰间别着BP机，手里拿着报纸和雨伞"，而不是否定现代物件。
- 连续："整段是一场连续发生的对话，站位不在镜头之间重置。"

结尾只留一句技术排除："画面干净，无字幕、水印与边框。"

### 4.6 上下文隔离

每条粘贴提示词都是一份密封的单镜头文档，不出现场次编号、单元编号、剧本小标题、前情摘要、"同上""接上一镜"、本单元不出场的人和物、只属于别的空间的陈设（R5）。

### 4.7 不同媒介轨

- 首句写明媒介："真人写实短剧质感""二维手绘动画质感""三维国风动画质感"。
- 2D 轨：表情和动作可以夸张，写预备动作和收势；可以写速度线、汗滴、闪光；光影写成"两层平涂阴影""边缘一条亮线"。
- 3D 轨：写材质、体积光、粒子；武打写清招式路径和打击反馈。
- 皮肤毛孔、胶片颗粒这类写实词只用于写实轨。

骨架见 `templates/04_粘贴提示词骨架.md`，完整示例见 `examples/`。

## 5. 自检

- [ ] 九段顺序正确；交接关闭时没有第 7 段，开启时第 7 段在最后 1 秒
- [ ] 恒定层与圣经卡逐字一致（R3）
- [ ] 每个镜头标题有时间码（一镜到底除外）
- [ ] @ 标签只出现在素材映射段和人物行，只用于真正出场的人和物
- [ ] 否定句只有技术项，且在 P61 限额内
- [ ] 速度写 km/h，空气写 % 和米，色温写 K，焦段写视场角度数
- [ ] 一个镜头一个说话人；不说话的人写了嘴唇闭合
- [ ] 写了"本段不使用背景音乐"（用户点名要音乐的除外）
- [ ] 长度在 P02 内；每镜段落不超过 P64；超过 P60 上沿时检查是否该多切一刀
- [ ] 没有场次编号、"同上"、人名与设备型号
