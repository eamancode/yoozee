# S6 导演分镜

> 逐单元、逐镜头做导演决定，产出导演分镜卡。上游：S3 节奏总表、S4 讲戏本、S5 氛围设定、圣经卡的空间卡。下游：S7 把分镜卡编译成粘贴提示词。镜头数以本环节的镜头表为唯一出处。

## 1. 输入

- S3：单元划分、叙事时长、节奏档、镜尾、接缝卡
- S4：任务卡、单元阐述、拍序
- S5：光、色、空气、声
- 世界圣经卡：空间卡（地标、光源物）、人物身份
- 同场景上一单元的结束状态（以及它的站位交接截图，如果用户提供了）

## 3. 判据表

| 编号 | 判断什么 | 判据 | 正例 | 反例 |
|---|---|---|---|---|
| J061a | 景别 | 观众需要离人物多近：远景读环境与孤立，中景读动作与关系，近景读反应与决定，特写读一个细节 | 老秦认出照片的瞬间 → 手和表的特写 | 为了"丰富"在两个中景之间插一个毫无信息的远景 |
| J061b | 运镜要不要动 | 删掉运动后表达是否受损；不受损就固定 | 她冲出门 → 跟拍 | 两人静坐对话时缓慢环绕 |
| J061c | 切还是不切 | 注意力、判断、关系、空间证据、节奏或时间发生转换时切；继续拍不等于必须运镜 | 林夏换战术的那一刻切到她的眼睛 | 同一句台词中间无理由切三次 |
| J068 | 越轴路径 | 局势反转、权力交换 → 条内可见的运动越轴；节奏紧 → 骑轴中性镜或插入镜；人物本来要走动 → 走位重立轴线 | 两人摊牌、她绕到他另一侧 → 走位重立轴线 | 上一镜 A 在画右，下一镜无过程地变到画左 |
| J084 | 什么是一个动作节拍 | 一个人物为一个目的完成的一串因果顺承动作（"转身拔剑劈断箭"是一个节拍），或者一次信息揭示加上它的直接反应。换了做动作的人、换了目的、出现了新信息，就是新的节拍 | 拿出录音笔、按下、放在桌上：为了"亮出证据"，一个节拍；下一镜录音播放：新信息，另一个节拍 | 一个 5 秒镜头里先拿出录音笔，再播放录音，再拍对方僵住——三个节拍挤在一镜，T7 实测此写法质量明显下降 |
| J062 | 镜头经济 | 每个镜头回答"删掉它观众会少知道什么"；答不出来就删 | 删掉一个重复的双人中景 | 为了"镜头多显得专业"加镜 |

## 4. 写法

### 4.1 导演九问

每个镜头严格按顺序回答：

1. **戏剧职责**：这一镜在单元里干什么活？建立、推进、转折、反应、揭示、喘息。
2. **观众感受**：这一拍要让观众靠近、警觉、窒息、无助、恍然大悟，还是暂时松口气？必须能回到剧本里的某个刺激。
3. **第一注意力**：观众先看哪一件事？只能选一个：人物反应、身体动作、环境压力、关键道具、空间出口。
4. **心理距离 → 景别**（J061a）。
5. **观看位置 → 机位**：观众是旁观、同行、被追赶、躲着偷看，还是被压住？据此定高度、俯仰、轴侧、距离、遮挡。不需要特别的观看位置时用 D062。
6. **光学 → 视场角**：从 P50 的档位里选；不需要特别的光学结果时用 D063。
7. **构图**：第一注意力放在画面哪里；前景、中景、背景各放什么；留白朝向哪边。
8. **运动**（J061b）：不需要时用 D064。确认这一镜只装一个动作节拍（D084）。
9. **切点与衔接**（J061c）。

### 4.2 景别

| 景别 | 画面内容 | 心理功能 |
|---|---|---|
| 大远景 | 尺度、地点 | 孤立、渺小、环境压迫 |
| 全景 | 完整人物 + 环境 | 空间关系、走位可读 |
| 中景 | 大约到腰 | 动作、关系、多人接触 |
| 近景 | 头和肩 | 反应、决定 |
| 特写 | 整张脸或一个元素占满画面 | 情绪高点、微表情 |
| 大特写 | 一个细节：眼睛、纽扣、手 | 关键信息、物件承载情绪 |

短剧以特写和近景为主，全集景别分布见 P58。相邻两个镜头的景别拉开差距（中景接近景，近景接特写），同景别连续两镜时要换机位角度或换人物。建立镜头放在段落开头，特写放在情绪高点。一个镜头一个主景别。

### 4.3 视场角

| 视场角 | 约等于 | 画面效果 |
|---|---|---|
| 107° | 14–16mm | 超广角，强透视 |
| 84° | 20–24mm | 广角，空间感强 |
| 63° | 28–35mm | 观察式广角，纪实感 |
| 47° | 40–50mm | 接近人眼 |
| 29° | 75–85mm | 人像压缩，背景虚化 |
| 18° | 100–135mm | 长焦人像，保身份 |
| 12° | 180–200mm | 长焦细节 |
| 8° | 300–400mm | 极限压缩，窥视感 |

- 提示词里写度数，不写毫米（毫米只是帮你理解）。
- 视场角要配"看得见的光学结果"：长焦写"背景压成柔和的色块，前景遮挡占画面下部三成"，至少 4 句；广角写"直线保持笔直，前景物体被放大，背景向纵深退去"，至少 3 句。
- 一个动作节拍内不混入人像特写、环境地理、微距细节这些互不兼容的内容，否则镜头会漂。
- 极端视场角（8°、107°）的多镜头单元用"四件套"：所有镜头共用同一个地点参考；每个镜头开头写视场角；每个镜头结尾再确认一次；色彩用"材质 + 光"表达。

常用光学技法：

- **观察式画面**：前景失焦遮挡物占画面 P56；摄影机与主体之间有雾、尘或热浪；8°–12° 远距离拍摄。
- **体育转播感**：8° + 1–2 厘米的轻微手持抖动 + "从远处寻找动作"。
- **广角贴物**：84° 低角度紧贴一个小物件，前景被放大，背景向纵深退去。
- **亲密广角**：63°–84° 拍一张贴近的脸，脸居中，环境清晰可读。

### 4.4 机位

- 高度：贴地、膝高、腰高、眼平、高位、俯瞰。
- 角度：平视（平等、真实）；俯拍（无助、被困）；仰拍（压迫、强大、陌生）；荷兰角（失衡、出事了）；鸟瞰（把人变成棋子）。
- 轴侧、距离、遮挡：越过谁的肩、隔着什么拍。
- 摄影机通常放在阴影一侧。

### 4.5 运镜

| 运镜 | 给观众的感觉 | 写法要点 |
|---|---|---|
| 固定 | 克制、聚焦、让沉默待着 | 显式写"固定机位" |
| 推 | 逼近、意识到、压力升高 | 写起止景别和速度："从中景缓推到近景，约 0.5 km/h" |
| 拉 | 抽离、揭示环境、孤立 | 写拉到什么景别、揭示出什么 |
| 横移 | 空间关系、并行 | 写方向（向画左/画右）和速度 |
| 摇 | 视线转移、跟随注意力 | 写从哪摇到哪 |
| 跟 | 共享速度和体力 | 写在主体前、后还是侧面，距离多远 |
| 升降 | 规模、压强、揭示 | 写起止高度 |
| 环绕 | 立体、揭示、关系旋转 | 写顺时针或逆时针和角度 |
| 手持 | 紧张、纪实、慌乱 | 写抖动幅度："1–2 厘米的轻微手持晃动" |
| 甩镜 | 暴烈急转、转场 | 不短于 P19 |
| 移焦 | 注意力换位 | 写从谁移到谁 |

- 一个镜头一个主运动；唯一例外是两个运动由同一个主体动作串起来（随他起身，同时上升并推近）。
- 方向和速度成对写；不给速度，模型默认慢镜。
- 运动有终点："推到近景后定住"。
- 情绪长镜里摄影机只做极缓的运动；快速的次要动作会抢走运镜的"能量"。
- 摄影机运动和人物运动分开写。

### 4.6 构图

三分法、居中对称、引导线、负空间、前中后景分层、框中框、低地平线、满构图。对称给秩序，负空间给孤独，分层给纵深，框中框给束缚。第一注意力放在画面最亮、最清楚、或线条汇聚的地方。

### 4.7 空间纪律：调度、站位、走位

- 只用画面语言说方位：画面左/右（以摄影机视角为准）、前景/中景/后景、靠近/远离摄影机、门内/门外、某个地标旁边。不用东南西北。
- 每个人的位置绑在一个地标上。
- 身体朝向和视线分开写："她身体朝向门口，视线回头落在他手上。"
- **180° 轴线**：对话场的轴是两人视线连线；运动场的轴是运动方向线。立轴后，正反打所有机位都在轴的同一侧，A 一直在画右，B 一直在画左；追逐中人物一直往画面同一个方向跑。
- **越轴的四条合法路径**（J068）：
  1. 一个连续运动镜头里，摄影机随人物动作绕过两人连线，观众看着它跨过去；
  2. 插入一个机位正压在轴线上的正面中性镜头；
  3. 人物走位把轴线转了方向，起点、路径、终点都在画面里完整可见，之后按新轴重写方位词；
  4. 插入一个不含双方空间关系的物件特写（最弱）。
- **首帧占位**：首帧景别里应当出现的人物和物件，从第一帧起就已在位并且在动，不用空镜开场。特写开场时，画面外的人物从他们第一次入画的镜头起就已在位，不写"走进画面"之类的入场，除非剧本要求。
- **第三方入场**：先说清他在轴的哪一侧。
- **字符俯视站位图**（D067）：

```
               [后景：窗]
   林夏 →                    ← 老秦
  （柜台外，面朝画右）      （柜台内，面朝画左）
   ════════ 柜台 + 铁栅 ════════
                 ▲
           摄影机（腰高，柜台正面，轴线近侧）
```

### 4.8 镜头经济性

- 每个镜头回答"删掉它观众会少知道什么"（J062）。
- 短剧以人脸为主：非人物镜头（环境空镜、物件特写、局部肢体、光影变化、反应局部）只在承载关键信息时使用（D066）。
- 一镜到底按 S3 的 D049。

### 4.9 转场衔接

| 手法 | 用法 |
|---|---|
| 硬切 | 默认（D069） |
| 猛切 | 节奏突变、惊吓 |
| 动作匹配剪 | 上一镜动作没做完，下一镜从另一角度接着做完 |
| 视线匹配 | 上一镜人物看向某处，下一镜给他看到的东西 |
| 反打切 | 对话正反打 |
| 插入切 | 切到一个细节再回来 |
| 声音前置 | 下一镜的声音先响起，画面再切 |
| 遮挡转场 | 前景物体划过画面，借遮挡切换 |
| 形状匹配 | 上下两镜的主要形状重合 |
| 甩镜 | 时间或空间的急转，不短于 P19 |

实时速度和慢动作之间只用硬切，每个镜头从头到尾只有一种速度。

### 4.10 导演分镜卡格式

每个单元一张卡。字段依次为：

| 字段 | 写什么 |
|---|---|
| 标题行 | 见 SKILL.md 第 5.5 节 |
| 事件链 | 本单元按顺序包含的事件（同场合并后可以有多条），并标出价值变化 |
| 情绪变化链 | 覆盖整个单元，如"试探 → 认出 → 追问 → 反击 → 逼问" |
| 信息差 | 观众知道什么、人物知道什么 |
| 开场钩子 | 本单元第一镜抓住注意力的东西 |
| 空间地图 | 场景、地标、轴线、摄影机在哪一侧 |
| 站位与走位 | 每人在哪个地标旁、画面哪侧、朝哪；起位 → 路径 → 落位 |
| 站位图 | 两人以上或有走位时画（D067） |
| 群像 | 主体层、反应层、背景层；无则写"无" |
| 氛围 | 光、色、空气、声、时 |
| 台词 | 说话人、台词、字数、预计秒数、脸朝镜头角度 |
| 节奏分段 | 本单元各段用哪一档（短剧档、紧档、停留档） |
| 镜头表 | 13 列：镜头、时间、戏剧职责、第一注意力、景别、视场角、机位、运镜、构图、动作与表情、台词与声音、光、切出；最后一行是站位交接镜头 |
| 结束状态 | 五字段 |
| 站位参考 | 同场景下一单元是否用本单元交接截图 |
| 接缝卡 | 出点、入点、手法、省略物证 |
| 首帧图建议 | D076 规定的情况才写 |

完整的单元卡示例见 `examples/01_写实_当铺.md`，空白骨架见 `templates/03_每集输出骨架.md`。

**结束状态五字段**：人物位置与姿态、视线、道具状态、光状态、情绪余温。它是本单元的终点、站位交接镜头要定格的内容，也是下一单元首帧的起点和交接卡的来源。

## 5. 自检

- [ ] 每个镜头按九问作答，戏剧职责和第一注意力都写了
- [ ] 没有特别理由的镜头用了 D062、D063、D064 的缺省值
- [ ] 相邻镜头景别拉开差距
- [ ] 激进机位都写了情绪理由；荷兰角不超过 P52
- [ ] 正反打不越轴，越轴有合法路径
- [ ] 两人以上或有走位的单元画了站位图
- [ ] 叙事镜头数不超过 P15（不含交接镜头）
- [ ] 全集景别分布符合 P58；非人物镜头符合 P53
- [ ] 交接开启时，最后一个镜头是 1 秒站位交接，构图符合 S3 第 4.5 节
- [ ] 每个镜头都答得出"删掉它会少什么"
- [ ] 每个镜头只装一个动作节拍（D084）；超过 P26 的短剧档、紧档镜头已自查
