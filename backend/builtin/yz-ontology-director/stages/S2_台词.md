## 4. 写法

### 4.1 底层判断

一句台词 = 说话人的意志 × 对象 × 战术 × 信息。好台词是人物为了得到某样东西，对另一个人做的一个动作；坏台词是作者借人物的嘴，向观众解释剧情。短剧的台词还要承担一件事：让人不划走。

动笔之前，先回答这场戏的五元素：

| 元素 | 问题 |
|---|---|
| 目标 | 这场戏里每个人想要什么？ |
| 阻碍 | 什么挡着他？ |
| 战术 | 他用什么办法去拿？ |
| 反转 | 哪一刻局面翻了？ |
| 价值变化 | 结束时，什么东西从正变负或从负变正？ |

### 4.2 诊断七病

| 病 | 怎么认 | 例子 |
|---|---|---|
| 说明腔 | 人物把双方早就知道的事说给观众听 | "你是我哥，十年前你离开了这个家" |
| 主题上身 | 人物说出影片的主题 | "我终于明白了，爱就是放手" |
| 情绪自报 | 人物直接说出自己的情绪 | "我好难过""我恨你" |
| 信息重复 | 画面已经交代过，台词再说一遍 | 他刚摔门而出，台词又是"我走了" |
| 口型超载 | 一镜里一个人说太多（超过 P31） | 单镜 6 秒塞 40 个字 |
| 身份失真 | 措辞、口音不符合年龄、阶层、年代 | 1930 年代的少爷说网络流行语 |
| 无钩子 | 场尾、集尾的最后一句落在已知信息上 | 集末台词"那我们明天见" |

### 4.3 病 → 首选手术

| 病 | 首选手术 | 第二选择 |
|---|---|---|
| 说明腔 | 删 | 物件承载 |
| 主题上身 | 删 | 潜台词化 |
| 情绪自报 | 潜台词化 | 动作替代 |
| 信息重复 | 删 | — |
| 口型超载 | 拆句并切镜 | 重音前置后删减 |
| 身份失真 | 声线校正 | — |
| 无钩子 | 钩子后置 | 打断与抢话 |

八种手术：

1. **删**：画面能交代的，嘴不说。
2. **动作替代**：把台词换成能拍的动作。"我不想听你说"换成她把手机扣在桌面上。
3. **潜台词化**：嘴上说 A，心里要 B。"三年了你为什么现在才回来，我恨你"改成：她把茶杯推回他面前，"茶凉了。"
4. **物件承载**：让道具替人说话，比如推回去的茶、没摘下的戒指、被反扣的相框。
5. **打断与抢话**：冲突戏用半句话、抢白提速；被打断的半句写成"你知道我——"，下一镜由对方接上（D028）。
6. **重音前置**：关键词放句首。"十年。你让我等了十年。"
7. **钩子后置**：场尾和集尾的最后一句落在新信息、新威胁或没回答的问题上。
8. **声线校正**：按声线锁统一用词、口头禅、口音。

### 4.4 台词怎样才能被拍出来

- **口型三前提**：短句（P31）、正脸（P36）、中景或近景。
- **说话时不站桩**：按 P34，说话人静止到阈值前，要么给一个具体动作（递物、转身、擦杯子、整理衣角），要么切镜。不说话的反应停留不受此限，反应停留本身就是戏。
- **反应写在台词说到一半时**："话说到一半，他擦杯子的手已经慢下来。"
- **台词不占满时长**：前后留气口（P35）。
- **画外音与内心独白**：注明"画外音，说话人嘴唇不动"。
- **人声表演单独写**：喘息、抽泣、轻笑、叹气写进声音，不算台词，克制使用。
- **关键信息不丢**：删掉台词里的信息时，要写明改由哪个画面或物件承载。
