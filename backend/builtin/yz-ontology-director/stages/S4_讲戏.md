## 4. 写法

### 4.1 场阐述

每场三到五句：这场戏在全集干什么活、情绪从哪里到哪里、打算怎么拍。第一句用公式：

> 【谁】想要【什么】，被【什么】挡住，用【什么战术】，结果【价值从 A 变成 B】。

例："林夏要老秦当场说出父亲的下落，被老秦十年的沉默挡着，她先拿怀表试探、再拿父亲的旧照逼他，结果两人的关系从'陌生的买卖'变成'共同保守秘密的人'。"

### 4.2 人物任务卡（五支柱）

```
【任务卡】老秦｜s02
目标：让林夏把怀表收回去、今晚就离开当铺
障碍与代价：林夏不走；她追问下去，他十年前替她父亲做的事就会暴露
战术序列：装糊涂（u1）→ 拖延，擦眼镜、拨算盘（u2）→ 被逼急后反问（u3）
变拍点：林夏拿出旧照的那一刻，他从"装糊涂"换成"反问"
潜台词：我知道你爸在哪，但我答应过他不说
倾听时在做什么：拇指一直在表盖上来回摩挲
```

### 4.3 把情绪翻译成身体

三个通道：

1. **大动作**：走位、坐立、转身、递物、靠近或后退。承载关系变化。
2. **小动作**（手和物件）：指节发白、拇指摩挲、捏紧又松开、整理衣角、反复开合打火机。承载内心暗涌。
3. **微表情**（脸、眼、呼吸）：瞳孔一缩、嘴角极轻地抽一下、喉结滚动、屏住呼吸、视线游移又移回、呼吸变浅。

情绪对照（左边是标签，右边才是表演）：

| 标签 | 可见的表演 |
|---|---|
| 愤怒 | 咬紧下颌，指节发白，呼吸变短，视线钉在对方脸上 |
| 委屈 | 下巴先抖，眼眶泛红但泪不落，手指抠着衣角 |
| 隐忍 | 咽一下口水，嘴角压平，肩膀不动，只有喉结动 |
| 惊讶 | 手上的动作停住，呼吸乱了半拍，视线定在一处 |
| 悲伤 | 红了眼眶却别过脸，手指无意识地摩挲某样东西 |
| 心虚 | 视线先落到对方手上再移开，手去找一件事做 |
| 释然 | 肩膀沉下去，长出一口气，嘴角松开 |
| 疲惫 | 揉着太阳穴，目光飘开，向后靠进椅背 |

**物理指令 + 潜台词说明**：情绪节点先写可执行的动作，再在括号里解释动作背后的意思；删掉括号，动作仍然成立。例："他把怀表推回她面前，指尖在表盖上停了半秒才收回（他想让她走，又舍不得这块表）。"

### 4.4 表演的强制项

- **眼活**：近景以上的镜头写清视线落点和移动（看对方 → 躲开 → 再抬起）。眼神空洞是 AI 表演的第一大病。
- **反应先于台词结束**：听者在对方话说到一半时开始反应。
- **不演结果**：只演人物此刻知道的事。
- **情绪要有触发**：先压抑，后破裂。
- **一场不止一种颜色**：每个变拍换一种战术。
- **手势不复读台词**：手势要么先于想法，要么和台词矛盾，要么没有。
- **身体符合履历**：体态、重心、节奏、磨损感与人物前史一致。
- **脸不"表演情绪"**：挑眉、苦相、挤眉弄眼都是图解。给手找一件事做。

### 4.5 动作链六要素

起势 → 发力 → 接触 → 反馈 → 余势 → 落点。

- 用因果顺承词咬住子动作：随即、顺势、脚步不停、几乎同一瞬。逗号并列互不相干的动作（"他跑步、开门、打电话"），模型会取平均，变成静止或飘。
- 每个子动作写清落点：脱手的刀飞向哪里，被踢开的人撞到什么。
- 穷尽到身体部位、方向和次序。
- **动词领头，速度显式**：模型默认慢镜，用"骤然冲出""猛地扑出"覆盖；动作写完补终点"随即定住"。
- **原文动词不降级**："落荒而逃"不能写成"小跑"，要写出速度、重心、步频、呼吸和回头。
- **物理成立**：身体有重量，脚有摩擦，打击有反作用力，衣摆和头发晚于身体半拍停下。

### 4.6 群像

- 主体层推动剧情；反应层每人一个可见反应，各不相同；背景层写死外观和一个统一动作。
- **情绪波**：从离事件最近的人开始，一圈圈往外传；不要所有人同一帧同一个表情。
- 人群写局部形态："挤在台口的身体、前景晃动的手臂"。
- 不说话的人嘴唇闭合。

### 4.7 不同媒介轨

- 写实轨：微表情和小动作为主。
- 2D 动漫轨：表情可适度夸张，动作有清晰的预备与收势，可用速度线、汗滴等漫画符号。
- 3D 国漫轨：动作有重量和惯性，武打写清招式路径；面部表演介于写实与动漫之间。

### 4.8 讲戏本格式

```
### s02 当铺·夜·内
场阐述：……
任务卡：
【任务卡】林夏｜s02 ……
【任务卡】老秦｜s02 ……
单元阐述：
s02-u1：……（一段散文：画面内容、人物动作、台词声音、镜头感觉、光影氛围、气口与镜尾）
拍序（D053 规定的单元才写）：
s02-u3：拍1 林夏把旧照拍在柜台上 → 拍2 老秦的手停在算盘上 → 停留：老秦盯着照片 ≥2 秒 → 拍3 老秦抬眼
```
