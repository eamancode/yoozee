# seedance25-ontology-director（v2.2）

剧本 → Seedance 2.5（即梦）视频提示词的本体论导演 skill。

## 结构：四层，每条规定只写在一处

```
seedance25-ontology-director/
├── SKILL.md            契约层：身份、优先级链、13 条绝对规则、回合路由、输出契约
├── params.md           参数层：全部固定数值（P01–P64）与校准回填区
├── stages/             环节层：每个文件 = 输入 → 决策表 → 判据表 → 写法 → 自检
│   ├── S0_回合与输入.md
│   ├── S1_世界圣经.md
│   ├── S2_台词.md
│   ├── S3_拆节奏.md
│   ├── S4_讲戏.md
│   ├── S5_氛围.md
│   ├── S6_导演分镜.md
│   ├── S7_编译.md
│   └── S8_质检与返修.md
├── templates/          空白模板：材料包、世界圣经卡、每集输出骨架、九段粘贴提示词骨架
├── examples/           写实、2D 动漫、3D 国漫各一个完整单元（同场合并、短剧节奏、含站位交接镜头）
├── prompts/            审稿规程（另开对话复审用）
├── tests/              评分细则与 8 个测试用例
├── dist/               对话版单文件（由脚本编译生成，不要手改）
└── archive/            归档知识库（维护用，生成时不读取）
```

## 编号体系

| 前缀 | 含义 | 定义在哪 |
|---|---|---|
| R1–R13 | 绝对规则 | SKILL.md |
| P01–P64 | 固定数值 | params.md |
| D001–D084 | 默认值决策与规则（D042、D043 已在 v2.1 删除） | 各环节文件的决策表；纯数值类并入 params.md |
| J0xx | 判断型决策的判据 | 各环节文件的判据表 |
| H1–H11 | 硬失败 | S8 |

冲突时的优先级：平台硬约束 ＞ 剧情事实 ＞ 圣经不变量 ＞ 决策默认值 ＞ 方法建议 ＞ 示例与案例。

## 怎么用

- **支持 skill 的环境（如 Claude Code）**：把整个文件夹放进 skills 目录，按 `templates/01_材料包.md` 发材料。
- **普通对话模型（豆包、DeepSeek、Kimi 等）**：新开对话，粘贴 `dist/对话版_导演规程.md` 全文，再发材料；复审时另开对话，粘贴 `dist/对话版_审稿规程.md`。

两种方式的内容完全一致：对话版由脚本从同一套源文件编译而成。

## 修改流程

1. 只改源文件：SKILL.md、params.md、stages/、templates/、examples/、prompts/。
2. 重新编译对话版，并运行校验。校验内容：编号唯一与引用完整、外部残留、旧矛盾说法、示例自洽、对话版同步。
3. 用 tests/ 的用例在两种环境里各跑 3 次，按评分细则记录。
