# 世界圣经卡模板（立项回合输出；整卡 ≤4000 字）

```
【世界圣经卡】【项目名】｜版本 v【1】｜【日期】

一、世界法则
  一句话故事：【主角】想要【目标】，被【阻碍】挡住，最终【变化】
  主题：【故事真正讨论的情感命题，一句话】
  类型与写实程度：【主类型/子类型；观众应相信到什么程度】
  时空：【国家、城市或地貌；具体年份或十年内范围；季节；剧情经历多久】
  科技与生活边界：【通讯、交通、服装、建筑的年代边界】
  语言与口音：【对白语言；各人物口音；阶层造成的措辞差异】
  特殊规则：【超自然/异能/系统设定的能力边界与代价；无则写“无”】
  时代锚句：【1–2 句，含 2–3 件画面里看得见的时代物证】

二、存在者名册
  【人物】【姓名】｜【核心/边角】
    身份短串：【≤40字：年龄、性别、脸型、发型、标志特征、体型】
    声线锁：【音高、语速、质感、口音条件、一个标志性习惯】（有台词才写）
    表演气质：【紧张/开心时的身体习惯；情绪表达方式】
    状态表：A＝【服装与状态】（第【N】集起）；B＝【……】
    小传：外在目标——【……】；内在需要——【……】；最大恐惧——【……】
    参考图：【@图N / 无】
  （每个核心人物一张）

  【空间】【名称】｜【内景/外景】｜【核心/边角】
    拓扑：【从哪进、通向哪】
    地标：【3–5 个可见地标】
    光源物：【灯、窗、屏幕……】
    场域锚句：【一句可直接粘贴的陈设描写，含年代物证】
    参考图：【@图N / 无】

  【物件】【名称】｜【核心】
    外观短串：【……】
    状态序列：【完好（第N集）→ ……】
    承重文字：【无 / 有：内容，标“后期叠加”】

  【群体】【名称】：【人数感、年龄构成、统一服装、统一动作】

三、关系与信息
  关系表：
    【A】—【B】：权力【谁高】；A想要【……】；B想要【……】；隐瞒【……】
  信息差表：
    | 秘密 | 谁先知道 | 观众何时知道 | 另一方何时知道 |
    | 【……】 | 【……】 | 【第N集sXX】 | 【……】 |

四、美学宪法
  媒介轨：【写实 / 2D动漫 / 3D国漫】
  通用基准段：【60–120字：媒介质感、色域、光的逻辑、镜头性格；不写年份、地名、陈设】
  色彩母题：【颜色 → 绑定的物件与光 → 叙事意义】
  光的逻辑：【全片光从哪来、冷暖、高调/低调】
  镜头性格：【固定/手持倾向、广角/长焦倾向、节奏快慢】
  声音基调：【环境声质感、对白录音感】
  表演基线：【克制 / 外放 / 喜剧夸张】

五、时间之弧
  季弧：【分几段，每段转折点】
  每集一句话与钩子：
    第1集：【……】｜集末钩子：【……】
  情绪曲线：1【节点名】【强度0–10】→ 2【……】→ ……（标出最高峰、主要反转、呼吸区）
  母题表：【意象】埋于【第N集】，回收于【第N集】
```
