# 材料包模板（用户填写，随本 skill 一起发给模型）

把【】里的内容换成你的信息；不需要的行整行删掉。

```
【指定】
片种：【都市情感短剧 / 古装 / 悬疑 / 喜剧 / 武侠 / 科幻 / 广告 / MV……】
画幅：【竖屏9:16 / 横屏16:9】
媒介轨：【写实 / 2D动漫 / 3D国漫 / 其他：……】
每集时长：【约2分钟】
背景音乐：【不要 / 要：在哪里、什么感觉】
站位交接镜头：【开启（默认）/ 关闭站位交接】
节奏：【短剧（默认）/ 文艺 / 其他：……】
其他要求：【……】

【素材清单】
@图1 = 【人物名】 【正面半身 / 全身 / 某状态】
@图2 = 【场景名】 【内景/外景，时段】
@图3 = 【道具名】
@音频1 = 【人物名】的音色参考
（没有参考素材就写：无）

【世界圣经卡】
（第 2 集起、或立项回合之后，把模型输出的圣经卡原样粘贴在这里）

【集交接卡】
（第 2 集起，把上一集的交接卡原样粘贴在这里）

【返修】
（只有返修回合才填：粘贴翻车的单元卡，并写症状，例如"第3镜林夏的脸和第1集不一样""动作没做完""多了一个路人"）

【剧本】
（粘贴本集剧本。不能改的台词前面加【保留】）
```
