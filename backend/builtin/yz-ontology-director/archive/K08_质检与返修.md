# K08｜质检与返修

> 本卷是本 skill 的结构化知识库之一，对应本 skill 的 S8。
> 什么时候查：五类病审稿、硬门槛、症状第一刀、返修路由。
> 本卷结构：一、核心规则与裁决 → 二、模块与卡片目录 → 三、知识卡片。卡片编号格式为 Kxx-yy-zz（卷-模块-卡片）。
> 卡片内容整理自多种既有方法，保留了完整论述；其中的时长、平台参数、否定句写法与主规程不一致时，以主规程为准。卡片中出现的阶段代号与旧术语见 references/01_术语对照.md。

## 一、核心规则与裁决

**本卷回答的本体问题**：生成之前怎样发现问题？翻车之后怎样找到责任层？对应本 skill 的 S8和审稿规程（prompts/审稿规程.md）。

### 1. 提炼出的规则

1. **只审不改**（〔K08-11 审稿环节总则〕）：审核者拿被审产物对照只读基准，查五类病——矛盾、断链、走样、模型雷、红线；四类审核点：拆解审、资产审、镜头表审、成片审。
2. **合规清单**（〔K08-08 合规清单〕）：逐项可核对的硬规则。
3. **回流路由**（〔K08-09 回流路由〕）：问题按责任层退回对应工位。
4. **排演锚点**（〔K08-10 排演锚点〕）：在花钱生成前用文字排演每个镜头。
5. **硬门槛只保护正确性**（〔K08-14 导演质量门槛〕）：剧本事实、用户确认、资产映射、物理与空间连续、平台限制、预演一致性、模型容量；创意偏好不设硬指标；失败只重写责任层，最多两轮。
6. **症状 → 第一刀 → 升级出口**（〔K08-02 症状与第一刀〕）：先做单变量修改，不行再升级到拆条、换参考、回上游。
7. **五出口修复路由**（〔K08-05 返修环节总则〕）：改词、视频编辑与延长、拆条重编、换角度、回资产站。
8. **视频编辑语法**（〔K08-04 视频编辑与延长语法〕）：2.5 智能编辑与延长的写法。
9. **图像手术**（〔K08-03 图像局部修改〕）：局部改图的写法。
10. **实验总结**（〔K08-13 实验总结〕）：30 个实测案例的规律，例如爆款开场、宫格驱动、多语版本的经验。

### 2. 冲突裁决

| 冲突点 | 各资料说法 | 本规程裁决 |
|---|---|---|
| 自评打分 | 旧版本有 100 分自评；匠心版方法 2.12 取消 | 不打总分，只查七条硬失败 + 主角表演量表 |
| 独立审核 | 工位方法：fresh 派发的审核者 | 方案 B 用"另开干净对话 + 审稿规程"平替 |

### K08-01｜返修案例

> 方法体系：工位方法。模块说明：当你接了一个返工案、要看整案怎么走完收案到落盘时对照它。演示视频就片编辑、图像手术式编辑、换 shot 三则标杆案例的诊断链、修复指令与编法注解。

#### K08-01-01｜示例定位

- 返工标杆案例三则，附「为什么这么编」注解。
- 三案覆盖：视频 · 出口 2 就片编辑、图 · 出口 2 手术编辑、视频 · 出口 3 换 shot。
- 三案自洽，不要求与其他 skill 引用同一故事。

#### K08-01-02｜案例 1 · 视频 · BGM 乱入 + 路人乱入 → 出口 2 两轮编辑

收案：

用户报修 ep01-s03-c2，雨夜巷口对峙，11 秒：1 全程有一层没写过的钢琴配乐；2 第 6–8 秒画面左侧走过一个撑伞路人。已抽 2 次。

诊断：

- 重读该条提示词原文：恒定层声音基调漏写 BGM 指令，违反不留空原则；正文与尾缀均无"无额外人物"问题——路人属于概率乱入。
- 两个症状片子大体成立、都是局部问题 → 出口 2，一次一改分两轮。

修复第一轮 · BGM 分离：

```
请将@视频1中的背景音乐全部移除，只保留人声与雨声环境音。画面必须保持完全一致。
```

修复第二轮 · 智能编辑删路人：

```
仅在第 6–8 秒期间，删除画面左侧撑伞走过的路人，用原有的湿砖墙与雨中巷道背景自然填补，其余保持不变。
```

落盘：

〔粘贴提示词〕 该条头部加注记 [v2 · 2026-08-25 · 症状：BGM 乱入 + 路人乱入 · 出口：2 · 改动：BGM 分离 + 6–8s 删路人；源头补声音基调"无背景音乐"]；并在该条恒定层声音基调句就地补"无背景音乐"，防下批复发。

为什么这么编：

- 两个症状分两轮编辑，一次只改一个对象——合成一条指令会互相污染。
- 删除配填补："用湿砖墙与雨中巷道背景自然填补"，只删不填模型会即兴发明填充物。
- 时序限定"仅在第 6–8 秒"防时序断裂；收尾锁两轮都写。
- 修片之外回改了源提示词——就片编辑治这一条，改源头治后面每一条；两处都记了版本注记。

#### K08-01-03｜案例 2 · 图 · 场景板时代穿帮 → 出口 2 手术式编辑

收案：

用户报修 scene-004，1998 年小城台球厅场景板，3/4 视角：画面右侧墙上挂着一台平板电视——时代穿帮物。构图、光线、纵深、年代质感其余全部成立。首次报修。

诊断：

底子成立、只有一处要动 → 编辑不是重建 → 出口 2 手术式母版。若整板正面平视无纵深，才是重建回 场景设定环节。

修复指令：

```
Edit the image: remove the anachronistic flat-screen TV.
CHANGE: remove the flat-screen TV on the right wall; fill the area with the same aged floral wallpaper and a faded 1990s calendar poster consistent with the room's era.
PRESERVE EXACTLY:
- pool tables, hanging lamps, cue rack, floor wear, window light direction, all existing shadows, the 3/4 camera angle
- Color grade, palette, contrast, grain, falloff
ONLY CHANGE: the TV area on the right wall. 100% identical otherwise.
```

落盘：

〔场景设定提示词〕 中 scene-004 条目加注记 [v2 · 2026-08-25 · 症状：平板电视时代穿帮 · 出口：2 · 改动：删除并以年代墙纸 + 90 年代挂历填补]；reference-index 该条指向 v2 图。

为什么这么编：

- 删除配填补且填补物押着时代锚——旧花纹墙纸 + 90 年代挂历——填补不只是"补上"，是继续为 1998 服务。
- PRESERVE 穷举到球台、吊灯、杆架、地面磨损、窗光方向、阴影、机位——"改多了 = 锁得不够"，清单越穷举编辑越干净。
- 同步给 场景设定环节 提了一句预防：该场景提示词的时代锚下批重生成时要把现代电器点名封禁进 absent 清单，根治不靠每次手术。

#### K08-01-04｜案例 3 · 视频 · 复杂动作抽 17 次穿模 → 出口 3 换 shot

收案：

用户报修 ep02-s05-c3，破门 + 缠斗 + 夺械，14 秒，B 轨 5 镜：缠斗段手臂穿模、兵器一变二。已抽 17 次、改词 5 版——物理锁、数量逐帧、砍运镜各试过一轮。

诊断：

17 次逼近铁律上限，且按下葫芦浮起瓢——修好穿模又冒出数量复制——条内复杂度超载。"救回来的镜头全靠换 shot，没有一个靠改措辞。" → 出口 3，三法里选拆条 + 开场即中态。

方案，先给用户过目：

- 拆为两条：条 3a · 破门突入，6 秒 2 镜，止于两人对峙起势；条 3b · 缠斗夺械，8 秒 3 镜，开场即中态——"两人已经扭抱在一起，他的手已经扣在对方持械的手腕上"，接近与起手过程全部不拍。
- 影响：本场条数 4 → 5，镜头表 s05 分镜重排。

执行，用户点头后：

- 〔导演分镜卡〕 更新 s05 镜头表，注记改动与理由；回 编译环节 重编译 3a、3b 两条，3a 结束状态五字段交接给 3b；重跑成片审；〔集交接卡（连续性台账）〕 更新该场落幅链。
- 〔粘贴提示词〕 原条 3 保留并标注 [v6 · 2026-08-25 · 症状：穿模 + 数量复制 · 出口：3 · 改动：拆为 3a、3b，本条弃用]。
- 交付后返工，条数变了：本集成片审报告与 〔粘贴提示词〕 头部「生成顺序与校准」小节当即失效，注记里写明；重跑成片审，编译环节 重写头部小节顺序，并在 〔决策记录〕 记一行复核结论。用户手上那份旧顺序作废，等新版出来再继续生成。

为什么这么编：

- 不再磨第 6 版措辞：17 次 + 症状轮转是"词的容量装不下这个 shot"的铁证，换 shot 是升级不是认输。
- 拆点选在戏剧断点即对峙起势完成处，不在动作半途。
- 3b 开场即中态——复杂动作不放时间轴中段，接近过程不拍，每条各自变简单，通过率翻倍。
- 镜头表是用户确认过的结构，先过目再落盘；结构变了所以重跑成片审，且结束状态继承链重接、台账同步——换 shot 不是只改一条，是把下游三个真相源一起改齐。交付后返工还要往回追一层：成片审与交付包都建立在旧条数上，一起作废重来，否则用户拿着一张波次对不上的旧顺序表去安排生成。
- 原条不删除：弃用条保留注记，17 次的失败记录是后续同类 shot 的设计依据。

#### K08-02-05｜判据卡 · 词的问题 vs 参考的问题

怎么认：

- 改词能治的症状，证据在「执行差」——动作方向错、速度错、多了少了；参考问题的证据在「身份差」——像素级不像、质感漂、角度一到位就崩。
- 快速试金石：想象把这条 prompt 配上完美参考图再跑一次，症状还会在吗？会在 = 词的问题；不会在 = 参考的问题。

认错长什么样：

- 身份漂移磨了五版措辞越磨越漂——从第一版就该去看参考图干不干净、角度覆盖够不够。

典型例子：

- 远景里主角脸糊——不是词没写好脸，是全身格带头的糊脸成了模型的脸源，回 人物设定环节 重做去头三格表。

#### K08-02-06｜判据卡 · 编辑 vs 重建

怎么认：

- 编辑 = 原片或原图的后处理——底子成立、只动一处、其余像素级保留。要动的东西越多、越核心——身份、结构、构图——越不是编辑。一次编辑只改一个对象；要改三处 = 三次编辑或直接重来。

认错长什么样：

- 对整体崩坏的图连做四轮编辑，每轮引入新瑕疵——"需要重建的帧不是编辑"，回生成站重出；对视频想用智能编辑改剧情走向——那是整段重编，编辑改不了因果链。

典型例子：

- 场景板右侧多一扇现代玻璃门 → 编辑，删 + 填补；场景板整体是正面平视墙纸感 → 重建，回 场景设定环节 按 3/4 视角重生成。

#### K08-02-07｜判据卡 · 该换 shot 了

怎么认：

- 三信号任一即评估换 shot——1 同条已抽 15–20 次；2 症状属于整段重编七情况；3 每次修好一处就崩另一处，按下葫芦浮起瓢，条内复杂度超载、词的容量装不下这个 shot。

认错长什么样：

- 接近 20 次仍在换同义词、调语序——"救回来的镜头全靠换 shot，没有一个靠改措辞"；把换 shot 当失败——拆条后两条各自简单，通过率反而翻倍。

典型例子：

- 破门 + 缠斗 + 夺械一条 14 秒抽了 17 次穿模——拆成「破门突入」与「缠斗夺械」两条，第二条开场即中态"他已在挥拳中段"，一次过。

### K08-03｜图像局部修改

> 方法体系：工位方法。模块说明：当你要对一张已生成的资产图或控制图动手改、或要判编辑还是重建时翻它。给图像规则集声明、手术式编辑骨架、纹理修复通道、delta 状态变体制作法与改输入手段。

#### K08-03-01｜定位

图像手术式编辑册，图支路出口 2 与出口 4 用。本册属于图像规则集，对象是已生成的资产图与控制图。

核心信条：编辑 = 原图的后处理——原图是底，改动最小化，其余像素级保留。

可填空母版见 〔K08-06 图像编辑模板〕。

#### K08-03-02｜图像规则集声明 · 本支路生效，禁带入视频支路

- 图像生成提示词：无负面参数——任何模型都没有负面参数，NOT 堆叠会把被禁概念本身注入画面；只写想要的，"clean dry skin" 而非 "no acne"；紧凑散文打败长文堆砌；纯正向。此规则集由资产站 character/scene/道具设定环节 与 控制图环节 持有，重生成时回那里。
- 图像编辑提示词是本册主场，有两条例外：1 显式删除是合法操作，如 "Remove the lamppost" 移走路灯，但必须配填补物，如 "continuous brick wall behind" 背后是连续砖墙——只删不填，模型自己发明填充物；2 CHANGE 与 PRESERVE EXACTLY 这类结构化大写块仅编辑提示词可用，生成提示词禁用——生成用连贯散文。

#### K08-03-03｜手术式编辑骨架

编辑链通用骨架，中英两式逐块对应，项目语言默认中文；母版本体的全库唯一权威版在 人物设定环节 的 〔K01-04 人物变体与群演〕，本节是它在图支路的展开式。

中文块，可整块抄：

- 编辑这张图：{{一句话目标——改什么、为了什么}}。
- 改动：{{唯一要变的那一处，描述到精确：位置、对象、目标状态}}。
- **严格保留：**
- {{穷举一切必须保持一致的元素——脸、服装、道具、位置、墙面地面、机位角度、既有阴影}}
- 调色、色板、对比度、颗粒、光衰减
- 只改{{重申那唯一一处}}，其余部分百分之百一致。

英文原句：

- Edit the image: {{one-line goal}}.
- CHANGE: {{only the single thing that changes, described precisely}}.
- PRESERVE EXACTLY:
- {{list every element that must stay identical: face, clothing, props, positions, wall/floor, camera angle, all existing shadows}}
- Color grade, palette, contrast, grain, falloff
- ONLY CHANGE: {{restate the one change}}. 100% identical otherwise.

三铁律：

- 一次一改，one change at a time：要改三处 = 三轮编辑，逐轮验收。
- 删除配填补：每个"删掉{{X}}"必须跟"背后或原位是什么"。
- "用户说你改多了 = 你锁得不够"——Lock everything, change one thing，锁死一切、只改一处。PRESERVE 清单写得越穷举，编辑越干净。

#### K08-03-04｜判据卡 · 编辑 vs 重建

怎么认：

- 底子成立、只动一处 → 编辑；结构、身份、构图、画风这类整体属性要动 → 重建，"需要重建的帧不是编辑"——回 character/scene/道具设定环节 或 控制图环节 重生成。

认错长什么样：

- 对整体崩的图连做多轮编辑，每轮引入新瑕疵、越修越花。

典型例子：

- 场景板混进一辆现代轿车 → 编辑，删 + 填补路面延续；场景板整体正面平视、无纵深的「墙纸感」 → 重建，回 场景设定环节 按 3/4 视角规则重出。

#### K08-03-05｜纹理修复通道 · 质感假但图成立时

怎么认：

- 症状是 AI 蜡感——皮肤无毛孔、织物无织纹、表面无尘埃划痕，而构图、身份、光线都对。走「只修表面」的编辑：CHANGE 只列表面项，如 skin pores 皮肤毛孔、fabric weave 织物织纹、surface dirt and wear 表面尘埃与磨损；PRESERVE 锁构图、身份、五官、光线、调色全部。

认错长什么样：

- 在纹理通道里夹带点位修改、顺手把道具也改了——纹理修复绝不做点位编辑，点位编辑另开一轮手术式母版。

#### K08-03-06｜delta 变体制作法 · 状态变体 = 编辑产物

怎么认：

- 角色、场景、道具的新状态——湿身、带伤、战损、夜版——不重跑底图：拿原表只改变化的部分，如换衣、加伤痕、打湿布料，其余像素不动。
- 底图永不整体过第二遍模型，皮肤纹理与身份才能存活——"The base image stays the same pixels."（底图保持同一批像素。）
- 产物登记：新变体 char/scene/prop-NNN-vN 写入 〔资产设定〕 对应文件 + reference-index，永不覆盖原版；命名可叠状态注记，如 v2 = 湿身。

认错长什么样：

- 为加一道疤把整张角色表重新生成——新表是"另一个很像的人"，全片一致性从此裂开。

典型例子：

- char-003 需要「第三幕带伤」版：手术式编辑在原特写与全身格加左眉骨挫伤与领口血渍，PRESERVE 锁五官、发型、服装其余部分、光线、中灰底，登记 char-003-v2。

#### K08-03-07｜改输入手段 · 出口 4 的图侧做法

怎么认：

- 视频侧纯 prompt 怼不动的反物理与特殊姿态，把物理烤进输入图，再放松 prompt 只钉锚点：
- 倒置图：需要倒吊或倒挂镜头 → 把角色表或关键帧整体倒转后作输入——prompt 精调常常全败，倒转输入图一次解决；倒转图从此登记为该角色的 inverted 状态变体。
- 预摆姿态：需要特定开场姿态 → 用手术式编辑把关键帧里的人物改到目标姿态，如 mid-swing 挥拳中段，以图定姿、以词定动。
- 状态烤入：视频保不住的属性——湿透、覆雪、破损——做进输入变体图，视频提示词侧连提都不提。

认错长什么样：

- 改了输入还写满帧物理描述提示词——物理已在图里，词只需钉关键锚点 + 运动因果，写满反而引入冲突。

典型例子：

- 倒吊审讯镜头：char-005 表倒转 → 登记 char-005-v3 即 inverted 态 → 视频条只写"镜头缓慢环绕，他悬垂的手指轻微晃动"，一次过。

#### K08-03-08｜垫图话术与工具边界

- 垫图迭代话术：明确说保留什么、只改哪一两个元素，如"以这张图为底，保留构图、人物与光线，仅把背景霓虹改为暖黄路灯"，迭代式微调，不整段重写描述。
- 站位图与图解类控制图的改稿两规则——回喂原始帧不喂上版图解、色键动作口令改稿——单源住在 控制图环节 的 〔K06-15 站位图〕，控制图返工先读那份，本册不复制。
- 工具无关性：以上母版与纪律适用于任何支持图像编辑的工具，即梦平台的图片编辑等 web 工具均可；指令原文交给用户在生成侧执行；编辑结果与原图并排对照验收，PRESERVE 项逐条扫。

### K08-04｜视频编辑与延长语法

> 方法体系：工位方法。模块说明：当你要就已生成的片做局部改写或续写、不打算重抽时翻它。给智能编辑、高级编辑、视频延长、BGM 分离、无缝衔接与空间视角修改五件工具的句式与通用纪律。

#### K08-04-01｜定位

就片编辑与延长的视频侧句式集，出口 2 用。本册全部属于视频提示词规则集，对象是已生成的片：能就片解决的不重抽。

五件工具依次为智能编辑、高级编辑、视频延长、BGM 分离、无缝衔接与视角修改，通用纪律压尾。

可填空母版见 〔K08-07 视频修补模板〕。

#### K08-04-02｜智能编辑 · 文字改写已有视频

怎么认：

- 官方公式：{{具体修改对象}} + {{动作与变化描述}} + {{生效时序}}。
- 必含操作动词之一：编辑、增加、删除、替换、改成。
- 生效时序三态，必写其一：全片统一修改保持一致；仅在第 X–Y 秒期间发生变化；从第 X 秒起逐渐显现。
- 收尾锁："其余保持不变" 或 "画面必须保持完全一致"。
- 完整修正母版，局部修复的满配版、症状复杂时用：
  - 保持【人物身份、服装、背景、摄影机运动、光线、色彩、声音和其他区域】完全不变。仅修改【时间段】内画面【区域或对象】。将【错误状态】修正为【目标状态】，严格参考【@资产】的【具体职责】。修正后的对象必须与前后帧在【位置、尺度、材质、光线、运动速度、遮挡和边缘】上连续，不闪烁、不变形、不污染相邻区域。

认错长什么样：

- 不写生效时序 → 改动时机随机，掉进时序断裂坑。
- 一条编辑指令改多个对象 → 互相污染，一次只改一个。
- 不写收尾锁 → 模型顺手重绘无关区域。

典型例子：

- 删除：仅在第 12–14 秒期间，删除画面右侧走过的路人，用原有的砖墙与街道背景自然填补，其余保持不变。
- 替换：将男主手中的白色马克杯替换为无标识的黑色搪瓷杯，全片统一修改保持一致，人物动作与画面其余部分必须保持完全一致。
- 改天气：从第 3 秒起逐渐显现小雨，雨丝细密、地面渐湿反光，人物与镜头运动保持完全一致。

#### K08-04-03｜高级编辑 · 带标注的框选改写，针对生成后视频

怎么认：

- 在智能编辑公式前加一段【标注工具与方位】：将红框内、沿红色箭头指向的区域、地标点处、红线左侧……
- 其余同智能编辑：对象 + 变化 + 时序 + 收尾锁。本地上传的素材片用「视频编辑」入口，语法相同。

认错长什么样：

- 画了框但文字不复述方位——标注与文字必须互相印证，只靠框模型会改错对象。

典型例子：

- 将红框内的霓虹招牌上的乱码文字替换为空白灯箱，仅在第 0–6 秒期间生效，招牌位置、亮度与画面其余部分保持完全不变。

#### K08-04-04｜视频延长 · 延长链，续写而不是重抽

怎么认：

- 适用症状：动作没落地、缺结尾一拍、要接力续写剧情反转、复杂动作分段导戏的「走一步看一步」。
- 必含词之一：向前延长、向后延长、延续、续写。
- 延长提示词只对新增段生效，原片完全保留——所以只写新增段：承接句续上原片落幅状态 + 新段动作因果链 + 新落幅。
- 一镜到底延长加固定句："要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现"。
- 参数底线：底片 ≤30s；单次可延 4–30s；套娃式多次延长上限 60s，极限打法是 30s 底片 + 延 30s 一步到位。

认错长什么样：

- 在延长提示词里重写原片内容——原片不受延长提示词控制，写了也白写还挤预算。
- 该延长的用重抽——原片里已经成立的 25 秒全部重新抽卡，纯浪费。
- 延长段开新动作不承接落幅——接缝跳变。

典型例子：

- 向后延长 6 秒：承接结尾处他持刀低垂、胸口起伏的状态，他缓缓直起身，把刀插回鞘中，转身走向门口，在门框处停步定住。要求延长自然、动作衔接流畅、动作衔接自然，禁止生硬切镜、禁止物体凭空出现。

#### K08-04-05｜BGM 分离与声音修复

怎么认：

- BGM 乱入已生成片时，用只动声轨不动画面的指令："请将@视频1中的背景音乐全部移除，只保留{{XX}}人声。画面必须保持完全一致。"
- 防复发：回源头在该条恒定层声音基调补"无背景音乐"，见 声音环节。

认错长什么样：

- 只移除音乐不锁画面——模型顺手重绘；下一批生成仍不写 BGM 指令——同症状复发。

#### K08-04-06｜无缝衔接与空间视角修改

怎么认：

- 双视频拼接，修接缝用："将【@视频1】和【@视频2】无缝衔接起来，但是不修改【@视频1】和【@视频2】" + 描述桥接内容 + 锁定项，如"保持{{XX}}的位置、大小和运动方向一致"。适用两条相邻条接缝跳变、需要生成过渡帧。
- 空间视角修改，改机位不重拍：显式列出需外推补全的内容，如"需要合理补全【新视角下会暴露的区域：人物肩背轮廓、桌面顶部、背景空间延展……】"，并锁定"身份、服装、姿势、动作节奏和画面内物体位置关系不变"。

认错长什么样：

- 只说"换个角度看"不列补全清单——新视角的空白区域由模型即兴，几何必错。

#### K08-04-07｜通用纪律

- 编辑类必人工验收：示范级案例的局部编辑也有翻车细节——消除不全留残影、物体消失得毫无征兆；编辑不是保票，逐帧扫一遍再收货。
- 一次编辑一个对象；要改多处，按重要度排序逐次做，每次验收后再下一刀。
- 输入时长经验值：视频编辑输入 ≤20s 最稳，超长片先想清楚改哪一段。
- 每次编辑同样记版本注记——症状、工具、指令原文一行——计入该条的迭代次数：编辑也占 15–20 次预算。
- 身份、结构、因果这类编辑救不了的别恋战，回诊断树升级出口。

### K08-05｜返修环节总则

> 方法体系：工位方法。模块说明：当用户带着生成翻车的视频条或图片回来报修时使用——说"这条不对、脸崩了、动作没做完、多了个人、想局部改一处、这张图不行"等任何生成后返工诉求。具备症状诊断、五出口修复路由、官方智能编辑与延长语法、图像手术式编辑与改输入改造能力。产出可直接执行的修复提示词或上游派活单，并就地更新对应产物文件与版本注记。

#### K08-05-01｜任务

返工修复，事件驱动的售后站。用户按 06 头部「生成顺序与校准」小节统一批量生成后，带着翻车的视频条或图——资产图/控制图——回到任意窗口报修，本站接案。

职责四步：诊断症状 → 路由五出口 → 产出修复，即新提示词/编辑指令/输入图改造/上游派活单 → 就地落盘 + 版本注记；涉状态更新台账。

边界：只修「生成后翻车」，生成前的审核 FAIL 走 审稿环节 的回流路由表 〔K08-09 回流路由〕、不进本站；不在售后重做创作决策，意图、节奏、这场戏怎么讲的问题指回上游站、不现场改剧；跨集共用资产的返工改动波及多集，在全局层窗口做，本集专属条在本集窗口做。

#### K08-05-02｜第一性原则

本环节是【导演思维】第 4 问「可生成性」的展开：翻车是模型对提示词最诚实的回答——先诊断它到底在回答什么，再决定改词、就片编辑、改输入、换 shot 还是回上游，绝不上来就磨措辞。

修前先重读原文：打开翻车条的提示词原文与它所引的参考图，对照着看，不凭记忆修——凭记忆描述参考图会攻错方向、连废好几版；生成与场景矛盾时，第一动作是重读参考图。

单变量纪律：一次只改一个变量再回看，一把改五处就失去归因；改不动先 re-roll——概率波动不是提示词缺陷。

15–20 次铁律：救回来的每一个失败镜头都是靠换 shot 救回的，没有一个靠改措辞；同一条抽满 15–20 次仍不过，问题在 shot 不在词，拆条、砍动作、换角度。

一致性崩优先查参考：身份漂移的最大单项提升是先出干净关键帧与多角度参考——那是参考问题不是 prompt 问题，改词是错方向。

反物理先改输入：先想能不能改输入，再想怎么写得更精——纯 prompt 怼不动的反物理与特殊姿态，把物理烤进输入图，如倒置 character sheet；改完输入，prompt 反而可以写松、只钉关键锚点。

双规则集隔离：图支路适用图像规则集——无负面参数、纯正向、紧凑散文，编辑提示词的例外规则见 〔K08-03 图像局部修改〕；视频支路适用视频规则集——负向可用但症状驱动 ≤3、块序优先。两套规矩禁止互相带入。

#### K08-05-03｜收案登记

- 三问：1 哪条或哪张——定位到 epNN-sXX-cN 或 char/scene/prop-NNN，用户口语说"第几条"按条号换算；2 哪不对——可指认到第几秒/哪个部位/什么现象，必要时请用户贴图或描述帧；3 这版已经抽了几次、改过几版词——次数决定起步出口，0–2 次从 re-roll 或改词起步，接近 15–20 次直接评估换 shot。
- 然后重读该条提示词原文 + 所引参考图对照，再进诊断。

#### K08-05-04｜图还是视频

- 资产图/控制图翻车 → 图支路，进第 2A 步。
- 视频条翻车 → 视频支路，进第 2B 步。

第 2A 步 · 图支路诊断——三分

- 局部瑕疵——多指/道具错/背景穿帮/该有的状态细节缺失/时代穿帮物 → 出口 2 图像手术式编辑，方法见 〔K08-03 图像局部修改〕 与母版 〔K08-06 图像编辑模板〕。
- 整体不对——结构错/身份不像/构图废/画风漂移插画化 → 重建不是编辑 → 出口 5 回 character/scene/道具设定环节 或 控制图环节 重生成，并核查其提示词是否踩了图像规则集的雷：触发词、负向堆叠、超长。
- 图本身没错、是模型做不出该姿态或物理 → 出口 4 改输入。

第 2B 步 · 视频支路诊断——查 〔K08-02 症状与第一刀〕 速查表，定性四层

- 词的问题：运镜被无视/默认慢镜/开放运动卡死/动作糊/负向没锁住/声音症状/时代漂移…… → 出口 1。
- 片大体成立、局部要改：换道具/消路人/改天气/BGM 乱入/缺结尾一拍/动作没做完 → 出口 2。
- shot 本身过载：动作链太复杂/主体数超稳定区/一条塞了多场戏/已抽 15–20 次 → 出口 3。
- 根子在上游：参考图脏/资产缺该角度/空间地图错/拆解节奏错/剧情因果本身不成立 → 出口 5。另一形态——画面完全符合镜头表、字段全对但戏不对：对照该条【导演意图】做一次反向回读定性，是意图没译成物理，还是意图本身空；前者回 分镜设计环节 重讲这场戏，后者回 表演环节 补表演意图。
- 反物理或特殊姿态怼不动 → 出口 4。
- 整段重编七情况——剧情顺序错、机位基础路径错、空间整体颠倒、一镜到底被拆、因果链全错、开场即换人、后半段整体失控——直接判出口 3 或 5，禁止局部修补。

#### K08-05-05｜五出口执行

- 出口 1 · 改词——单变量，定性为词的问题时走。
  - 按 〔K08-02 症状与第一刀〕 取该症状的「第一刀」，只动一处，其余逐字保留。负向补刀按视频规则集：症状驱动 ≤3、化进散文。
  - 模型反复画没要的东西 → 点名封禁：把它的常见形态列成 absent 清单 + 写死精确数量——例如画面反复冒出多余铁路站台时，列尽站台、雨棚、灯架为 absent，写死精确轨道数才治得好。
  - 改完回看；同一症状改过 2–3 个变量无效 → 升级出口 2、3 或 5。
- 出口 2 · 就片编辑与延长——不重抽，片大体成立、局部要改时走。
  - 视频侧五件工具，语法见 〔K08-04 视频编辑与延长语法〕，母版见 〔K08-07 视频修补模板〕。
  - 智能编辑：改对象 + 变化 + 生效时序三态 + "其余保持不变"。
  - 高级编辑：前置标注工具与方位——红框内/箭头指向/地标点/红线左侧——针对生成后视频。
  - 视频延长：动作没落地/缺结尾拍/要接力续写时用延长而不是重抽——底片 ≤30s，单次延 4–30s，套娃上限 60s，延长提示词只对新增段生效、原片完全保留。
  - BGM 分离与声音修复：只动声轨不动画面。
  - 无缝衔接与空间视角修改：两段拼接或改机位不重拍。
  - 图侧对应 = 手术式编辑母版，见 〔K08-03 图像局部修改〕。
  - 编辑结果仍需人工验收——示范级案例的局部编辑也有翻车细节，生效时序不写则改动时机随机。
- 出口 3 · 换 shot——shot 本身过载时走。
  - 三法：一是拆成两条——复杂动作不放时间轴中段，开场即中态，如"他已经在挥拳中段、门已经在裂开"，接近过程另拆一条；二是砍动作——并掉次要并列动作，只留因果主链；三是换角度——换景别或机位绕开死角。
  - 镜头表是用户表确认点过头的结构 → 改动先给用户过目，点头后写回 〔导演分镜卡〕，再按编译段重编译受影响条、回 编译环节，重跑成片审。
- 出口 4 · 改输入——反物理或特殊姿态纯 prompt 怼不动时走。
  - 把需要的物理、姿态、状态烤进输入参考图：倒置图、预摆姿态图、湿身/带伤/战损这类状态变体图。产出方式 = 图像手术式编辑以 delta 改造原图、只改变化部分，或回资产站同源重生成。
  - 新图 = 新变体：登记 reference-index 为 char/scene/prop-NNN-vN，永不覆盖原版。然后放松 prompt、只钉关键锚点，让模型自由发挥运镜，多 take 选优。
  - 换图即改绑定集：落盘按 [落盘与版本注记]「涉绑定」行走，条头【上传清单】与正文在同一文件里一次改齐、@图N 整条重编号。
- 出口 5 · 回上游站——指名，根子在上游时走。
  - 按 〔K08-02 症状与第一刀〕 的回上游站点对照表派活：指名站点 + 要修的产物文件 + 症状证据原文。上游修完沿流水线重编译受影响条，重跑该级审核。绝不在本站代做上游的活。

#### K08-05-06｜迭代纪律核对

每轮修复后自问

- re-roll 先行了吗 → 单变量守住了吗 → 2–3 变量无效升级了吗 → 逼近 15–20 次评估换 shot 了吗 → 每版注记留了吗。
- 修复 ≥2 轮仍不过 → 升级问用户：给出已试出口、剩余选项与建议，由用户拍板，不无限自转。

#### K08-05-07｜完成标准

### K08-08｜合规清单

> 方法体系：工位方法。模块说明：当跑合规横切线、逐条做布尔判定、给命中项找依据与规避写法时翻它。12 类判据 + 片型附加组，每类四段：依据 / 命中样态逐条布尔 / 不算命中边界 / 可执行改向。🔴 绝对红线、🟡 平台误杀规避、🔵 投放侧合规三色严格分性质，按定位取条目用，不顺序读完。

#### K08-08-01｜定位

本卡是五类病里「红线」的判据库，不是又一份规则。〔K08-11 审稿环节总则〕 已立纪律：布尔判定、零容忍、任一 🔴 命中即 站位调度环节、逐条过、命中要定位符 + 原文证据。本卡给的是"这条具体长什么样才算命中、依据什么、怎么改能规避"——翻这里。

🔴、🟡、🔵 是三种性质，混判即缺陷。🔴 绝对红线 = 法律与平台硬禁，内容里有它就不许生成，命中即 站位调度环节；🟡 平台误杀规避 = 不是法律红线，是提升生成通过率的工程约束，命中只标"建议改 + 通过率风险"；🔵 投放侧合规 = 内容本身能生成，卡的是上线前的手续与资质，命中只标"投放前置事项 + 责任方"、reflow_to 一律 user。🟡 与 🔵 都不判 FAIL、不置 站位调度环节，除非同时踩了某条 🔴。生成侧与投放侧不许互相顶替：内容干净、缺的是备案或许可，是类 12 命中，不是类 1–10 里任何一条命中。

判定只看被审对象的文字与素材引用，不替用户脑补动机。证据是原文片段，不是转述。

各审级的扫描范围：拆解审扫剧作与设定层，即拆解阐述、资产清单、大纲；资产审扫三个 prompts 包、镜头表审扫全集镜头表，图像与视频提示词都算；成片审全量重扫 + 跨条组合风险——单条无害、连起来构成可操作教程或侵权叙事的，按组合判。

#### K08-08-02｜怎么用

1. 逐条扫：每条/每镜/每个资产提示词过一遍 12 类，不是整篇扫一遍就算。
2. 命中先归类：先判 🔴、🟡 还是 🔵，再写命中样态 + 定位符 + 原文证据。
3. 给可执行改向：每条命中都要能让回流 skill 照着改，不是只说"违规"。
4. 写进报告：合规节 PASS/FAIL、逐类布尔、站位调度环节 标记、回流去向。路由细表见 〔K08-09 回流路由〕：角色/服装类回 人物设定环节，场景类回 场景设定环节，道具类回 道具设定环节，提示词文字类回 编译环节，剧情设定层回 拆节奏环节 / 剧本改造环节，投放侧类回 user。

#### K08-08-03｜联网纪律

平台红线和法规会更新。判前涉及"某条是否仍是红线、平台拦截边界是否变化、新规是否生效"，先 WebSearch 核实再下结论，不拿记忆当事实；拿不准的合规结论一律重查。

#### K08-08-14｜类 11 · 🟡 平台误杀规避 · 通用组

- [ ] 医学/解剖/手术类场景 → 易被判血腥，建议加"医学示意"语境。
- [ ] 大面积裸露皮肤、湿身、束缚类视觉 → 非色情但高误杀，建议弱化。

- 服装类回 人物设定环节、画面描述类回 编译环节：逐条软化，标注"为通过率规避，非红线"。

#### K08-08-15｜类 12 · 🔵 投放侧合规 · 备案 / 分级 / 许可

定位：

- 内容能不能生成、片子能不能上线，是两件事；本组只管后者。与类 1–10 的分界：内容里有违禁物 = 那几类；内容干净、缺的是手续与资质 = 本组。命中不判 FAIL、不置 站位调度环节、不改 compliance 线 status——它拦不住生成，只决定成片能不能公开投放。

依据：

- 网络剧片上线走《网络剧片发行许可证》与重点网络影视剧信息备案；重大革命历史、民族宗教、军事外交等题材另有重大题材备案要求。国内无正式影视分级，但平台有内容分级与青少年模式的自审要求。音乐、字体、影像素材与真实品牌的商用授权按各自许可条款。《人工智能生成合成内容标识办法》的显式标识义务落在出片与上线环节，不落在提示词。

命中样态 · 逐条布尔：

- [ ] 题材落在重大革命历史、民族宗教、军事外交、涉案这类需前置备案或从严审查的区间。
- [ ] 暴力、惊悚、性暗示的强度需要分级或限制受众才适合投放，内容侧本身未踩 🔴。
- [ ] 引用的音乐、字体、影像素材或真实品牌，内容侧不构成类 2 侵权，但商用投放需另拿许可，授权状态查不到。
- [ ] 片子定位为公开发行，项目里却查不到发行许可与备案的责任人与进度。
- [ ] 成片的 AI 生成标识由谁在哪一步打，交付材料里无着落。

不算命中 / 边界：

- 自用、内部试片、不公开投放：本组整组不适用，标 clear。
- 〔决策记录〕 已记过备案与许可安排：有着落即 clear，不重复提醒。

改向：

- reflow_to 一律 user——手续与资质是用户侧决策，审核只暴露、不派制作 skill；fix 写清是哪一项、要什么材料、卡在哪一步，随成片审报告呈给用户。内容层面无须改动，不许因本组去改剧本或提示词。

#### K08-08-16｜类 13 · 片型附加项 · 按 creative-brief 的片种分轨取用，只查本片片型那组

电影级 / 短剧：

- 🟡 短剧高频冲突桥段，如婆媳/地域/职业贬损梗，易滑向类 8 刻板丑化 → 建议冲突落在具体人物行为，不落在群体标签。

漫剧，动漫风：

广告 / MV：

- 🔴 真实品牌 logo、商标、产品外观入镜按类 2 判；真人名人形象暗示代言按类 1 + 类 9 判。
- 🔵 功效/排名绝对化断言，如"最好""第一""根治" → 广告法投放侧风险，按类 12 判、随报告提示用户在生成侧自查，不判 FAIL。

UGC vlog：

- 🟡 画面含可辨认真实店铺招牌、路人面孔描述 → 类 9 风险，建议虚构化处理。

#### K08-08-17｜判定速查 · 写进报告的最小集

每级扫完，compliance 线给出：

- status：PASS/FAIL，任一 🔴 命中即 FAIL；🟡 与 🔵 单独命中不改 status。
- dimensions：1–13 各一个 hit/clear，12 为投放侧合规组、13 为片型附加组。
- 站位调度环节：任一 🔴 命中即 true；🟡 与 🔵 单独命中不置 true。
- 每条命中：定位符 + 类别编号 + 🔴/🟡/🔵 + 原文证据 + reflow_to + fix。

三色在报告里分区高亮，不混在一段。

### K08-09｜回流路由

> 方法体系：工位方法。模块说明：当审核发现要派修、而默认规则——回被审产物的生产站——不适用时翻它。只列默认之外的特殊路由；派活清单写进报告的发现清单，你照单派活零现场推理。

#### K08-09-01｜默认规则

每条发现回被审产物的生产站修：拆解审回 拆节奏环节——visual-style 定稿增量与索引骨架的发现同回它，定稿是它落的笔；资产审回对应设计站；镜头表审回 分镜设计环节；成片审回 编译环节。

修复方回来只报"改了哪、在哪个文件"，不自宣 PASS——重审由你重新派 fresh 审稿员。

上游观察不派活——随下一个 ★确认 呈用户，用户拍板才走对应上游的再入协议。

#### K08-09-02｜特殊路由 · 默认之外的全部例外

| 情形 | 回哪 | 说明 |
|---|---|---|
| 死引用 · 资产该有而未产 | 对应设计站先产并登记 | 双出口之一；引用本不该存在则走默认，删改引用 |
| 死引用 · 控制图该有而未产 | 控制图环节 先产落 05 | 控制图不进 reference-index |
| 工艺类发现——运镜/空间/表演/光/声音写法 | 编译环节 或 分镜设计环节 收拢对应工艺卡重写该维度 | 工艺五卡永不直接派 |
| 账实不符 · 账错 | 连续性台账环节 修 ledger，走变更记录 | 实错走默认回 编译环节；两处都错各记一条 |
| 状态变体缺失——伤后仍绑无伤版一类 | 对应设计站补变体并登记 | 引用侧随后改绑 |
| 成品冒出核心级新资产 | 拆节奏环节 补清单，随后设计站补做 | 拆解遗漏 |
| 镜头表结构性矛盾被成片审发现 | 分镜设计环节 改表，经用户点头 | 结构改动必过用户；受影响条回 编译环节 重编 |
| 红线命中 | 内容所在层的生产站；剧情设定层回 拆节奏环节 | 🔵 投放侧一律 user——手续与资质归用户，不派制作站、不改内容 |

#### K08-09-03｜纪律

- 一个发现只派一个主出口；双出口的在改向里写明判断条件。
- 站位调度环节 修完靶向重审该级；major/minor 照发现清单修，修完不重审、不阻塞下一步。
- 发现清单的「状态」列追踪到底——待修 / 已修；随产物交确认前全部清账。

### K08-10｜排演锚点

> 方法体系：工位方法。模块说明：当审前做脑内预演、给被审拆解/镜头表/资产提示词/控制图/动态提示词比对已知失败模式、把质量问题落成可指认锚点时翻它。每条锚点三段式：会怎么跑偏 / 在文字里怎么看出 / 证据怎么写；按需取用不逐条读完，末节防误杀反例总表在判回前必对照。

#### K08-10-01｜定位

这是"想象会生成什么"的标定库，五类病里「模型雷」的弹药库，不是审核流程。〔K08-11 审稿环节总则〕 已立原则：脑内预演优先、按预演结果挑毛病而非只看格式齐不齐。本卡补的是"哪些写法在 Seedance 2.5 / 文生图上有据可查地会出错"——翻这里把抽象的"质量"换成可指认的失败锚点。

每条锚点三段式：会怎么跑偏，写模型实际行为 / 在文字里怎么看出，写审读时的命中信号 / 证据怎么写，写落进审核报告的话术，即定位符 + 原文 + 预演结论 + 回流建议。

锚点只决定"挑出问题"，不决定 PASS/FAIL 阈值——阈值与严重度口径在 〔K08-11 审稿环节总则〕 与报告模板。

双向校准：每条高危锚点尽量带"不命中反例"，末节另有 [防误杀反例总表]——判回标杆写法与放过真缺陷同罪，写证据前先对反例过一遍。

#### K08-10-02｜四类预演与审级对应

A 静态预演，图像侧：资产图提示词、控制图单帧/宫格提示词丢进文生图会出什么。主用于成片审的资产图与控制图；拆解审取其中可拍性相关项做初判。

B 动态预演，视频条侧：动态提示词丢进 Seedance 会怎么动、怎么响。主用于成片审。

C 节奏预演：这条/这场的密度与气口，成片赶不赶、落不落地。主用于拆解审的节奏与时长预算、镜头表审的时间轴落地。

D 空间与光学预演：首帧、站位、视线、轴线、镜头、光向，末附十八问速查。主用于镜头表审；成片审查跨缝重置。

顺序跟生产链走：拆解审跑 C 与 A 类可拍性相关项；镜头表审跑 D 全份 + C 时间轴 + 十八问；成片审全四类——A/B 全量、B9/D8 跨缝项、风格与合规全量。

#### K08-10-03｜A 静态预演锚点 · 图像侧 · 资产图 / 控制图提示词

A1 · 歧义气质词被按刻板印象跑偏

- **会怎么跑偏：**
  - 形容词缺视觉约束时，文生图按训练分布的高频解读走："清秀"渲成女性化脸、"沧桑"渲成流浪汉、"贵气"渲成礼服影楼风。
- **在文字里怎么看出：**
  - 出现清秀、英气、沧桑、高级、禁欲、邪魅、贵气这类可多解的气质词/抽象词，没有同时给脸型/眉眼/发型/年龄段/体态这类可落地的物理锚点兜底。
- **证据怎么写：**
  - "char-002 提示词：原文'清秀儒雅的脸'。预演：'清秀'易被解读为女性化面孔，与男性设定冲突。回 人物设定环节 补物理锚点——剑眉、薄唇、二十出头男性、利落短发——压住歧义。"

A2 · 画面内文字——判的是渲错会怎样，不是画面里有没有字

- **会怎么跑偏：**
  - 分三档，别一刀切。短的印刷体、正面、字号大、镜头静或慢——现在多数出得对，个别笔画走形是常态但没人看得出来。
  - 长文本、手写与书法、牌匾题字、小字、强透视、快速运动中的字——仍然不稳，错字与笔画粘连是常态。
  - 视频侧另有一个图片侧看不出来的失败模式：首帧渲对了，第 40 帧字形漂成另一个字。**时间上的字形稳定性是独立问题，比单帧渲对难。**
  - 所以真正的判据是后果：内容不承重的字渲错一两笔无人察觉；剧情要观众读对那几个字的，读错就是穿帮而不是瑕疵——那一档别赌。
- **在文字里怎么看出：**
  - 提示词要求观众读出具体文字内容，且**读错剧情就断**——字条、短信、合同条款、报纸标题、关键人名地名。
  - 或者：长文本、书法题字、小字密排被写成"清晰可辨"。
- 不命中反例，判回前必对照：
  - 招牌、菜单、价签、门牌、海报这类只交代年代与场所的字——内容不承重，写成清楚可见是**对的**写法，不判回、不要求虚化。
  - 场景设定环节 标杆场景把霓虹「乐园」招牌当画面视觉重心兼强调色来源，那是正例；把它判成"画面内文字"要求后期叠加，是误杀。
- **证据怎么写：**
  - "ep01-s03-c2：字条内容'别回头'是本条的叙事支点，观众读错即剧情断，却写成由模型渲染。预演：渲错的是内容而非笔形，属穿帮档。回 剧本改造环节 台词化，或标注 道具设定环节 出带字道具特写在资产层锁定。"
- 本条的档位划分标「待实测校准」：Seedance 2.5 的中文渲字实际能力未实测，上面三档是按已知失败模式推的。实测方法见 剧本改造环节 的 feasibility-checklist [雷区卡 04]。

A3 · 多角色同框锚点不分化 → 画成相似脸

- **会怎么跑偏：**
  - 同框 2+ 角色的身份锚点——发色/服装色块/体型/标志物——区分度低时，模型把他们画成相似脸，后续跨镜漂移加剧。
- **在文字里怎么看出：**
  - 同框角色的短串描述颗粒度一样粗、无分化锚点，如两人都是"青袍男性"；或群演与主角描述同颗粒。
- **证据怎么写：**
  - "ep01-s05 镜头3：主角与讲师同框均为'青袍男性'，无分化锚点。预演：画成相似脸、丢主次。回 人物设定环节 给讲师加区分锚点——年长、灰须、深色长袍——登记进短串。"

A4 · 群演被错误建档 / 群像人数写实数

- **会怎么跑偏：**
  - 一次性群演建资产编号既占参考位又不稳定；群像写具体人数时，超过 15 人会塌缩成三五个人形（"the crowd collapses into a few figures"）。
- **在文字里怎么看出：**
  - 只出现一次的路人建了资产编号或要求跨镜一致；提示词写"上百人的观众席"类实数，而非群演体块写法——写"挤在台口的身体、前景晃动的手臂"，不写人数。
- **证据怎么写：**
  - "ep01-s07-c1：'台下三百名学员'且群演'路人甲'建了 char-011。预演：人数塌缩 + 一次性配角建档浪费参考位。回 编译环节 改群演体块写法；回 拆节奏环节 把路人甲移出资产表、外观写死在阐述。"

A5 · 参考图画幅与输出画幅不一致 → 拉伸形变

- **会怎么跑偏：**
  - 关键帧/参考图比例与输出视频画幅不一致时，模型拉伸或裁切起始帧，人物构图形变。
- **在文字里怎么看出：**
  - 条声明的画幅与所引关键帧/场景角度图的画幅对不上，如 16:9 条引 9:16 竖图；控制图产出卡没记画幅。
- **证据怎么写：**
  - "ep01-s02-c1：输出 21:9，引用的 ctrl-ep01-s02-c1-kf1 为 9:16。预演：起始帧被拉伸形变。回 控制图环节 按输出画幅重出该帧。"

A6 · 图像提示词串入视频规则集：负面参数 / NOT 堆叠

- **会怎么跑偏：**
  - 图像模型没有负面参数，"no acne""not smiling"这类否定措辞把被禁概念本身注入画面——"does NOT fall on his back（不要仰摔）"等于邀请模型想仰摔。
- **在文字里怎么看出：**
  - 资产/控制图提示词里出现负向清单、"无XX/不要XX/no X"堆叠；禁令没有改写为期望态——"clean dry skin" 而非 "no acne"。
- **证据怎么写：**
  - "scene-004 提示词：结尾挂'no people, no weapons, no text'负向清单。预演：图像链路无负面参数，NOT 堆叠反向注入概念。回 场景设定环节 改期望态写法如'空无一人的仓库地面'，双规则集不得串用。"

A7 · 资产禁词触发环境/风格污染

- **会怎么跑偏：**
  - "studio" 画出真摄影棚并把棚灯烤进资产；"overhead key light" 画出灯具本身；rim light 烤进资产后不再响应场景光；"character reference sheet / painterly" 触发插画风，photoreal 崩。
- **在文字里怎么看出：**
  - 角色/道具表提示词出现 studio、overhead key light、rim light、character reference sheet、painterly 等禁词。合法替代：no studio, no equipment, no walls 语义改写成"纯中灰背景、无环境无器材"；"character reference sheet" 改用 "film character sheet / studio photographs"。
- **证据怎么写：**
  - "char-003 三格提示词：原文'studio lighting, character reference sheet'。预演：画出摄影棚实体 + 触发插画风。回 人物设定环节 改'纯中灰无缝背景、柔和均匀光'与'film character sheet'。"

A8 · 图像提示词词数膨胀 → 注意力稀释

- 密度判堆砌、不数词数：「4k, masterpiece, best quality」这类质量关键词对模型无效，只稀释注意力，命中即回对应设计站删修饰堆叠、保材质与比例锚点；不带信息增量的重复子句同判，给板名与行号。

#### K08-10-04｜B 动态预演锚点 · 视频条侧

B1 · 一镜叠互斥独立动作 → 全糊

- **会怎么跑偏：**
  - 单段硬拼多个互斥、无因果顺承的独立动作，Seedance 每个都做半截。
- **在文字里怎么看出：**
  - 单个时间段/单镜里并列多个互不连续的动作，如"她转身、拔剑、后跃、再回头"无因果地挤一段，且未按节拍分段。
  - 不命中反例：因果顺承动作链加一个主运镜、加主体动作驱动的衔接运镜，且已按时间戳段落或镜头N分镜——这是标杆写法；因果顺承指前一动作的结果引出后一动作。
- **证据怎么写：**
  - "ep01-s04-c2 [8-14秒]：一段塞'转身、提笔、挥毫、收笔、抬眼'五个并列动作、无因果无分段。预演：互斥叠加全做半截。回 编译环节 按节拍分段或保主动作降其余为衔接；若为因果链且已分段则不判。"

B2 · 运镜叠加 / 无动机打架 → 退化成静止

- **会怎么跑偏：**
  - 单镜叠推+摇+升或方向矛盾的运镜，模型直接退化为静止；每镜最多双轴。
- **在文字里怎么看出：**
  - 一镜同时要求三种运镜或方向冲突，如"左移同时右摇环绕"。
  - 不命中反例：复合运镜由同一主体动作串起即合法，如"随他起身镜头上摇，再随他走向门口横移跟拍"。
- **证据怎么写：**
  - "ep01-s06 镜头4：'推进同时环绕同时升起'。预演：多轴叠加退化为静止。回 编译环节 保单一主运镜，其余删或改为动作驱动衔接。"

B3 · 戏剧动作默认被做成慢镜

- **会怎么跑偏：**
  - 模型倾向把戏剧性动作渲成唯美慢镜，丢速度与冲击；需速度词显式覆盖。
- **在文字里怎么看出：**
  - 冲刺、暴起、坠落、挥拳这类本该有速度的动作用了走向、举起、moving 这类弱动词，无猛地、骤然、急速这类速度词。
- **证据怎么写：**
  - "ep01-s08-c1：'他从高台落下'无速度词。预演：默认唯美慢镜，与坠落冲击相悖。回 编译环节 动词领头加速度显式，如'骤然坠下，衣袍猎猎作响'。"

B4 · 开放式运动无终点 → 卡死 / 抽搐

- **会怎么跑偏：**
  - 动作与运镜没有终点时模型大概率卡死或无限抽动。
- **在文字里怎么看出：**
  - 只给起点不给终点："门缓缓打开"无"至完全敞开定格"；"镜头持续推进"无"推至面部特写停"。
- **证据怎么写：**
  - "ep01-s02-c3：'推门'无运动终点。预演：开放运动卡死。回 编译环节 补终点'推门至完全敞开，定格在门后光'。"

B5 · 次要快速运动抢走主体运动预算

- **会怎么跑偏：**
  - 模型把运动预算花给画面里能量最大的元素；主体静、背景暴雨飞鸟车流时，模型只做背景。
- **在文字里怎么看出：**
  - 主体微动/静态，同框写了暴雨、闪电、疾驰车流、漫天落花这类高能次要运动且没声明主次。
- **证据怎么写：**
  - "ep01-s09-c1：主体'静立沉思'，背景'狂风骤雨电闪雷鸣'。预演：预算给暴雨、主体被冷落。回 编译环节 弱化背景动势或显式声明主体为运动焦点。"

B6 · 可变层重描静态 → 与 @参考打架；恒定层不算

- **会怎么跑偏：**
  - 可变层大段重述 @参考已锁的长相、服装、陈设，挤占词数且 prose 覆写 reference 造成漂移——"Do not overwrite the reference with excessive prose.（不要用过量散文覆写参考图。）"
- **在文字里怎么看出：**
  - 分镜正文里动作占比小、静态外观描写占大头；角色行内公式之外又展开写五官服装细节。
  - 不命中反例：恒定层逐字注入风格基准/短串/时代锚是编译机制，不是重描静态；角色行内公式——@图N：年龄+角色+状态+关键可见锚点——是规范用法。
- **证据怎么写：**
  - "ep01-s03-c1 分镜正文：约六成篇幅重描 @图1（条头清单：char-001）已锁的'白袍、剑眉、束发'。预演：prose 覆写参考、挤占动作词数。回 编译环节 删可变层静态重述，只留动与变。"

B7 · 未分段长 blob → 被"取平均"丢细节

- **会怎么跑偏：**
  - 一坨未分段的超长段落被模型取平均、细节全丢。
- **在文字里怎么看出：**
  - 单段无时间戳无镜头N、明显超约 70 词、形容词堆叠、动作占比小。
  - 不命中反例：A 轨时间戳段落式、B 轨镜头N分镜，每段紧凑、整条跟动作走——密集动作条总词数大是标杆密度，不按总词数判回。
- **证据怎么写：**
  - "ep01-s05-c2：整条约 180 词无任何分段。预演：取平均丢细节。回 编译环节 按双轨选型分段成时间戳或镜头N，每段一个节拍；已分段的序列不因总词数判回。"

B8 · 物理因果"看起来对" + 数量/尺度失锚

- **会怎么跑偏：**
  - 模型做"看起来合理"的画面：徒手空接飞剑、脚底打滑无摩擦、运动中道具一变二如掉落的三明治变两个、身高体型逐镜漂。
- **在文字里怎么看出：**
  - 多步因果或危险接触用"接住""处理掉"这类模糊词，不指明方式工具；运动中道具没逐帧锁数量；尺寸没有三重锚定——真实尺寸+画面占比+与框内已有物比较；身高没给失败方向，合法句式如 "NOT taller by a single centimeter; if in doubt, render him a touch shorter.（他绝不比她高出一厘米；拿不准就渲染得略矮半分。）"。
- **证据怎么写：**
  - "ep01-s08-c2：'他接住飞来的剑'。预演：徒手空接物理失真。回 编译环节 指明方式，如'侧身让锋，单手扣住剑柄'；同条掷出的酒坛在运动中未锁数量，补'始终只有一只酒坛'。"

B9 · 条缝/镜缝处身份漂移、变脸、状态重置

- **会怎么跑偏：**
  - 模型逐条独立采样、无记忆：结束状态不继承就瞬移换装；同一角色绑多张差异大的脸照触发换脸；multi-shot 每个 cut 不锁连续性就重置伤口、方向、情绪。
- **在文字里怎么看出：**
  - 条无【结束状态】五字段——位置、朝向、持物、动作动势、情绪——或下条衔接段对不上；同条给同一角色绑了多张脸源；镜头N切换处未保持同角色表/同地理/同银幕方向/同视线/同伤口血污状态/同情绪进程。
- **证据怎么写：**
  - "ep01-s06-c2 → c3 缝：c2 结束状态'右手持剑、面向门'，c3 首段'空手背对门口坐下'无衔接交代。预演：跨条瞬移换姿。回 编译环节 补承接句或修结束状态；状态归属若在台账错，回 连续性台账环节。"

B10 · 负向政策两头病：该补未补 / kitchen-sink

- **会怎么跑偏：**
  - 本条有真实症状——易渲进字幕/分屏/多余人物——却零针对负向 → 标注物渲进画面；反头堆几十项负向大杂烩 → 降相干性掉画质。
- **在文字里怎么看出：**
  - 有明确症状风险却无对应负向；或负向超 3 项、成清单单列、与本条无关。
  - 不命中反例：零负向是常态——本条无真实症状时不带针对性负向是合格状态，不按"必带负向"判回；全局禁止项尾缀即固定短清单，不算针对性负向。
- **证据怎么写：**
  - "ep01-s01-c1：画面含大量店招易自发渲字幕，却无对应负向。预演：多余字幕渲进画面。回 编译环节 按症状补 ≤3 个化进散文，如'画面中不出现可读文字'。"

B11 · 情绪单词化、无双向夹钳 → 漫画化或死面

- **会怎么跑偏：**
  - 单个情绪词让模型即兴出浅表结果：要么夸张漫画脸（mugging），要么面无表情；解法是双向夹钳硬性判定句——"between joy and aggression; a rage-twisted face = failed take; a soft beaming smile = failed take; deadpan = failed take.（在喜悦与攻击性之间；狰狞暴怒脸=废镜；灿烂微笑=废镜；面瘫=废镜。）"
- **在文字里怎么看出：**
  - 关键情绪节点只写"愤怒/悲伤/喜悦"单词，无物理动作落实、无两端排除；或"nobody moves"式整帧冻结——静止要写成 held tension + 每 1–2 秒一个微事件。
- **证据怎么写：**
  - "ep01-s07-c3 镜头2：'她很愤怒'。预演：单词情绪出漫画脸或死面。回 编译环节 用物理指令+情感解析成对改写并加双向夹钳，如'下颌绷紧、指节发白——不狰狞、不含泪'。"

B12 · 口型与台词时机违规

- **会怎么跑偏：**
  - 长句、侧脸、大特写下口型必崩；台词起点不锚定则说话时机漂；引用上条台词却让它可视化会画出不在场的说话人。
- **在文字里怎么看出：**
  - 单句台词超过 20 词未拆；说话期间说话人非正脸/近正脸却写"口型严格对上"；台词前后无 ≥1 秒静默也未要求 0.3 秒内开口；用上条台词续情绪时没走 prior audio 语法——"Prior audio context only, not visual content: '……'（仅作先前音频语境，不作视觉内容）"。
- **证据怎么写：**
  - "ep01-s03-c2：单句 34 词且说话人全程侧背身，仍写'口型严格对上'。预演：口型崩、废片。回 编译环节 拆短句并只在正脸+中景时写口型锁；口型纪律详 声音环节。"

B13 · 声音四要素缺位或写出提示词外

- **会怎么跑偏：**
  - 声音不写进提示词文字就不存在：台词无语气与声线锁则换声，音效不绑动作则凭空响或缺席，环境声缺则真空感，BGM 无指令则模型随机配乐。
- **在文字里怎么看出：**
  - 对白条台词没带语气词与声线锁引用；音效未绑可见动作，只写"背景音效丰富"类空话；全条无环境声一层；无 BGM 指令——"无背景音乐"也是指令，缺席≠无；或出现任何"声音另行处理"的指令通道。
- **证据怎么写：**
  - "ep01-s02-c2：全条无环境声与 BGM 指令，台词未引声线锁。预演：环境真空 + 随机配乐 + 换声。回 编译环节 补四要素：环境声一层、BGM 指令、声线锁自 reference-index 逐字引用。"

B14 · 关键帧序列使用病——2.5 主流控制方式的专项

- **会怎么跑偏：**
  - 关键帧绑定不带防复制声明时，模型复制帧的静止性——画面在每个关键帧处停顿或跳切，帧间运动断裂；帧顺序与时间轴不符时画面倒放或来回抽；帧与角色/场景资产分权不声明时，脸从关键帧取而非从身份参考取，跨条变脸；同场各帧调色未校同一基准时，条内颜色逐帧跳变。
- **在文字里怎么看出：**
  - 绑定块缺总声明"以 @图M 至 @图N 的顺序作为本条关键帧"，或缺防复制声明双列表——允许借构图/景别/位置/到位时刻；不得复制静止性，帧间运动由文字驱动；面孔体型服装以角色参考为准、冲突时角色参考胜。帧编号顺序与 A 轨时间点/B 轨镜头号对不上，或关键帧在条头上传清单里没有连续相邻编号、被别的资产穿插；帧数超 1–5 张/条、数值待实测校准，或有帧没有镜头表节点对应；控制图产出卡"调色状态"标未校却已入绑定。
- **证据怎么写：**
  - "ep01-s04-c1：条头上传清单第 5–7 行为 kf1–kf3 → @图5–@图7；绑定块列 @图5–@图7 但无防复制声明，且 @图6 的时间点绑定在 [12秒] 晚于 @图7 的 [9秒]。预演：画面在各帧处停顿跳切、且中段倒放。回 编译环节 补双列表声明并修帧序；帧本身病如画幅错、调色未校，回 控制图环节。"

#### K08-10-05｜C 节奏预演锚点 · 2.5 重标定 · 赶、塞满、空拖、时间轴

这一类查的不是单镜动不动得起来，而是这条/这场的节奏对不对——"赶"是历史头号用户问题，看不见单镜、要从整场密度想出来。2.5 单条容量 30s，场景级容量非必须填满，"装得下"的东西多了一倍，"装下就赶"的陷阱也大了一倍。数字基准见 拆节奏环节 的 〔K03-03 时长与节奏〕——全库时长真相源，均待实测校准。

C1 · 一条塞太满 → 每件事做半截

- **会怎么跑偏：**
  - 把一段完整叙事全压进一条，时间不够、句句来不及落，节奏赶、动作糊。
- **在文字里怎么看出：**
  - 命中任一即算，只看密度、标了节奏意图不免疫：1 文戏一条 ≥3 个对白回合，却没走合条档该有的配置——每回合反应 hold 有要求 + 回合轻重有显式分配（拆解层为 hold 要求与相对轻重，编译层为时间戳）；2 一条同时背"建场 + 对白 + 独立情绪动作 + 段落收尾"四件异质成分；3 动作戏一条 6–8 镜没标"刻意狂剪"。
  - 不命中反例：2.5 合条是容量红利——一条 15–22s 装 2–3 回合、每回合 hold 齐、回合轻重有显式分配的，是合法合条，不判塞满。
- **证据怎么写：**
  - "ep01-s04-c1：一条 20s 塞四个对白回合、无一处反应 hold、回合无时间戳分配。预演：句句赶、没有落点。回 拆节奏环节 按节奏意图重选档：分条即每 1–2 回合一条，或砍回合数补 hold。"

C2 · 文戏无气口 / 反应 hold → 像念稿、空、赶

- **会怎么跑偏：**
  - 整条全是台词与动作、没有一格停在脸上的反应 hold，情绪没有发酵时间。
- **在文字里怎么看出：**
  - 节奏疏档条的阐述/时间轴里找不到任何"停顿/反应 hold/留白"占秒；对白时长=刚好说完，说完之后没有沉淀；地板是说完 + 停顿 ≥1.5–2s。
- **证据怎么写：**
  - "ep01-s03-c1：情绪条全程对白+动作、零 hold。预演：像念稿、空、赶。主回 拆节奏环节 补 hold 预算；若拆解已预算、是编译把气口填成动作，回 编译环节 清掉填充。"

C3 · 峰值压末帧、无落地 → 结尾收不住

- **会怎么跑偏：**
  - 峰值动作/情绪压到最后零点几秒才发生、镜尾直接切走，没有 1.5–3s 落地，结尾急促。
- **在文字里怎么看出：**
  - 段落收尾/情绪峰值/全片结尾那条，关键内容压末帧、镜尾写"余势带出/切下条"而非"落地停住"；或收尾条被按中段接续处理。
- **证据怎么写：**
  - "ep01-s10-c3 全集结尾条：末镜峰值压最后 0.5s、镜尾余势甩出。预演：结尾不落地。回 编译环节 峰值前移 + 末段 1.5–3s 落地停稳；若时长预算本身没留落地，回 拆节奏环节 补档。"

C4 · 时长配过头 / 空拖——塞满的反向病

- **会怎么跑偏：**
  - 长档只有 1–2 拍内容又没设计性留白，画面停在没东西看的状态，模型摆烂或自动加戏。
- **在文字里怎么看出：**
  - 条配 22–30s 档却无显式理由；事件稀、没安排反应 hold/留白占秒；长镜靠"站着发呆"硬撑。
  - 不命中反例：留白是有意停在某状态发酵、有着落——停在具体神情/物上，不是空拖；短条 4–8s 桥接不是缺内容。
- **证据怎么写：**
  - "ep01-s06-c1：配 26s 仅 2 拍内容、无留白设计、无长档理由。预演：空拖，模型自动加戏。回 拆节奏环节 砍档到内容够用，或把富余还成有着落的 hold。"

C5 · 时间轴病：A 轨时间戳 / B 轨秒数

- 判据动手核：A 轨 0 起 / 无重叠 / 无缺口 / 末点=首句总时长、B 轨正文零秒数——逐条算，给条号与行号。另判两件——关键卡点如峰值到位、口型起点是否顶格无冗余，应留 1–2s；2.5 的时间戳遵循度待实测，「整体比时间戳快、过早切镜」是上一代模型的已知模式。

C6 · 超 30s 处置错误 / 超长模式误用

- **会怎么跑偏：**
  - 内容+气口合算超 30s 硬塞进一条 → 砍必要动作或挤掉 hold；不是一镜到底刚需却走 30–180s 超长模式 → 控制颗粒变粗、返工以整条计。
- **在文字里怎么看出：**
  - 条时长预算被顶到 30s 且阐述里事件明显装不下；拆解把非长镜刚需的条标了"超长模式候选"；或该拆条的地方用超长模式回避拆条。
- **证据怎么写：**
  - "ep01-s08：整场追逐 41s 内容硬并一条 30s。预演：砍动作或全程赶。回 拆节奏环节 按叙事子目的拆两条、接缝卡补齐；超长模式仅一镜到底刚需可标候选。"

#### K08-10-06｜D 空间与光学预演锚点

D1 · 空首帧 / 人物迟到 / 无用定场开场

- **会怎么跑偏：**
  - 首帧没锁占位时，模型开一个空镜或让人物走进画面才出现，前 2 秒废掉；或自作主张开在无用的 establishing 大远景。
- **在文字里怎么看出：**
  - 条首段没有首帧占位声明；写"他走入画面/推门而入"当开场却没声明首帧已含人物。合法锁句式即首帧占位锁，五句全文双语归 站位调度环节 的 〔K06-04 空间语言〕 [首帧占位锁 · 默认挂，五句全文双语]，此处留判本条要用的三句只读副本："The first visible frame already contains all required characters in their correct positions.（第一帧画面里已包含全部该在场的人物、各就各位。）""No empty establishing frame.（无空场开场。）""No delayed character reveal.（无延迟入场。）"——正向的第一句是它的定式，后两句正对本锚点点名的两个失效态；三句一句不见才判。
- **证据怎么写：**
  - "ep01-s02-c1：首段无首帧占位声明且写'门开后他入画'。预演：首 2 秒空场等待。回 编译环节 加首帧占位锁或显式声明入画是设计；若是设计则不判。"

D2 · 视线反转 / 朝向含糊

- **会怎么跑偏：**
  - 朝向与视线不分开写时，模型让身体和眼睛各选各的方向，对话戏视线对不上。
- **在文字里怎么看出：**
  - 多人条没有"躯干朝向 X、视线锁定 Y"的分开写法；只写"看着他"没有 frame-left/right 画面方位。
- **证据怎么写：**
  - "ep01-s04-c2 镜头3：'两人对视'无朝向与方位。预演：视线各漂。回 编译环节 按 站位调度环节 规范分写躯干朝向与视线锁定、绑 frame-left/right。"

D3 · 弱空间词 → 位置抽奖

- **会怎么跑偏：**
  - near/beside/around/nearby 与"在他左边""三米外"对模型无意义，人物位置每次重掷骰子；"The hero in the room."（主角在房间里。）是抽奖，"The hero at the lamp, facing the door."（主角在台灯旁，面朝门。）才可用。
- **在文字里怎么看出：**
  - 走位没绑画面内可见地标；出现弱空间词而非可测量语言——within 1 meter / touching / back against the wall，即一米之内/贴着/背抵墙。
- **证据怎么写：**
  - "ep01-s06-c1：'他站在她旁边'。预演：位置抽奖、左右随机。回 编译环节 绑地标改可测量语言，如'他站在吧台尽头的立灯旁，与她相隔一臂'。"

D4 · 机位错侧 / 越轴 / 空间地图缺失

- **会怎么跑偏：**
  - 多人场不贴空间地图块——镜头侧、180°线、人物-地标绑定——模型每个镜头重新发明地理：左右互换、瞬移、越轴。
- **在文字里怎么看出：**
  - 多人/复杂场的恒定层没有空间地图块，或各条的地图块文字不一致，应逐字复用；cut 后没重述谁在哪、看哪。
- **证据怎么写：**
  - "ep01-s05 全场四条：三条带空间地图块、c3 缺失且镜头2 越轴。预演：c3 地理重掷、正反打跳轴。回 编译环节 把场景资产档案的地图块逐字补进 c3 恒定层。"

D5 · 镜头滑向舒适中值 / Content-FOV 不对齐

- **会怎么跑偏：**
  - 不钉死镜头则滑向中间焦段，长焦压缩感、广角张力全丢；一个 beat 内混人像+环境地理+微距内容，镜头必漂——内容决定镜头，模型从画面内容反推 FOV。
- **在文字里怎么看出：**
  - 条内声明了特定视场角却在多镜间无镜头锁；同一镜头段同时要求大特写细节与全景地理。多镜头合法锁句式："LENS IS 29° ACROSS ALL SHOTS. NOT NEGOTIABLE.（全部镜头锁定 29° 视场角，不容更改。）"
- **证据怎么写：**
  - "ep01-s07-c2：首句声明长焦观察感，镜头3 却要求'环境全景交代'且无镜头锁。预演：FOV 滑中值、压缩感丢失。回 编译环节 拆 cut 各配镜头或加镜头锁；词库详 运镜环节。"

D6 · 平面顺光 / 光沦为装饰

- **会怎么跑偏：**
  - 不把光写成优先级锁，模型默认平光正打，层次全无；逆光条不锁曝光基准就变成脸部补光的平片。
- **在文字里怎么看出：**
  - 光只有"光线柔和/氛围感"类装饰词，无方向、来源、明暗侧；逆光条没写主体与亮背景的位置关系与"无正面主光"。逆光合法锁块："Subject stays between camera and the brighter background. Camera stays on the shadow side. No frontal key. No flat exposure.（主体始终处在机位与更亮背景之间。机位在阴影侧。无正面主光。无平光曝光。）"
- **证据怎么写：**
  - "ep01-s09-c2：'逆光剪影'但无机位侧与曝光声明。预演：模型给脸补光、剪影变平片。回 编译环节 按 灯光环节 规范补光向五要素与曝光优先级声明。"

D7 · prose 覆写参考 / 僵尸 tag / 上下文泄漏

- **会怎么跑偏：**
  - tag 重复出现是生成拒绝启动的头号原因；场景引用不带继承禁令就交回场景板复制品；场号、"same as before/上一条那样"类措辞对无记忆的模型等于没说，还会污染画面。
- **在文字里怎么看出：**
  - 同一 @图N 在条内绑定两次；场景绑定缺"只控几何、材质、光线、氛围，不控构图"继承禁令；正文残留场号引用、"同上一条"指代、已废弃 tag、编译注释。
- **证据怎么写：**
  - "ep01-s03-c2：条头清单第 2 行为 scene-002 → @图2；@图2 在绑定段与正文各 @ 一次，且无继承禁令。预演：重复 tag 拒绝启动风险 + 构图被场景板锁死。回 编译环节：每 tag 恰好绑定一次、正文用代称、补继承禁令。"

D8 · multi-shot 切镜重置连续性

- **会怎么跑偏：**
  - 镜头N切换处模型默认重开采样：伤口消失、雪泥变干、银幕方向翻转、情绪归零。
- **在文字里怎么看出：**
  - B 轨条的镜间没有连续性锁——同角色表、同地理、同银幕方向、同视线逻辑、同伤口血污泥雪状态、同情绪进程；切镜用了 fade/dissolve 类禁用切型，合法切型限 HARD/SMASH/MATCH/INSERT/REVERSE/WHIP CUT。
- **证据怎么写：**
  - "ep01-s08-c3 镜头2 → 3：镜头2 左脸带血，镜头3 无连续性锁。预演：切镜后血污消失。回 编译环节 补跨 cut 连续性锁清单；成片审层同法查条缝与场缝。"

#### K08-10-07｜预演收尾 · 反向回读三问

每条/每场预演完，按【导演思维】的反向校验自下而上回读一遍——生成 → 画面 → 意图，逐层问，命中就补证据：

- 生成层 · 模型跟得住吗？——这条丢进文生图/Seedance，最可能出错的那个视觉元素、最可能"动不起来或动错"的地方是什么？塞太满没给气口、该落地的结尾没落地也在这一问：按 2.5 的 30s 容量想，装得下 ≠ 该装满。A/B/C 类。
- 画面层 · 拍出来是这个画面吗？——首帧、站位、视线、轴线、FOV、光向过了十八问吗？跨到下一条/下一场什么会飘：结束状态、伤势服装、风格、时代锚？D 类 + B9/D8。
- 意图层 · 观众能感到当初的意图吗？——把预演出的成片倒回去对镜头表【导演意图】与本场场阐述：戏眼那一下在不在、情绪到没到、这场要讲的那件事还在不在。画面全对但戏不对照样是 finding，reflow_to 指 分镜设计环节 重讲戏，纯表演落差指 编译环节 收拢 表演环节 重写该维度。

预演暴露的问题写进 finding 的 rehearsal 与 evidence，不是只判"格式齐了"。

[防误杀反例总表]——写任何判回证据前对照；判回标杆写法 = 审核事故

- 因果顺承动作链 + 一主运镜 + 动作驱动衔接运镜：不按"一镜一动作"判回（B1）。
- 时间戳段落式 / 镜头N分镜序列：整条跟动作走的不按总词数判回（B7）。
- 零针对性负向是常态：本条无真实症状时不按"缺负向"判回；全局尾缀不算针对性负向（B10）。
- 恒定层逐字重复注入通用基准段/场域锚句/短串/时代锚/空间地图块：是编译机制，不按"重描静态/冗余"判回（B6）。
- B 轨无秒数：是轨型规范，不按"缺时间轴"判回；A 轨才要求时间戳（C5）。
- 30s 未填满、4–8s 短条：容量非必须填满，不按"内容不足"判回（C 类）。
- 合法合条，即 15–22s 装 2–3 回合 + 各回合 hold + 时间戳分配：不按"塞太满"判回（C1）。
- 有着落的留白/反应 hold：是设计不是空拖（C4）。
- 松档的镜头自由度边界声明——"景别机位剪辑可自然变化，因果顺序与动作结果不得变化"——是控制策略，不按"控制不足"判回。
- 密版描述不进提示词、场景空场留空槽：是设计纪律，不按"信息缺失/场景不完整"判回。
- 图像提示词零负向、无画幅声明：是图像规则集与 UI 参数纪律，不按视频侧标准判回。
- 🔴 与 🟡/🔵 严格分性质：🟡 与 🔵 单独命中永不判 FAIL，不把生成侧工程约束或投放侧手续当法律红线。
- 首帧"入画式开场"若显式声明是设计、延迟出场为叙事目的：不按 D1 判回。

### K08-11｜审稿环节总则

> 方法体系：工位方法。模块说明：当拆解、资产包、全集镜头表、全集提示词四类产物落盘触发拆解审 / 资产审 / 镜头表审 / 成片审，或用户说要审核、质检、检查提示词、验证合规、复核某个产物时使用。审核由 fresh 派发的 审稿员 执行，只审不改：拿被审产物对照只读基准查五类病——矛盾 / 断链 / 走样 / 模型雷 / 红线。产出 .review/ 下一页起步的人读报告，并给出回流路由。

#### K08-11-01｜任务

审核 = 交签前的一次对照检查：拿被审产物对着只读基准查五类病，出一页报告；硬伤挡线，其余修而不挡；基准的毛病只记观察、不动手。每个审核点审过 PASS，产物才交用户确认。

四个审核点，产物落盘即派审——交货质检，不是站岗门禁：

- 拆解审——〔节奏总表与讲戏本〕 落盘后；连审 visual-style 定稿增量与 reference-index 骨架。
- 资产审——资产包三站出齐登记后。
- 镜头表审——全集 〔导演分镜卡〕 落盘后。
- 成片审——全集 〔粘贴提示词〕 与台账落盘后；场数多可分组批检。

报告落盘 .review/{breakdown|assets|shots|final}〔本集剧本〕，一级一份、集级；结构照 〔K08-12 审稿报告模板〕。

用户点名 /review 某产物时按对象套审级：拆解 → 拆解审，资产 → 资产审，镜头表 → 镜头表审，提示词 → 成片审。

#### K08-11-02｜第一性原则

本环节是【导演思维】第 2、3、4 问的镜像：生产怎么想，审核就反向怎么查——预演反跑画面化，对账反跑一致性，可跟随反跑可生成性；生产与质检共用同一套思维，不另立标准。

审核员的唯一优势是新鲜眼睛加跨文档对照——所以只查五类病，不做工艺品味、不提「可以更好」；风格好不好、决策对不对，用户确认时自己看。

基准只读：已确认的上游产物是尺子，永远不是病人。产物与基准对不上 = 产物走样；怀疑尺子本身坏了 → 记「上游观察」，不入判定、不派活——重开上游是用户的权力。

阶段门：先查便宜的三类——矛盾 / 断链 / 走样，纯对照；命中 站位调度环节 即交报告，模型雷预演不跑——烂地基不评精装修。前三类干净才做预演与红线。

对账动手做：编号连不连号、台词逐不逐字、时长求和超不超——数出来、diff 出来，不凭「看起来一致」下结论。

可跟随性高于 completeness：能被模型照着生成才算好；判回前必对照 rehearsal-anchors [防误杀反例总表]——判回标杆写法与放过真缺陷同罪。

红线零容忍：合规是布尔判定，任一 🔴 命中即 站位调度环节，与质量分无关；🟡 只标建议与通过率风险、🔵 只标投放提示，均不判 FAIL；合规拿不准就 WebSearch 核实，不靠记忆里的旧红线。

审核与生产解耦：永远 fresh 派发 审稿员，不自审、不复用生产上下文——创作者不能既当运动员又当裁判。

#### K08-11-03｜五类病 · 全库唯一的审核维度

1. 矛盾——同一事实在被审产物内两处互斥：声明与预算打架、同一物两个尺度、基准段与字段表相反、恒定层跨条不一致、缝两端状态对不上、任务进度回退。
2. 断链——指向不存在或对不上的东西：死引用、编号跳号、登记与包不双向对齐、注记指不到落点、下游动手缺信息（自包含破洞）。
3. 走样——产物对只读基准的翻译悄悄偏了：场漏拆、台词不逐字、板未嵌基准段或不同源、表与拆解对不上、成品与表对不上、三态与剧情进度不符；带显式声明的偏离（狂剪标注、偏离理由）不算。
4. 模型雷——已知让生成翻车的写法，对照 rehearsal-anchors 本级锚点脑内预演：抽象情绪词、互斥动作叠加、开放运动无终点、口型违规、弱空间词、图纸词进视频侧、双规则集串用、负向 kitchen-sink、气口被挤没。
5. 红线——合规布尔判定，照 compliance-checklist 12 类 + 片型附加组；成片审另查跨条组合风险——单条无害、连起来构成教程或侵权叙事的按组合判。

#### K08-11-04｜对照表 · 每点审什么、对照什么

| 审核点 | 被审产物 | 只读基准 | 模型雷取哪些锚点 |
|---|---|---|---|
| 拆解审 | 〔节奏总表与讲戏本〕 + visual-style 定稿增量 + reference-index 骨架 | 〔本集剧本〕、creative-brief、decisions（含拷问拍板）；ep02 起加上集 ledger | C 类节奏 + A 类可拍性项 |
| 资产审 | 三份 prompts + reference-index 登记 | 拆解三张清单、visual-style、decisions | A 类图像侧 |
| 镜头表审 | 〔导演分镜卡〕 全集，含场级空间地图块 | 拆解、reference-index 与三包、visual-style、decisions、拆解审报告 | D 类 + C 类时间轴 + 十八问 |
| 成片审 | 06 全集连条头 + 05 控制图 + 07 台账 | 〔导演分镜卡〕、02 接缝卡、04 索引、〔世界圣经〕 全套、前三级报告；多集加上集 ledger 落幅区 | 全四类；继承链逐缝按 连续性台账环节 的 〔K01-08 接缝核查〕 |

风格增量口径：拆解审对 visual-style 只查定稿增量——锚句表覆盖齐不齐（断链）、定稿与 decisions 拷问拍板打不打架、变更记录之外的实质偏离（走样）、段内自相矛盾（矛盾）；风格轴本身选得好不好是拷问已确认的决策，出圈——顶多进上游观察。

#### K08-11-05｜判定与轮次

- 站位调度环节 白名单，名单外不判 站位调度环节：断链类的死引用；矛盾类的同一资产双真相源——锚定资产双重发明、一条多脸源；模型雷类的规划类控制图被绑成画面参考；红线任一 🔴。
- 有 blocking → FAIL；major/minor 不挡线：全部进派活清单修，修完不重审，随产物交 ★确认时摘要报「审核发现 N 条、已修」；major 与 minor 只差派活优先级。
- FAIL → 按 [回流] 修 站位调度环节 项 → 靶向重审：只核销上轮 站位调度环节 项与其修复处。重审只有这一种；重审轮里新冒的发现按严重度归位——blocking 改判定，其余进派活清单，不另起一轮。
- 熔断：同一审核点连续两轮 FAIL → 停下，把两轮报告与分歧摆给用户裁决，不自转第三轮；对判据本身有分歧的发现随时交用户，不占轮次。
- PASS 后被审产物被改动——你改的或用户要的——旧报告作废，重审该对象一次；无改动不重审。

#### K08-11-06｜上游观察

审核中发现只读基准自身有毛病——已确认文档内部矛盾、两份基准没同步、判据与现实打架——写进报告尾部「上游观察」小节：一条一行，不算发现、无严重度、不派活、不影响判定。由你随下一个 ★确认 一并呈给用户；用户说改，才走对应上游的再入协议。

#### K08-11-07｜派发契约

每次审核派 fresh 审稿员，定义在 审稿员 的 agent 定义。派发单四要素：审级 + 范围 + 完整上下文 + 本轮轮次；上下文分两摞列明——被审产物、只读基准（标「只读」），给原文或精确文件路径；轻装档项目在范围注明档位。只给事实与判定标准出处，不复制不转述你的判断、不夹带处置主张与判定倾向——裁决在它那一端。

成片审分组批检：逐条病类按场切、继承链按缝切、红线一名工人；工人只回发现清单片段，由你机械拼接成一份报告并统一编号，不增删改内容。

派发通道不可用时按 〔原工具链内容，本 skill 未收录〕 [Sub-Agent 调度规则] 停下问用户；用户同意降级才自审，报告开头显著标注「降级自审」——该点记为未放行，通道恢复补一次 fresh 审。

#### K08-11-08｜审核执行 · 审稿员 侧

1. 读材料：派发单逐份读原文，被审与基准分清，不靠摘要与记忆；材料不足按路径读盘补取。
2. 查前三类——矛盾 / 断链 / 走样：纯对照，动手数、动手 diff；命中 blocking → 直接第 4 步交报告，预演不跑。
3. 前三类干净才查模型雷与红线：按本级锚点逐条预演，判回前过防误杀反例总表；红线逐类布尔判本级范围。
4. 写报告照 〔K08-12 审稿报告模板〕：站位调度环节 给完整证据块，其余一行一条；基准的毛病进上游观察；落盘 .review/{级别}〔本集剧本〕，返回摘要——总判定 + 问题计数 + 最重的一条。

#### K08-11-09｜回流

默认规则：每条发现回被审产物的生产站修——拆解审回 拆节奏环节（visual-style 定稿增量与索引骨架同回它），资产审回对应设计站，镜头表审回 分镜设计环节，成片审回 编译环节。默认之外的少数特殊路由见 〔K08-09 回流路由〕。上游观察不派活。

##### 2. v2 四原则的最终验证结果

###### 原则 1：画质即风格

- **结论**：**有效但需深化为"4 层画质退化"模板**
- **关键发现**：v2 单层"画质来源"声明（如"手机随手拍"）模型执行不充分，必须叠加：
  - 平台压缩 artifacts
  - 设备瑕疵
  - 现场瑕疵
  - 镜头变形
  + 9 个禁用清单 + 正向强约束
- **完整模板见第 4 节方法论 ④**

###### 原则 2：时序角色显式询问

- **结论**：**机制本身正确，但"图作时间锚点"概念已被推翻**
- **关键发现**：v2 的"首/中/尾/反/闪"机制让模型把图卡为某一帧——**反而绑架了叙事自由度**
- **新机制**：图降级为"氛围/环境/人物参考"，不强制卡任何一帧
- **详见第 4 节方法论 ①**

###### 原则 3：物理时间常数

- **结论**：**仅适用于"反应模式"，凝视模式不适用**
- **关键发现**：v2 默认所有人像都按"反应模式"（情绪反应+子节拍展开）——但凝视模式根本没有反应
- **新机制**：先选模式（反应/凝视）再决定是否适用物理时间常数

###### 原则 4：时长服从内容

- **结论**：**完全有效**（无任何修正）
- 5 个 case 时长：6/8/6/6/8 秒——没有一个默认 15 秒
- 这是 v2 最成功的原则

##### 3. ⭐ 最重大成果：路径 C v3 方法论完整定型

###### 3.1 路径 C 双范式：反应模式 vs 凝视模式

v2 缺失"凝视模式"是本次最大盲区。v3 必须新增这个范式。

| 维度 | 反应模式（v2 已有） | 凝视模式（v3 新增） |
|------|---------------------|---------------------|
| 主体 | 有情绪变化（害羞/惊讶/被击中） | 无情绪变化、自然存在 |
| 节奏 | 按子节拍展开 ≥X 秒 | 整段时间被时间本身展开 |
| 镜头 | 可切镜可定格 | 单一缓慢推进，不切不拉远 |
| 叙事 | "她注意到了什么" | "她不知道被偷拍" |
| 时序角色 | 可作中间帧/尾帧/反转帧 | 通常作首帧或不卡帧 |
| 物理时间常数 | 必须遵守 | 不适用 |
| 画质策略 | 写实质感 | 偏向偷拍/业余/脏镜头 |
| 美感来源 | 情绪反应的真实性 | 时间凝固的诗意 |

###### 3.2 凝视模式适用判断

- 用户说"自然神态、不需要发现镜头"
- 用户说"慢慢放大、不要切镜"
- 用户说"就拍那个 X，有 X 氛围就行"
- 图本身是"日常瞬间"而非"高燃情绪定格"

---

##### 4. 路径 C v3 八条新方法论原则（按重要性排序）

###### ① 图作"框架参考"，不作时间锚点（最重要）

**v2 的错误**：把图作"首/中/尾/反/闪"某一帧锚点
**v3 的修正**：图只提供"主体外貌+服装+场景氛围+大致姿态"，**不强制卡任何一帧**

**Prompt 写法模板**：
```
参考@图片1的[主体外貌服装]+[场景氛围]但不强制卡任何一帧，
视频自由演化为日常 [场景类型] 自然瞬间。
```

**适用场景**：90% 路径 C 场景（除非图本身就是高戏剧性瞬间，那种少数情况可保留 v2 的"中间关键帧"机制）

###### ② 凝视 ≠ 一动不动，必须有"3-4 个自然小动作分布"

**v2/v3 早期错误**：把"凝视模式"理解为"主角不可大幅度移动" → 主角呆滞
**v3 v5 修正**：凝视模式下主角必须做这个场景里的人会自然做的事

**Prompt 写法模板**：
```
主角必须做 [场景] 中自然会做的事（X秒内必须明显发生 3-4 个动作）：
- 动作1（具体）
- 动作2（具体）
- 动作3（具体）
- 动作4（具体）
不可表情呆滞不可一动不动不可只是 [被动姿态] 不可平静
```

**关键技巧**：每个动作都写**正向夸张 + 反向否定**双重锁定（见第 ⑦ 条）

###### ③ 符合日常物理常识

**v2 错误案例**：
- 演唱会主角站最前排但前景出现其他观众挡视线（不可能）
- 老师"边面向学生边在黑板上写字"（手与黑板物理矛盾）
- 老师"突然转头看学生但什么也没讲"（不符合讲课常识）

**v3 修正**：每个场景必须做"日常常识审计"——这件事在现实生活中是怎样发生的？

**Prompt 写法模板**：
```
环境：[场景描述]，[关键常识约束]（**禁止 [反常识动作]**）
```

**例子**：
- 演唱会："前面只有舞台/栏杆/安保剪影，禁止前面出现其他观众挡视线"
- 讲课："手与黑板物理关系必须符合现实——写字时粉笔贴板，转身时粉笔离板，讲解时粉笔不再接触黑板"

###### ④ 画质"4 层退化"模板 + 9 个禁用清单 + 正向强约束

**v2/v3 错误**：单层"画质来源"声明（如"手机随手拍"）模型不充分执行
**v3 v4.1 修正**：4 层叠加 + 多重否定 + 正向强约束三件套

**Prompt 写法模板**：
```
画质：[场景对应的画质类型]的双重画质退化：
①[平台压缩 artifacts]——[平台名] 低码率压缩感、画面细节磨平、暗部色块、彩色色噪、压缩边缘抖动；
②[设备瑕疵]——[设备] 在 [环境] 下的 ISO 噪点/曝光起伏/白平衡漂移；
③[现场瑕疵]——[场景特定瑕疵 如 信号瞬抖/雨水痕迹/手肘擦镜]；
④[镜头变形]——广角畸变/色散/脏点污染。
禁用4K高清禁用Cinematic禁用电影级禁用稳定器质感禁用调色精致禁用工业渲染禁用画面锐利禁用清晰画质。
```

**风格锁定结尾必加**："画质必须呈现明显的 [X 感] 不可呈现 4K 锐利画质不可呈现电影级稳定画质"

**4 个不同场景的"4 层退化"实例库**（详见对应 case 报告）：
- **球场看球**：直播流压缩 + 直播信号瑕疵 + 手机录屏特征 + 底层手机相机
- **演唱会**：抖音/小红书平台压缩 + 手机弱光录像 + 雨夜现场瑕疵 + 广角变形
- **讲课**：B 站/视频号压缩 + 学生手机偷拍 + 偷拍特征 + 广角变形
- **化妆间**：朋友圈视频压缩 + 室内闪光自拍 + 握持随意 + 广角变形

###### ⑤ 群演必须"段内具体写动作"，不能只是风格锁定声明

**v2/v3 错误**：风格锁定写"群演不可静止" → 模型忽略
**v3 v4 修正**：每个位置（左侧/右后方/前景/远处）写具体动作

**Prompt 写法模板**：
```
环境同步演化：身边 [群演类型] 必须有可见微动具体写——
左侧 [位置] [群演角色] [具体动作]、
右后方 [群演角色] [具体动作]、
前景 [群演角色] [具体动作]、
远处 [群演角色] [具体动作]。
```

**例子**：
- 球场："左侧紫色应援服女球迷和身边男生交头接耳指着场上方向、右后方男球迷举起饮料喝一口然后放下、前景一个观众随欢呼举起应援扇挥动两下、远处看台有一片观众随某次进攻起立又坐下"

###### ⑥ 主角行为必须"正向夸张 + 反向否定"双重锁定

**v3 v4 错误**：写"嘴唇随歌词轻动小声跟唱+小幅度晃动" → 模型理解为"几乎不动"
**v3 v5 修正**：每个行为都写**正向夸张**+**反向否定**

**Prompt 写法模板**：
```
- ✅ 正向夸张：[动作 + 幅度强调]
- ❌ 反向否定：（不是 X，是真的在 Y）
```

**例子**：
- "嘴明显张开跟唱歌词嘴动幅度大能看出是在唱" + "（不是抿唇小声哼，是真的在唱出声）"
- "她是这条视频的核心主角是全场所有粉丝里最投入的那个"（**给主角一个清晰的角色定位**让模型知道她不是被动旁观者）

###### ⑦ 镜头运动锁死声明（凝视模式专用）

**Prompt 写法模板**：
```
镜头单一 Very Slow Push In 极缓慢推进（X秒内仅放大约15%），
全程单一机位无任何切换无任何拉远不可上升下降不可切角度。
```

**关键点**：用**否定句穷举**（不可切换/不可拉远/不可上升/不可下降/不可切角度）锁死，否则模型会自由发挥

###### ⑧ 跨人物互动事件（多人场景必加）

**v3 v4 错误**：多人场景中每个人各做各的事 = 6 个孤立角色拼贴
**v3 v5 修正**：必须有**至少一个跨人物的互动事件**作为视频的"叙事骨架"

**Prompt 写法模板**：
```
跨人物互动事件（视频核心，必须发生）：[发起者] [发起动作] 作为视频起点的招呼信号，
[其他人] [响应动作] 但不需要 [完成度过高的动作]，过程中有自然 [互动类型] 动作发生：
- 角色1：[具体动作 + 对其他人的反应]
- 角色2：[具体动作 + 对其他人的反应]
- ...
```

**例子（化妆间）**：
> staff 男生举着手机说"来快过来合个照"作为招呼信号，几个女孩陆续从各自位置笑着往 staff 男生方向凑过来准备合影但**不需要完全凑齐到位**，过程中有自然打闹动作发生：和风女孩戏谑性贴近 staff 男生张大嘴喊"嘿嘿嘿"+staff 男生身体闪躲、皮甲女孩搭肩、金发被推一下抬头说"等我一下"...

##### 12. ⚠️ 本批最重要教训：字符数估算铁律 + 版权过滤双层规避

###### 12.1 字符数估算翻车（v1 教训）

**问题**：5 个 prompt 中 4 个超长。最严重 case-13 实测 3102 字符，自估"约 1995"，**超 1100+**。

**根因**：中文每字 = 1 字符（标点也算），但 Agent 写长 prompt 时容易低估字数 30-50%。

###### 12.2 版权过滤双层规避（v2 教训，2026-05-16 实测后追加）

**问题**：所有具体品牌词（iPhone/抖音/小红书/ESPN/NBA/UE5/王家卫/台湾...）都换成中性词后，**case-12/13 仍被即梦平台笼统判定为版权违规**。

**根因发现**：**真凶不是具体品牌名，而是"风格借喻"措辞**——「社交短视频爆款 vlog 自拍感」「职业联赛级体育转播画质」即便不写"抖音/ESPN"，平台也能识别出"这是想对标 X 平台/X 实体的质感"，触发版权过滤。

**双层规避策略（已沉淀到 SKILL/image-to-prompt）**：

| 层 | 类型 | 处理 |
|----|------|------|
| **第 1 类** | 具体品牌词（iPhone/抖音/ESPN/UE5/王家卫/台湾...）| 中性替换 |
| **第 2 类** | 风格借喻措辞（vlog 爆款/旅行 vlog/探店/职业联赛级转播/体育解说级/VFX 工作室级/大师式...）| **彻底改为纯物理描述**（手机随手拍/高速摄影/慢动作/暗光噪点/一对一对抗）|

##### 15. ⭐ 本批最重大方法论升级：极简优先铁律（v3.1）

**实战发现**：5 个 case 从 1800-2000 字符精简到 270-490 字符后：
- ✅ 即梦版权过滤通过率显著提升
- ✅ 出片自由度更高（不再被逐秒动作绑死）
- ✅ 更符合 Seedance 2.0 "图作主体+文字补充"的设计哲学

**升级前**（v3 八条原则·繁式版）：
> 凝视模式必须 3-4 个自然小动作 + 主角行为正向夸张+反向否定 + 群演段内具体写 + 跨人物互动事件 + 镜头运动锁死声明 + 4 层画质退化 + 9 个画质禁用清单 + 跨人物互动详细分镜...

**升级后**（v3.1 极简优先）：
> 路径 C/D 的 prompt **优先信任 Seedance 对图的理解能力**——文字只补 4 件事：①图没有的 ②图存在但需强化的 ③图里需规避的 ④保险硬约束。其它让模型自由发挥。

**4 件事补什么**：

| # | 类别 | 例子 |
|---|------|------|
| 1 | 图没有的 | 时长/比例/运镜大方向（一镜到底/缓推/段间硬切或溶解）|
| 2 | 图需强化的 | 节奏/情绪 hook/关键瞬间 |
| 3 | 图需规避的 | 不复刻网格/格子编号/原图水印 |
| 4 | 硬约束 | 无文字/真人面孔不可识/合规风险 |

**减负清单**（**这些都不要写**）：
- ❌ 每个动作具体到 0.X 秒的时间戳
- ❌ "正向夸张+反向否定"双重锁定
- ❌ 4 层画质退化模板（"抖音平台压缩+手机弱光录像..."）
- ❌ 9 个画质禁用清单
- ❌ 光影三层结构详细描述
- ❌ 品质锚定开头（"UE5 渲染+工业光魔级 VFX"等借喻商业产品）
- ❌ 段内具体写群演每个位置的动作
- ❌ 跨人物互动事件详细分镜

**何时仍可用繁式 v3 八条原则**：
- 用户明确要求"细节精雕"且第一版极简版出片不达标
- 反应模式高戏剧瞬间需精确时间锚点（凝视模式默认走极简）

**判断流程升级**：
1. **默认走极简版**（300-500 字符）—— 首选
2. 出片后若反馈"细节不够 / 节奏太自由" → 再升级为繁式
3. 出片后若反馈"画面僵硬 / 不像图 / 版权违规" → 更要回到极简版

**已沉淀到**：
- 〔K07-24 Seedance 提示词手册总则〕 路径 C 速览：升级为 v3.1·极简优先版
- 〔K07-21 图生提示词〕 新增"⭐ 极简优先铁律"小节（含减负清单、4 件事补什么、case-13 实战对照）

**给未来 Agent 的核心心法**：
> Seedance 2.0 不是 GPT。它对图的视觉理解能力比你想象的强很多。文字 prompt 不是"逐秒指挥模型"，而是"给模型一个清晰的目标和必要的约束"——剩下的让它自由发挥。
> **过度精细的 prompt 反而是噪声**。300-500 字符往往比 1800-2000 字符出片更好。

###### 17.1 多宫格分镜板控制力强（case-13 印证）

**通过率仅 25%** 证明极简策略不能盲目套用。3 类必须升级到繁式或换思路：

3. **凝视+抖音味子模式**（case-09/12）：需要 1 个明确心动 hook 锚点，不能纯随机演化

###### 17.3 心动 hook 概念正式提出

- 被发现：突然看向镜头微笑/掩嘴笑/捂脸笑/装作没看见又偷瞄
- 情绪反转：从淡定到爆笑/从认真到俏皮
- 道具互动：举食物/饮料对镜头 cheers/物品凑近镜头展示

###### 20.1 即梦平台版权审查·机制新理解（推翻多个错误假设）

> 即梦平台审的**不是单个词**，**不是叙事意图**，**不是镜头运动结构**——而是**词汇/词组本身在 AI 训练语料中的"涉灰联想强度"**。

| 4 | 图本身被识别为高风险所以拦（v5 错版）| **极限版 31 字符 + 同一张图过审** | 图没问题，问题在 prompt 词汇 |

###### 20.6 「三层动作分级」方法论（v5 翻盘后定型，多人场景必用）

> **case-17 v8/v9 翻车 + v10 修复 → 沉淀的最重要新规律**：人物动作不是"写多少"或"写少"的问题，而是**分层管理**。

| 层级 | 范围 | 写法 | 防什么 |
|------|------|------|--------|
| **第 1 层 · 持续微动** | 呼吸自然起伏胸口轻微抬落 / 肩颈极轻微浮动 / 偶尔眨眼 / 头发被空气自然轻微飘动 / 视线在画面前方做极小幅度流转 / 身体重心极轻微左右偏移 | "全程持续微动 X 秒每位都不能停" | **防石像化**（v9 翻车症状）|
| **第 2 层 · 被聚焦/节拍回应** | 嘴角轻扬 / 轻微点头一次 / 视线短暂锁定镜头方向约 0.5 秒 / 跟节拍极小幅度律动 | 时间段具体写"X-Y 秒：[人物 Z] 做[具体回应]" | **保持画面节奏**（叙事要求）|
| **第 3 层 · 大动作**（禁止）| 起身 / 走动 / 转身 / 换姿势 / 伸手拿物 / 举杯 / 拿出物品 | "禁止任何起身/走动/转身/换姿势/伸手拿物等大动作" | **防物理崩坏**（v3 酒杯飞、v4 物体错乱）|

**关键写作技巧**：
- 第 1 层用「持续微动」「X 秒不能停」**正向声明**，抵消"保持参考图站姿"的石像副作用
- 第 2 层回应描述要**具体到 3 个细节**（嘴角+点头+视线时长），不能写模糊"自然回应"
- 第 3 层禁止动作要**穷举**（起身/走动/转身/换姿势/伸手），不能只写"不要大动作"

###### 20.7 「多人场景脸部不同质化」3 条护栏（防 v8 翻车）

> **case-17 v8 用"镜头平移到第 X 位"导致 6 张脸都长一样**——AI 的"特写"会重新生成脸，不会跟参考图对齐。

**3 条护栏**（多人场景必用）：

```
✅ 护栏 1：镜头零移动 + 全员永远在画面里
   ❌ "镜头平移到第 X 位"（→ AI 把每次抵达理解为脸特写）
   ✅ "镜头单一固定全景静态机位 X 秒不动" + "全员全部入画"
   ✅ 靠台词指代（"画面左 X 这位是..."）+ 该位轻微回应

✅ 护栏 2：禁止面部特写
   ✅ 末尾必加："关键约束：脸部容貌严格遵循参考图，不要做面部特写不要替换面孔"

✅ 护栏 3：被聚焦时的动作幅度极小
   ✅ "嘴角轻扬+轻微点头+视线锁定 0.5 秒" 这种**只动微表情**的描写
   ❌ "撩头发+举杯+转头看朋友"（→ 大动作触发 AI 重新生成姿态，姿态变了脸也跟着变）
```

###### 20.8 「防物理崩坏」3 条铁律（防 v3 翻车）

> **case-18 v3 用"举杯 cheers"导致酒杯飞**——多人 + 物理交互是 AI 视频生成的崩坏重灾区。

**3 条铁律**（前景有道具的场景必用）：

```
✅ 铁律 1：前景道具显式锁定
   ✅ "前景酒杯/果盘/冰块保持参考图位置不动"
   ✅ "禁止酒杯漂浮/移动/被举起"

✅ 铁律 2：禁止人物与道具的物理交互
   ❌ "举杯 cheers / 拿起手机 / 抓起头发别上发卡"
   ✅ 改成纯肢体动作（律动/微笑/点头）

✅ 铁律 3：动作越多，物理越容易崩
   ✅ 5 个人 5 个动作 → 改成 5 个人共享同一个动作或微动
   ✅ 整体律动统一 + 仅主角靠视线/表情差异化（不靠肢体）
```

### K08-14｜导演质量门槛

> 方法体系：匠心版方法。

#### K08-14-01｜1. 原则

取消100分制、85分通过线和对外分数。由同一AI给自己的镜头打分不能证明专业性；本文件只做可反读的`通过/重写`判断。

P3A负责导演方案并逐段取得站位交接选择，同时允许创作者显式加入BGM；P3B负责把已确认方案生成并内部检查为首帧分镜，P4负责最终提示词。每个单元固定只确认一次P3A；项目第一视频单元或用户明确要求新分镜时执行P3B，但不增加分镜确认回合。确认方案并完成站位交接选择时，未明确写BGM即自动锁定无BGM并进入P4，不得追加音乐确认。P4只在内部重写。

#### K08-14-02｜2. P3A导演方案门槛

先读取〔K06-30 情绪镜头语法〕，再检查：

1. 原文边界只包含一条主事件链及其直接后果；下一句若开启新地点、新目标、新发现或新问题，已经留给下一单元；
2. 已完成对白与表演、动作关键路径、观众识别时间三次冷演，并按复杂度安全装载选择最优可靠边界；
3. 完整原文已编译为一条按顺序发生的情绪变化链；内部导演判断明确观众感受、第一注意力、立即/延迟信息、主要视觉变化与本段落点；
4. 每个叙事镜头都只有1个主要情绪任务与第一注意力，并已确定景别/构图、角度、机位、运镜和切点；
5. 景别、机位与构图让心理距离、观看位置、关键动作和焦点顺序清楚，不要求为了变化而变化；
6. 已按〔K06-29 导演规则〕选择最小充分的固定、切镜或运镜方案；继续拍没有被误写成摄影机继续移动；
7. 项目首镜和场景首镜前1至3秒存在动作、异常、威胁、矛盾或未回答问题；说明型全景只有环境压力、人物孤立、空间陷阱或关系几何承担戏剧职责时通过；
8. 内部第一帧技术预演已写明焦段、机位、身体裁切、前中后景、构图关系、第一注意力和开场钩子；对外首帧效果与其一致且能让非专业用户直接想象画面；
9. 一镜到底、长镜头＋切镜或受控多镜由连续时空和模型容量决定，不以“高级感”决定；
10. 镜头数量没有为凑30秒或凑固定数量而增加；
11. 对外默认只显示完整原文、准确时长、一句话导演意图、3至6个成片视觉节拍、首帧效果、结束衔接与BGM建议；六列技术表和动作轴只按用户请求展开，不显示隐藏思维链、导演姓名、理论堆砌或分数。
12. 机位选择能看清关键动作、人物关系和空间方向，保持180度轴线连续；没有为了套用斜轴或正中构图而牺牲清晰度。
13. P3A已固定询问本段是否需要1秒站位交接，用户选择已记录为`handoff_mode=on/off`；提案卡同时显示准确叙事时长及两种选择对应的准确总时长，且不得继承上一单元选择。

任一失败先改方案，再展示给用户。用户未明确确认P3A，不得生成新分镜或进入P4。

#### K08-14-03｜3. P3B首帧分镜门槛

项目第一视频单元或本次计划生成新分镜时，逐项检查：

1. 分镜只在P3A确认后生成，并实际传入P2S已确认的最少充分参考资产；
2. 人物身份、人数、身体裁切、画面左右、前后层、朝向、动作和关键地标与P3A一致；
3. 第一注意力可从主体大小、运动趋势、明暗、景深或构图中明确读出；
4. 遮挡、引导线、负空间或主体偏置等构图关系与已确认导演职责一致；
5. 开场首帧为前1至3秒的动作、异常、威胁、矛盾或视觉问题建立有效起点；
6. 失败项只允许自动重画1次；仍失败时明确说明失败项，并以已确认P3A文字预演为首帧依据进入P4；
7. P3B不设置创作者确认门禁，内部检查结束后与提示词在同一轮交付。
8. 首帧机位与构图能清楚显示关键动作、人物关系和必要空间，并为动作、视线或威胁保留可读区域。

用户要求实质改变景别、机位、构图逻辑、第一注意力或原文边界时返回P3A，不把它伪装成P3B局部重画。

#### K08-14-04｜4. P4冷读门槛

切换为第一次看到提示词的执行模型，只读最终交付内容，逐项判定：

1. **导演方案一致**：逐镜情绪任务、第一注意力、时间、景别/构图、角度、机位、运镜和切点与已确认P3A一致；实质变化必须回P3A确认。
2. **分镜一致**：P3B内部检查通过的分镜存在时，第一帧人物身份、身体裁切、画面左右、前后层、焦点、地标和动作方向与该分镜及文字预演一致；分镜检查未通过时只对照已确认P3A文字预演。
3. **开场钩子**：项目首镜/场景首镜前1至3秒存在明确动作或视觉问题；若使用全景，其环境/关系职责可从构图直接读出。
4. **单镜单注意力**：每镜只有1个主要观看对象，其他人物、道具和环境服从焦点顺序。
5. **情绪可读**：删掉抽象情绪形容词，仅凭构图、距离、角度、人物调度、镜头运动和切点仍能读出情绪变化。
6. **最小充分摄影机**：固定机位已经呈现必要信息时保持固定；运镜仅用于跟随人物或揭示固定机位看不到的必要信息；换观看位置、压缩时间或强调反应时可以直接切镜。删掉运动后表达不受损却仍发生推进、后退、抬升、下沉、摇移或漂移，当前镜头失败。
7. **资产缺口与映射闭环**：本批所需资产先与P2S快照比对，缺口已有创作者明确处置；外部上传表与提示词槽位一一对应。图片、音频、视频三类分别从1连续编号；任何增删或替换后都已按最终素材集重排所属类别，不存在空号、虚构图号、音频号或路径。三条路线的当前说话者都必须引用创作者提供并经P2S确认的实际声音文件。
8. **原文动作强度**：强动作已翻译为重心、步频、呼吸、接触和环境反馈，没有被降级。
9. **道具状态机**：持有、触发、脱手/换手、独立运动、碰撞/钩挂、最终状态和后续接触互斥完整。
10. **不可达关系**：`够不到/卡住/吊住/无法取回`至少有2个可见几何证据，普通伸手或爬半步不能解决。
11. **空间和第一帧**：屏幕方向、地标、身体裁切和当前站位依据一致，不使用东西南北代替画面关系。
12. **BGM显式加入一致**：确认回复明确写BGM时，【声音设计】直接写具体配器和准确时间弧线，不出现`Seedance同步生成本段原创纯器乐BGM：`或同类元命令，并有1000字符以内Suno备用提示词；确认方案并完成站位交接选择但省略BGM时即为无BGM，直接生成提示词，【声音设计】明确无BGM且不输出Suno，不得再次向创作者询问音乐。
13. **站位交接选择一致**：`handoff_mode=on`时，总时长最后完整1秒硬切至45度斜俯全景，人物正面身份可辨、全身完整、世界坐标和持物状态不变；`handoff_mode=off`时，不预留交接秒且不得出现【站位交接镜头】或交接专用构图。
14. **模型容量**：单镜只有1个主要职责，复杂摄影机运动不超过1项，不同时堆叠过多人物接触、道具状态、对白和特效。
15. **极简映射**：【素材映射】只写人物、场景、道具、声音或连续性参考的身份，不复述人物外貌/服装、声音音色或场景装修/材质/光线。
16. **机位与轴线**：机位能清楚显示关键动作、关系和空间方向，并保持180度轴线连续；正中、斜轴、侧面、背面或过肩均不因形式本身判定失败。
17. **两段精简风格锁定**：【风格锁定】严格为两个自然段。第一段只保留P1已确认的1部主要视觉参考影片并翻译为至少2个可见借鉴维度，不出现补充声音影片或听觉借鉴；第二段只写当前片段精确故事时刻、摄影机/胶片与镜头系统、帧率/运动模糊、真实光源与曝光、色彩影调，并在段末写禁止项。不包含国家/地域/地点、剧情复述、构图运镜方案、材质纹理清单、画幅、横竖屏或`{{Mixed N}}`等未解析占位符。
18. **场景图职责边界**：本批映射普通场景图时，【素材映射】全部身份行后有且只有一句`本批场景图仅参考环境与氛围，不继承原图的空间结构、拍摄方向、焦段、透视、景别与构图；最终镜头以本提示词为准。`纯文字、仅人物/道具图或图片已明确作为起始帧/连续性帧时没有误加；最终空间事实、机位和构图由正文独立确定。
19. **正文语义命名**：外部上传表与【素材映射】可保留视觉槽位编号；离开【素材映射】后，人物、场景与道具只使用映射确认的具体姓名/称谓、场景名和道具名，同一身份多状态用状态词区分。正文不得出现`图N、图片N、Image N`或图片占位符；音频N、视频N仅在确需指定声音或连续性来源时保留。
20. **生成信息外置**：【本段生成信息】位于视频提示词代码块外，准确列出Seedance版本、叙事时长、站位交接秒数、总时长和独立生成；代码块第一个非空行是【风格锁定】，内部没有`Seedance 2.5｜叙事时长…｜总时长…｜独立生成`、`总时长：…秒`或同类元信息。
21. **全局补充职责单一**：【全局补充】只保留会造成画面作废的误生限制，不写站位交接启用/停用、交接镜头/交接图/交接帧、直接结束秒数、额外时长或生成元信息。`handoff_mode`只由【站位交接镜头】栏目存在或缺席表达。

所有适用项通过才允许交付。

#### K08-14-05｜5. 硬失败

以下任一项出现即重写：

- 镜头选择的理由只能写成“更高级、更电影感、更紧张”；
- P3A确认前生成新分镜或提示词，或P3B适用时把分镜确认设成独立用户门禁；
- 为接近平台上限吞入下一事件、未做三次冷演、把不能同时发生的动作/对白重叠计时、翻译字幕重复计入对白，或内部执行表缺少情绪任务/第一注意力、景别/构图、角度、机位、运镜/切点；
- 项目首镜/场景首镜只是说明型平视全景、多人物整齐全身陈列或无职责空镜；
- 为套用某种角度而越轴、遮挡关键动作、破坏空间连续或制造无意义倾斜；
- 起幅已经建立人物与场景关系后仍无理由推进、后退、抬升、下沉、摇移或漂移；
- 一镜到底依赖穿墙、瞬移、整幅遮挡伪装切点，或超过模型可控容量；
- 当前选择所依赖的人、道具、出口或威胁既不在画内，也没有清楚因果反打；
- 原文强动作被降级；道具状态重叠；运动违反坡度、重力或惯性；不可达关系缺少几何证据；
- 素材缺口未取得创作者决定、映射不闭环、图片/音频/视频任一类别没有从1连续编号或删除素材后仍残留空号、说话者缺少创作者提供并确认的实际声音文件、映射复述资产档案、第一帧冲突、屏幕方向矛盾，或站位交接栏目与P3A确认的`handoff_mode`不一致；启用交接时缺少合格交接镜头，停用时仍残留交接栏目；
- 用户选择BGM却写“后期独立轨道”“不要求视频模型内生音乐”，缺少具体配器/时间弧线，或添加`Seedance同步生成本段原创纯器乐BGM：`等元命令；
- 创作者已经确认方案并完成站位交接选择、回复中没有明确BGM，却继续追问`BGM/无BGM`或阻止进入P4；
- 【风格锁定】不是两个自然段，出现第二部补充影片或声音借鉴，丢失P1主要视觉参考影片及至少2个可见借鉴维度，缺少当前片段精确故事时刻、摄影镜头、光线曝光、色彩影调或禁止项，或者残留国家/地域/地点、剧情复述、构图运镜、材质纹理清单、画幅与未解析占位符；
- 本批映射普通场景图却缺少固定职责边界、重复添加或扩写成新栏目；或者纯文字、无普通场景图、明确起始帧/连续性帧误加该句；
- 离开【素材映射】后仍用`图N、图片N、Image N`或图片占位符代替具体人物名、场景名或道具名；
- 视频提示词代码块没有直接从【风格锁定】开始，或代码块内出现Seedance版本、叙事时长、总时长、独立生成等外部生成信息；
- 【全局补充】出现站位交接启用/停用、交接镜头/交接图/交接帧、直接结束秒数、额外时长或其他生成元信息；
- 单镜同时承担4项以上高风险职责。

#### K08-14-06｜6. 自动重写

1. 结构脚本失败先修结构；
2. 逐项运行P4冷读门槛；
3. 只重写失败责任层，不给分、不追加解释性补丁；
4. 第二轮仍失败时优先改为固定机位或直接切镜，再减少同镜人物/道具任务，必要时缩小原文边界；
5. 最多2轮。若需要改变用户已确认的情绪任务、第一注意力、景别、构图、角度、机位、运镜、切点或原文边界，回P3A展示修订方案并重新确认；若只需让分镜重新贴合方案，P3B内部重画1次，不增加确认回合；
6. 只有最终通过版本进入P5，对外不显示分数和质检行。

#### K08-14-07｜7. 成片反馈

通过只表示提示词镜头逻辑、物理和执行条件自洽，不保证模型完全照做。生成后以实际画面为准，读取〔K03-10 循环工程〕做最小修复；不得因为内部已通过就否认成片问题。
