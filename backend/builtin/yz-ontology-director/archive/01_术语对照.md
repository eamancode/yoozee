# 术语对照

知识卡片整理自多套既有方法，保留了它们原来的术语。本表把这些术语翻译成本 skill（SKILL.md、params.md 与 stages/）的说法。读卡片遇到看不懂的代号，先查这里。

## 一、基本单位

| 卡片里的说法 | 主规程的说法 | 说明 |
|---|---|---|
| 条、生成单元、批次、段 | 生成单元 | 一次 Seedance 生成 = 一条提示词。卡片里的条编号 sXX-cN 对应主规程的 sXX-uN |
| 场、sXX | 场 | 跟剧本场头走：内外景、地点、时间 |
| 镜头N、镜、切N | 镜 | 单元内的切镜 |
| 拍、节拍、beat | 拍 | 镜内最小的动作或情绪变化 |
| 小节 | 生成单元 | 即梦分镜规程的叫法 |
| 集、epNN | 集 | 多集项目中的一集 |
| 落幅、结束状态、尾帧 | 结束状态 | 五字段：位置姿态、视线、道具状态、光状态、情绪余温 |
| 接缝卡、条间缝 | 接缝卡 | 出点、入点、手法、省略物证 |
| 镜尾接续、镜尾落地 | 镜尾二态 | 接续：约 0.5 秒余势；落地：停稳 1.5–3 秒 |

| 卡片里的说法 | 主规程的说法 | 说明 |

## 三、流程阶段代号（匠心版方法）

匠心版方法把工作分为以下阶段，并设置多个确认点。主规程采用全自动模式，不设确认点；对应关系如下：

| 代号 | 原含义 | 主规程中的对应 |
|---|---|---|
| P0 | 项目接收 | 立项回合开始 |
| P0A | 十项剧本解析与创作基准（含全片情绪曲线） | 世界圣经卡 |
| P0R | 选择生产路线 A/B/C | 本 skill 固定为"只出提示词"路线 |
| P1 | 全片创作基准（视觉、声音、音乐基准） | 世界圣经·美学宪法 |
| P2 | 三路线资产阶段（人物、道具、场景） | 补图建议 |
| P2S | 实际资产扫描与确认 | 材料包里的素材清单 |
| P2V | 视频版本与平台设置确认，含成片时长预估 | 本 skill 固定为 Seedance 2.5 |
| P3A | 逐单元导演提案（情绪、注意力、观看位置、首帧效果） | 导演分镜卡 |
| P3B | 首帧黑白分镜图与符合度检查 | 首帧描述与字符俯视站位图 |
| P4 | 内部提示词编译与质量门槛 | 编译与自检 |
| P5 | 交付精准视频提示词 | 粘贴提示词 |
| P6–P7 | 结果反馈与连续性登记 | 返修回合与集交接卡 |
| 路线 A / B / C | A：完整资产制作；B：只出资产提示词；C：直接做视频 | — |
| handoff_mode on/off | 是否追加 1 秒 45° 斜俯全景站位交接镜头 | 本 skill 默认开启（D050），整集统一，不逐单元询问 |
| bgm_mode | 是否启用背景音乐 | 默认不加 |

## 四、工位方法里的环节与确认点

| 卡片里的说法 | 含义 |
|---|---|
| 立项访谈环节 | 定片种、风格、叙事范围、一致性要求，以及五元素剧作审计 |
| 剧本改造环节 | 结构、可视化、可实现性三类改造 |
| 编剧环节 | 从梗概写剧本或逐场共创 |
| 拆节奏环节 | 逐场讲戏、拆条、时长预算、资产清单 |
| 人物 / 场景 / 道具设定环节 | 出参考图与设定提示词 |
| 分镜设计环节 | 镜头表：空间地图、场阐述、逐镜分镜卡 |
| 站位调度 / 运镜 / 灯光 / 表演 / 声音环节 | 为分镜卡和提示词提供对应子句 |
| 控制图环节 | 关键帧、宫格、站位图、白模深度图 |
| 编译环节 | 把镜头表编译成视频提示词 |
| 连续性台账环节 | 维护跨条、跨集状态 |
| 审稿环节、审稿员 | 只审不改，查五类病 |
| 返修环节 | 诊断翻车症状并给出修复 |
| ★拷问确认、★拆解确认、★表确认等 | 原方法中需要用户点头的确认点；主规程不设，改为待确认清单 |
| 拆解审、资产审、镜头表审、成片审 | 原方法的四类审核点；主规程用自检 + 审稿规程覆盖 |
| 〔原工具链内容，本 skill 未收录〕 | 原方法中依赖特定脚本、目录或自动化工具的部分 |

## 五、提示词结构

| 卡片里的说法 | 主规程的说法 | 说明 |
|---|---|---|
| 恒定层 / 可变层 | 恒定层 / 可变层 | 恒定层逐字复用；可变层只写本单元增量 |
| F1 九段结构 | 九段固定顺序 | 见 S7 第 4.2 节；第 7 段为站位交接镜头 |
| A 轨（时间戳轨） | 带时间码的镜头 | "0–4 秒 ……" |
| B 轨（镜头N轨） | 镜头N 标题行 | "镜头2（4–9秒｜特写 18° ……｜揭示）" |
| 针对性负向、全局禁止尾缀 | 正向锁定 + 一句技术排除 | 否定可视对象会召唤画面，一律改正向 |
| 控制等级 L1–L4 | — | 原方法按空间控制难度给镜头分级，等级越高越需要控制图 |
| 首尾帧模式、严格首帧 | — | 以首帧（和尾帧）图片约束生成的模式 |
| 宫格 / 九宫格 | — | 一张图里排多个分镜格，用作参考 |
| FOV、视场角 | 视场角 | 只用 107°、84°、63°、47°、29°、18°、12°、8° 档位 |

## 六、平台与版本

| 卡片里的说法 | 说明 |
|---|---|
| Seedance 2.0、SD2.0、即梦 2.0 | 旧版本：单条 ≤15 秒、提示词较短。卡片中按 2.0 写的时长和长度，要按主规程第二章换算 |
| Seedance 2.5 | 本 skill 的目标平台：单条 ≤30 秒，提示词 ≤15000 字符，原生对白与音效 |
| 超长模式、视频延长 | 2.5 的特例通道：单次 30–180 秒直出，或在已有视频后延长 |
| 即梦、LibTV | 生成平台名称 |

## 七、知识库编号

| 编号 | 含义 |
|---|---|
| Kxx | 卷，例如 K06 是导演分镜卷 |
| Kxx-yy | 卷内模块，一个模块整理自一份既有方法文档 |
| Kxx-yy-zz | 模块内的知识卡片 |
| 〔Kxx-yy 名称〕 | 卡片正文里的交叉引用，指向本知识库的另一个模块 |
| 〔世界圣经·…〕〔本集剧本〕〔粘贴提示词〕等 | 指向主规程里的对应产物 |
