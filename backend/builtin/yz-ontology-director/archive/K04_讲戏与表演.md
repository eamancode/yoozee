# K04｜讲戏与表演

> 本卷是本 skill 的结构化知识库之一，对应本 skill 的 S4。
> 什么时候查：人物任务卡、情绪外化、动作链、群像、烂演技修法。
> 本卷结构：一、核心规则与裁决 → 二、模块与卡片目录 → 三、知识卡片。卡片编号格式为 Kxx-yy-zz（卷-模块-卡片）。
> 卡片内容整理自多种既有方法，保留了完整论述；其中的时长、平台参数、否定句写法与主规程不一致时，以主规程为准。卡片中出现的阶段代号与旧术语见 references/01_术语对照.md。

## 一、核心规则与裁决

**本卷回答的本体问题**：人物此刻想要什么？他用身体做什么去得到？对应本 skill 的 S4。

### 1. 提炼出的规则

1. **五支柱 + 任务阶梯**（〔K04-02 任务制表演法〕）：目标（及物动词 + 对象）、障碍与代价、战术（随失败更换）、节拍（换战术即变拍）、倾听。状态词、对象缺失、主题当目标都是错的目标。
2. **ACTING TASK 块**：每个主要人物每场一块，主规程简化为"人物任务卡"。
3. **表演档案母版**（〔K04-04 表演档案指南〕）：核心角色建档——身体四参数（重心、节奏、开合、磨损）、习惯动作、压力下的变化。主规程放进人物本体卡的"表演气质"。
4. **烂演技图谱 18 条**（〔K04-03 烂演技图谱〕）：图解式表演、演结果、等口令、单一战术、手势图解、白给的情绪、身体背叛履历等，每条给提示词级修法；0–5 表演量表，主角镜头必须 4 分以上。主规程第 7.4 节和第 12.3 节吸收了主要条目。
5. **眼活强制项**：近景以上写视线落点与移动。
6. **动作链六要素**：起势、发力、接触、反馈、余势、落点。
7. **物理指令 + 情感解析成对写法**（〔K07-09 强弱句改写〕）：先写可执行动作，再用括号写潜台词；删掉括号仍可拍。
8. **克制原则与表演三通道**（短剧分镜硬约束 第 18 条）：藏七分露三分；大动作、小动作、微表情三通道，重要情绪启用两个；强情绪反用"静"。
9. **群像**（〔K04-05 表演环节总则〕、人物设定环节 〔K01-04 人物变体与群演〕）：主体、反应、背景三层；群演不具名、不写人数，写局部形态。
10. **对照建构**（contrast pairing）：同一场里两人的表演方式形成对照，比各自加码更有效。

### 2. 冲突裁决

| 冲突点 | 各资料说法 | 本规程裁决 |
|---|---|---|
| 表演外放程度 | 短剧分镜硬约束：短剧一律克制；Seedance 提示词手册 部分爆款案例：夸张表情吸睛 | 默认克制；2D 动漫轨可适度夸张；喜剧类在圣经"表演基线"里另定 |
| 表演档案是否必建 | 工位方法：核心角色必建 | 方案 B 压缩进人物本体卡的"表演气质"一行 |

## 三、知识卡片

### K04-01｜表演示例

> 方法体系：工位方法。模块说明：当你写一场重场对白戏的表演、想对照标杆手感时对照它。演示一场双人对白重场戏从任务阶梯、ACTING TASK 块、场景适配表演段到 B 轨镜头内表演句与结束状态供给的完整链路，每段附「为什么这么编」注解。照密度写，不照抄场景。

#### K04-01-01｜示例定位

- 标杆：一场双人对白重场戏，从任务阶梯走到可嵌进动态提示词的成品段。本标杆自洽、与任何项目无关。
- 场景设定：深夜当铺。小马二十出头，拿亡父留下的怀表来当，急用钱；老周六十岁、当铺老板，打开表盖，认出内侧刻着三十年前一桩旧案里的名字——那桩案子他不干净。全场只有验表、问价、还价；末了老周付了高于开价的钱，把表面朝下扣在丝绒垫上，说："这表……走得太准了。"
- 每段产物后附「为什么这么编」注解。

#### K04-01-02｜阶梯工作单

```
场戏目标（共同暗向）：把这次交易维持成一桩普通生意。
结尾最后一拍：老周多付钱、把表扣过去、说"这表……走得太准了"——说的是表，指的是报应。
事件命名：被认出的债回来讨还。
表面活动/地形：一次例行的验货议价。
物理通道：
    老周：经由无瑕的验货程序——放大镜、看机芯、上弦听摆，每一步都做得比平时更标准，程序是他的掩体。
    小马：经由撑住体面的讨价还价——报价时坐直、把磨破的袖口往回收、抢在对方之前说出表的"来历"。
动机——同向不同燃料：
    老周：一说破就得卷进旧案——他维持"普通生意"是自保；收尾处这股燃料换成了偿还，见破口。
    小马：不能让人看出这是他最后一件东西——他维持"普通生意"是为了体面，妈妈教的。
个人目标：
    老周：验完、给个数、送走这块表和它带来的三十年。
    小马：当出够数的钱，今晚就走，不多说一个字。
障碍：那行刻字。每次开盖它就在放大镜里；老周多看一秒都是烫的，小马根本不知道它意味着什么——不知情者的坦然反过来压着知情者。
本质轴（+/- 镜像）：对这块表的过去——老周：生意人（+娴熟）/知情者（-有罪）；小马：来销急（-看着可疑）/干净（+他什么都不知道）。观众读的轴：谁背着这块表的历史。
```

为什么这么编：

事件从结尾倒读得来——"走得太准了"这句双关末句是全场的钥匙，即阶梯 1a 级；事件"被认出的债回来讨还"装得下两个人，即 1b 级：老周被讨，小马不知情地在讨——他继承的正是这段过去；两人同推"普通生意"这一个方向、燃料相反，即 2 级——这正是"观众感到压力恰因无人演它"的结构：全场没有一句台词提旧案。

#### K04-01-03｜ACTING TASK 块 ×2 · 嵌进该条【分镜正文】对应段

```
ACTING TASK——当铺老板（全情投入于他的战术；戏在他的眼睛里）：
场戏方向（共同暗向）：把这次交易维持成一桩普通生意。
动机：一说破，就得卷进三十年前那桩案子。
目标：验完、给个数、把这块表和它带来的三十年一起送走。
障碍：表盖内侧那行刻字；柜台外年轻人毫不知情的坦然，让每一秒装出来的"例行"都更重。
战术：用验货程序压住局面——放大镜在刻字上只停一秒就挪开、多停即暴露；上弦、听摆，抬眼核对对方瞳孔里有没有"知情"的影子、报价前盯住对方喉结等一次吞咽。
逐拍：
——"哪儿来的？"——试探，眼睛从表盘抬起、先扫对方的手再进他的眼，找一星闪躲。
——"我爸留的。他跑船。"——核对：这句落地时对方的目光稳不稳；稳——他真的不知道。战术从试探换成送走，即一次变拍。
——"这表……走得太准了。"——破口：燃料在这句耗尽，自保换成偿还——多数出的钱推过去时，指背在丝绒垫上压了一拍才松。
安全行：目光始终咬在任务上——绝不冻结、玻璃化、失焦；自然眨眼节奏。
```

```
ACTING TASK——柜台外的年轻人（全情投入于他的战术；戏在他的眼睛里）：
场戏方向（共同暗向）：把这次交易维持成一桩普通生意。
动机：不能让人看出这是他最后一件东西——体面是妈妈教的。
目标：当出够数的钱，今晚就走，不多说一个字。
障碍：他每报一个数，手就想去摸表——那是他爸的东西，正在变成钱。
战术：撑住行家的样子——抢在被问之前报"来历"、盯着老板的手学他怎么拿表、听到报价时先数自己的呼吸再开口还价，核对对方的眼睛：他信没信我不急。
逐拍：
——"我爸留的。他跑船。"——递交底气，说完眼睛没躲、迎着对方核对：够不够像一句说惯的话。
——"……行，就这个数。"——收拢：答应得比预想快了半拍，随即用收袖口的动作把这半拍盖过去。
安全行：目光始终咬在任务上——绝不冻结、玻璃化、失焦；自然眨眼节奏。
```

为什么这么编：

两块任务的战术全部写成对搭档做的事 + 眼工动作，即 5 级；没有一个情绪副词、没有一处面部编排；老周的变拍试探 → 送走钉在"我爸留的"那句台词上——变拍锚台词不锚秒数；破口安排给知情者而非哭穷者——破口即交付；小马"答应快了半拍再用收袖口盖过去"是潜台词的行为标记——过短的回答 + 掩饰动作，观众看得见、人物没说破。

#### K04-01-04｜场景适配表演段 · 老周档案的本场重写，嵌【分镜正文】，示范「重写不粘贴」

```
当铺老板坐在柜台后的高凳上，低重心、不动如山——他的"掌柜巡视步"今晚用不上，那股慢而沉的能量全部转进手上的程序：放大镜起、落，动作比平时更标准、更慢半拍——面具是一张看过千件旧货的无聊脸，藏着全部注意力。他的招牌 tic 保持原样——报数前用鼻子缓慢地、可闻地吸一口气；说谎的可能出现在面前时，他彻底静止，让沉默去压。眼活：视线在表盘、对方的手、门口之间安静地扫，眨眼罕见而蓄意，目光先落到人、头过一拍才转。However 条款本场触发：放大镜扫过表盖内侧的一瞬，无聊面具裂开半秒——喉结一滚、镜片抬离刻字一毫米——随即他自己把它合上，动作接回程序，比刚才更标准。
```

为什么这么编：

步态无关、人在坐姿 → 能量转移进验货程序，即转移不删除；tic 与面具全部从档案继承且带原触发器，恒定核不动；However 裂缝在本场有了具体触发物——那行刻字，裂开半秒又自己合上——一段里演了两个真相，面具 + 裂缝即 two-truths 的行为实现；全段无服装、无镜头、无调色，以特征代称开头——@编号只在【参考资产绑定】段出现一次，不进正文。

#### K04-01-05｜B 轨镜头内表演句 + 结束状态供给 · 示范落位与交接

```
镜头4 特写，怼在当铺老板脸上：景别越紧动作越少——只留眼睛和想法。放大镜的光斑压在他半边脸上，他读到刻字——反应只有三样：瞳孔的一次微缩、喉结一滚、镜片抬离一毫米；脸上的无聊面具没动。他的神情停在如常与失守之间——彻底垮下的惊惶 = 废镜，毫无波澜的木然 = 废镜。
```

```
本条【结束状态】五字段，供下一条承接：位置：柜台后高凳，上身前倾于验货垫上方｜朝向：面向柜台外的年轻人，头低向表｜持物：右手放大镜、左手怀表、表盖开｜动作动势：验货中段，刚从刻字上移开镜片｜情绪：如常面具下压着认出的震动，外稳内紧。
```

为什么这么编：

特写遵守"景别越紧动作越少"，即图谱第 14 条的反向执行，三个微动作全部可拍；重情绪用双向夹钳句写出两端废镜判定，防单词情绪漫画化；结束状态的"情绪"字段写的是"外稳内紧"这个可观察的复合态而非抽象词，下一条的场景适配段从这里接着演余波——情绪不复位，即图谱第 12 条。

### K04-02｜任务制表演法

> 方法体系：工位方法。模块说明：当你写重场对白戏、要走五支柱与任务阶梯、或表演被审出"演结果/死脸/主题上身"类问题时翻它。给五支柱判据卡、任务阶梯全文、ACTING TASK 块格式、对照建构与常见失败逐条修法。

#### K04-02-01｜定位

本卡是任务制表演的完整方法卡：五支柱判据卡、任务阶梯全文、ACTING TASK 块格式、对照建构（contrast pairing）与常见失败。〔K04-05 表演环节总则〕 收拢的是速查版；写重场对白戏、或表演被审出"演结果/死脸/主题上身"类问题时，翻开本卡全文。

五支柱、身体与群像、任务阶梯、眼工均为已实战验证的方法；定义按本卡原文执行，不用教科书定义替换。

本卡每节按「怎么认 / 认错长什么样 / 典型例子」给判据。

#### K04-02-02｜判据卡 · 五支柱

Objective 目标

- **怎么认：**
  - 一个及物动词 + 具体对象，本场此刻就要，如"让他招供""求她再宽限一周""说服她我不害怕"；可能失败，失败有后果。背后有贯穿全片的超目标，本场目标是走向它的一步。
- **认错长什么样：**
  - 状态词冒充目标——"愤怒着""内疚着"，状态演不出来；对象缺失——"想要尊严"，向谁要；影片主题当目标——"体现救赎"，人物永远不知道影片的用意。
- **典型例子：**
  - 反例「他很愤怒地质问她」 → 正例「他要她当场认下偷表——用一句句逼问，逼她在孩子面前亲口说出来」。

Obstacle & stakes 障碍与代价

- **怎么认：**
  - 外部障碍——对方要相反的东西、在场的证人、还剩两小时的死线，或内部障碍——自尊不许他开口求人、他不信自己说的话，都成立；"拿不到会怎样"有一个吓到人物本人的答案。
- **认错长什么样：**
  - 障碍是摆设，拿不到也无所谓；代价抽象——"会很糟糕"，糟糕成什么样；只有外部没有内部，人物一片坦途。
- **典型例子：**
  - 反例「他想借钱，但不太好开口」 → 正例「不借到这笔钱，明早他儿子就上不了手术台；而挡着他的是：对面坐着的是他十年没喊过一声哥的人」。

Tactics 战术

- **怎么认：**
  - 动作动词——施压、魅惑、羞辱、哀求、挑衅、讨价、威胁、拖延，一场里随失败而更换；每次换战术就是一次变拍。
- **认错长什么样：**
  - 整场一个战术、从头吼到尾或从头哀到尾 = 死演；战术写成情绪——"他更生气了"不是换战术，"他从威胁换成哀求"才是。
- **典型例子：**
  - 讨债戏三换：先摆交情即讨好 → 对方装傻，换算账即施压 → 对方翻脸，换掀底牌即威胁——三个战术，三拍，行为每拍可见地变。

Beats 节拍

- **怎么认：**
  - 最小行动单元——人物要同一样东西、用同一种方式争取的那一段。终结条件四选一：目标达成、战术失败、新信息抵达、力量对比翻转。每次变拍行为可见：停顿、换姿势、换语速、移视线。一场 2–4 次。
- **认错长什么样：**
  - 全程行为不变，演平了；变拍只在台词里发生、身体没跟上；变拍密到每句一变，碎成抽搐。
- **典型例子：**
  - 她数钱的手停了——变拍一，新信息：数目不对；把钱推回去、身体后靠——变拍二，换战术：从收下改为拒收；起身、拿外套——变拍三，力量翻转：这局她不玩了。

Subtext 潜台词

- **怎么认：**
  - 真想的与嘴上说的两层并存；不演，靠演真目标、说假台词时自己漏出来。可埋的行为标记：不是问题的问题、不信答案的重复追问、话题急转、挡住脆弱的错时玩笑、过短的回答——"行。""嗯。" = 关上的门。
- **认错长什么样：**
  - 把潜台词直接演出来——一边说"我没事"一边挤出哭腔，这是把里子演成了面子；或干脆没有里子，台词说什么人物就是什么。
- **典型例子：**
  - 她说"你随便，我无所谓"，同时把他常坐的那把椅子往桌下推了推——嘴上放行，手上关门。

#### K04-02-03｜任务阶梯全文 · 严格按序，跳级必错

0. 通读全场对白
- **怎么认：**
  - 动笔前把这场每个角色的每句台词读完，看清任务在哪里成立、在哪里破口。
- **认错长什么样：**
  - 拿单句台词直接建任务——任务活在整场往复里，单句建出来的必偏。
- **典型例子：**
  - 只看"可怜的家伙"一句会当成怜悯；读完全场才知道这句是说他自己。
1. 场戏目标：全员共同暗向
- **怎么认：**
  - 一句所有人都在无言执行的共同约定。范例：母亲收拾行李箱送儿子入伍，一小时后出发——场戏目标 = "把这场分别过得不痛：藏住感受，不给对方留下伤心，绝不丢掉那股正劲"，同时属于两个人。
- **认错长什么样：**
  - 把揭示、反转、主题这类影片功能当场戏目标——人物从不演影片的用意，那些是经由他们完成的副产品。
- **典型例子：**
  - 反例「这场戏的目标是揭示父子隔阂」 → 正例「这场戏全员的暗向是：把晚饭吃完，别让任何一句话掉进那件事里」。

1a. 结尾倒读命名事件

- **怎么认：**
  - 先看这场怎么收——最后一拍是读懂全场的钥匙，用它倒读。警惕双关末句：说的是一件事，指的是另一件。
- **认错长什么样：**
  - 从开场顺着读、读到一半就命名事件——事件是被结尾证实的，不是被开场宣布的。
- **典型例子：**
  - 末句"可怜的家伙。就是没法原谅自己。"——看着病床上的人说的，说的是他自己；这句同时命名了场内三个人。

1b. 全员入事件

- **怎么认：**
  - 事件必须装下场内每一个人——包括沉默者与昏迷者——作为同一进程的参与者或镜子。
- **认错长什么样：**
  - 有人站在事件外 = 事件命名错了，重命；给沉默者留白 = 他在画面里死掉。
- **典型例子：**
  - 三人病房戏，事件 = "寻找自我原谅"。病人在梦里无法原谅自己；年轻医助在床边无法原谅自己——他的照护就是他的赎罪；医生早已放弃——他的"漫不经心"是希望死掉后的疤痕组织，他好奇地看着年轻医助，想知道这一个能不能找到他自己没找到的出口。三面镜子照同一句判词。表面的"例行查房"只是事件穿行的地形。

1c. 各自的物理通道

- **怎么认：**
  - 例行查房、收拾行李这类表面活动保留为物理动作层；每个角色经由各自不同的、摄影机拍得到的行为追同一事件——同一事件、同一地形、每人一条不同通道。
- **认错长什么样：**
  - 所有人用同一种行为追事件——全员都在"沉重地干活"；或任务悬空没有物理通道——"他在内心挣扎"。
- **典型例子：**
  - 事件"寻找自我原谅"、地形"例行查房"——病人：经由回忆，闭睑下的快速眼动、那滴泪；医生：经由一丝不苟做完分内事，按时、精确地写下正确数据，甚至复核一遍，用无瑕的程序保住自己还是个医生；医助：经由照护，超出清单的照看——看的是人，不是表。
2. 动机：同向不同燃料
- **怎么认：**
  - 所有人推同一个方向，各有各的理由——儿子把分别演得不痛是为了妈妈，母亲是出于忌讳、行前落泪不吉利。同一矢量、不同燃料：燃料让每个表演各自成立，整场读起来却是一体。动机可有备选假设，由导演拍板选定。
- **认错长什么样：**
  - 动机无视既定情境——接了实验监狱差事的人已经是同谋，演不了道德无辜者；或全员共用一个动机，表演彼此不可区分。
- **典型例子：**
  - 同是"维持例行公事"，医助的版本可以是怕在前辈面前露怯，也可以是用职业性守住医者本分——同一方向、两种颜色，选一种。
3. 个人目标
- **怎么认：**
  - 由动机孵出的、这个人自己在场内争的东西——普通、个人、可演。
- **认错长什么样：**
  - 与场戏目标同词——那是共同方向不是个人之战；或写成主题词。
- **典型例子：**
  - 母亲的个人目标——把他体面地送出门，别让他背着我的恐惧走；儿子的——让她安心，证明我准备好了。
4. 障碍
- **怎么认：**
  - 顶着共同方向的那股压力——真实感受随时要顶破防线；一次破口，整场的线就塌。"The audience feels it precisely because nobody plays it."（观众感到它，恰恰因为没有人演它——全员都在演把它挡在外面。）
- **认错长什么样：**
  - 让人物直接演那股压力——哭出来、说破；压力被演出来的一刻就不存在了。
- **典型例子：**
  - 行李箱戏里那股压力是真实的不舍，一个湿润的对视就能让全场塌线——所以她数袜子，他啃苹果。
5. 战术 = 表演任务本体
- **怎么认：**
  - 写成对搭档做的事，逐拍锚在台词原文上；眼工是有目的的动作——在对方双眼里核对一星信任、每说完一点核对落没落地、偷看后在被抓到前弹回、丈量并记住对方。剧本要求处，标出燃料耗尽、防线破口的位置——破口本身就是这场戏的交付。
- **认错长什么样：**
  - 写成"眼皮抬起、瞳孔放大"式眼部编排；或战术不及物——"他保持冷静"，对谁做什么。
- **典型例子：**
  - 她"如常地"收拾，眼睛偷到他身上、丈量、记住，他一抬头就弹回袜子上；他"随意地"吃着，看她的手、不看她的脸——因为脸是危险所在。观众落泪，恰因银幕上没有人落泪。

#### K04-02-04｜ACTING TASK 块格式

块式——英文骨架双语保留；正文默认中文散文，随整条提示词语言走：

- ACTING TASK — {{NAME}} (invested in his tactic; the work happens in his eyes):（表演任务——某某（全情投入于他的战术；戏在他的眼睛里）：）
- SCENE DIRECTION (shared, unspoken): {{共同暗向，一行}}
- MOTIVE (his fuel): {{他为什么推这个方向}}
- GOAL: {{他个人在争的东西}}
- OBSTACLE: {{顶着防线的压力；破一次口的代价}}
- TACTIC: {{他对搭档做的事——眼工写成有目的的动作}}
- Moment to moment:（逐拍：）
- ——"{{台词原文}}"——{{对搭档的动词 + 眼睛核对什么}}
- ——"{{台词原文}}"——{{动词 + 眼工}}
- ——{{若防线破口：破在哪一句、破成什么样}}
- (Safety: gaze always engaged in the task — never a frozen, glassy, unfocused stare; natural blink cadence.)（安全行：目光始终咬在任务上——绝不冻结、玻璃化、失焦；自然眨眼节奏。）

五条规则：

1. 动词指向搭档；禁"悲伤地""紧张地"式情绪副词做指令。
2. 禁面部编排——"眉毛抬起""嘴角颤抖"；外观描述只允许出现在末尾安全行。
3. 没有人演情绪，所有人演方向；观众经由压力收到感受。
4. 每个入镜角色都要有任务——包括沉默的倾听者："判断他是不是认真的""等笑点落地""护住此刻的气氛"。
5. 逐拍锚在台词原文上，不锚在秒数上。

#### K04-02-05｜对照建构（contrast pairing）

怎么认：

- 双人戏按镜像正负建构——每人带一正一负，与搭档互为倒置；并命名本场的本质轴（ESSENTIAL AXIS）——观众真正读取的那条对立轴，其余特质只是色彩。

认错长什么样：

- 两人写成同色——都冷或都热，观众没有轴可读；对立写到台词上互相争吵——对立应活在共同方向之下；把轴命在"谁拿到钥匙"的情节上而非"谁在乎人"的价值上。

典型例子：

- 认可范例——实验室二人组。
- 医生——忠诚（+）/漫不经心（-）：他的忠诚真实，但效忠的是公司和钱，不是病人；在本质轴"对病人的在乎"上，他是负。
- 医助——被收买（-）/在乎（+）：他接了差、他知道这地方是什么，他的负真实；但他对病人的在乎在负里活着；在本质轴上，他是正。

规则五条：

1. 一人一正一负，与搭档互为镜像。
2. 命名本质轴——观众读的是这条轴，别的都是色彩。
3. 两人仍推同一场戏方向，如"把它维持成例行公事"——对立活在共同方向之下，从战术和眼睛里漏出：漫不经心者的例行是真的例行；在乎者的例行是铠甲，而且会裂。
4. 动机同时由正负建构与事件推出：医助照护病人是他的赎罪之路；医生的敷衍不是打发，是安静的实验——他在观察这个年轻人能不能从被出卖的良心里活着出来。
5. 表面特质常是其反面的疤痕组织——"漫不经心"常是希望死掉后的疤痕。"Direct the history, not the surface."（导历史，别导表面。）

#### K04-02-06｜常见失败 · 逐条：症状 → 修法

从单句台词建任务 → 回任务阶梯 0 级，先通读整场再动。

把影片的揭示/主题派给角色演 → 人物从不演影片的用意；重命个人目标。

场戏目标与角色目标混同 → 场戏目标是共同暗向；角色目标各自不同且个人。

动机无视既定情境、已同谋却演无辜 → 从情境重推动机。

写成眼部/面部编排而非有目的的眼工 → 改写成对搭档的动词 + 眼睛核对什么。

情绪形容词做指令 → 换成会产出该情绪的任务；情绪是任务的副产品。

### K04-03｜烂演技图谱

> 方法体系：工位方法。模块说明：当你写完表演段自检、成片审出表演类问题、或 返修环节 收到"演得假"类翻车片时翻它。给 18 条烂演技图谱的症状与提示词级修法、含 two-truths rule 的 0–5 表演量表、发出前十二查与终极公理。

#### K04-03-01｜定位

本卡是表演质检卡：认症状 → 提示词级修法的 18 条烂演技图谱、含 two-truths rule 的 0–5 表演量表、发出前十二查与终极公理。写完表演段自检、成片审出表演类问题、或 返修环节 收到"演得假"类翻车片时，翻开本卡对症。

用法：先按图谱认症状，再按修法改提示词；改完过量表自评，主角镜头必须 4+，自评 ≤2 整段重写。

#### K04-03-02｜烂演技图谱 · 每条：怎么认 → 认错长什么样 → 提示词级修法

1. 图解式表演（Indication / mugging）
- 怎么认：脸在"表演"情绪。
- 认错长什么样：挑起的眉、夸张的苦相、挤眉弄眼。
- 修法：把脸从任务里拿掉——写目标、给手找一件事做（business）。
2. 演结果（Playing the result）
- 怎么认：第一秒就在演这场戏的结局。
- 认错长什么样：还没被拒绝，脸上已经全是被拒绝。
- 修法：只写人物此刻知道的信息；把"后面才发生的"从这一拍里删干净。
3. 等口令（Waiting for the cue）
- 怎么认：对方说话时自己是空的。
- 认错长什么样：全程中性脸，对方一说完才"启动"。
- 修法：把反应写在对方台词说到一半时开始，如"话到一半，他擦杯子的手已经慢了下来"。
4. 单一战术（Monotactics）
- 怎么认：整场一个色。
- 认错长什么样：从头吼到尾、从头哀到尾。
- 修法：标出节拍，每拍换一个战术动词，如讨好 → 施压 → 威胁。
5. 手势图解（Gesture illustration）
- 怎么认：手势复读台词。
- 认错长什么样：说"大"就张开双臂，说"走"就指门。
- 修法：手势要么先于想法出现、要么与台词矛盾、要么干脆没有。
6. 白给的情绪（Free emotion）
- 怎么认：没铺垫没触发的爆发。
- 认错长什么样：无事发生却泪流满面、拍案而起。
- 修法：搭梯子——压抑在前、破裂在后；情绪必须有代价、有触发事件。
7. 身体背叛履历（Body false to biography）
- 怎么认：体格体态与人物前史打架。
- 认错长什么样：街头混混一身舞者的挺拔；瘾君子动作清新流畅。
- 修法：回表演档案定身体四参数——重心、节奏、开合、磨损，场景段从档案重写。
8. 台词太干净（Speech too clean for the class）
- 怎么认：street 人物说书面语。
- 认错长什么样：修辞完整、从不打断、句句收尾。
- 修法：往语言里掺打断、掉尾、重复——台词本体归剧本侧，本卡管"说的行为"：抢话、咽回半句。
9. 威胁信号化（Threat signaling）
- 怎么认：动手前打了半天招呼。
- 认错长什么样：眯眼、冷笑、慢转身、"威胁性停顿"。
- 修法：威胁平常化、暴力不预告——上一拍还在擦桌子，下一拍已经动完手。
10. 群像同步（Synchronized ensemble）
- 怎么认：所有人同时同样地反应。
- 认错长什么样：一句笑话全场同秒大笑。
- 修法：波浪式错开、强度各异——先笑的、慢半拍的、没笑的各一。
11. 死停顿（Dead pauses）
- 怎么认：静默里什么都没发生。
- 认错长什么样：两人干瞪眼，画面空转。
- 修法：往停顿里填消化时刻或 business——或干脆把停顿砍掉。
12. 情绪秒复位（Emotional reset）
- 怎么认：强事件后瞬间"恢复出厂"。
- 认错长什么样：刚摔了杯子，下一句已语气如常。
- 修法：状态有惯性——把余波写进下一拍：手还在抖、呼吸没平；跨条的余波记 ledger 落幅情绪。
13. 评论角色（Commenting the role）
- 怎么认：表演朝观众挤眼。
- 认错长什么样："你我都知道这很好笑"的自知表情。
- 修法：全信规定情境；喜剧要死认真地演。
14. 特写过载（Close-up overload）
- 怎么认：大特写上五官大动。
- 认错长什么样：怼脸镜头里眉眼嘴全在忙。
- 修法：景别越紧动作越少——特写只留眼睛和想法，幅度减半再减半。
15. 死眼（Dead eyes）
- 怎么认：AI 表演头号破绽。
- 认错长什么样：冻结凝视、不眨眼、玻璃 catchlights、目光无对象。
- 修法：整套眼活强制项写满——具名注视目标、眨眼质感、眼先于头；死眼用"给眼睛派活"修，不用打光修。
16. 整帧冻结 · 补充症状
- 怎么认：写了"所有人静止不动"。
- 认错长什么样：僵尸帧——连布料和呼吸都停了。
- 修法：静止写成绷住的张力 + 每 1–2 秒一个微事件：指节收紧、喉结滚动、视线扫过门口。
17. 同时态混合脸 · 补充症状
- 怎么认：一拍里两种情绪同时挂脸。
- 认错长什么样："怒中含笑""又哭又笑"产出的诡异混合面。
- 修法：一拍一主导 + 递进过渡；要两个真相走 mask + crack 行为分层：脸维持面具、手漏真相。
18. 情绪单词漫画化 · 补充症状
- 怎么认：情绪只有一个词。
- 认错长什么样："狂喜"写成咧到耳根的漫画笑，"暴怒"写成面目全非。
- 修法：双向夹钳——写出两端废镜判定："停在喜悦与攻击性之间；扭曲成狂怒 = 废镜；灿烂柔和的笑 = 废镜；面无表情 = 废镜"。

#### K04-03-03｜表演量表 0–5 · 自评用；主角镜头必须 4+，自评 ≤2 重写

0. 假人（Mannequin）：台词送达，行为缺席。
1. 朗诵者（Declaimer）："有表现力"的台词、被图解的情绪、复读台词的身体。
2. 用功生（Diligent）：能猜出目标，但整场一个战术、反应迟到、停顿空转。≤2：整段重写。
3. 手艺人（Craftsman）：有目标有节拍、听得见搭档、身体说得通；缺潜台词、缺意外战术、缺状态惯性。
4. 活人（Alive）：连续不断的行为、对比鲜明的战术、潜台词偏离台词、地位写在身体里、反应先于台词，且至少一个意外但真实的选择。主角镜头的及格线。
5. 磁石（Magnet）：4 的全部 + 悖论——人物把不相容的东西合在一起：好笑又吓人、残忍又迷人、撒谎又动人。
- Two-truths rule（双真相律）：5 分的角色永远同时演两个真相——帮着忙、又恨这件事；道着歉、又在防御；爱着、人已离开。单一干净情绪在特写上读作合成。

#### K04-03-04｜自检

发出前逐条勾，十二查全过才发出：

- [ ] 每个入镜角色的目标 = 指向搭档的动词。
- [ ] 障碍与代价存在，失败的代价吓得到人物。
- [ ] 2–4 次变拍，每次行为可见——停顿/姿势/语速/视线。
- [ ] 反应先于对方台词结束；重要事件后有消化时刻。
- [ ] 人人有 business；打断动作的标点用在了刀刃上。
- [ ] 距离变化有动机；地位写在身体里，不只在台词里。
- [ ] tic 全带触发器；面具有裂缝（However, when X）。
- [ ] 眼活显式写出：跳视与具名目标、眨眼质感、catchlights、眼先于头。
- [ ] 说话的角色其声线锁已由声音四要素逐字引用，本卡不改写它；沉默者省略。
- [ ] 写状态不写过渡；表演段内无服装、无镜头、无调色。
- [ ] 群像反应错开；强者静、弱者躁；静止写成张力不写成冻结。
- [ ] 量表自评：这段到 4 了吗？没到，回去改。

#### K04-03-05｜终极公理 · 十条，双语保留

1. "Acting is behavior under pressure, not a demonstration of feelings."（表演是压力下的行为，不是感受的展示。）
2. "Listening matters more than speaking; reacting matters more than declaiming."（倾听比说话重要；反应比朗诵重要。）
3. 情绪是一场斗争胜负的后果——而且它昂贵，白给的情绪一文不值。
4. "The body is smarter than the words."（身体比台词聪明：身文冲突时，观众信身体。）
5. 强者静而轻声，弱者躁而喊叫；例外即事件。
6. "Every tic needs a trigger; every mask needs a crack."（每个 tic 要触发器，每张面具要裂缝。）
7. "Every scene is somebody's defeat."（每场戏都是某个人的败局；没人输，就没有戏。）
8. "Subtext is not shown — it fails to be hidden."（潜台词不是演出来的，是没藏住的。）
9. "States, not transitions; the model films what is, not what becomes."（写状态不写过渡：模型拍"是什么"，拍不了"变成什么"。）
10. "When in doubt — cut."（拿不准就砍。演得越少，越真。）

### K04-04｜表演档案指南

> 方法体系：工位方法。模块说明：当你为核心角色建表演档案、或要把档案重写进某场戏时翻它。给母版块序、八条写作规则判据卡、眼活规范、声线边界、场景适配规则与标杆全文。

#### K04-04-01｜定位

本卡是角色表演档案（master profile）的完整写法卡：母版块序、八条写作规则判据卡、眼活规范、声线边界、场景适配规则与标杆全文。为核心角色建档、或要把档案重写进某场戏时，翻开本卡。

档案是"这个角色怎么演"的唯一真相源：写一次，登 〔人物设定提示词〕 该角色条目的「表演档案」段；使用方式是每场重写适配，永不整段粘贴。填空母版见 〔K04-07 表演档案模板〕。

#### K04-04-02｜母版与块序 · 顺序固定

Character acting as {{NAME}}.（角色表演档案——某某。）

体格即传记：年龄、体型、体格、体态——身体是履历的文件，职业、旧伤、自我认知都要能从中读出，如"当过拳手的厚脖子、中年后腰腹发福""为立威而过度矫正的坐姿"。

一句话心理引擎：解释这具身体一切行为的内在驱动，一个从句说完，如"几十年的等待——等活儿、等回合、等麻烦——把耐心磨成了他的武器"。

说话行为（Vocal profile）：音高音色、口音出身、语速与交付方式、情绪压力下声音怎么变——写的是戏剧行为，不是声线本体，边界见下文。

习惯动作与 tic：招牌 tic + 触发器；压力 tic + 触发器；掩饰行为——他用什么动作藏住感受；默认面具 + 面具破裂的精确条件。

步态（Walking style）：命名的步态——引号内造词，再拆解生物力学：重量、步幅、躯干与手臂、头。

转变条款：However, when {{情绪触发器}}, {{transformation}}——体态、步态、脸怎么变。每份档案至少一条。

唯一软化目标，可选：让这张脸真正柔软下来的那一个人、动物或物件。只给一个。

长度：一段流水散文，无列表、无标题；密度对标 [标杆档案全文] 的 VIKTOR——删无可删，不为凑段注水。

#### K04-04-03｜判据卡 · 八条写作规则

只写可观察行为

- **怎么认：**
  - 每个内在状态都配一个身体标记，摄影机拍得到。
- **认错长什么样：**
  - 「他很紧张」「他内心矛盾」——内心拍不到，模型只会给一张空脸。
- **典型例子：**
  - 反例「他很紧张」 → 正例「下唇微颤，一次沉重的吞咽，用嘴长吸一口气、再从抿紧的唇间短促吐出」。

每个 tic 必带触发器

- **怎么认：**
  - {{tic}} + {{何时/为何}} 成对出现。无触发器的 tic 是装饰，有触发器的是戏。
- **认错长什么样：**
  - 「他爱掰指节」——什么时候掰？为什么掰？没有答案就是贴纸。
- **典型例子：**
  - 正例「在无关紧要的寒暄里掰响指节——用来伪装从容」。

步态要命名

- **怎么认：**
  - 引号内一个自造的名字锚住生物力学，再拆解：重量、步幅、躯干手臂、头。
- **认错长什么样：**
  - 「走路很有气势」——没有名字、没有力学，模型自由发挥。
- **典型例子：**
  - 「老拳手步」（"old boxer's walk"）——沉、滚动，步幅短而经济，双肩持平，双手松弛备战，从不赶路。

面具 + 裂缝必有

- **怎么认：**
  - 默认面具（facade） + 让它塌掉的精确触发器，写成 However, when X 条款。同时演两个真相，是木偶与人的分界。
- **认错长什么样：**
  - 从头到尾一张脸，即无面具；或裂缝无条件随时裂——无面具的另一种写法。
- **典型例子：**
  - 不可一世的横步，被拒绝的一瞬塌成孩子式的驼背；训人的铁面，只在某一个人面前融成毫无防备的笑。

唯一软化目标

- **怎么认：**
  - 只给一个人、动物或物件。一个即人性化，两个即稀释。
- **认错长什么样：**
  - 「他对家人和老朋友都很温柔」——软化面一宽，人物立刻变糊。
- **典型例子：**
  - 他的脸只为流浪狗真正柔软——他用大衣口袋里的东西喂它们。

禁服装

- **怎么认：**
  - 档案在任何换装下都成立。服装住在资产与场景块里。
- **认错长什么样：**
  - 档案里写"总穿一件旧皮衣"——换装那集档案就作废。

禁镜头、禁调色

- **怎么认：**
  - 档案只驱动脸、声音行为、动作；机位、景别、调色、光住在提示词别处。
- **认错长什么样：**
  - 档案里写"适合大特写""冷色调下更有味道"。

体格即传记

- **怎么认：**
  - 年龄、体型、体态的每个选择都在讲前史——职业、旧伤、自我认知可从身体读出。
- **认错长什么样：**
  - 体格与履历打架——街头混混长着舞者的挺拔体态，却没有任何解释。
- **典型例子：**
  - 「因常年伏案而前倾的颈椎、握笔处的茧」——不用说他是老会计，身体已经说了。

#### K04-04-04｜眼活规范 · 写进每份档案，逐场重表达；死眼是 AI 表演头号破绽

微跳视 + 具名注视目标：视线永远有对象，在目标间扫动、停驻、弹回，绝不锁死一点。

眨眼率与质感随状态：紧张连眨、掌控慢眨、失神一眨后散焦。

活的 catchlights：眼睛读作湿润、受光、活着。

受控的静止是选择："Controlled stillness is chosen, never dead."（受控的静止是选出来的，不是死掉的。）近乎不眨的捕食者式平静，要写成罕见、缓慢、蓄意的眨——一个决定，不是一次冻结；目光仍带意图地缓慢移动。

眼先于头：视线先到目标，头随后才转；话没出口，想法已先在眼睛里可读。

眼活随变拍走：眨眼率、注视稳定度、目光温度随节拍一起变。

#### K04-04-05｜声线边界

档案内的"说话行为"写戏剧变化：何时变慢、何时更轻、压力下声音在哪里破。

声线锁是另一样东西：声音本体的书面条件——音区、音色、语速、口音、语气，由 人物设定环节 登记在 〔世界圣经·存在者名册（资产索引）〕，由 编译环节 的声音四要素逐字引用。"Voice is locked … never modify it per scene."（表演逐场重写；声线永不适配。）声线锁改一个同义词都是漂移风险。

两者必须相合：档案说"越严肃越轻"，声线锁就不能写"急了会吼"。冲突时以声线锁为准，回改档案。

#### K04-04-06｜场景适配规则 · 档案是"他是谁"，每场把它重写成"他此刻在做什么"

只写在场者：不在画面里的角色没有段落。

恒定核不动：身份、说话行为、招牌 tic、眼活、情绪贯穿线每场一致——这是跨镜头"认得出同一个人在演"的锚，永不与档案矛盾。

按本场重表达：按本场的坐/站/跑/躲姿态、动作与节拍、情绪状态、时段，选取、强调、改写或按下档案里的具体行为。

转移不删除：本场做不了的行为转移进可行通道——踱步者坐上沙发，同一股神经能量转入微晃、甩腕、撕纸。能量恒定，出口改变。

一段流水散文：无列表、无标题、无"参数"式行；以该角色的可视特征代称开头，如"眉骨带旧疤的老司机坐在驾驶座上……"，让模型把表演绑到正确的人身上；@编号只在成品条的【参考资产绑定】段出现一次，重复 @tag 是平台拒绝启动的头号原因，重场对白戏每条必中。

#### K04-04-07｜标杆档案全文 · 英文原文 + 逐块解析

下面这段原样保留，作直接套用的密度标尺——写到它这个量级。

英文原句：Character acting as VIKTOR. Early 60s male, a retired night-shift taxi driver and former amateur boxer; heavy, thick-necked build gone soft at the middle, with a flat-nosed face and old scar tissue over both eyebrows; sits and stands with a low, grounded center of gravity, weight always on the whole foot. Runs on a single engine: decades of waiting — for fares, for rounds, for trouble — have made patience his weapon. Vocal profile: low, hoarse, unhurried baritone with a working-class rasp, short sentences delivered flat and economical, dropping to a slower, quieter register the more serious things get — he never speeds up. Key physical habits and tics: rolls an old coin across his knuckles when sizing a situation up; a slow, audible nose-breath before he says no; when lying is happening in front of him, he goes completely still and lets a long silence do the pressing; his default face is a heavy-lidded, bored mask that conceals total attention. Eye life: sleepy, hooded eyes with slow deliberate blinks and constant quiet scanning — mirrors, hands, exits — the gaze settling on a speaker a beat before his head turns; catchlights low but alive. Walking style: a heavy, rolling "old boxer's walk," short economical steps, shoulders level, hands loose and ready, never hurrying. However, when someone raises a hand near him, the sleepy mask vanishes in a half-second: the chin drops, the hands rise halfway, the feet find their old stance — then he catches himself and folds it away, embarrassed. His face only truly softens for stray dogs, which he feeds from his coat pocket.

逐块解析：

- 体格即传记：夜班车 + 业余拳击两段履历全写在身体上——厚脖子、塌鼻梁、眉骨疤、低重心、全脚掌落地。
- 心理引擎一句话："几十年的等待把耐心磨成了武器"——后面每个 tic 都由它解释。
- 说话行为：越严肃越慢越轻、从不加速——给了压力下的声音方向，与声线锁一致。
- tic 全带触发器：硬币过指节 = 打量局面时；可闻的鼻息 = 说"不"之前；彻底静止 + 长 silence = 面前有人说谎时；面具 = 重眼皮的无聊相，藏着全部注意力。
- 步态命名："老拳手步" + 力学拆解：沉、滚动、步幅短、肩平、手松弛备战。
- 转变条款：有人在他附近抬手 → 半秒内面具消失、下颌收、双手半抬、脚找回旧站位——然后他自己收住、有点难堪。裂缝裂完还自己合上，一条条款演出两个真相。
- 软化目标唯一：流浪狗。一个。

场景适配标杆——夜间出租车内，后座年轻乘客在为车费撒谎：

- 下面这段示范中文散文形态：以可视特征代称开头，全段不出现 @编号。
- 中文块，可整块抄：眉骨带旧疤的老司机沉沉地坐在驾驶座里，不回头，从后视镜里看乘客——低垂的眼皮下，视线在镜子、对方的手、门锁之间缓慢安静地扫动，眨眼罕见而蓄意，目光先落在镜中人身上、头过了一拍才微微偏转。那枚旧硬币在椅背旁的指节间不紧不慢地走；随着乘客的说辞越编越漏，硬币在指节中段停住——他让沉默压上去，用鼻子缓慢地、可闻地吸了一口气，然后用低哑的男中音开口，比刚才更平、更轻，从不加速。直到那孩子声音发颤，昏昏欲睡的面具才松动一分：一次长长的呼气、一次缓慢的眨眼、硬币重新滚动——耐心暂且选择了仁慈。
- 解析——为什么这么改写：开头是可视特征代称不是 @编号，@ 只在【参考资产绑定】段出现一次；步态无关、人在坐姿 → 步态的能量转入静止与硬币；tic 全部保住触发器——硬币 = 打量、硬币停 = 打断动作做标点、鼻息 = 拒绝、静止 + 沉默 = 对说谎者施压；眼活服从档案但重新锁靶到后视镜、手、门锁；变拍可见——硬币停 → 沉默 → 更轻的嗓音 → 松动；说话行为未违档案；声线锁一字未动——它由声音四要素逐字引用。

### K04-05｜表演环节总则

> 方法体系：工位方法。模块说明：当镜头表或动态提示词需要写人物表演——对白戏演技、情绪节拍、动作戏连招、群像反应，或需要为核心角色建表演档案、把一段情绪意图落成可拍的行为，或用户说角色演得死、眼神空、表情假时使用。提供五支柱 + 任务阶梯的任务制表演方法、表演档案母版、动作链六要素、眼活强制项与微表情词库。产出可拼进镜头表与动态提示词的表演段落、ACTING TASK 块与角色表演档案。

#### K04-05-01｜任务

把"观众该感到什么"翻成"人物在镜头里做什么"。本卡是表演工艺层，被 分镜设计环节 与 编译环节 在写表演维度时收拢，产出三类东西：

1. 角色表演档案（master profile）：核心角色一人一段的表演真相源——体格、心理引擎、习惯动作、面具与裂缝、步态、眼活。写一次，此后每场重写适配、永不整段粘贴。落盘位置：〔人物设定提示词〕 该角色条目的「表演档案」段，并在 〔世界圣经·存在者名册（资产索引）〕 该角色行加一句档案指针。
2. 场景适配表演段：把档案重写进本场姿态与节拍的一段流水散文，嵌进动态提示词【分镜正文】的对应段落。
3. 逐拍表演内容：重场对白戏的 ACTING TASK 块、情绪戏的微动作弧线、动作戏的动作链——全部是子句或段落，回到镜头表或动态提示词里拼装，不独立成片。

边界：只写行为与表演。运镜归 运镜环节，空间站位与轴线归 站位调度环节，光归 灯光环节，台词音效的声音句式归 声音环节，组装与块序归 编译环节。唯一约定的咬合点：动作戏要把"哪个肢体往哪伸、翻转、落点在哪"写清，供 运镜环节 的动作驱动运镜咬锚。

规则集声明：本卡服务视频提示词规则集——负向可用，但症状驱动、化进散文句，第 7 段【针对性负向】每条 ≤3。否定句划界——只读引用，真相源 编译环节 的 〔K07-08 否定句政策〕，改判据只去那里改：否定对象是具体可视意象（动作、物体、人物）→ 改写成期望态，或进第 7 段【针对性负向】占名额；否定对象是技术性设定（布光方案、机位、镜头运动、漂移）→ 允许贴着正向规则内联，不占 ≤3 名额。表情特写的幅度夹钳「不皱眉、不流泪」同属技术性设定——它约束表演幅度、不是清画面杂质，贴着它压的动作内联即可，不进【针对性负向】、不占名额。资产图提示词的图像规则集纯正向、无负面参数，归资产类 skill，两套规则禁止串用。

#### K04-05-02｜第一性原则

本环节是【导演思维】第 2、4 问「画面化、可生成性」的展开：把情绪与意图翻成摄影机拍得到的行为，把行为写成模型跟得住的状态链。

表演是压力下的行为，不是情绪的展示："Acting is BEHAVIOR under pressure, not a display of emotion."（表演是压力下的行为，不是情绪的展示。）人物要什么、什么挡着、他做什么去争取——情绪是这场斗争的副产品，永不直接写。

任务先于外形："An acting task is when the character is INVESTED in his/her tactic of reaching the goal."（表演任务 = 人物全情投入于达成目标的战术。）写"悲伤地"这类情绪标签，得到漫画脸或死脸；写"眉毛抬起、嘴角颤抖"这类外部编排是 playing the result（演结果），同样死脸。战术可以完全活在眼睛里——the eye movement IS the doing（眼睛的动作本身就是"做"）。死眼永不用打光和 catchlight 修，用给眼睛派活修。

物理通道优先：看不见的任务必须有摄影机拍得到的物理通道——"揉太阳穴"可生成，"表现疲惫"生成不出来。模型形变的是像素级的脸和身体，不是心理状态。

写状态，不写过渡："States, not transitions."（写状态，不写过渡。）模型演不了过程、演得了状态："mid-throw, arm extended"（正在掷出中段、手臂已伸展）落地，"伸手进包、掏出、抡起"塌掉。连续过程拆成逐拍状态链；复杂动作开场即中态。

变化量优先：参考图已锁长相与初始情绪，提示词只写变化量，不重描五官长相——重述静态挤占词数、稀释变化信号。

情绪双向夹钳：单词情绪会漫画化，重情绪必须两向夹——"between joy and aggression; a rage-twisted face = failed take; a soft beaming smile = failed take; deadpan = failed take"（情绪停在喜悦与攻击性之间；扭曲成狂怒的脸 = 废镜；灿烂柔和的笑 = 废镜；面无表情 = 废镜）。

一拍一主导：绝不写"又哭又笑、怒中含笑"式同时态——产出诡异混合脸。要"同时演两个真相"靠行为分层：脸维持面具、手或眼漏出真相，即 mask + crack，不靠混合表情。肢体的物理并发如蹬地滑步的同时回旋踢，不在此禁。

#### K04-05-03｜维度与方法

八个方法，按这一镜写哪类戏取用；对白重场走五支柱与任务阶梯，动作戏走动作链，群像戏走群像规则，核心角色另建表演档案。

五支柱——每个入镜角色过一遍，缺一即塌；判据卡见 〔K04-02 任务制表演法〕。

- Objective 目标：本场此刻、对具体的人要什么，动词表述，如"让他招供""求她再宽限一周"；禁"生气""内疚"这类状态词。场目标背后有贯穿全片的超目标，每场目标是走向它的一步。
- Obstacle & stakes 障碍与代价：什么挡着——外部的对方要相反的东西、在场的证人、两小时的死线，或内部的自尊不许他开口求人。必答"拿不到会怎样"，答案必须吓到人物本人。
- Tactics 战术：此刻争取目标的具体手段 = 动作动词：施压、魅惑、羞辱、哀求、挑衅、讨价、威胁、拖延。战术失败，活人就换战术；整场一个战术 = 死演。
- Beats 节拍：最小行动单元——人物要同一样东西、用同一种方式争取的那一段。节拍终结于：目标达成、战术失败、新信息抵达、力量对比翻转。每次变拍必须行为可见：一个停顿、一次换姿势、语速一变、视线一移。一场戏 2–4 次变拍；全程行为不变 = 演平了。
- Subtext 潜台词：人物真正想的 vs 嘴上说的。潜台词不演——演真目标、说假台词，它自己漏出来。可埋的行为标记：不是问题的问题、不信答案的重复追问、话题急转、挡住脆弱的错时玩笑、过短的回答——"行。""嗯。" = 关上的门。

任务阶梯——重场对白戏严格按序走；全文与范例见 〔K04-02 任务制表演法〕。

0. 通读全场对白：禁止从单句台词建任务——任务活在整场的往复里。
1. 命名场戏目标：全员共同的暗向，一个无言的共同约定，如"别让这场分别沾上痛"。场戏目标不是影片的主题功能——人物永远不知道、也不演影片的用意。
- 1a. 结尾倒读命名事件：先看这场怎么收，用最后一拍反读全场；警惕双关末句——说的是别人，指的是自己。
- 1b. 全员入事件：事件必须装下场内每一个人，含沉默者与昏迷者；有人站在事件外 = 事件命名错了，重命。
- 1c. 各自的物理通道：例行查房、收拾行李这类表面活动只是地形；每个角色经由各自不同的、可拍摄的物理行为追同一事件。
2. 动机——同向不同燃料：所有人推同一个方向，各有各的理由。既定情境约束动机：进过那种地方的人，演不了道德无辜者。
3. 个人目标：由动机孵出的、这个人自己在场内争的东西——普通、个人、可演；永不与场戏目标同词、永不是主题。
4. 障碍：顶着共同方向的那股压力——真实感受随时要顶破防线。观众恰恰因为没人演它而感到它——全员都在演"把它挡在外面"。
5. 战术 = 表演任务本体：写成对搭档做的事，眼工是有目的的动作：在对方双眼里核对一星信任、每说完一点核对落没落地、偷看后在被抓到前弹回。

动作链六要素——动作戏。

- 动词领头 + 哪个肢体 + 方向 + 力度 + 顺序时序 + 落点，缺一不可；动作之间用顺势、随即、借……惯性这类顺承词串成因果，不并列堆砌。
- 时序密度是动作戏的命脉：该写间隔写死间隔，如"两枪间隔不足 0.3 秒"；该并发写明并发，如"左脚蹬地滑步的同时右腿回旋踢"，别把一串连击糊成"打了几下"。
- 借力与卸力写物理传递：力从哪来、传到哪去，如借撞击残余惯性漂移、侧滚翻卸力——动作的真实感来自力的传递，物理成立性配合 灯光环节 卡的物理锁一起写。
- 复杂动作开场即中态："he is ALREADY mid-swing, the door ALREADY cracking"（他已在挥棒中段、门已在开裂）——把复杂动作放进时间轴中段，模型只会让角色在旁边蹭来蹭去；接近与准备过程另拆一条，条的拆分回 分镜设计环节 定。
- 每条链结在明确终止姿态，如单膝跪地撑住、重新站定，不停在半空——落幅直接供给该条【结束状态】五字段的"动作动势"与"情绪"。

眼活强制项——每个档案、每场戏都要有；死眼是 AI 表演头号破绽。

- 微跳视 + 具名注视目标：视线永远有对象——后视镜、对方的手、门锁——在目标间扫动、停驻、弹回，绝不锁死一点。
- 眨眼率与质感随状态：紧张时快速连眨；掌控时缓慢平静；失神时一眨之后目光散焦。
- 活的 catchlights：眼睛要读作湿润、受光、活着。
- 受控的静止是选择，不是死："Controlled stillness is chosen, never dead."（受控的静止是选出来的，不是死掉的。）捕食者式的不眨眼要写成罕见、缓慢、蓄意的眨。
- 眼先于头：视线先到目标，头随后才转；话没出口，想法已先在眼睛里可读。
- 眼活随变拍走：变拍时眨眼率、注视稳定度、目光温度一起变。
- 安全句，每个 ACTING TASK 块末尾一行："gaze always engaged in the task — never a frozen, glassy, unfocused stare; natural blink cadence"（目光始终咬在任务上——绝不冻结、玻璃化、失焦；自然眨眼节奏）。

倾听、身体与地位——戏在台词之间。

- 倾听四标记：反应在对方话说完前就开始，等对方说完才"启动" = 死演；答难题前有可见的微停顿；重要事件后有消化时刻（assessment moment）；节奏音量被对手感染——喊叫要么被回喊、要么被针锋的安静接住，绝不无视。
- 身体四参数先于心理：重心高低——高 = 自信攻击，低 = 疲惫恐惧屈从；节奏快慢——最危险的人动得最少；开合——敞肩摊掌 vs 抱臂低头；呼吸——高而急 = 慌，低而慢 = 控制，且声音与物理必须匹配，刚跑完的人不能用平稳嗓音说话。
- Business 手上有事：人物几乎永远该有一件在做的事——修引擎、数钱、擦杯子，台词压在事上说。打断动作是最强标点——切面包的人在某句话停了手，这句话就成了事件。
- Proxemics 距离即戏：亲密圈 0.5 米内不请自入 = 侵犯，贴脸 10 厘米的耳语比隔屋喊叫更吓人；社交距离 = 生意与提防。距离变化 = 变拍，谁在收距离、谁在断距离就是这场戏的图形。
- Status 地位在行为里：高位 = 头不动、动作慢、凝视长、占空间、碰别人的东西；低位 = 小动作多、频繁摸脸摸头发、用眼神求许可、填缝式讪笑。最有戏的是地位破口（status break）：老板露出一秒恐惧、下属突然收起笑。
- 台词质感——供 声音环节 的语气描述参考，本卡只管行为：最吓人的话说得最轻——喊叫是弱者的货币；完美句子杀死街头真实——真实语言有打断、重复、没说完。

群像规则——前景 3–5 人的反应分层。

- 反应走波浪，永不同步：第一个人先懂，第二个人慢半拍，第三个人没懂——齐刷刷的同步反应读作假。
- 事件之后最值钱的画面，是目击者的脸。
- 威胁时刻全场冻结：平时群像持续微动——换重心、比划、倾身；关键威胁一到全部停住——喧闹到静止的反差就是标点。
- 强者静而轻声，弱者躁而喊叫；危险不由危险者演，由周围所有人的紧绷演。暴力不预告：没有威胁性停顿、没有慢转身——真实世界里暴力不打招呼。
- 损耗跨场累积不重置：被磨损的人物一场比一场更灰、更沉、反应更慢——每条落幅情绪记入 〔集交接卡（连续性台账）〕，下一条从那里接，不许瞬间"恢复出厂"。
- 静止的写法：绝不写"所有人都不动"——会冻住整帧；静止写成绷住的张力 + 每 1–2 秒一个微事件：指节收紧、喉结滚动、视线扫过门口。
- 画面内超过 15 人的群体塌缩问题归 人物设定环节 的群演写法；本卡管前景 3–5 人的反应分层。

表演档案与场景适配——全文见 〔K04-04 表演档案指南〕，母版见 〔K04-07 表演档案模板〕。

- 核心角色一人一段档案，密度对标 master-profile-guide 的标杆档案，块序固定：体格即传记 → 一句话心理引擎 → 说话行为 → 带触发器的习惯动作 → 面具与裂缝 → 命名的步态 → "However, when X"转变条款 → 唯一软化目标。
- 铁律四条：每个 tic 必带触发器——无触发器的 tic 是装饰，有触发器的是戏；必有面具 + 裂缝；步态要命名——引号内造词再拆解生物力学；档案内禁服装、禁镜头、禁调色。
- 场景适配 = 重写，永不粘贴：身份、说话行为、招牌 tic、眼活不变；行为按本场姿态重新表达；本场做不了的行为转移而不删除：踱步者坐上沙发，同一股神经能量转入微晃、甩腕、撕纸。
- 声线边界：档案内的"说话行为"写戏剧变化——何时变慢、何时更轻；声线锁本体归 人物设定环节 登记 reference-index、由 编译环节 的声音四要素逐字引用——本卡永不改写声线锁，两者必须相合。

成句与落位——节拍落位与质检，写完怎么落位、怎么自评。

- 双轨落位：A 轨即时间戳轨，表演内容写进 [X-Y秒] 段落的"反应 → 主动作"位，段级时间戳遵循度待实测校准；B 轨即镜头N轨，挂对应镜头内、不写秒数。拍内时序密度可写显式间隔，如"间隔不足 0.3 秒"；情绪节拍在段内用省略号 + 递进词锚定，不再另标秒。
- 情绪弧线：起始态 + 结束态两锚点，1–3 个过渡节拍填中间；跨度大就加节拍、放慢速度，不一帧跳变。
- 收束纪律：结尾定格在明确神情或姿态；收幅度优先正向改写——"嘴角归平"优于"不笑"；确需负向时化进散文句、贴着它压的动作放——幅度夹钳属技术性设定，不占第 7 段的 ≤3 名额，划界判据见 [任务] 规则集声明。
- 质检：0–5 表演量表自评，主角镜头必须 4+，自评 ≤2 重写；5 分需 two-truths rule——同时演两个真相：帮着忙、又恨这件事；18 条烂演技图谱对症下药；发出前过十二查。全文见 〔K04-03 烂演技图谱〕。

#### K04-05-04｜词库

速查取词，成段时按当前戏的类型取对应类目，不照搬整表。

情绪外化对照——八情绪，面部 + 身体行为；任何情绪标签先在这里拆成可见动作再写。

- 喜悦 → 嘴角抑制不住上扬、眼角真笑细纹、双眼微眯"笑意抵达眼底"、眉眼舒展；脚步变轻快、下意识哼起小曲、忍不住原地转个圈。仅嘴角动不动眼 = 假笑。
- 悲伤 → 眉头内侧上抬、视线下沉、嘴角下垂、下颌微收、呼吸放缓；低头、肩膀微微颤抖、眼眶泛红、手指无意识攥紧衣角、泪水在眼眶里打转却没落下。
- 紧张/焦虑 → 呼吸急促、眼神闪躲；频繁看表、手指不停敲击桌面、无意识啃咬指甲、脚不安地抖动。
- 恐惧 → 双眼骤睁、眉毛上抬并内聚、嘴唇微张、下颌后缩、呼吸急促继而屏住、身体本能后缩。
- 愤怒 → 眉头下压内聚、瞪视如刀、鼻翼张开、下颌线紧绷、嘴唇紧抿；双拳紧握、胸口剧烈起伏、从牙缝里挤出话语。
- 惊讶 → 眉毛高抬、双眼圆睁、嘴微张、一次短促吸气。
- 释然 → 长长地舒一口气、紧绷的肩膀完全放松下来、脸上浮起久违的淡淡微笑、抬头望向远方。
- 克制/隐忍 → 表情外松内紧、嘴角勉强归平、视线偏移、一抹藏起情绪的浅笑、不流泪。

战术动词——对搭档做的事。

- 施压、逼问、魅惑、讨好、羞辱、揭穿、哀求、挑衅、试探、讨价、威胁、拖延、安抚、冷落、将军。

眼工动作——有目的的眼部任务，不是眼部编排。

- 在对方双眼里核对一星信任、核对刚才那句落没落地、偷看后在被抓到前弹回、丈量并记住对方、比对我感到的与他表现出的、判断他是不是认真的、等笑点落地、护住此刻的气氛。

微表情

- 双眼睁大/微眯、眼角真笑细纹、蹙眉/扬眉/眉头内侧上抬/眉宇舒展、额头放松、咬紧下颌/下颌松张、嘴唇紧抿/嘴唇微启/嘴角上扬/嘴唇微颤、鼻翼张开、笑意抵达眼底。

视线/眼神

- 望向画外、目光锁定、瞥向别处、垂眸、直视镜头、视线下移、泪眼盈眶、视线扫过门口/对方的手/后视镜、目光弹回。

肢体——静态姿态，情绪戏。

- 双肩垮下、前倾/后仰、蜷缩/退缩、攥拳、双手颤抖、上前一步/退后一步、身姿僵直、收颌内敛、仰头/低头、换重心、倾身。

动作链——战斗物理动词，动作戏。

- 蹬地/滑步/侧身横移/滚翻卸力、格挡/架开/锁喉/缠臂、借力/卸力/借惯性、伸臂/探手/扣住/抓握/拽住、压制/按地/顶住/死死顶住、贯穿/击穿/劈开/斩切、回旋踢/蹬踹/撞墙/砸落、抛出/推开/甩出、扣扳机/横移枪口/待击、单膝跪地/撑地/重新站定。

呼吸/节奏

- 呼吸一滞、倒吸一口气、缓缓吐气、屏住呼吸、呼吸加快、停拍、一顿、一闪而过、渐进、沉淀。

温和表演指令词

- 温柔浅笑、自然眨眼、轻轻颔首、望着镜头羞涩一笑、眼神柔和、一抹淡淡的自嘲式浅笑。

递进连接词

- 渐渐转为、缓缓柔化、由……演化为……、随即……、一拍之后、沉淀为。

收束词——优先正向。

- 嘴角归平、目光沉定、呼吸放平、定格在 {{X}} 神情；确需负向时如不露齿、不流泪、不踉跄，化进散文句、贴着它压的动作放——幅度夹钳属技术性设定，不占第 7 段的 ≤3 名额，划界判据见 [任务] 规则集声明。

#### K04-05-05｜范例句式

三段式情绪弧——情绪戏基本型：

- 触发：双眼微微睁大，嘴唇微启轻倒吸一口气；
- 过渡：瞬间凝住，额头渐渐舒展，目光沉定；
- 收束：温暖释然的笑意抵达眼底，眼角浮起细纹，定住这个神情。

B 轨镜头内表演句——挂镜头N、不写秒数：

- 镜头2 她神情由警觉渐渐转为敬畏，双眼缓缓睁大，嘴唇微启，指尖从刀柄上松开。

A 轨段内表演位——嵌进 [X-Y秒] 段落因果链的"反应 → 主动作"位：

- [4-9秒] 他听到钥匙转动声——反应先于回头：肩线一紧、擦杯子的手停住——打断动作即标点；随即转身，抹布仍攥在手里，目光先到门口、头随后跟上。

双向夹钳句——重情绪必用，写出两端废镜判定：

- 他的脸停在愤怒与恳求之间——扭曲成狂怒 = 废镜，软塌塌的哀求相 = 废镜，面无表情 = 废镜。

ACTING TASK 块——重场对白戏，完整母版见 〔K04-06 表演任务模板〕：

- ACTING TASK——当铺老板（全情投入于他的战术；戏在他的眼睛里）：
- 场戏方向（共同暗向）：把这次交易维持成一桩普通生意。
- 动机：他认出了这块表——但一说破，就得卷进旧案。
- 目标：不动声色地压价，让年轻人自己知难而退。
- 障碍：表盖内侧刻着三十年前那个名字，每次开盖都在烫他的手。
- 战术：用验货流程施压——放大镜在刻字上多停一秒、抬眼核对对方瞳孔里有没有"被认出"的慌、报价时盯住对方喉结等一次吞咽。
- 安全行：目光始终咬在任务上——绝不冻结、玻璃化、失焦；自然眨眼节奏。

群像波浪句：

- 笑声走波浪：靠门的先笑出声，中间那个慢半拍才咧嘴，角落的女人没笑——她盯着桌上的表。

静止张力句——替代"所有人不动"：

- 全场绷住：没有人换姿势，但指节在收紧、喉结在滚动，视线每一两秒扫一次门口。

动作链——六要素齐、标间隔与并发、留落点：

- 双脚蹬地猛地侧身横移避开扑击，左臂格挡开抓来的手臂、同时右臂稳定持枪贴脸扣下第一枪，枪口顺势横移、第二枪命中眉心——两枪间隔不足 0.3 秒，落在重新站定的姿态，不踉跄。

正例——状态链改写，写状态不写过渡：

- 枪已在手，手臂已抬至肩平——正在瞄准中段；下一拍：枪口压向门缝，指节收紧。

反例——同一句写成过渡，模型演不了：

- 他伸手进包里，掏出枪，举起来瞄准。
