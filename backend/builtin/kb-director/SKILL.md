# 知识包 · 导演分镜

这是 yoozee 1.0 skills 的知识包，只有卡片，没有流程。由 yz-* 技能指名读取：引用写成「kb-director › 卡片路径」。读卡的方法见 技能 yz-producer 的 `RUNTIME.md`（用 skill_read_file 读）。
一次只读需要的那一张，不整包读；卡片开头两行写了来源和何时读。

| 卡片 | 何时读 |
| --- | --- |
| `cards/分段拆分与镜头密度.md` | 分段时读：按什么切段、一段几个镜头、台词时长怎么估、头尾安全区、段尾钩子 |
| `cards/分镜字段模板与写法.md` | 写镜头字段时读：每个字段写什么 |
| `cards/场景调用索引.md` | 拿到一场戏先查：这类戏该读哪几张卡 |
| `cards/导演大脑-信息等级与镜头主语.md` | 每场戏拆镜前先读：剧情功能、信息等级、镜头主语、观众信息量、结尾钩子 |
| `cards/导演思维决策矩阵.md` | 拿不准某个镜头怎么拍时读；伏笔、隐藏观察者、监控物件也在这里 |
| `cards/意图到视听语言转换表.md` | 知道想表达什么、不知道怎么拍时查表 |
| `cards/景别节奏与相邻景别禁忌.md` | 排一段内的景别顺序时读：相邻景别不硬切 |
| `cards/特殊镜头与类型模板.md` | 要用特殊镜头（变焦、荷兰角、主观镜头）或套类型模板时读 |
| `cards/第一原则与全局参数.md` | 改编前读：台词剧情不可改、视觉可补的边界，开工前要定的全局参数 |
| `cards/类型戏-打斗追逐悬疑.md` | 打斗、追逐、悬疑恐惧戏读 |
| `cards/类型戏-揭示反转工艺情感.md` | 身份揭露、反转、工艺制作、情感戏读 |
| `cards/词库-景别机位构图焦距.md` | 选景别、机位、构图、焦距时查词 |
| `cards/词库-灯光声音转场.md` | 写灯光、环境声、转场时查词 |
| `cards/词库-运镜.md` | 选运镜时查词 |
| `cards/镜头取舍与节奏曲线.md` | 一段镜头太多、太拖或节奏平时读 |
| `cards/镜头第一判断与对话戏.md` | 对话、争吵、告白、审讯戏读 |
| `cards/高级视听策略.md` | 要让一段有「导演感」时读：信息、情绪、潜台词策略 |
