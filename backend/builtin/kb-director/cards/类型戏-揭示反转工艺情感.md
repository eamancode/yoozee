15.6 信息揭示、身份揭露和反转怎么拍
============================================================

1. 道具揭示
   - 先给人物反应，再给道具特写，最后回到人物表情。
   - 运镜：推向道具、拉焦、下摇、手部动作带出道具。
   - 焦距：85mm 或微距，浅景深。

2. 身份揭露
   - 先隐藏脸或身份标志：背影、剪影、手部、声音。
   - 再通过光线、转身、摘下面具、抬头、镜面反射揭示。
   - 运镜：缓慢推近、环绕到正面、从脚上摇到脸。
   - 光影：逆光剪影转正面光，或侧逆光勾边后露出面部。

3. 真相反转
   - 先给误导信息。
   - 再给关键证据特写。
   - 再切主要人物沉默反应。
   - 最后给空间全景，让观众重新理解局面。

4. 异世界/陌生环境揭示
   - 目的：让观众和主角一起意识到“这里不是熟悉世界”，而不是用一句旁白直接解释。
   - 先拍身体感知：刺眼日光、干燥喉咙、皮肤被热浪灼痛、呼吸不顺、耳边陌生风声。
   - 再拍环境证据：没有道路、没有建筑、没有电线、没有现代文明痕迹，只有陌生地貌、异常天空、奇怪植被或非地球色彩。
   - 再拍主角观察：主角快速扫视四周，眼神从困惑变成确认，呼吸短暂停住。
   - 镜头建议：主观扫描、低机位贴地看异色尘土、远景展示陌生地貌、细节特写看不属于地球的岩层/河流/天空。
   - 声音建议：风声、热浪嗡鸣、陌生动物/水声/电流般环境声；禁止BGM，不用音乐解释情绪。
   - 禁忌：不要只写“这里不是地球”；必须用画面证据让观众自己得出结论。

5. 危机反转为爽点
   - 目的：把别人眼里的危险，转成主角眼里的机会、优势、食物、武器或解法。
   - 结构：众人恐惧 -> 主角观察 -> 危险对象露出一瞬 -> 主角理解规则 -> 主角身体放松或露出微笑。
   - 镜头：先拍敌人后退/武器垂下/脸色发白，再拍主角视线转向危险源，再拍危险源短暂露出，最后拍主角微表情变化。
   - 表演：主角先眉头紧锁、瞳孔搜索，随后肩膀松开，嘴角微扬，眼神从紧张变成兴奋或笃定。
   - 声音：敌人喊声退远，环境声变清楚，危险源水声/低鸣声突出；主角内心OS可以压低进入。
   - 禁忌：不要让主角突然大笑或解释太多；爽点要来自观众看懂“他发现了别人不懂的规则”。

6. 禁地/边界揭示
   - 适用：红河、悬崖、禁门、祭坛、封印区、无人敢靠近的领域。
   - 先拍追逐或冲突突然停住，再拍所有人的反常反应，最后揭示边界本体。
   - 镜头：主角刹停脚步 -> 追兵齐停 -> 老者/队长反应 -> 边界全景或特写。
   - 目的：让观众先从人物恐惧判断“这里有问题”，再看到问题本身。
   - 衔接：可用声音骤变、脚步声突然停止、风声变空、低频轰鸣进入。

15.6A 工艺制作、生存技巧与垂钓场景怎么拍
============================================================

本节用于处理制作鱼钩、搓鱼线、绑鱼竿、打窝、下钩、备战、搭陷阱、修工具等“流程很长但必须看懂逻辑”的段落。目标不是把每一步都拍完，而是让观众明白：角色为什么这样做、材料如何变成工具、工具如何改变局面。

1. 工艺制作段落的四节点结构
   - 材料来源：让观众看清关键材料从哪里来，例如金属吊坠、黑石、锋利石片、藤蔓、植物纤维、树枝。
   - 关键变形：只拍最能说明变化的一两个动作，例如吊坠被敲弯、边缘被石片磨出钩形、藤蔓被拧成线。
   - 结果验证：必须给成品特写或人物掌心展示，例如粗糙鱼钩、灰绿色鱼线、绑好的简陋钓具。
   - 外部反应：用围观者困惑、嘲笑、恐惧或沉默来说明他们看不懂，而主角知道自己在做什么。

2. 时间压缩规则
   - 剧本出现“十几分钟后”“很快”“一段时间后”“时间一分一秒过去”等时间跳跃时，必须在小节字段写“叙事时间跨度”。
   - 视频生成时长仍保持4-30秒（常规20-30秒），叙事时间可以被省略剪辑、微蒙太奇、图形匹配或声音匹配压缩。
   - 正确写法：叙事时间跨度：约十几分钟，通过鱼钩制作微蒙太奇压缩，视频只呈现敲打、打磨、成品展示三个节点。
   - 错误写法：生成时长0-13秒，却让角色完整制作十几分钟的鱼钩或鱼线。

3. 制作过程的镜头节奏
   - 不要连续多个手部特写拍重复劳动。手部特写只给关键接触点：敲击、弯曲、打磨、绑结、抛线。
   - 每个制作小节最多保留2-4个制作节点，其余用省略剪辑压缩。
   - 用声音帮助压缩时间：石头敲击声连续叠化成几次有节奏的重击，藤蔓摩擦声延续到成线结果；禁止BGM。
   - 成品必须有清晰焦点和结果验证，否则观众不知道角色完成了什么。

4. 垂钓场景的导演视听语言
   - 观察水情：用主角视线匹配到水流速度、回水湾、气泡、鱼星、小鱼啄食、黑影游过；内心OS必须配合可见证据。
   - 打窝：重点拍食物碎屑入水、顺水扩散、鱼群逐渐聚拢，不要拍角色反复丢很多次。
   - 下钩：重点拍手腕控制、鱼钩轻落水、细小涟漪、草茎浮漂微动。
   - 等口：镜头变静，环境声放大，人物呼吸压低，远处猎人逐渐安静。
   - 咬钩前悬念：水面看似平静，水下黑影逼近，浮漂轻颤但不立刻爆发。
   - 禁忌：不要过早把大鱼完整展示；不要让鱼群、猎人、主角、鱼竿、鱼钩和水下黑影在一个镜头里全都清楚，AI会混乱。

5. 水面/水下双层叙事
   - 表层：浮漂、涟漪、窝料碎屑、红河反光。
   - 水下：鱼群银红影子、大黑影、鱼钩、黏稠暗红水流。
   - 镜头只能一次强调一层。需要同时表现时，用拉焦或切镜：水面浮漂特写 -> 水下黑影短暂掠过 -> 主角眼神特写。
   - 水下镜头要短，避免复杂全景。优先拍黑影轮廓、背鳍、尾部摆动、靠近鱼钩的局部。

6. 围观者嘲笑与主角专注的对照
   - 群体嘲笑不是主线。只选1-2个代表猎人给近景或中近景，其余猎人作为背景群声和反应。
   - 主角制作或钓鱼时，镜头主语应主要在主角手部、眼神、工具和水面证据上。
   - 嘲笑台词可以作为离画台词压在主角专注画面上，形成声画反差：别人以为他荒唐，画面却证明他在精确操作。
   - 当猎人从嘲笑变安静，必须给反应变化：嘴角笑意停住、眼神转向水面、身体前倾、武器垂下或低语消失。

7. 生存技巧爽点
   - 爽点来自“别人不懂，主角看懂规则”。不要让主角解释太多，要让观众通过气泡、鱼星、回水湾、窝料扩散、鱼群聚拢看懂。
   - 内心OS要短，画面证据要强。每句OS旁边必须有一个可见判断依据。
   - 结尾钩子适合停在“最大黑影靠近鱼钩”“浮漂第一次下沉”“鱼线突然绷直”这类未完成动作上。

15.7 情感戏怎么拍
============================================================

1. 亲密、温柔
   - 景别：中近景、近景、手部特写。
   - 机位：平视、轻微侧面、肩后柔和视角。
   - 焦距：50mm-85mm，浅景深。
   - 运镜：缓慢推近、轻微环绕、固定长镜头。
   - 光影：柔光、暖光、低反差、眼神光。
   - 声音：环境声降低，呼吸和衣料摩擦可轻微突出。

2. 告别、失去
   - 景别：背影远景、中近景、空镜。
   - 机位：背后机位、高机位俯拍、门外视角。
   - 运镜：缓慢拉远、固定长镜头。
   - 光影：逆光、侧逆光、低饱和、夕阳或冷月光。
   - 重点：不要急切，多留停顿。

3. 崩溃
   - 景别：近景、极致特写、手部特写。
   - 机位：轻微手持、略低机位、压迫式构图。
   - 运镜：缓慢推近或手持不稳定。
   - 表演：呼吸断裂、眼眶泛红、手指颤、下颌收紧。
   - 声音：台词后留白，环境声可突然变弱。
