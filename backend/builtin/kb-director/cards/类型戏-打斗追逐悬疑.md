15.3 打斗戏怎么拍
============================================================

打斗戏的核心是动作因果，不是把镜头写得很快。每个动作必须让观众看清：谁先动、从哪个方向来、在哪里接触、结果是什么。

1. 打斗拆分基本公式
   - 发起：谁先动，身体重心如何变化。
   - 路径：拳、刀、枪、身体从哪个方向移动。
   - 防守/闪避：对方如何挡、躲、失衡。
   - 接触点：拳打到哪里、刀刃碰到哪里、子弹击中哪里。
   - 结果：谁后退、倒地、武器脱手、空间位置如何改变。
   - 反应：疼痛、惊讶、重新站稳、下一招方向。

2. 普通近身搏斗
   - 景别：全景交代站位，中景看攻防，近景看接触点，特写看结果。
   - 机位：侧面机位最清楚，斜侧面增加动感，低机位强化力量。
   - 焦距：24mm-35mm 看动作路径，50mm 看接触和表情。
   - 运镜：侧面跟拍、手持轻晃、快速横摇、动作匹配切。
   - 剪辑：发起 -> 接触 -> 结果，不能一镜写完整复杂打斗。

3. 兵器打斗
   - 景别：中全景看武器距离，特写看刀刃/枪口/剑柄，近景看人物反应。
   - 机位：侧面和斜侧面优先，避免正面让武器路径不清。
   - 运镜：横移跟随、低机位跟拍、快速推近接触点。
   - 声音：金属碰撞、破空声、脚步声、呼吸声必须跟动作同步。
   - 光影：武器反光、火花、能量光、轮廓光可强调接触瞬间。

4. 群战
   - 先用全景建立人数、位置、包围方向。
   - 再选一个主要动作轴线跟随主角。
   - 每个镜头只表现一组明确动作，不要同时写十个人乱打。
   - 运镜：稳定器穿行、背后跟拍、横移切换攻击方向。
   - 禁忌：只写“众人混战”，模型会糊成杂乱运动。

5. 高速爆发动作
   - 结构：蓄力特写 -> 爆发全景/中景 -> 接触慢动作特写 -> 结果反应。
   - 运镜：极速推镜、撞击式推近、快速横摇、动作匹配切。
   - 焦距：广角表现速度，中长焦表现冲击压缩。
   - 声音：动作前短暂静音，接触点爆发音效。
   - 适用：拔刀、冲刺、飞踢、瞬移、爆发反击。

6. 打斗中的慢动作
   - 目的：强调关键接触点、致命一击、人物意识到危险的瞬间。
   - 使用时机：刀刃擦过脸、子弹掠过、拳头命中、武器断裂、角色落地。
   - 禁忌：整段都慢动作，节奏会拖。

7. 动作戏空间地图
   - 动作戏开始前必须建立空间地图：主角在哪里、敌人在哪里、出口在哪里、障碍物在哪里、危险从哪个方向来。
   - 如果有多人包围，先用全景或高机位交代包围形状，再切入主角可逃方向。
   - 如果有投掷物，必须写清投掷方向、飞行路径、掠过位置和落点，例如“石矛从画面右后方飞来，贴着林川左肩掠过，钉入左前方岩壁”。
   - 如果主角闪避，必须写清闪避前位置、闪避方向、身体重心和结果位置。
   - 每次动作后要重建空间：主角离追兵更远还是更近，是否靠近出口、河岸、门口、岩石或悬崖。

8. 3D动画复杂动作安全规则
   - 翻滚、摔倒、爬起、投掷、跳跃、撞击、多人追逐都要拆成“预备 -> 爆发 -> 接触/避开 -> 结果姿态”。
   - 单镜不要同时写翻滚、爬起、回头、躲避三根矛、再说台词；复杂动作必须拆镜。
   - 角色身体受伤时，动作要带限制：起身慢半拍、肩膀偏低、呼吸急促、脚步不稳。
   - 关键动作要有清楚剪影：身体轮廓、四肢方向、重心变化能一眼看懂。
   - 动作结尾必须有稳定姿态，方便下一镜衔接。

15.4 追逐戏怎么拍
============================================================

追逐戏的核心是方向、距离和障碍。

1. 必须交代三件事
   - 谁在追谁。
   - 二者距离是在拉近还是拉远。
   - 前方障碍或出口在哪里。
   - 追逐路线从哪里到哪里，屏幕方向是否稳定。
   - 追逐终点是什么：出口、禁地、河岸、门口、悬崖、交通工具或安全区。
   - 追逃关系必须写成物理可成立的前后关系：被追者在前方逃，追兵在后方追。若被追者向画面右侧逃，追兵通常应在画面左后方、后景或画面外身后追来；不得把追兵写在同一画面右侧前方，否则等于被追者往追兵方向跑。
   - 每个追逐镜头必须写“镜头运动方向”：被追者朝哪个世界方向/屏幕方向移动，追兵位于被追者前方、后方还是侧后方，距离是在拉近还是拉远。

2. 推荐镜头
   - 背后跟拍：跟随被追者，制造沉浸感。
   - 正面倒退跟拍：看见人物恐惧和后方危险。
   - 侧面跟拍：看清速度和地形。
   - 高机位俯拍：交代路线和包围。
   - 主观视角：制造慌乱、逃生感。
   - 背后跟拍的镜头朝向是被追者前进方向，因此适合看前方路线、障碍、出口和地形；追兵如果在真实空间中位于被追者身后，通常只能以画外喊声、身后脚步声、影子或短暂回头反打表现，不能把追兵放在被追者前方背景。
   - 正面倒退跟拍的镜头朝向是被追者正面和其身后空间，适合同时看见被追者表情与后方追兵。
   - 侧面跟拍适合在同一画面中表现“主角在前、追兵在后”的横向距离关系；如果主角向画面右侧逃，追兵应位于画面左侧或左后方。
   - 高机位路线全景适合重建追逐方向：用箭头式语言写清主角路线、追兵路线、障碍和终点，防止局部镜头把方向写反。

3. 推荐运镜
   - 手持奔跑、稳定器跟拍、快速横摇、穿行跟拍、低机位贴地跟拍。
   - 关键障碍用特写：脚踩水坑、手扶栏杆、撞开门、跨过障碍。
   - 投掷物或飞行危险用快速横摇、主观擦过、接触点特写和落点特写。
   - 地形障碍用脚部特写、侧面全景和高机位路线镜头交替呈现。

4. 剪辑节奏
   - 开始：建立方向。
   - 中段：交替距离变化和障碍。
   - 高潮：危险逼近，剪辑加快。
   - 结束：逃脱、被抓、跌倒或进入新空间。

5. 追逐中的距离管理
   - 每 2-3 个镜头必须让观众知道追兵与主角距离是变近还是变远。
   - 距离拉近：脚步声变响，追兵进入同一画面，投掷物更贴近主角身体。
   - 距离拉远：追兵变成背景，声音被风声吞没，主角暂时获得喘息。
   - 距离突然停止：适合发现禁地、悬崖、河流、陷阱、封闭门或未知怪物。
   - “追兵进入同一画面”不等于追兵出现在被追者前方。必须写清追兵进入画面的正确方位：后景、左后方、右后方、侧后方或画面边缘身后；除非剧情明确写出前方也有拦截者，否则追兵不得出现在被追者逃跑方向的正前方。

6. 追逐终点刹停
   - 主角突然停下时，必须说明为什么停：前方出现河流、悬崖、敌人、封锁、怪物或无法跨越的障碍。
   - 刹停动作要清楚：脚掌刮起尘土，身体前倾，手臂张开保持平衡，呼吸急促。
   - 追兵也停下时，要拍出“为什么他们不敢继续追”：表情变化、武器垂下、脚步后退、队长抬手制止、环境声音变异。

15.5 悬疑、恐惧和惊吓怎么拍
============================================================

1. 悬疑
   - 目的：让观众知道“有问题”，但还不知道问题是什么。
   - 景别：空镜、背影、中远景、道具特写。
   - 机位：门缝、走廊纵深、镜中反射、前景遮挡。
   - 运镜：缓慢推镜、缓慢横摇、固定长镜头、拉焦。
   - 光影：低光、侧逆光、半明半暗、百叶窗影、冷色低照度。
   - 声音：环境声放大，非音乐化低频环境声持续，远处异响先入；禁止BGM。

2. 恐惧
   - 目的：让观众贴近角色身体反应。
   - 景别：近景、面部特写、手部特写。
   - 机位：主观视角、手持轻晃、低机位。
   - 运镜：不稳定手持、微推近、焦点从虚到实。
   - 表演：呼吸变浅、眼神寻找、嘴唇微张、肩膀僵住。

3. 惊吓
   - 结构：安静建立 -> 视线引导 -> 突然出现/声音爆点 -> 反应镜头。
   - 运镜：固定后突然快速横摇、快速推近、闪白、硬切。
   - 声音：短暂静音后突然音效爆发。
   - 禁忌：没有铺垫直接吓人，会显得突兀。

4. 未知生物短暂露出
   - 适用：水下怪物、巨兽阴影、未知鱼影、草丛生物、黑暗中的东西。
   - 结构：环境异常 -> 局部露出 -> 快速掠过 -> 后果留存 -> 人物反应。
   - 不要第一次就完整展示怪物全貌；先给背鳍、鳞片、触手、眼睛、影子、水花、爪痕或巨大轮廓。
   - 镜头写法：河面突然炸开，黑色背鳍只露出一瞬，暗红黏液反光，随后沉入水下，只留下扩散波纹和低沉水声。
   - 目的：保留未知感，让观众意识到危险规模，但不破坏悬念。
   - 禁忌：不要写成完整怪物站在画面中央；不要一镜同时要求怪物全貌、攻击、追逐和人物长台词。
