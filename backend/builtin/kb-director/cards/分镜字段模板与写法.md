四、每个小节必须输出的基本格式
============================================================

小节N：小节标题

生成时长：0-XX秒
叙事时间跨度：【本小节在故事里经过多久；若有“几分钟后/十几分钟后/半天后”，必须写清用省略剪辑/微蒙太奇压缩，不得让视频时长等于真实时间】
剧情功能：【建立空间 / 对话拉扯 / 动作推进 / 信息揭示 / 情绪爆发 / 反转 / 收束留白】
本小节高级视听策略：【先按15.2B判断戏剧功能、镜头主语、观众信息量和镜头价值，再从15.2A选择1-3个策略，并说明服务的剧情目的】
场景：【时间】，【地点】，【天气或环境状态】。
人物：【本小节出现的人物，只写名字或 @人物资产名】。
人物站位：【人物A在画面/空间哪里，人物B在哪里，二者距离与朝向如何；必须使用固定空间坐标描述，不要只写画面左/右。例如：红河在林川身后北侧，猎人在林川正前方南侧20-30米外，林川背对红河、面对猎人】
空间坐标锁定：【建立本小节不可改变的空间地图：关键地标分别在人物的前/后/左/右/远/近哪一侧，角色和机位不能跨越河流、门、墙、车辆、悬崖等阻隔物，除非动作字段明确写出移动过程；剧本没有写对岸/门后/墙外有人，就禁止在阻隔物另一侧生成任何人物】
运动方向锁定：【建立本小节不可改变的运动向量：谁从哪里向哪里移动，谁追谁，谁远离谁；例如：林川从包围圈向风化石林/红河方向逃跑，猎人始终在林川后方追赶，二者运动方向相同但前后关系相反，不得把猎人写到林川前方】
场景锚点连续锁定：【列出本小节必须保持连续的背景物件和空间状态，例如：电梯门开/关状态、门口位置、墙面、车辆、桌椅、窗户、地面水渍、河岸方向、河流所在侧、对岸是否为空、道具摆放；下一镜不得凭空改变背景或出现/消失物件】
动作连续锁定：【列出本小节必须保持连续的姿态/道具/动作，例如：猎人队长右手握石矛，矛尖始终抵住林川咽喉，直到明确写出撤回或刺出；猎人群体持续手持武器包围，不得无端收起武器】
持续氛围：【压抑 / 紧张 / 冷寂 / 温暖 / 高燃 / 神秘 / 荒诞 / 浪漫】。
持续光源：【本小节一直存在的主光源，例如月光、室内顶灯、霓虹、火光、屏幕光】。
持续声音：【雨声、风声、电流声、人群声、脚步回声、机器低鸣等；同一场景内持续音效必须不中断，除非写明声音变化原因】
群像差异化锁定：【如果本小节出现多人群像/追兵/村民/士兵/观众/背景人群，必须写明差异化锚点：年龄层、脸型、发型、胡须、疤痕、纹身/颜料、饰品、体型、身高、肤色深浅、站姿或表情差异；禁止同脸和复制粘贴式人群】

镜头1（0-3秒）
镜头目的：【建立空间 / 引出人物 / 推进动作 / 捕捉反应 / 揭示道具 / 衔接上一镜 / 本镜头唯一主要高级视听策略】
镜头人物站位：【本镜头开始时，每个人物具体在场景哪里、与其他人物距离多远、面向哪里、处于前景/中景/背景哪一层；必须承接上一镜结束站位；如果人物转身，必须写清转身后谁在他前方、谁在他身后】
镜头场景锚点：【本镜头可见的关键背景锚点和物件状态，例如门窗开合、电梯门状态、车辆位置、墙面、桌椅、地面痕迹、河岸、河流在人物哪一侧、石林；必须承接上一镜背景】
镜头机位坐标：【摄像机位于人物哪一侧、靠近哪个场景锚点、朝向哪里；前景/中景/背景分别是什么；不得让摄像机无解释跨到河对岸、墙外、门后或人物未到达的位置；镜头朝向阻隔物另一侧时，必须写清对侧为空或只有原文明确存在的对象】
镜头运动方向：【本镜头内每个行动主体的移动方向和相对关系；追逐时必须写清被追者是否远离追兵、追兵在被追者前方/后方/侧后方；屏幕方向和世界方向必须一致】
镜头动作连续：【本镜头从上一镜承接的姿态/手部/武器/道具/移动方向是什么，本镜头内动作如何变化，结束时为下一镜留下什么动作状态】
画面：【景别 + 视角 + 明确机位 + 空间关系 + 最多2个关键环境细节；必须与镜头人物站位、镜头场景锚点、镜头机位坐标一致】
构图：【居中构图 / 三分法 / 对称构图 / 前景遮挡 / 框中框 / 留白构图 / 压迫式构图 / 纵深构图；构图中的前景/背景不得违反空间坐标】
镜头：【焦距 + 景深 + 焦点 + 1-2个专业视听锚点】
运镜：【一种主要运镜 + 方向 + 速度 + 起始景别 -> 结束景别；如固定镜头也必须写“固定，起始景别=结束景别”】
动作：【人物名或 @资产引用 + 具体身体动作链 + 手/肩/呼吸/视线/姿态等身体锚点】
表情：【眼神、眉头、嘴角、下颌、喉咙、呼吸等微变化】
台词：角色名：原文台词【音色（声线质地＋线路质感）+语速（…）+语调（…）+情感（…）】；标注画内台词/画外台词/离画台词；台词后的停顿与反应。无台词则写：无。
画外音：【旁白内容 / 角色内心音 / 画外传来的角色台词 / 声音先入或声音延后 / 无】
声音：【环境声 + 动作音效 + 台词/画外音状态；禁止BGM/配乐】
灯光与光影：【主光 + 辅光 + 轮廓光 + 光比 + 色温 + 阴影 + 曝光 + 光线变化】
衔接：【上一镜到当前镜的方式；当前镜到下一镜的方式；衔接点是视线/动作/声音/光线/道具/场景锚点；说明与上一镜相比景别是否跳跃两级以上或机位角度是否改变30度以上；说明人物动作、道具状态、站位和背景锚点如何从上一镜延续】
起始画面：【镜头开始时人物、道具、光线、声音、背景锚点处于什么状态；必须承接上一镜结束姿态和上一镜背景，不得无端改变动作、收起道具或替换背景】
结束画面：【镜头结束时人物停在哪个姿态，手中道具处于什么状态，所在位置和背景锚点处于什么状态，视线或动作如何承接下一镜】

镜头2（3-7秒）
按同样字段继续输出。

小节约束：
人物形象保持一致；人物站位与上一镜连续；人物动作、身体朝向、手部姿态和道具状态必须与上一镜结束画面连续；背景锚点、门窗开合状态、车辆/桌椅/墙面/地面痕迹/道具位置必须与上一镜连续；群像人物禁止同脸，背景群体必须有差异化面孔和体型锚点；场景结构保持一致；光源方向保持一致；同一场景持续音效保持不中断；台词口型同步；动作自然连贯；无字幕；无水印；无多余文字；避免变脸、手指变形、服装跳变、场景跳变、光影闪烁、武器/道具无端消失、背景物件凭空出现或无关人物闯入。

小节人物场景站位标注：
人物：【列出本小节所有出现的人物，包括主要人物、说话人物、听话人物、背景群体或无名角色】
场景：【写清本小节发生在哪里，例如：夜晚雨水冲刷的赛博朋克暗巷 / 地下车库电梯门口 / 火星荒原红河岸边】
人物在场景中的位置：【逐个写清人物处于场景什么位置、与关键背景锚点的关系、彼此距离、朝向、前后景关系；例如：A站在电梯门口正前方，背后是关闭的电梯门；B站在右后方车辆旁，面向A】

小节动作连续性总结：
【逐条说明本小节关键人物的动作/姿态/武器道具状态如何从镜头1延续到最后一镜；如果动作状态发生变化，写清发生在哪个镜头以及原因。】

小节场景连续性总结：
【逐条说明本小节关键背景锚点、人物站位、门窗/电梯门状态、车辆/桌椅/墙面/地面痕迹/道具位置如何从镜头1延续到最后一镜；如果背景或物件状态发生变化，写清发生在哪个镜头以及原因。】

小节声音连续性总结：
【说明本小节持续环境声从头到尾如何保持；哪些声音增强、减弱、先入、延后或被动作音效短暂压过；同场景进入下一小节时哪些声音继续承接。】

即梦粘贴提示词：
【把本小节所有镜头整合成一段连续自然语言提示词，可直接复制到即梦 SD2.0 / Seedance 2.0。必须按时间段写清画面，不要只保留字段标签。包含：素材引用声明、场景环境、人物动作、景别机位、运镜、焦点变化、台词/画外音、声音、灯光与光影、衔接、约束。】

============================================================
五、镜头字段写作细则
============================================================

1. 画面
   - 必须写清景别、视角、机位和空间关系。
   - 必须出现“机位”二字，例如：正面平视机位、侧面略低机位、桌面高度机位。
   - 不要展开无关美术设定，环境细节最多写 2 个。

2. 构图
   - 写清主体在画面中的位置：左侧、右侧、中央、前景、中景、背景、边缘。
   - 写清视线方向：看向对方、看向道具、看向门口、看向画面外。
   - 对话镜头要保持轴线关系，避免人物左右方向混乱。

3. 镜头
   - 必须写焦距、景深和焦点。
   - 可用 24mm 广角交代空间，35mm 自然叙事，50mm 人物关系，85mm 情绪特写，长焦压缩空间。
   - 如有焦点变化，写清“焦点从A转移到B”。

4. 运镜
   - 每个镜头只写一种主要运镜。
   - 文戏优先固定镜头、缓慢推镜、过肩反打、轻微横移。
   - 动作戏按动作方向跟拍、横摇、手持、快速推近。
   - 信息揭示用推向道具、摇到道具、拉焦、下摇或拉远。

5. 动作
   - 动作必须是具体物理行为，不能只写抽象心理。
   - 错误：他很愤怒。
   - 正确：他握紧拳头，肩膀绷住，视线从地面抬到对方脸上。

6. 灯光与光影
   - 每个镜头必须写灯光与光影。
   - 不只写“电影级光影”，必须写清主光、方向、色温、阴影和变化。
   - 如果光源来自手机、火光、车灯、闪电、屏幕、门缝，必须写进对应镜头。

7. 衔接
   - 每个镜头都要写与上一镜、下一镜的衔接。
   - 可以是硬切、动作匹配切、视线匹配切、声音先入、声音延续、推镜接特写、极速拉镜、快速横摇、遮挡转场、闪白。
