一、第一原则：台词与主线绝对忠实，视觉细节合理延展
============================================================

1. 台词与剧情不可撼动
   - 绝对保留原文所有角色台词，不擅自增删、改写、合并或替换台词。
   - 绝对保留原文核心剧情转折、人物关系、因果关系和信息揭示顺序。
   - 如果原文存在长台词，必须按语意拆分到多个镜头或多个小节中，不能为了压缩时长删减台词。

2. 视觉与动作允许合理填充
   - 允许根据原文情境补充具体可见的动作、微表情、站位变化、道具互动、环境反应、气氛空镜。
   - 补充内容必须服务原文剧情，不得改变人物动机、剧情结果和信息量。
   - 没有台词的时间段，必须用环境空镜、动作特写、人物无声反应、道具特写或光影变化填充。

3. 叙事描述式优先
   - Seedance 2.0 更适合完整的导演式叙事提示词，不要只堆关键词。
   - 每个镜头必须写清楚“画面如何开始、人物如何变化、镜头如何运动、光怎么打、声音怎么接、如何衔接下一镜”。

============================================================
二、生成前必须确认的全局参数
============================================================

在正式输出分镜前，先根据原文自动判断或在输出开头列明以下参数：

画幅比例：16:9 / 9:16 / 21:9 / 3:4 / 其他
视频类型：电影故事片 / 短视频 / 短漫剧 / 广告片 / MV / 其他
视觉风格：3D动漫 / 真人写实 / 2D动画 / 国风 / 赛博 / 暗黑奇幻 / 其他
单条生成时长：上限30秒 / 常规20-30秒（完整戏剧单元）/ 短单元4-15秒
整体画面质感：电影感 / 动漫电影感 / 高级短剧感 / 游戏CG感 / 广告质感
色彩基调：冷色 / 暖色 / 冷暖对比 / 低饱和 / 高饱和 / 暗调 / 明亮
声音规则：有环境声和动作音效；全文禁止BGM/配乐；台词与口型同步；无字幕
素材引用规则：如用户提供 @图片 / @视频 / @音频，必须在对应镜头中说明用途

时长判定原则（唯一真源，全文其他位置一律引用本段，不要重复硬编码）：
- 上限30秒：即梦 SD2.0 / Seedance 2.0 单条连续生成上限为30秒。
- 常规20-30秒：小节＝一个完整戏剧单元（一次完整的对峙 / 一段完整的追逐 / 一场完整的审讯）。能在一个单元内讲完的，不拆成两条。
- 短单元4-15秒：短反应、普通过渡、单句命令、强留白段落仍用短小节。
- 长度例外：仅当单个连续动作、长镜头调度或长台词单元无法在30秒内完成时，才拆为相邻小节，并在小节标题后标注[连续拼接对]。
- 禁止为凑时长把无关内容塞进同一条。

漂移护栏（≥15秒小节必须遵守）：
- 中段再锚点：第12-15秒处必须重述一次「人物形象＋服装＋光源方向」，禁止整条只在首尾锚定。
- 禁止平坦段：20-30秒小节中途必须有一次转折或信息增量（景别拐点或情绪拐点），否则判为拖沓，退回拆成两条。

镜头组织形式（按剧情自动选择，不强制统一）：
- 多镜头式：一节内拆6-10个镜头，用时间段描述切；适合信息密集、多人对话、动作链复杂的小节，稳定性最好。
- 长镜头式：单镜20-30秒连续运镜调度，零内部切换；适合单一主体、情绪连续、空间完整的小节（一次完整的沉默对峙、一段连续奔跑）。使用长镜头时必须额外锁定：运动路径连续、被摄主体始终在焦平面内、光源方向不跳变、背景锚点不替换。
- 选择依据：本小节主语是否单一、动作是否连续、是否有必须让观众同步发现的信息。主语单一且动作连续 → 长镜头；主语多、信息密 → 多镜头。

情绪词规则（台词情感标注白名单，禁止越界）：
- 可用：不耐 / 防备 / 敷衍 / 托 / 转嫁 / 权衡 / 撑住 / 撤温 / 试探 / 克制。
- 禁用：咆哮 / 怒吼 / 激动 / 愤怒 / 崩溃 / 歇斯底里。
- 情绪升级优先表现为「撤温」（变冷、变快、变低、变随意），不要升高音量。

全局风格锁定写法：
全片保持【视觉风格】，画面具有【电影级构图 / 动漫电影质感 / 稳定3D角色一致性 / 流畅镜头运动 / 统一色彩基调】。人物形象、服装、妆发、场景空间、关键道具和光源方向保持连续一致。动作符合物理规律，台词口型同步，避免人物变脸、肢体变形、服装跳变、场景结构变化、光源方向混乱、镜头突然漂移、字幕、水印和无关文字。
