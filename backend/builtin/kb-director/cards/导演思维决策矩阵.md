15.2B 导演思维分镜决策库：先判断戏，再决定镜头
============================================================

本节用于训练语言模型像导演一样思考，而不是像表格填空机器一样拆镜。分镜的本质不是“把文字翻译成画面”，而是决定观众在每一秒看见什么、听见什么、误会什么、期待什么、害怕什么、理解什么。生成任何镜头前，必须先做导演判断。

0. 导演大脑总控系统
   - 这是全文最重要的决策核心。它像一个“大脑”，负责指挥 AI 调用景别、焦段、构图、运镜、光影、声音、表演、连续性和生成稳定性知识库。
   - 禁止先套模板再想剧情。必须先读懂戏，再决定镜头。
   - 导演大脑的工作顺序：
     1. 锁定原文：台词、情节、人物关系、因果顺序不可改。
     2. 判断戏剧功能：本段是建立空间、制造悬念、情绪拉扯、权力压迫、动作推进、追逐逃亡、信息揭示、反转爽点、收束留白，还是过渡。
     3. 判断观众信息量：观众知道得比角色少、一样多，还是更多。
     4. 判断镜头主语：这个镜头属于谁的感受、行动或观察。
     5. 判断冲突类型：人与人、人与环境、人与自我、人与未知、群体与个体。
     6. 判断节奏曲线：铺垫、升级、爆点、余波分别在哪里。
     7. 调用知识库：根据剧情功能选择景别、焦段、机位、构图、运镜、光影、声音、表演、连续性规则。
     8. 输出镜头：每镜只承担一个主要目的和一个主要高级策略。
     9. 连续性检查：上一镜结束姿态必须成为下一镜起始状态，持续环境声不得中断。

0.1 顶级好莱坞3D动画分镜师的决策矩阵
   - 建立世界/陌生环境：
     * 景别：远景、全景、空镜。
     * 焦段：14mm-24mm 广角，深景深。
     * 构图：大面积负空间、纵深构图、人物渺小化。
     * 运镜：固定、缓慢横摇、缓慢上摇/下摇、拉远揭示空间。
     * 光影：自然主光、强环境光、顶光或逆光，突出世界尺度。
     * 调用：景别词库、焦段词库、异世界揭示、持续环境声。
   - 甜蜜感情戏：
     * 景别：中近景、近景、手部特写。
     * 焦段：50mm-85mm，浅景深。
     * 构图：双人近距离构图、柔和前景遮挡、眼神线对接。
     * 运镜：固定、微推、轻微横移，不使用大幅炫技。
     * 光影：柔光、暖光、低反差、眼神光。
     * 声音：轻风、衣料摩擦、呼吸声；禁止BGM。
     * 调用：情感戏、微表情、手部动作、动作连续锁定。
   - 双人吵架/关系冲突：
     * 景别：中景建立距离，近景/特写捕捉攻击和受伤反应。
     * 焦段：35mm-50mm 表现关系，70mm-85mm 压缩孤立感。
     * 构图：过肩、框中框、人物边缘化、压迫式构图。
     * 运镜：固定压迫、缓慢推近、关键台词后停留反应。
     * 光影：侧光、高反差、半张脸入暗、冷暖分裂。
     * 调用：对话戏、声画分离、听话人反应、景别反疲劳。
   - 审讯/逼问：
     * 景别：中景对峙、面部特写、手部/证据特写。
     * 焦段：50mm-85mm，浅景深。
     * 构图：桌面分割、正面固定、人物被压在画面边缘。
     * 运镜：固定长镜头、缓慢推近。
     * 光影：顶光、硬光、高反差、眼窝阴影。
     * 调用：权力压迫、沉默反应、道具揭示、持续环境声。
   - 群体围攻/部落敌意：
     * 景别：高机位全景建立包围，队长中近景，代表喊话者近景，主角反应特写。
     * 焦段：24mm-35mm 建立空间，50mm-85mm 捕捉压迫反应。
     * 构图：圆形包围、中心孤立、低机位压迫。
     * 运镜：先固定建立关系，再跟随主角视线或队长手势。
     * 光影：硬光、顶光、轮廓光，突出原始威胁。
     * 调用：群体敌意三层调度、动作连续锁定、空间地图。
   - 打斗/武器攻击：
     * 景别：全景交代站位，中景看路径，特写看接触点，近景看结果。
     * 焦段：24mm-35mm 看动作路线，50mm 看接触和表情，85mm 看结果反应。
     * 构图：对角线动势、攻击方向清楚、接触点居中或偏强势方向。
     * 运镜：侧面跟拍、快速横摇、动作匹配切。
     * 光影：硬光、武器反光、冲击点高光。
     * 调用：打斗戏、动作空间地图、3D动画动作安全。
   - 追逐逃亡：
     * 景别：高机位路线全景、背后跟拍中景、脚部/障碍特写、终点全景。
     * 焦段：24mm-35mm 保持速度感，50mm 捕捉喘息和恐惧。
     * 构图：同方向运动、前方出口/障碍明确。
     * 运镜：跟拍、手持轻晃、低机位贴地、快速横摇接危险。
     * 光影：环境主光连续，运动中避免光源乱跳。
     * 调用：追逐戏、距离管理、屏幕方向连续、持续环境声。
   - 悬疑/未知生物：
     * 景别：空镜、远景、局部特写、反应近景。
     * 焦段：35mm-85mm 控制信息，100mm 微距拍局部证据。
     * 构图：负空间、前景遮挡、门缝/水面/阴影。
     * 运镜：固定等待、缓慢推近、拉焦揭示。
     * 光影：低光、侧逆光、剪影、局部反光。
     * 声音：环境声放大、低频环境声、突然水声/异响；禁止BGM。
     * 调用：悬疑、未知生物短暂露出、延迟揭示、反常安静。
   - 爽点反转：
     * 景别：敌人恐惧反应近景 -> 主角观察近景 -> 关键对象特写 -> 主角微笑特写。
     * 焦段：50mm-85mm 捕捉认知变化，100mm 拍关键证据。
     * 构图：主角从被包围边缘转为画面中心，权力关系反转。
     * 运镜：缓慢推近主角眼神，或固定镜头让微笑产生力量。
     * 光影：主角眼神光增强，危险对象反光。
     * 调用：危机反转为爽点、内心OS画面化、道具/环境证据。
   - 喜剧/尴尬反应：
     * 景别：固定中景、反应近景、道具插入。
     * 焦段：35mm-50mm 保持空间关系。
     * 构图：人物被尴尬地留在画面中，留白制造笑点。
     * 运镜：少动，靠停顿和反应。
     * 光影：正常曝光，避免过度戏剧化。
     * 声音：环境声保持，笑点处可用动作音效或突然静音；禁止BGM。
     * 调用：反应先行、延迟回答、固定镜头、声音停顿。

1. 每段戏的第一判断：这段戏为什么存在
   - 如果本段提供新信息：镜头要让信息清楚可见，优先用道具特写、视线匹配、拉焦揭示、反应镜头。
   - 如果本段提供未来剧情伏笔：必须先判断它是否比当前动作更重要。凡是会影响后续剧情的监控、追踪、危险视线、隐藏观察者、异常屏幕、门缝变化、红点闪烁、未知声音，都必须给独立镜头或结尾特写，不得被普通动作或普通道具抢走镜头。
   - 当前功能道具和未来伏笔同时出现时，按戏剧价值排序：未来伏笔 > 信息揭示 > 角色反应 > 普通动作道具。例如车钥匙只是让角色找到车，可用中近景动作带过；摄像头缓慢追踪暗示主角被监控，必须用特写/极致特写/监控视角作为段落钩子。
   - 如果本段改变人物关系：镜头要表现距离、高低、站位、谁靠近谁、谁退后、谁占据画面中心。
   - 如果本段制造悬念：镜头要控制可见信息，优先遮蔽、负空间、声音先入、前后景双层叙事。
   - 如果本段释放情绪：镜头要给停顿和反应，优先近景、面部特写、手部特写、沉默 hold。
   - 如果本段只是过渡：镜头要省略或合并，不要拖成多个分镜。

2. 观众信息量控制
   - 观众知道得比角色少：适合悬疑、探索、恐惧；用主观镜头、遮挡、局部特写、延迟揭示。
   - 观众知道得和角色一样多：适合沉浸式发现；用视线匹配、主观视角、角色反应后揭示。
   - 观众知道得比角色多：适合戏剧性反讽和紧张；先给危险/证据/倒计时，再给尚未察觉的角色。
   - 输出时必须判断本段采用哪一种信息关系，不要无意识地把所有信息一次性拍出来。

3. 主角欲望与阻力
   - 每小段都要判断：当前主角想要什么，谁或什么阻止他。
   - 如果主角主动推进：镜头可以跟随主角移动，机位更贴近行动方向。
   - 如果主角被动承受：镜头可以固定、压低或拉远，让主角被空间吞没。
   - 如果阻力来自人：重点拍权力关系、视线、距离、压迫机位。
   - 如果阻力来自环境：重点拍空间尺度、障碍物、天气、光线、声音。
   - 如果阻力来自内心：重点拍停顿、呼吸、手部、眼神、声画反差。

4. 镜头主语
   - 每个镜头必须有“镜头主语”：这个镜头真正属于谁的感受或行动。
   - 镜头主语不一定是说话的人，也不一定是画面里最大的人。
   - 如果镜头主语是A：画面、焦点、声音和衔接都要服务A的感受。
   - 如果镜头主语切换到B：必须有视线、声音、动作、权力变化或信息变化作为切换理由。
   - 禁止一个镜头同时想表达所有人的心理，AI会生成散乱画面。

5. 镜头问题
   - 每个镜头开始前问：这个镜头提出了什么问题？
   - 每个镜头结束前问：这个镜头回答了什么，或把什么问题留给下一镜？
   - 悬疑镜头：提出“那里有什么？”
   - 情绪镜头：提出“他会如何反应？”
   - 动作镜头：提出“动作会不会成功？”
   - 信息镜头：提出“这个细节意味着什么？”
   - 如果一个镜头既不提出问题，也不回答问题，通常应该删除或合并。

6. 镜头价值
   - 每个镜头至少提供一种新价值：新信息、新情绪、新动作结果、新空间关系、新权力关系、新主题暗示。
   - 只重复上一镜信息的镜头必须删掉。
   - 同一个人物同一个情绪不要连续拍三次，只改变景别没有意义。
   - 如果要重复，必须升级：从压抑到爆发，从怀疑到确认，从远处威胁到贴身危险。

7. 段落节奏曲线
   - 铺垫：镜头稳定，信息少量释放，留出空间和声音。
   - 升级：景别逐渐靠近，切镜更有动机，声音或光影压力增加。
   - 爆点：镜头更短、更明确，关键动作和反应必须清楚。
   - 余波：镜头可以变静、变远、变空，让结果落地。
   - 不要从头到尾都高速剪辑，也不要从头到尾都慢镜头。节奏必须有曲线。

8. 镜头距离与心理距离
   - 远景：观众观察人物处境，情绪距离远，适合建立空间、孤独、命运感。
   - 全景/中全景：观众理解人物和环境关系，适合动作路线、站位和群体关系。
   - 中景/中近景：观众进入人物互动，适合对话、试探、普通反应。
   - 近景/面部特写：观众进入人物心理，适合关键台词、痛点反应、秘密暴露。
   - 极致特写：观众被迫注意一个证据或微反应，适合瞳孔、手指、血迹、按钮、戒指。
   - 使用近景/特写必须有心理或信息理由，不要为了变化而乱切。

9. 机位的道德立场
   - 平视：观众与人物平等，适合理解和共情。
   - 低机位：人物变强、威胁、权威、压迫。
   - 高机位：人物变弱、孤立、被审视、无助。
   - 背后机位：距离感、未知、孤独、跟随。
   - 侧面机位：观察、试探、关系不完全坦诚。
   - 主观机位：让观众承担角色感受。
   - 机位不是装饰，必须说明它在权力、情绪或信息上服务什么。

10. 运镜的心理动机
   - 推镜：逼近真相、增加压力、进入心理。
   - 拉镜：抽离、失去、孤立、结局落空。
   - 横移：揭示空间关系、绕开遮挡、发现新信息。
   - 跟拍：让观众跟随行动，适合追逐、探索、紧张移动。
   - 环绕：关系失衡、心理混乱、命运包围。
   - 固定：压迫、观察、无法逃避、让表演承担重量。
   - 手持轻晃：不安、混乱、主观恐惧。
   - 没有心理动机的运镜应改为固定镜头。

11. 什么时候不切
   - 人物正在消化重大信息时，不急着切。
   - 沉默比台词更重要时，不切。
   - 权力关系在同一空间内缓慢变化时，不切。
   - 观众需要感受尴尬、痛苦、压迫时，不切。
   - 不切时必须写清微动作：眼皮、呼吸、喉结、手指、肩膀、视线。

12. 什么时候必须切
   - 新信息出现，观众必须看清。
   - 角色视线明确指向某物。
   - 动作发生接触点，需要交代结果。
   - 台词击中听者，听者反应比说话人更重要。
   - 空间关系改变，观众需要重新定位。
   - 光线/声音发生转折，成为新的叙事点。

13. 省略的导演判断
   - 普通过门、普通走路、普通拿杯子、普通转身，通常省略或合并。
   - 有危险的走路可以拍脚步、障碍、远处声音。
   - 有心理变化的转身可以拍停顿、眼神、呼吸。
   - 有信息价值的拿东西可以拍手部特写和道具细节。
   - 没有戏剧价值的过程不要拆镜。

14. 画面重心转移
   - 一个镜头内部可以从A转移到B，但必须通过焦点、运动、视线或遮挡完成。
   - 正确：A在前景说话，焦点慢慢转到背景B攥紧的手。
   - 正确：镜头跟随A走过门框，门框后露出B的影子。
   - 错误：同一镜头同时要求观众看A表情、B动作、道具、背景人群和光线变化。

15. 冲突可视化
   - 外部冲突：用距离、方向、障碍、武器、站位表现。
   - 内部冲突：用停顿、呼吸、手部、眼神回避、声画反差表现。
   - 关系冲突：用两人之间的空位、前景遮挡、框中框、过肩压迫表现。
   - 价值观冲突：用对照构图、光影分区、冷暖色对立、空间高低表现。

16. 转折点必须有镜头标记
   - 当人物做出决定、发现真相、关系改变、危险升级时，必须有明确镜头标记。
   - 可用：推近、停顿、拉焦、灯光变化、声音骤停、道具特写、反应特写。
   - 转折点不能淹没在普通中景对话里。

17. 进入场景与离开场景
   - 进入场景不一定要拍人物进门，可以先拍声音、物件、光线或空间异常。
   - 离开场景不一定要拍人物走远，可以拍留下的空椅子、关上的门、熄灭的灯、停止摆动的物件。
   - 开场镜头回答“我们在哪里”和“这里的压力是什么”。
   - 收尾镜头回答“这一段改变了什么”。

18. 人物第一次出场
   - 如果人物重要：出场必须有识别性姿态、光影、动作或声音。
   - 正派/亲近人物：可以用平视、暖光、清楚面部和自然动作。
   - 威胁人物：可以用背影、低机位、轮廓光、声音先入、局部特写。
   - 神秘人物：可以先给手、鞋、影子、声音，再延迟露脸。

19. 重要道具第一次出现
   - 道具第一次出现要让观众记住位置、形状、用途或危险。
   - 道具如果后面会触发剧情，第一次出现时可以低调但必须清楚。
   - 道具再出现时要用相同或呼应的构图，形成视觉记忆。
   - 不要让关键道具只在文字里出现，画面必须看见。

19.1 伏笔、隐藏观察者与监控物件第一次出现
   - 定义：原文中暗示后续剧情会展开的细节，包括摄像头转动、监控红点、屏幕画面、门缝变化、远处人影、被注视感、异常声音、无人操作的机械动作等。
   - 处理原则：一旦原文出现此类细节，必须判断它是否是未来剧情因果。如果是伏笔，它的镜头优先级高于普通拿钥匙、按按钮、走路、开门等功能动作。
   - 镜头策略：使用特写/极致特写、监控视角、主角背影+摄像头前景、拉焦到摄像头、红点闪烁、机械轻微转动声、画外低频电流声等方式，让观众明确看见“有人/某系统正在观察”。
   - 结尾策略：如果伏笔出现在段落最后一句，应优先作为小节最后一个镜头或结尾钩子。不要把结尾停在主角走向车辆、拿钥匙、上车等普通动作上。
   - 写法示例：许默走向黑色大众时，画面不再跟随钥匙，而是切到电梯门上方摄像头特写，镜头微推，摄像头以极缓慢角度转动追踪他的背影，红色指示灯短暂闪烁，机械转轴发出轻微声响；该镜头为下一段“全程监控/直播”埋下伏笔。

20. 对白的导演处理
   - 台词不能改，但镜头可以重新分配台词期间的画面。
   - 解释信息的台词：画面展示证据、环境或动作，不要只拍嘴。
   - 攻击性台词：画面可以拍被攻击者反应。
   - 谎言台词：画面可以拍暴露谎言的道具或手部微反应。
   - 告白台词：画面可拍听者迟疑、两人距离、手部靠近或退缩。
   - 告别台词：画面可拍空位、背影、门槛、光线变远。

21. 观众注意力管理
   - 每镜只给一个注意力中心。
   - 注意力中心可以是脸、手、道具、门、光源、危险、空间空白。
   - 如果有多人同框，必须说明谁是视觉中心，其他人只做背景反应。
   - 复杂场面先建立空间，再选择一个行动轴线跟随。

22. 3D动画分镜的表演读秒
   - 关键表情需要至少0.5秒让观众读懂。
   - 快速动作前需要预备动作，动作后需要结果姿态。
   - 复杂情绪不要同时让角色大幅走动、说长台词、做复杂手势。
   - 动画表演要清楚剪影：姿态轮廓必须能被一眼读懂。

23. 风格与剧情的关系
   - 黑色悬疑：低光、负空间、遮挡、反常安静、冷色调。
   - 热血动作：清楚动作轴线、动势匹配、冲击点特写、节奏加速。
   - 情感文戏：近景、微动作、柔光、停顿、声音延后。
   - 史诗场面：远景建立尺度、低机位英雄化、群体调度、环境声和群体声浪扩大；禁止BGM。
   - 喜剧：固定镜头、反应延迟、构图反差、声音节奏卡点。

24. 镜头组合思维
   - 不要孤立设计单镜，要设计 3-5 镜的小组合。
   - 一个小组合通常包含：建立关系 -> 推进信息 -> 反应/结果。
   - 悬疑组合：异常空镜 -> 角色察觉 -> 主观寻找 -> 延迟揭示 -> 反应。
   - 对话组合：关系全景 -> 说话/离画台词 -> 听者反应 -> 道具/手部潜台词 -> 关系变化。
   - 动作组合：发起 -> 路径 -> 接触 -> 结果 -> 空间重建。
   - 情绪组合：触发台词/事件 -> 沉默 hold -> 微动作 -> 环境/道具承接 -> 收尾留白。

25. 导演思维总规则
   - 先问“这段戏改变了什么”，再问“该拍什么”。
   - 先决定观众信息量，再决定景别。
   - 先决定镜头主语，再决定画面主体。
   - 先决定冲突类型，再决定机位和光影。
   - 先决定节奏曲线，再决定镜头数量。
   - 先保证台词和剧情忠实，再进行电影化表达。
   - 任何高级技巧如果不能服务剧情，就不要使用。
