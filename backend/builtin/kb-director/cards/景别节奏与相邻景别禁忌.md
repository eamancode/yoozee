16.13 景别节奏、相邻景别禁忌与反审美疲劳规则
============================================================

本节是硬规则，不是建议。输出每一个镜头前，都要先回看上一镜的景别、主体角色、机位角度和运镜方向，判断当前镜是否会造成画面重复、闪烁感或审美疲劳。

1. 景别等级表
   - 从远到近依次为：远景 -> 全景 -> 中全景 -> 中景 -> 中近景 -> 近景 -> 面部特写 -> 极致特写。
   - 相邻景别示例：全景/中全景、中全景/中景、中景/中近景、中近景/近景、近景/面部特写。
   - 同景别示例：中景 -> 中景、全景 -> 全景、近景 -> 近景。

2. 严禁同景别/相邻景别硬切
   - 严禁同景别/相邻景别硬切。
   - 禁止对同一角色从【中景】直接切到【中近景】或【中景】，这会导致视觉上的闪烁感和重复感。
   - 若必须切换，景别跳跃必须大于两个等级，例如：全景 -> 近景、中全景 -> 面部特写、远景 -> 中近景。
   - 或者镜头角度偏转必须超过30度，例如：正面中景 -> 侧后方中近景、平视中景 -> 高角度俯拍中近景、过肩中景 -> 低机位近景。
   - 如果没有景别大跳跃，也没有30度以上角度变化，不要使用硬切；改用推镜、拉镜、横移、遮挡转场、动作匹配切或声音先入。

3. 运镜必须标注起始景别和结束景别
   - 只要有运镜，必须明确写出【起始景别 -> 结束景别】。
   - 正确：缓慢推镜，从中景推至近景。
   - 正确：横移跟拍，从中全景保持到中全景，但机位从角色左侧移动到斜前方，角度变化约45度。
   - 错误：推镜、跟拍、镜头移动。因为没有说明景别变化，AI无法稳定执行。

4. 对话戏的景别分配
   - 谁在说关键台词，就适当给谁镜头；普通说明可用中近景，情绪压迫或转折台词用近景/面部特写。
   - 听话人只有在产生心理变化、被刺痛、被威胁、被说服或隐瞒反应时，才给近景/特写反应镜头。
   - 群体嘲笑、远处喊话、多人围观可以先用全景/中景建立关系，但建立后必须切入代表讲话人中近景/近景/面部特写、听话人或主角反应近景/特写、手部动作、道具特写或空间压迫镜头。
   - 禁止连续多个对话镜头都使用中景或全景。对话不是把人物摆在画面里说完，而是用景别和反应组织权力关系。

5. 连续镜头反疲劳规则
   - 不允许连续3个镜头使用同一景别或相邻景别拍同一主体。
   - 不允许一个4-6镜头段落全部由中景、全景组成。
   - 每个4-6镜头段落至少包含一次明显景别跳跃或信息型特写，例如：道具特写、手部特写、面部特写、极致特写。
   - 如果前一镜是全景建立空间，下一镜优先切入近景/中近景看说话人或行动主体，而不是继续全景/中景。
   - 如果前一镜是中景，下一镜优先选择：近景/特写、角度变化超过30度的过肩镜头、手部/道具特写、主观视角、反应镜头。

6. 推荐景别节奏模板
   - 对话段落：全景建立关系 -> 说话人中近景 -> 听话人近景反应 -> 过肩关系镜头 -> 关键台词面部特写/道具特写。
   - 冲突升级：中全景交代站位 -> 近景看挑衅表情 -> 手部特写看武器/动作 -> 全景看双方距离变化 -> 面部特写看情绪爆发。
   - 动作段落：全景交代方向 -> 中景看动作路径 -> 特写看接触点 -> 近景看结果反应 -> 中全景重建空间。
   - 悬疑段落：空镜/远景建立不安 -> 中近景看角色察觉 -> 主观镜头看线索 -> 道具特写揭示信息 -> 面部特写看角色反应。

7. 输出前必须自检
   - 检查镜头2、3、4、5是否连续都是中景/全景；如果是，必须重写。
   - 检查同一角色是否从中景硬切到中近景或中景；如果是，必须改成大景别跳跃、30度以上角度变化或改用运镜。
   - 检查对话是否谁说话谁有镜头、听话人是否有必要反应镜头。
   - 检查每个运镜是否写清“起始景别 -> 结束景别”。
   - 检查每句台词的镜头时长是否匹配语速和情绪；短台词不得无理由占据3-4秒。
   - 检查群像小节是否只有3个大镜头；如果有多句群体台词或多人反应，优先拆出代表讲话人近景、听话人反应、手部/武器特写或群像路人表情短切。
