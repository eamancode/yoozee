# 质检 02 导演复看清单

每集一轮（`手册/11`）。顺序：先硬检查（对错），再导演复看（好坏），再盲评（打分，`质检/01`），最后交接。这份清单把 `手册/11` 的要求整理成可以逐项打勾的形式。每一项要么过、要么不过；不过的，写清哪里不过、怎么改的。

**没有改动的复看不算复看。** 这一轮至少改一处，改的那一处写进复看记录：改了哪里、原来是什么、现在是什么、为什么。

---

## 一、硬检查（整集）

### 时长与数量
- [ ] 各单元的叙事秒数相加（全景定格、换场尾巴不算），等于本集设计里由镜头表推出来的集时长（时长由戏推出，不是先定一个数再往里填，`参数.md` 第五节）。用户或平台指定了集时长、推出来的数差得多的，没有为凑数拉长或砍镜头，已在待确认里写明差多少、差在哪。（叙事合计　秒／集设计　秒）
- [ ] 没有单元超过平台上限。
- [ ] 没有单元的镜头数超过本档上限（长档 ≤10，常见 4–8；短档 ≤5，常见 1–4；平台 30 秒上不足 16 秒的单元按长档核）。
- [ ] 每个单元难事 ≤1。
- [ ] 高复杂度长档 ≤25 秒、≤8 镜。
- [ ] 最短的镜头 ≥1.5 秒（插入镜头、闪回可到 1 秒）。
- [ ] 每个长档 3–5 个动作节拍、3 个主说话人＋最多 2 个短句角色（每人 ≤2 句、每句 ≤10 字）、台词约 116 字以内；每个短档 1–2 个动作节拍（最多 3）、≤2 个说话人、约 56 字以内。用了容量回退的，按旧值（约 100 字／约 50 字／3 个说话人）核，并在单元总表登记。
- [ ] 每个单元表演者加关键道具 ≤5（在场不表演的人不计）。

### 剧情事实
- [ ] 原剧本、讲戏本、台词定稿表并排逐场对过：谁做了什么、谁知道了什么、东西到了谁手里、谁和谁的关系变了，没有改、漏、加。
- [ ] 台词手术登记为"必留信息"的每一条，都找得到去向（定稿表或画面）。
- [ ] 原剧本每一场都落在了某个单元里。

### 人物在场
- [ ] 每场戏开头有在场人物账：说话的、不说话的、群体都登记了；只在台词里提到的人没有登记。
- [ ] 每个单元：开始人数 ＋ 进场 − 离场 ＝ 结束人数。（逐单元写：U　 　＋　−　＝　）
- [ ] 相邻单元逐人继承：后一段开始时每个人的位置＝前一段结束时的位置。
- [ ] 全景定格名单＝这一段结束时的在场名单（不只是表演者；离场的人空位写空着）。
- [ ] 每个在场的人，在他在场的每个单元里至少入画一次；每个单元至少一个两人以上同框的关系镜头。
- [ ] 每一次进场、离场都有镜头（压着台词，或登记为动作镜头）；没有"脚步在取景外停下"。
- [ ] 群体登记为"领说者＋其余几人"，画面是群像，人数前后一致，没有被缩成一个人。
- [ ] 每条提示词的生效参考素材里有本场此刻在场的每一个人；在场不表演的人在场景背景、场景地图或首帧与走位里有位置。
- [ ] 交接卡写了场尾在场名单。

### 锁
- [ ] 随机抽三个单元，第三段与圣经逐字比对无误差。（抽查：U　、U　、U　）
- [ ] 同一个人本集所有单元的造型句相同（剧情换装的已在集设计里写明）。
- [ ] 同一个场景本集所有单元的场域锚句相同。
- [ ] 签名动作的写法与圣经引用块一致。

### 接缝
- [ ] 每一对"收尾状态→开场画面"六项对上：位置、姿态、服装、道具、光、情绪。
- [ ] 换场景的接缝：收尾是稳定画面，开场是新的建立。
- [ ] 没有任何一句台词跨在接缝上。
- [ ] 同场景被切开的每一段（除这一场最后一段，且其后不在同场景同一时刻接着演），最后一秒是全景定格：84°、高位 45° 斜俯、本场此刻在场的所有人完整入画（超过 5 人核人数、位置、衣服颜色）、地标入画、嘴唇闭合、稳定 1 秒、硬切进入、无新内容。平台固定输出 30 秒的，不足 30 秒的单元尾部定格补到第 30 秒。
- [ ] 下一段的"生效参考素材"登记了上一段的定格截图（@站位参考），开场画面的站位与它一致。
- [ ] 每个接缝标了开局方式（接着往下演／独立开局，可另加末帧接力）；用了末帧接力的，登记了那张首帧图。

### 装满
- [ ] 单元是在整场镜头表定稿以后装箱分的；装箱前后镜头的顺序、时长、台词、镜头数一致。
- [ ] 每个场景的实际段数 = 最少段数 N（⌈本场叙事总秒数 ÷ 封顶⌉）。多出来的每一刀在"多切理由"栏写明超了哪一个容量数，或"允许的切点排不开"（附最近两个切点的秒数）；用了容量回退的写了是哪一项。（逐场：　N＝　，实际　）
- [ ] 不足一个封顶的场景没有被切开。
- [ ] 切点都在允许的位置：话轮结束、节拍边界、动作落点；没有拆句、没有切在同一个人一番话的中间、动作半途、转身中途，没有把主顶点和它的停留切开。
- [ ] 段数最少的前提下，切点按等级挑（情绪转折 ＞ 功能转换 ＞ 对白回合结束 ＞ 动作落点）；同等级挑了前段更满的。"完整话轮"没有被当成多切的理由。
- [ ] 没有为装满往单元里加戏、加说不出职责的镜头，没有拉长镜头和气口，没有擅自添台词。
- [ ] 单元总表的成本账齐全：每场最少段数与实际段数；每单元装载率；合计生成次数　次、付费秒数　秒、空置秒数　秒。

### 节奏
- [ ] 带台词的镜头，时长不短于字数 ÷ 语速（常速 4 字/秒，慢说 3 字/秒，抢话 5 字/秒）；比这个数长出来的部分，对得上登记的气口，或者画面与表演栏里写着的动作。
- [ ] 气口登记在职责栏：一处 0.5–2 秒，写明在等什么；一个话轮话前话后最多各一处。
- [ ] 没有台词的镜头，职责栏登记了五种职责之一，并写了一句"观众从这里知道或感到了什么"：建立（2–5 秒，每场至少一次，可以延后）／反应（1.5–4 秒）／动作（1.5–6 秒）／过渡（1.5–4 秒）／停留（2–5 秒，每集最重的一处可到 6 秒）。（无台词镜头　个，各类　／　／　／　／　）
- [ ] 每场戏有一句节奏设计（基准速度、在哪变速、最长的镜头给谁），镜头表对得上它。
- [ ] 三个镜头以上的单元，最长镜 ÷ 最短镜 ≥2。
- [ ] 一场对白戏里，句和句之间的接法（直接切／抢话／留气口）至少用了两种。
- [ ] 话后的气口、单给的反应、停留连着出现、说的是同一件事的地方，只留了一个（`参数.md` 第〇节"防拖"）。
- [ ] 长镜头（8–15 秒）每 4–5 秒有一个看得见的变化；说话的人不动不超过 5 秒。
- [ ] 连续 10 秒以上没有人说话的地方，在本集设计里登记为无对白段落。
- [ ] 听的人的镜头（压着画外台词，或单给的反应）占对白镜头的三分之一以上。
- [ ] 报数，不设及格线：全集平均镜长　秒（低于 3 秒查是不是拍成了快切，高于 8 秒查是不是拖）；台词秒数占集时长　%（常见五成到七成）；无台词时长占　%（常见两成到四成，低于一成或高于一半要查；全景定格不算）。

### 声画
- [ ] 每个单元至少一个声音事件。
- [ ] 静默最多两处（0.5–3 秒），落在登记的气口或者停留里，并登记了后期备忘；没有合适位置的集可以不做。
- [ ] 每条提示词写了"无背景音乐"（或有明确特例说明）。
- [ ] 一镜一个人连续说的台词 ≤40 字，超过 20 字的中间写了一处看得见的变化；一镜只有一个人开口；3 字以内的极短句并进了相邻镜头，或单给 1.5 秒。
- [ ] 每一句台词按固定句式写：说话人（本句表演，与定稿表一致）说："台词。"；声线串（与圣经逐字一致）写在生效参考素材的声音条目里；表演段写了"口型与台词同步"，在画的其他人"嘴唇闭合"。
- [ ] 本句表演写的是听得见的结果（音量、相对语速、质地、停顿重音），没有情绪名词；一场戏的语气有走向，不是每句一样。

### 横屏
- [ ] 抽查每个单元的首镜、记忆画面镜、末镜：重要的东西不贴四边（各约 5%），不放在底部约 15% 的字幕区。
- [ ] 单人近景、特写里空出来的那半边有用处（视线的方向、另一个人、门、一样东西、一块光），不是随手空着。
- [ ] 每场戏至少一个全景或大全景；特写加大特写不超过这场戏镜头数的三分之一；对白戏里关系镜头（两人以上同框、过肩）不少于三分之一。
- [ ] 用户指定竖屏 9:16 的：节奏和结构照旧，构图里的"左右"按"上下"核，安全区按顶部约 10%、底部约 20% 核。

### 格式
- [ ] 八个部分齐全：本集设计、台词定稿表、讲戏本、单元总表、单元卡、后期备忘、集交接卡、复看记录与待确认。
- [ ] 每张单元卡各栏齐全。
- [ ] 镜头表时间、提示词时间、单元总表时长，三处一致。
- [ ] 每条提示词过了十八条硬检查（`手册/10` 第四节）。
- [ ] 每条提示词是即梦十五段结构，段名单独一行，顺序正确。
- [ ] 每一段都能指出上游出处；抽查两条提示词，把"场景地图""光学""表演""物理"四段逐句对回单元卡（空间约定、焦点栏、表演时间轴、物理要点），没有编译时新想的句子。
- [ ] 跨段一致：同一切的时间、视场角、运动、焦点在格式模式、光学、摄影机三段一致；台词在格式模式、表演、声音三段与定稿表一字不差。
- [ ] 生效参考素材只列本段生效的（按在场算，不按开口算：本场此刻在场的人都在，不在本场的人不在）；@标签名与圣经素材登记一致。

**同一条硬失败最多重写两轮。** 两轮不过，回到上游那一步改，并在复看记录里写明。

## 二、导演复看

### 换眼睛
只读每个单元镜头表的"画面与表演"和"台词/声音"两栏，从第一镜一路读到最后一镜，中间不停。在出现下面三种反应的地方做记号：

- [ ] **走神了**（拖）：位置　　　原因
- [ ] **没看懂**（断）：位置　　　原因
- [ ] **没感觉**（平）：位置　　　原因

### 五个问题

**第一，每一镜都有不可替代的理由吗？**
- [ ] 每个单元找出最弱的一镜，问删掉损失什么。可删的已删（本集删去　镜）。
- [ ] 没有台词的镜头逐个问：遮住职责栏那一句再看画面，观众还能从这里知道或感到那件事吗？和相邻的镜头是不是在做同一件事？说不出的、重复的已删或已压到相邻台词底下（本集删去或压掉　镜）。
- [ ] 反方向：有没有该有而没有的——哪一场戏没有建立过空间；最重的一两句话后面没有反应、没有气口；顶点之后没有停留；该让观众看清的动作被台词盖过去了。

**第二，记忆画面真的记得住吗？**
- [ ] 本集所有 ★ 镜头抽出来排成一列，每一个都是"只有这场戏才有"的（含签名／地标／道具／权力关系之一）。
- [ ] 它们彼此不雷同（景别、构图方式有区别）。
- [ ] 封面帧已选定：U　 第　镜。
- [ ] 最弱的一个已重新设计（如需要）。

**第三，顶点够高吗？结尾留得住吗？**
- [ ] 顶点前的戏是一步一步往上走的，不是平着过来再跳上去。
- [ ] 本集的破规用在了顶点（或写明了用在哪、为什么）。
- [ ] 顶点那一刻，声、光、镜头至少两样同时转。
- [ ] 顶点之后有停留（2–5 秒，全集最重的一处可到 6 秒），全集最长的停留在这里；别处的停留没有比它更长。
- [ ] 顶点强度和情绪曲线上写的强度对得上。差了的，查三处：前面漏气／顶点太快／对手反应没拍够。
- [ ] 结尾先定了是余味式还是悬念式。余味式：最后一帧时观众带走的感受，写成一句话：____________，这个感受是画面给的，不是靠最后一句台词说出来的。悬念式：最后一帧时观众心里的问题，写成一句话：____________，画面停在答案出来之前。
- [ ] 结尾末镜 3–6 秒，最后两三秒画面几乎静止；没有在最后一帧上再塞一句解释的话。

**第四，这一集认得出是这部片子吗？**
- [ ] 强调色出现在：　　（次数　，未超限）
- [ ] 签名构图出现在：
- [ ] 视觉母题出现在：　　阶段：
- [ ] 声音母题出现在：
- [ ] 主角行为签名出现在：　　时机符合规则：是／否
- [ ] 同一签名本集出现 ≤2 次。
- [ ] 和上一集交接卡"已用手法"对过：开场类型、顶点拍法、结尾类型、主要运镜、转场手法没有撞。
- [ ] 启发库同一条目同一选项本集用了 ≤2 次。

**第五，有没有哪里在为难模型？**
- [ ] 每个单元的难事再过一遍，没有"两件难事叠在一起"的。
- [ ] 没有藏着的难事：画面内文字、精细手部操作、多人精确走位、镜子和倒影、长时间一致性、两人身体接触超过一秒。
- [ ] 开场、顶点、结尾单元的降级方案真的能用，降级后阐述仍成立。

### 至少改一处
- [ ] 从上面的清单里挑出对本集提升最大的一处，回到对应那一步改（改镜头回镜头表，改完重新编译，再过那一条的十八条硬检查）。
- [ ] 复看记录里写清：改了哪里、原来是什么、现在是什么、为什么。
- [ ] 值得改但这一轮不动的，列进待确认。

## 四、交接与收尾

- [ ] 集交接卡按 `模板/03` 写完，≤800 字。
- [ ] 失忆测试：只拿交接卡和圣经，能把下一集接上。
- [ ] 圣经增补已写入（只增不改）；王牌状态已更新。
- [ ] 后期备忘补全：每个接缝的剪辑建议、每个单元尾巴剪多少、全景定格镜位置（剪掉，截图交下一段）、音乐进出点（对应单元和秒数，不落在接缝上）、画面内文字与字幕的完整内容、静默和主观声音的位置、顶点停留镜"不要剪短"。
- [ ] 复看改了镜头的，后期备忘里引用的单元号和秒数已核对。
- [ ] 待确认 ≤5 条，每条是可以直接回答的问题，附默认做法。
- [ ] 交付文本最前面三四句：这一集怎么理解、最用心的地方、建议先试哪个单元（通常是顶点单元）。
