# 范例索引

范例是给你看"颗粒度"的：一个合格的单元和一个 SSS 的单元，差在哪一句话、哪一个镜头、哪一个决定上。**它们不是答案，句子一个都不要抄。** 看完一组，合上，去写你自己的那场戏。

## 先看这一段：范例都是电影版

这个技能和短剧版同源。`01` 到 `08` 八个范例都已按电影模式改写，文件标题下写着"本范例已按电影模式改写"：按 `参数.md` 第〇节"戏带着镜头走"写的——横屏 16:9；带台词的镜头时长不短于字数 ÷ 语速，话前话后有登记的气口；没有台词的镜头登记了五种职责之一（建立、反应、动作、过渡、停留）；每场戏有一句节奏设计，最长的镜头给最重的东西。数字和写法可以对照着学。文件名里的"钩子""卡点""爽点"沿用短剧版的叫法，读作开场、结尾、兑现。

**电影节奏的标准样板是 `08_一整集全流程示范.md`**（《铜钥匙》第 2 集周家餐厅，一场戏装成两个单元：U1 叙事 28 秒、9 镜，U2 叙事 28 秒、10 镜，各加 1 秒定格）。其中 E2-U2 的单元卡与 `模板/04_单元卡.md` 后半的填写示例逐镜一致，提示词与 `模板/05_提示词骨架.md` 的完整示例一致。数字和写法拿不准的时候，先以 `参数.md` 为准，再看这几处。

## 读到短剧版的写法时怎么换

启发库各条目里的例子、以及你手边可能有的短剧版材料，很多是按竖屏、快切、"每个镜头都压着台词、话落就切"写的。读的时候照这张表换：

| 范例里写的 | 电影模式里是 |
|---|---|
| 竖屏 9:16，眼睛在上半部，避开顶部和右下角 | 横屏 16:9，避开底部约 15% 和四边各约 5%；人在画面哪一侧、空出来的那一侧是什么，见 `启发库/B03_横屏构图.md` |
| 每个镜头都有台词；反应、物件、动作一律叠在话底下 | 可以叠，也可以单给：没有台词的镜头登记五种职责之一，写一句"观众从这里知道或感到了什么" |
| 时长 = 字数 ÷ 语速，话落就切，首尾余量 0.3 秒 | 时长不短于字数 ÷ 语速；话前话后可以有登记的气口（一处 0.5–2 秒，写明在等什么） |
| 白名单、慢点每集最多三处 | 五种职责；先登记这一集最重的几处慢，慢不叠着用 |
| 台词覆盖率七成以上、无台词时长一成半以内 | 只报数：平均镜长、台词秒数占比（常见五成到七成）、无台词时长占比（常见两成到四成） |
| 钩子（前三秒抓人） | 开场：第一个单元结束前，观众心里有一个想知道答案的问题 |
| 爽点 | 兑现／顶点 |
| 卡点（勾着点下一集） | 结尾：余味式或悬念式，末镜 3–6 秒 |
| 每镜台词 20 字以内 | 一镜一人连续最多 40 字，超过 20 字的中间有一处看得见的变化 |
| 一个单元 10–12 个一两秒的镜头 | 长档常见 4–8 镜，平均镜长参考 4–6 秒；每场至少一个全景，关系镜头不少于三分之一 |

## 什么时候看哪一个

| 文件 | 内容 | 什么时候看 |
|---|---|---|
| `01_合格版与SSS版对照_饭桌施压.md` | 同一场家庭饭桌戏，合格版和 SSS 版的单元卡并排，逐条标出差别；同样的台词，换一个地方放 | 第一次做集、或者写出来"挑不出毛病但没劲"的时候 |
| `02_合格版与SSS版对照_爽点.md` | 同一个身份揭晓的兑现，两版对照；主顶点之后的那一停怎么停、停多久 | 本集的顶点是一次兑现时 |
| `03_长档与短档_同一场戏两种切法.md` | 同一场戏在 30 秒平台和 15 秒平台上怎么切 | 平台上限是 15 秒，或者要在长短档之间做选择时 |
| `04_三媒介_同一单元三种写法.md` | 同一个单元，真人写实、二维动画、三维动画三种提示词 | 媒介不是真人写实时 |
| `05_戏型示范.md` | 跨题材的五场戏：审问（悬疑）、告白（爱情）、谈判（职场）、重逢（年代）、对峙（古装） | 遇到某种戏型、想看不同题材怎么落地时 |
| `06_钩子与卡点示范.md` | 六个开场单元和六个结尾单元，各自的设计理由 | 写每集第一个和最后一个单元时 |
| `07_返修示范.md` | 五次返修：症状、诊断、改法、结果；"拖"的那一次按电影模式诊断，也写了"赶"该怎么查 | 返修回合；用户说"拖""赶""没感觉"时 |
| `08_一整集全流程示范.md` | 一整集的八个部分，从本集设计到复看记录 | 第一次做一集之前，通读一遍，看八个部分各长什么样 |

## 怎么看对照

对照范例的读法是：**先只读合格版，自己挑毛病，写下来；再读 SSS 版；最后读"差在哪"，看你挑的和它写的重合了几条。** 重合得少，说明你还在用"有没有错"的眼光看，而不是用"够不够好"的眼光看。SSS 和合格之间的差，几乎从来不是错误，是一连串的"可以更好"。

## 范例里的人物和地方

为了让你在不同的范例之间对照，多数范例用同一部片子《铜钥匙》的人物和场景：林夏（修车女工、真千金）、周家（周母、周父、周建、周婷）、穿驼色大衣的男人（男主，名叫顾既白）、拄手杖的老人（沈家老爷子，林夏的祖父）、修车铺、周家餐厅、老式当铺、宴会厅、宗祠。它们的锁（身份串、场域锚句等）在 `08_一整集全流程示范.md` 的开头集中列出。

`05_戏型示范.md` 故意换了五种题材，免得你以为这套方法只适合家庭复仇的戏。
