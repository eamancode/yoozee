# 知识包 · 角色设计

这是 yoozee 1.0 skills 的知识包，只有卡片，没有流程。由 yz-* 技能指名读取：引用写成「kb-character › 卡片路径」。读卡的方法见 技能 yz-producer 的 `RUNTIME.md`（用 skill_read_file 读）。
一次只读需要的那一张，不整包读；卡片开头两行写了来源和何时读。

| 卡片 | 何时读 |
| --- | --- |
| `cards/三视图布局与平台.md` | 出定妆三视图、处理视角和一致性问题时读 |
| `cards/写实约束块与定妆照门禁.md` | 口味是真人剧时，出任何人物图、场景图之前读；验收定妆照时读 |
| `cards/提示词输出与字数预算.md` | 交付任何完整角色提示词前读：结构、锁定卡、字数上限 |
| `cards/视觉词库-材质与面部.md` | 需要准确的材质、面部词汇时查 |
| `cards/角色提示词调用示例.md` | 想看完整示范时读 |
| `cards/角色设计规则.md` | 设计角色外观、画风、多角色差异、局部修改时读 |
| `cards/需求提取与问询.md` | 新角色开始前读：先从剧本和对话里提取已知设定，只问缺项 |
